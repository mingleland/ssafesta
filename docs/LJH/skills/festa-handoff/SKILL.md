# FESTA 세션 인계

**정적 텍스트를 저장하는 게 아니라 그 시점의 상태를 실측해 생성한다.** 커밋 해시·대기 MR·블로커는 매번 바뀌므로 하드코딩하면 즉시 낡는다.

## 0. 가장 중요한 규칙

**운영 방침·함정 목록을 인계 프롬프트에 복사하지 마라.** 이미 `docs/LJH/26_로컬_규약_스냅샷.md`·세션 메모리·`CLAUDE.md` 세 곳에 있다. 복사하면 4벌째 사본이 되고, 이 프로젝트가 `#45`·`#51`로 겪은 문서 자기모순 사고를 반복한다. **파일 경로만 가리킨다.**

## 1. 종료 가능성 판정

```bash
git status --short
git fetch origin front && git rev-list --left-right --count front...origin/front
git stash list
```

**미커밋 변경·미푸시 커밋이 있으면 종료 불가**다. untracked 중 작업용 산출물(`_workspace/`·`.claude/worktrees/` 등)은 예외로 두되, 무엇을 예외로 뒀는지 보고에 적는다.

## 2. 기록 의무 확인 — 최신 섹션 존재만으로는 불충분

작업일지에 오늘 날짜 섹션이 **있다는 것**과 **이번 세션 작업이 반영됐다는 것**은 다르다. 이번 세션의 커밋 범위를 뽑아 대응 여부를 본다.

```bash
git log --oneline --since="$(date +%Y-%m-%d) 00:00" --author="$(git config user.name)"
grep -n "^## \|^### " docs/LJH/24_작업일지.md | head -10
```

이번 세션 커밋 중 작업일지에 대응 항목이 없는 것이 있으면 **"종료 불가 — 기록 미확인"**으로 판정한다.

트러블이 있었으면 `docs/LJH/25_트러블슈팅.md`에 T-번호가 등록됐는지도 확인한다. 이 규칙에 예외는 없다.

## 3. 열린 MR 상태 — 목록만으로는 인계가 안 된다

MR 번호만 넘기면 CI 실패·충돌·미해결 리뷰를 다음 세션이 모른다. 리소스 필드로 실제 상태를 뽑는다.

```bash
glab mr list --author=@me
glab api "projects/s15-metaverse-game-sub1%2FS15P21A604/merge_requests/<IID>" | python -c "
import sys,json
d=json.load(sys.stdin)
print(d['iid'], d['detailed_merge_status'], 'conflicts=%s' % d['has_conflicts'], 'blocking_resolved=%s' % d['blocking_discussions_resolved'])
"
```

`detailed_merge_status`가 `mergeable`이 아니면 그 이유를 인계에 적는다.

## 4. 미해결 항목 수집

`festa-inbox`를 재구현하지 않는다. 이미 이번 세션에서 파악한 것 중 **넘길 것만** 추린다.

- 남의 응답 대기 중인 것 (내 액션 없음)
- 나에게 걸린 액션 중 미처리
- 블로커 — 무엇이 막고 있고 누가 풀어야 하는지
- 합의 대기 — Unity 유발이라 자체 처리 불가한 것

## 5. 인계 프롬프트 생성

아래 골격에 **실측값만** 채운다. 방침·함정은 경로로 대체한다.

```text
SSAFY FESTA front 파트 세션 인계 ({날짜})

[먼저 할 일]
festa-boot 스킬을 실행한다. 규칙 적재·원격 실측·낡음 탐지가 그 안에 있다.

[현재 상태]
- front = origin/front {동기 여부} · 미커밋 {건수}
- 마지막 커밋: {해시} ({제목})
- 검증 기준선: {vitest 결과 또는 "미확인"}

[대기 중 — 남의 응답, 내 액션 없음]
- MR !{N} ({제목}) → {대상 브랜치}, {detailed_merge_status}, 리뷰어 {누구}
- #{N} — {무엇을 기다리는가}

[블로커]
- {무엇} — {누가 풀어야 하는가}. {해제 조건}

[다음 작업 후보 — 우선순위 없음, 지시 대기]
1. {항목}

[이번 세션에서 새로 확정된 것]
- {방침·규약 변경이 있었으면. 없으면 이 절 생략}

운영 방침·함정은 docs/LJH/26_로컬_규약_스냅샷.md와 세션 메모리에 있다. 여기 복사하지 않는다.
지시를 기다린다. 확인했으면 현재 상태만 한 줄로 보고하고 대기하라.
```

## 6. 출력

인계 프롬프트를 **코드블록으로** 출력해 바로 복사할 수 있게 한다. 그 앞에 종료 판정을 한 줄로 붙인다.

```text
종료 가능 — 미커밋 0 · 원격 동기 · 기록 반영 완료
```

종료 불가면 **무엇이 막는지**를 먼저 적고, 인계 프롬프트는 그것을 해소한 뒤 생성한다.

파일로 저장할지는 사용자에게 묻는다. 기본은 출력만 — 저장하면 갱신해야 할 문서가 하나 더 늘어난다.
