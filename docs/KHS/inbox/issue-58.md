## 내가 답해야 하는 것
- A/B/C 중 무엇에 동의하는가 (game 파트 관점 — Unity 가 이 봉투를 소비하는 경로가 있는지부터)
- §3 `rule` 이 규칙명과 요청 필드명 두 뜻으로 쓰이는 결함 — `field` 분리안에 동의하는가
- B 라면 #17 확정 예시 재확정에 동의하는가 (#17 은 내가 관여한 계약)

## 승인 후 확인할 것

- R-09 "빈 배열이 optional 보다 안전" 판단이 spec 005 어디에 기록됐는지
- `GlobalExceptionHandler:80` 이 실제로 필드명을 `rule` 에 넣는지 (제안자 실측 주장 재확인)
