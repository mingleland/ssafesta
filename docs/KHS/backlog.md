   - 직원 시각물과 상호작용 콜라이더 중심은 씬에서 일치시켰다.
   - 남은 확인: 최신 develop에서 다른 씬 왕복 후에도 위치 유지, 상호작용 시 플레이어 바라보기, 발·다리 파묻힘 없음, 5분 뒤 수면 위치 복귀.

2. **헤어·의상 색상 최종 반영 확인** — `S15P21A604-776`, 기존 `S15P21A604-746`
   - 상태: **최신 Unity 위 재적용 완료/MR !927 자동병합 대기**. 사용자가 초록 헤어 정상 표시를 확인했다.

   - 남은 확인: 최신 develop에서 로컬·원격 아바타와 재접속 후 색상 유지.

3. **속옷 단독 상태 제거와 기본 의상 강제** — `S15P21A604-777`
   - 상태: **구현·컴파일 완료/커밋 전**.
   - 여성 기본 상의는 링거 티셔츠, 기본 하의는 일자 팬츠로 고정한다.
   - 상의·하의의 `없음` 선택으로 속옷만 남는 경로를 제거하고, 저장값이 0이거나 유효하지 않아도 기본 의상으로 정규화한다.
   - 남성도 카탈로그의 기본 상·하의를 같은 규칙으로 보장한다.

4. **한벌 의상 ↔ 상의·하의 전환 시 기존 의상 유지**
   - 상태: **S15P21A604-777에 함께 구현·컴파일 완료/커밋 전**.
   - 한벌 의상에서 상의를 선택하면 기존/기본 하의를 유지하고, 하의를 선택하면 기존/기본 상의를 유지한다.
   - 어느 전환 순서에서도 속옷 단독 상태가 발생하지 않아야 한다.

5. **NPC 옷이 화면 가장자리에서 사라지는 컬링 회귀** — `S15P21A604-749`
   - 상태: **좌표계 보정 재구현·컴파일 완료/시각 검증 대기**.
   - 좌·우·위 프러스텀 경계에서 NPC 의상 `SkinnedMeshRenderer`가 사라지는 현상이다.
   - 기존 보정은 서로 다른 렌더러 로컬 공간의 bounds를 그대로 합쳤다. 원본은 프리팹 루트 공간, 신체·병합 파츠는 대상 렌더러 공간으로 변환한 뒤 합치도록 수정했다.
   - 남은 확인: NPC 의상 조합별 좌·우·위 화면 경계 왕복과 WebGL 빌드 검증.

## 작업 운영 기준

- 최신 develop의 `festa-unity/`만 game 동기화 브랜치로 가져와 game을 게임 파트 최신본으로 유지한다.
- Unity 작업은 최신 game에서 작업 브랜치를 만들고 원본 프로젝트 폴더에서 진행한다.
- 작업 브랜치는 먼저 game 대상 MR로 병합하고, game 파이프라인과 무관하게 최신 game에서 다음 작업을 계속한다.
- 배포 시 develop에서 별도 이식 브랜치를 만든 뒤 game의 완료된 작업 파일만 이슈 단위로 가져와 develop에 반영한다. game 브랜치 전체를 develop에 병합하지 않는다.
- 씬·프리팹·asset 변경은 Unity에서 수행하며 YAML을 직접 편집하지 않는다.
- 게임 파트 작업일지와 트러블슈팅은 각각 `docs/KHS/24_작업일지.md`, `docs/KHS/25_트러블슈팅.md`에만 기록한다.
- 사용자 소유의 `ProjectSettings/QualitySettings.asset` 변경과 미추적 QA 산출물은 작업 커밋에 포함하지 않는다.
