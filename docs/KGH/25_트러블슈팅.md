## T-001 — spec 007 산출물 간 확정 계약과 작업 목록 불일치

- **날짜**: 2026-08-26
- **증상**: 확정된 callback 404 정책과 저장소 운영 범위가 일부 산출물에만 반영됐고, 세 번째 OpenAPI 계약 테스트·callback 종료 컬럼 migration 작업이 누락됐다. `tasks.md`에는 표준 형식이 아닌 `T008a`, `T075a`, `T075b`도 남아 있었다.
- **원인**: GitLab 후속 합의를 기존 작업 목록에 증분 반영하면서 계약 수, 데이터 모델, migration, 작업 식별자와 의존성 참조를 함께 점검하지 않았다.
- **해결**: P0 수동 장애 정책과 미확정 항목 등록 위치를 통일하고, 세 OpenAPI 스키마 검증·storage reconciliation Backend 동작 테스트 및 callback 종료 필드를 작업에 추가했다. 작업 식별자와 모든 참조를 `T001~T079`로 재정렬한 뒤 중복·누락을 검사했다.
- **예방**: 파트 간 계약 변경 시 spec·plan·research·data-model·contracts·quickstart·tasks를 한 묶음으로 검색하고, 작업 ID 연속성·계약 파일 수와 테스트 수·DB 필드와 migration 작업 대응을 구현 착수 전 검사한다.
