# S15P21A604-911 — 월드 좌상단 일일 미션 런처 버튼

> [FE] 월드 좌상단 일일 미션 런처 버튼 (S15P21A604-859 후속)
> 브랜치: `feat/S15P21A604-911-daily-mission-launcher` (develop 분기)
> 작성: 2026-09-18

## 1. 목표

회원이 월드에서 기존 일일 미션 패널로 바로 진입할 수 있도록 좌상단 HUD 버튼을 추가한다. 보상 수령 성공 시 받은 코인을 안내하고, 내 정보의 코인 사용 내역에서 원장 사유를 사용자 문구로 표시한다. 화면·API·ESC 진입점은 재사용하며 새 미션 상태나 API 계약은 만들지 않는다.

## 3. 완료 상태 조회 방식

- 런처 버튼은 미션 API를 조회하지 않는다. 상시 마운트되는 HUD에서 진행도를 조회하면 월드 플레이 중 바뀐 상태가 자동 갱신되지 않아 오래된 뱃지를 보여 줄 수 있기 때문이다.
- ESC 메뉴 또는 런처로 미션 화면을 열면 `DailyMissionOverlay`가 마운트되고 `['daily-missions']` 쿼리를 실행한다. React Query 기본 `staleTime`은 0이므로 캐시가 있어도 화면을 여는 시점에 서버 상태를 다시 조회한다.
- 미션 화면이 열린 동안에는 월드 플레이가 중단되므로 새로운 활동 진행도가 생기지 않는다. 보상 수령 성공·경합 오류 때는 기존 구현이 같은 쿼리를 무효화해 다시 조회한다.
- 화면을 닫고 월드에서 활동한 뒤 다시 열면 재마운트와 함께 최신 상태를 조회한다. 별도 폴링·Unity 이벤트·신규 API는 추가하지 않는다.

- 런처 단위 테스트: 회원 노출, 게스트·비로그인 미노출, 클릭 배선

- `npm run lint`
- `npm run build`

### 수동 검증

- 회원으로 월드 입장 → 좌상단 버튼 클릭 → 최신 미션 진행도 조회 및 패널 표시
- 보상 수령 → 받은 코인 수가 성공 알림으로 표시됨
- 내 정보의 코인 사용 내역 → 해당 행 사유가 `일일 미션 보상`으로 표시됨
- 패널 닫기 → 월드 복귀 → WASD·F 입력 정상
- 게스트로 월드 입장 → 런처가 보이지 않음
- ESC 메뉴의 기존 일일 미션 진입점이 그대로 동작함
