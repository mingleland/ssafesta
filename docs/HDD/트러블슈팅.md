# HDD 트러블슈팅

> 황덕 백엔드 파트 개인 트러블슈팅 기록.

### T-95. pgvector Testcontainers 이미지 pull 타임아웃 (2026-08-18, 해결)

- **증상**: 초기 ERD Flyway migration 검증 중 `pgvector/pgvector:pg17` 이미지가 Docker Hub에서 2분 동안 내려받기 진전을 보이지 않아 `mvnw test`가 실패했다.
- **원인**: Docker Desktop 및 Redis Testcontainer는 정상 기동했고 실패 지점은 원격 pgvector 이미지 pull이었다. SQL/Flyway 실행 전 컨테이너 생성이 실패했다.
- **해결**: pgvector 이미지를 local Compose와 Testcontainers에 명시한 뒤 이미지 pull 완료 후 테스트를 재실행했다. `mvnw test`가 Tests run 1, Failures 0, Errors 0으로 성공했다.
- **예방**: pgvector 의존 migration은 CI 또는 개발 환경에서 사전에 이미지를 pull해 두고, 이미지 pull 실패와 migration 실패를 구분해 기록한다.
