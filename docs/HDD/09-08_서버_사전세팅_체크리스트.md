## 0. 서버 기동 전제 — BE 몫은 끝났다

`#117` 은 **양쪽 다 처리됐다.** 새 compose(`infra/environments/compose/dev/back.yaml`)가 `#123` 의 dev 안을 그대로 넣었고(`festa_dev_business`·`festa_dev_back_app`·`dev_back`), secret 은 `COMPONENT_ENV_FILE` 로 온다. 그 파일에 들어갈 목록은 `backend/.env.example` 과 `#117` note 로 이미 넘겼다.

아래 표는 **참조용으로 남긴다** — 배포 실패 시 이 목록과 대조하면 원인이 바로 나온다.

> 현재 compose 정의로는 백엔드 컨테이너가 기동하지 않습니다.
> `back.compose.yaml` 이 백엔드에 넘기는 환경변수 **0개**

기본값이 없어서 **없으면 기동이 실패하는** 값들:

| 변수 | 비고 |
|---|---|
| `JWT_SECRET` | **base64 여야 한다.** 평문이면 `Illegal base64 character` 로 죽는다 |
| `CONNECTION_TOKEN_SECRET` | 게임 서버 전용 서명 키, Access Token 키와 분리 (헌법 14조) |
| `INTERNAL_AI_TO_SPRING_TOKENS` | FastAPI→Spring 서비스 토큰. **FastAPI 쪽 같은 이름 값과 일치해야 한다** |
| `GOOGLE_CLIENT_ID`·`_SECRET`·`_REDIRECT_URI` | |
| `KAKAO_REST_API_KEY`·`_CLIENT_SECRET`·`_REDIRECT_URI` | |
| `SSAFY_CLIENT_ID`·`_CLIENT_SECRET`·`_REDIRECT_URI` | **`-357`(09-07)에 생겼는데 이 표에서 빠져 있었다 — 그래서 dev·demo 어디에도 안 들어갔다 (T-160).** `_REDIRECT_URI` 는 `https://api.ssafesta.world/login/oauth2/code/ssafy`, SSAFY 콘솔 등록값과 한 글자도 달라선 안 된다 |

기본값은 있으나 **컨테이너 안에서 틀린** 값: `POSTGRES_*`·`REDIS_*`(안 주면 컨테이너 자기 localhost 를 본다) · `FRONTEND_BASE_URL`(CORS) · `AUTH_COOKIE_SECURE`(HTTPS 면 true) · `WORLD_SCHEME/HOST/PORT`.

**`#123`(EC2 dev DB·Redis 연결 계약)은 내가 09-05 에 답했고 infra 적용 대기다.** dev 는 `festa_dev_business` / `festa_dev_back_app` / Redis ACL `dev_back` / key prefix `dev:*` 로 가는 안이 올라와 있다. **Redis 가 EC2 에서는 ACL 을 쓴다** — 로컬 무인증과 다르다.
