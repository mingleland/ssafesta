# PJW 작업일지

> 박준우 — Game Studio 파트 개인 작업 기록. 공용 작업일지와 별도로 관리한다.

## 작성 지침

- 작업(티켓 단위)을 완료하면 **그 즉시** 이 파일을 갱신한다. 하루 끝에 몰아서 적지 않는다.
- 기록은 최신 날짜가 위로 오도록 `## YYYY-MM-DD` 섹션 아래, 작업 세션마다 `### 제목 (S15P21A604-N)` 소제목으로 작성한다.
- 각 항목에 담을 것: 무엇을 / 왜 / 결과, 관련 파일·MR·커밋.
- 담당 구분: 👤 사람 / 🤖 AI.
- 문제가 생기면 해결 여부와 무관하게 **`25_트러블슈팅.md`에 반드시 등록**하고, 여기엔 T-번호로 링크만 남긴다.
