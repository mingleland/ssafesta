CI 러너 부재로 통합 배포 환경 자체가 존재하지 않아, **로컬 dev 서버(`npm run dev`,
`VITE_USE_MOCK=true`)로 대체 검증**했다.

## 커버 못한 부분 (한계)

- **캔버스 클릭/드래그로 신규 오브젝트 배치**는 이번 검증 환경(스크린샷 비활성)에서
  좌표 기반 클릭이 불가해 직접 확인하지 못했다. 대신 이미 배치된 43개 오브젝트에 대한
  선택·속성 수정·이동으로 대체 검증했다. 제품 결함이 아니라 **이번 검증 방법의 한계**다.
  실제 마우스 드래그 배치는 사람이 브라우저로 한 번 더 확인하는 것을 권장.
- 6개 템플릿 중 실제 진입·편집까지 전량 검증한 것은 PLATFORMER 1종. 나머지는 목록 표시와
  ESCAPE의 확인 다이얼로그만 점검 — 동일 코드 경로라 리스크는 낮다고 판단.
