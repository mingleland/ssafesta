# SSAFY FESTA 서비스 기능 명세서

> **문서 목적**: 화면과 시스템이 사용자에게 제공해야 하는 기능 동작을 정의한다.  
> **기능 우선순위**: `P0 = 1차 MVP`, `P1 = 2차 MVP`, `P2 = 확장`  
> **세부 정책**은 정책 문서, **구현 방식**은 각 기술 설계서에서 관리한다.

---

## 1. 사용자 역할

| 역할 | 설명 |
|---|---|
| Visitor / User | 월드 탐색, 부스 이용, AI·설문·이벤트 참여 |
| Booth Owner | 부스 임대, 콘텐츠 제작, 직원·서비스·수익 관리 |
| Booth Staff | 권한 범위 내 콘텐츠 관리 및 상담 |
| Admin | 사용자·부스·이벤트·경제 정책 운영 |

| RUNTIME-09 | P0 | 내부 퇴장·정리 | 퇴장 또는 임대 만료 시 플레이어를 외부 복귀 지점으로 이동시키고 로컬 내부 오브젝트를 제거한다. |

1차 MVP의 내부 공간은 사용자마다 생성하지 않고 7개 물리 임대 슬롯에 대응하는 7개 내부 앵커 풀을 사용한다. 일반 방문은 공유 입장이며 부스 전체 예약·독점은 제공하지 않는다.

| `PROJECT_PANEL` | 프로젝트 링크·정보 | projectId |
| `SURVEY_KIOSK` | 설문·지원서 | surveyId |
| `RECRUITMENT_BOARD` | 팀원·스터디 모집 | recruitment configId |
| `CONSULTATION_DESK` | 사람 직원 상담 | boothId / consultation config |
| `LAPTOP` | 임대자 홈페이지 열람 | homepageUrl *(2026-08-12 신설)* |
| `LIKE_VOTE` | 평가·투표 | targetId / competitionId |

정적 Decoration은 실시간 네트워크 상태를 갖지 않는다.

## 4. 주요 상태 정의

### 4.1 Booth Layout

```text
DRAFT → PUBLISHED
```

Published 버전만 일반 방문자의 Unity Runtime에 반영한다.

### 4.2 Staff Presence

```text
AVAILABLE / BUSY / AWAY / OFFLINE
```

### 4.3 AI Document

```text
QUEUED / PROCESSING / READY / FAILED / DISABLED
```

### 4.4 Consultation

```text
REQUESTED → ACCEPTED → ACTIVE → ENDED
          ↘ REJECTED / EXPIRED
```

세부 timeout 값은 정책 문서에서 확정한다.
