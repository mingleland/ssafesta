# 수달 답변 생성 LLM 비교 검토 (자동 지표 포함)

> 이 문서는 세 가지를 자동 계산해 채웠다:
> 1. **거절 판단 적절성** — NO_ANSWER 문항은 거절 문구 포함 여부, ANSWERABLE/PARTIAL 문항은
'문서에서 확인할 수 없습니다' 문구가 답변 전체를 차지하는 부적절한 전면 거절인지를 규칙으로 판정.
> 2. **정답 유사도** — 모델 답변 vs gold_answer 임베딩 코사인 유사도 (Relevance 근사치).
> 3. **근거 유사도** — 모델 답변 vs gold의 relevant_contains(근거 문장) 임베딩 코사인 유사도
(Groundedness 근사치, 근거가 없는 NO_ANSWER 문항은 N/A). text-embedding-3-large 실측.
>
> **Groundedness·Relevance·환각·한국어 자연스러움 4개 축은 자동화하지 않았다** — 정답 유사도·근거
