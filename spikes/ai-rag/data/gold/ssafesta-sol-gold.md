# SSAFY FESTA Sol 정답 청크 제안

> `gpt-5.6-sol`이 임베딩 검색 결과를 보지 않고 원문만 대조해 만든 골드 라벨 후보입니다.

- 전체: 15개
- ANSWERABLE: 9개
- PARTIAL: 3개
- NO_ANSWER: 3개

## 1. 서비스를 간단하게 설명해주세요.

- 판정: **ANSWERABLE**
- 제안 답변: SSAFY 구성원이 가상 SSAFY 공간에서 만나고, 부스를 임대해 AI 서비스·프로젝트 전시·설문·상담·이벤트 공간을 직접 제작하고 운영하는 소셜 메타버스 플랫폼입니다.
- 판정 이유: 문서의 한 줄 소개가 서비스 대상, 공간, 제작·운영 기능을 직접 정의한다.
- 정답 청크:
  - `SSAFY 구성원이 가상 SSAFY 공간에서 서로 만나고, 한정된 부스를 임대해 AI 서비스·프로젝트 전시·설문·상담·이벤트 공간을 직접 제작하고 운영하는 사용자 제작형 소셜 메타버스 플랫폼`

## 2. 서비스의 주요 사용자는 어떤 사람들인가요?

- 판정: **ANSWERABLE**
- 제안 답변: 프로젝트를 홍보하려는 사용자, 목적형 AI 서비스를 운영하려는 사용자, 프로젝트·스터디 팀원을 모집하려는 사용자, 다른 팀의 결과물과 이벤트를 방문·탐색하려는 사용자가 주요 대상입니다.
- 판정 이유: 핵심 사용자 절의 프로젝트 홍보형, AI 서비스 운영형, 모집형, 방문·탐색형을 대표하는 요구를 각각 선택했다.
- 정답 청크:
  - `완성한 프로젝트를 다른 교육생에게 보여주고 싶다.`
  - `자소서 첨삭, 기술 상담, 프로젝트 설명 등 목적형 AI 서비스를 빠르게 운영하고 싶다.`
  - `프로젝트·스터디 팀원을 모집하고 싶다.`
  - `다른 팀의 프로젝트와 포트폴리오를 구경하고 싶다.`

## 3. SSAFY 11층을 구현한 이유는 무엇인가요?

- 판정: **PARTIAL**
- 제안 답변: 기본 월드가 실제 SSAFY 11층을 모티브로 한다는 점은 명시되어 있습니다. 그러나 왜 11층을 선택했는지에 대한 구체적인 이유는 설명되어 있지 않습니다.
- 판정 이유: 11층과 실제 공간의 관계는 확인되지만 선택 배경이나 목적까지는 문서가 밝히지 않는다.
- 정답 청크:
  - `기본 월드는 실제 SSAFY 11층을 모티브로 한다.`

---

## 4. AI NPC가 답변하지 못하는 질문을 하려면 어떻게 해야 하나요?

- 판정: **PARTIAL**
- 제안 답변: AI 상담에서 사람 상담을 요청해 등록된 Staff에게 연결하는 흐름이 계획되어 있습니다. 다만 AI가 답변하지 못한 경우의 구체적인 전환 조건이나 사용자 조작 방법은 명시되지 않았습니다.
- 판정 이유: 사람 상담 전환과 요청 이후 흐름은 존재하지만, 질문에 제시된 실패 상황의 처리 절차는 상세히 정의되지 않았다.
- 정답 청크:
  - `- AI → 사람 상담 전환`
  - `→ 사람 상담 요청`
  - `→ 등록 Staff에게 알림`

## 6. 부스 임대 기간이 지나면 콘텐츠가 모두 사라지나요?

- 판정: **ANSWERABLE**
- 제안 답변: 아니요. 만료되면 부스 슬롯은 초기화되지만 기존 콘텐츠는 Draft로 보존되며 Layout·AI·문서·설문·프로젝트·인벤토리 데이터도 보존됩니다.
- 판정 이유: 임대 만료 시 슬롯 처리와 보존되는 콘텐츠 범위를 문서가 직접 명시한다.
- 정답 청크:
  - `- 임대 만료 시 슬롯 초기화 및 기존 콘텐츠 Draft 보존`
  - `| 부스 만료 후 데이터 | Layout·AI·문서·설문·프로젝트·인벤토리 보존 |`

## 7. 최대 몇 명의 사람이 접속할 수 있나요? 너무 많은 사람이 접속했을 때의 처리가 어떻게 되나요?

- 판정: **PARTIAL**
- 제안 답변: 전체 서비스는 100명 이상으로 확장 가능한 구조를 목표로 하며, 11층 월드 한 채널은 30~40명 운영 목표이고 최대 50명 수준으로 부하 테스트합니다. 이는 확정된 최대치가 아니며 실제 값은 테스트 후 결정됩니다. 초과 인원 대응을 위한 World Channel 자동 분배는 선택 확장 기능입니다.
- 판정 이유: 서비스·채널별 목표와 시험 규모는 제시되지만 확정 최대 인원은 아니며, 초과 시 채널 분배도 P2 선택 확장이라 질문 전체에는 부분적으로만 답할 수 있다.
- 정답 청크:
  - `| 전체 서비스 | 100명+ 확장 가능한 구조 |`
  - `| 11F World 1채널 | 30~40명 운영 목표 |`
  - `| 월드 부하 테스트 | 최대 50명 수준 |`
  - ``30~40명`은 NGO의 절대 제한이 아니라 Unity Web 환경의 렌더링·애니메이션·네트워크 비용을 고려한 운영 목표다. 실제 값은 부하 테스트 후 결정한다.`
  - `- World Channel 자동 분배`

## 14. 코인은 어떻게 모을 수 있나요?

- 판정: **ANSWERABLE**
- 제안 답변: 신규 사용자는 200 Coin을 받고 매일 50 Coin을 지급받습니다. 설문 참여 시 5~10 Coin, 관리자 게임으로 일일 최대 약 50 Coin을 받는 방안도 후보로 제시되어 있습니다.
- 판정 이유: 코인 지급·획득 경로와 수량을 정책 표가 제시하며, 확정 지급과 후보 보상을 구분할 수 있다.
- 정답 청크:
  - `| 신규 사용자 지급 | 200 Coin |`
  - `| 일일 지급 | 50 Coin |`
  - `| 설문 참여 보상 | 5~10 Coin 후보 |`
  - `| 관리자 게임 | 일일 최대 약 50 Coin 후보 |`

## 15. 부스를 사용하고 있는데 부스 이용이 종료되면 어떻게 하나요?

- 판정 이유: 부스 이용 종료를 임대 만료로 해석할 때 슬롯 초기화와 데이터 보존 결과가 직접 명시되어 있다.
- 정답 청크:

  - `| 부스 만료 후 데이터 | Layout·AI·문서·설문·프로젝트·인벤토리 보존 |`
