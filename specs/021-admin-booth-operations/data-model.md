# Data Model: 관리자 부스 운영 권한

## 기존 엔터티 사용

| 엔터티 | 역할 | 이 슬라이스 변경 |
|---|---|---|
| `users` | 전역 관리자·마스터 판정 | 없음. `account_type`, `is_master`를 기존 규칙대로 조회한다. |
| `booths` | 부스와 소유자 | 없음. `owner_user_id`로 마스터 보호 대상을 결정한다. |
| `booth_staffs` | 부스별 직원 역할 | 없음. 기존 Owner/ADMIN/CONTENT_EDITOR 판정을 보존한다. |
| `admin_actions` | 관리자 행위 감사 | 스키마 변경 없음. `action=BOOTH_EDIT`, `target_type=BOOTH`, `target_id=boothId` 행을 추가한다. |

## 권한 결정표

| 호출자 자격 | 읽기 | 변경 | 마스터 소유 부스 변경 | 감사 |
|---|---:|---:|---:|---:|
| Owner | 허용 | 허용 | 본인이 마스터면 허용 | 없음 |
| 부스 ADMIN / CONTENT_EDITOR | 허용 | 허용 | 기존 부스 직원 자격이면 허용 | 없음 |
| 전역 Admin만 보유 | 허용 | 허용 | 거부 (`MASTER_PROTECTED`) | `BOOTH_EDIT` 1행 |
| CONSULTANT / 일반 회원 / 게스트 | 거부 | 거부 | 거부 | 없음 |

## 상태와 트랜잭션

1. 변경 요청은 부스 존재 확인 후 Owner·직원 권한을 우선 판정한다.
2. 둘 다 아니면 전역 Admin 여부를 판정한다.
3. 전역 Admin이면 대상 소유자가 마스터인지 검사하고, 보호 대상이 아니면 동일 트랜잭션에 감사 행을 기록한다.
4. 활성 임대가 필요한 경로는 그 다음 기존 임대 검사를 실행한다.
5. 이후 검증·저장이 실패하면 감사 행도 같은 트랜잭션으로 되돌아간다.
