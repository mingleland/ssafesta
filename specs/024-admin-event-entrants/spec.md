# Feature Specification: 관리자 이벤트 참여자 조회

**Feature Branch**: `feat/S15P21A604-742-admin-operations`

**Created**: 2026-09-16

**Status**: Complete

**Input**: S15P21A604-742 #59 — 경품 지급은 보류하고 전역 관리자가 이벤트 설문 참여 회원을 페이지로 조회한다.

## Requirements

- **FR-001**: 전역 Admin만 `surveyKey`로 식별되는 이벤트 설문의 참여자 목록을 읽을 수 있어야 한다.
- **FR-002**: 응답 id·회원 id·닉네임·제출 시각만 최신 제출순으로 반환한다.
- **FR-003**: 이 경로만 이벤트 설문 참여자의 식별 정보를 반환한다. 기존 부스 설문 결과·주관식 API의 익명 계약은 바꾸지 않는다.
- **FR-004**: 없는 이벤트 키는 `SURVEY_NOT_FOUND`, 일반 회원은 `FORBIDDEN`, 페이지 값은 공통 0~100 규약으로 거부한다.
- **FR-005**: 경품 지급·추첨·당첨자 선정·코인 변경은 구현하지 않는다.

## Acceptance

1. Admin은 이벤트 참여자를 페이지로 읽고 일반 회원은 읽지 못한다.
2. 목록에는 부스 설문 응답이나 게스트 식별자가 섞이지 않는다.
3. 기존 익명 부스 설문 결과 응답에는 식별 필드가 추가되지 않는다.
