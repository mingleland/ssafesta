## User Scenarios & Testing

### User Story 1 — 설문을 만들고 받는다 (Priority: P1)

부스 소유자가 설문을 만들어 부스에 배치하면, 방문자가 응답한다.

**Independent Test**: 설문 생성 → 부스에 배치 → 공개 → 방문자 응답 → 소유자가 결과 확인.

**Acceptance Scenarios**:

1. **Given** 부스 소유자, **When** 설문을 만들면, **Then** 제목·설명과 문항들을 저장할 수 있다.
2. **Given** 설문, **When** 문항을 추가하면, **Then** 객관식·복수선택·별점·단답·장문·지원서를 만들 수 있다.
3. **Given** 공개된 부스의 설문, **When** 방문자가 응답을 제출하면, **Then** 저장되고 완료가 안내된다.
4. **Given** 1인 1응답 설정, **When** 같은 사용자가 다시 응답하려 하면, **Then** 거부된다.
5. **Given** 보상이 설정된 설문, **When** 정상 제출되면, **Then** 정책에 따라 코인이 지급된다 (spec 003 원장 기록).

### User Story 2 — 결과를 본다 (Priority: P1)

**Acceptance Scenarios**:

1. **Given** 응답이 있는 설문, **When** 소유자가 결과를 보면, **Then** 전체 응답 수·최초·최근 응답 시각이 보인다.
2. **Given** 선택형 문항, **When** 결과를 보면, **Then** 선택지별 응답 수와 비율이 보인다.
3. **Given** 별점 문항, **When** 결과를 보면, **Then** 평균과 점수별 분포가 보인다.
4. **Given** 주관식 문항, **When** 결과를 보면, **Then** 응답 목록이 **페이지 단위로** 보인다.
5. **Given** 익명 설문, **When** 결과를 보면, **Then** 응답자 식별 정보가 노출되지 않는다.
6. **Given** 권한이 없는 사용자, **When** 결과 조회를 시도하면, **Then** 거부된다.

### Edge Cases

- 응답이 0건일 때 → **0으로 나누는 오류가 없어야 한다**
- 복수 선택에서 한 사람이 여러 개 선택 → 비율 합계가 100%를 넘을 수 있음을 표시
- 미응답 문항 → 문항별 응답 수에서 제외
- 매우 긴 주관식 응답 → 화면이 깨지지 않아야 한다
- 마감된 설문 → 기존 결과는 조회 가능
- 삭제된 설문 → 명확한 오류

## Requirements

### Functional Requirements

- **FR-001**: 소유자는 설문을 생성·수정할 수 있어야 한다.
- **FR-002**: 문항 유형은 객관식·복수선택·별점·단답·장문·지원서를 지원해야 한다.
- **FR-003**: 익명 여부·마감·1인 1응답을 설정할 수 있어야 한다.
- **FR-004**: 방문자는 공개된 설문에 응답할 수 있어야 한다.
- **FR-005**: 보상이 설정된 경우 정상 제출 후 지급되며 **원장에 기록**되어야 한다 (헌법 20조).
- **FR-006**: 결과는 **전체 응답 수 / 선택지별 수·비율 / 별점 평균·분포 / 주관식 목록**을 제공해야 한다.
- **FR-007**: 집계는 **서버가 계산**해야 하며, 프론트가 원본 응답 전체를 받아 직접 계산해서는 안 된다.
- **FR-008**: 주관식 응답 목록은 **페이지 단위**로 제공되어야 한다.
- **FR-009**: 익명 설문에서는 응답자 식별 정보를 반환·표시하지 않아야 한다.
- **FR-010**: Owner와 허용된 Staff만 결과를 조회할 수 있어야 한다.
- **FR-011**: 다른 부스의 설문 결과를 조회할 수 없어야 한다.
- **FR-012**: 응답이 0건이어도 오류 없이 빈 상태가 표시되어야 한다.
- **FR-013**: **고급 분석(교차·추이·AI 분석·상관·전환율·통합·자동 보고서·내보내기)은 범위에서 제외**한다.

### Key Entities

- **Survey**: 설문. 부스, 제목, 설명, 상태(작성/공개/마감), 설정(익명·1인1응답·보상)
- **Question**: 문항. 설문, 유형, 제목, 선택지, 필수 여부, 순서
- **Response**: 한 사람의 제출. 설문, 응답자(익명 시 미노출), 제출 시각
- **Answer**: 문항별 답. 응답, 문항, 선택지 식별자 / 텍스트 / 숫자

---

## Success Criteria

- **SC-001**: 집계 수치가 실제 응답 데이터와 100% 일치한다.
- **SC-002**: 응답 0건 설문에서 오류가 발생한 사례가 0건이다.
- **SC-003**: 익명 설문에서 응답자 정보가 노출된 사례가 0건이다.
- **SC-004**: 다른 부스의 설문 결과가 조회된 사례가 0건이다.
- **SC-005**: 소유자가 결과 화면만 보고 응답 경향을 파악할 수 있다.
