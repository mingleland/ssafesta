# Game Studio 첫 사용자 20분 사용성 검증 기록지

> 목적: 개발 경험이 없는 한국어 사용자도 도움을 요청하지 않고 `열쇠 획득 → NPC 대화 → 조건부 문 이동 → 게임 완료`를 수정·저장·플레이할 수 있는지 확인한다.

## 참가자 조건

- FESTA 또는 Game Studio를 처음 사용한다.
- Unity, Phaser, JSON, Component/Event 용어를 사전에 설명하지 않는다.
- PC 브라우저 권장 작업 폭 1280px 이상, compact 확인은 760~1039px에서 수행한다. 마우스와 키보드를 사용한다.
- compact 확인자는 큰 맵에서 Shift+F 집중 모드를 찾고 패널을 복구할 수 있는지도 기록한다.

## 시작 상태

- 로컬 mock 또는 실제 회원으로 `/app/games/{gameId}/edit`에 첫 방문한다.
- `비밀 도서관` starter project와 첫 방문 guide가 보인다.
- 진행자는 문제 해결 방법을 말하지 않고 사용자가 읽는 문구와 막힌 지점만 기록한다.

## 20분 과제

1. NPC의 이름 또는 대사를 자기 이야기로 바꾼다.
2. 열쇠의 이미지나 위치 중 하나를 바꾼다.
3. 열쇠가 있어야 열리는 문 규칙을 찾아 설명한다.
4. 오브젝트 하나를 레이어 패널에서 잠그고 다시 움직이지 않는지 확인한다.
5. 저장하고 플레이 테스트를 시작한다.
6. 열쇠를 얻고 NPC와 대화한 뒤 문을 열어 게임을 완료한다.

## 합격 기준

- 5명 중 4명 이상이 20분 안에 6개 과제를 완료한다.
- 첫 유효 편집까지 중앙값 3분 이하, 첫 플레이까지 중앙값 10분 이하이다.
- 되돌릴 수 없는 데이터 손실 0건, 진행자 개입 1회 이하이다.
- 참가자 80% 이상이 “다음에 무엇을 해야 하는지 알 수 있었다”를 5점 중 4점 이상으로 평가한다.
- 가장 많이 막힌 동일 지점이 2명 이상이면 문구·배치·기본값을 수정하고 재검증한다.

## 후속 분류

- 5분 이상 막힘: P0 사용성 결함
- 데이터 손실 또는 복구 불가: P0
- 기능은 찾았지만 의미를 오해함: P1 문구·정보구조
- 3회 이상 반복 조작: P1 기본값·자동화 후보
- 선호도 차이: P2 개선 후보
