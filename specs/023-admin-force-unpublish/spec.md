# Feature Specification: 관리자 강제 비공개

**Feature Branch**: `feat/S15P21A604-742-admin-operations`

**Created**: 2026-09-16

**Status**: Complete

**Input**: S15P21A604-742 #40 — 전역 관리자가 운영상 공개 중인 일반 사용자 부스를 즉시 비공개 처리한다.

## Requirements

- **FR-001**: 전역 Admin만 부스의 공개 배치 포인터를 해제할 수 있어야 한다.
- **FR-002**: 공개 이력과 Draft는 보존하고, 방문자 공개 경로만 즉시 `LAYOUT_NOT_PUBLISHED`로 닫아야 한다.
- **FR-003**: 마스터 소유 부스는 다른 Admin이 비공개 처리할 수 없어야 한다.
- **FR-004**: 성공 처리에는 수행자·부스·사유를 감사 기록으로 남겨야 한다.
- **FR-005**: 이미 비공개인 부스 재요청은 상태·감사를 더 바꾸지 않아야 한다.

## Acceptance

1. 공개된 일반 사용자 부스를 Admin이 비공개 처리하면 방문자 공개 배치 조회가 닫히고, 소유자의 Draft와 공개 이력은 남는다.
2. 일반 회원과 마스터 소유 부스 대상 요청은 거부된다.
3. 성공만 `BOOTH_UNPUBLISH` / `BOOTH` 감사 행을 남긴다.

## Assumptions

- 강제 비공개는 임대 해제·코인 환불·콘텐츠 삭제가 아니다. 공개 포인터만 해제한다.
- 운영 사유는 감사 가능하도록 1~500자로 필수다.
