# Contract: 월드 공용 텍스트 채팅 (STOMP)

**Spec**: `002-world-session` | **Date**: 2026-09-13 | **Ticket**: `S15P21A604-687`

> 이 기능은 spec 에 FR 이 없다. `docs/02` 의 WORLD 목록에 음성채팅(WORLD-09)만 있었고 텍스트 채팅은 어디에도 없어, `WORLD-11` 로 신설하며 이 파일에 계약을 고정한다. 반나절 규모라 spec 을 따로 파지 않았다.
>
> 서술본은 `docs/16` §8-1 이다. 이 파일은 그 계약의 근거와 경계를 적는다.

---

## 왜 이 모양인가

### Unity 는 관여하지 않는다

Unity 는 Spring 과 통신하지 않고(2026-09-07 확정), 텍스트 UI 는 React 가 그린다(헌법). **React 오버레이가 STOMP 로 직접 보내고 받는다 — Unity 작업 0건.**

### 클라이언트가 서버로 보내는 유일한 경로다

`S15P21A604-686` 이 클라이언트 `SEND` 를 전부 거부해 두었고, 이 기능이 `/app/world/chat` **한 건만** 연다. allowlist 는 접두 매칭이 아니라 **정확히 일치**다 — `/app/world/` 로 시작하는 것을 다 열면 나중에 추가되는 핸들러가 목록을 손대지 않고 열려 버린다.

### 회원 전용은 공짜로 성립한다

STOMP 연결에 WS Token 이 필요하고 그 토큰은 회원에게만 발급된다(`aGuestGetsNoToken`). **게이트를 따로 두지 않았다** — 같은 판정을 두 곳에 두면 둘이 갈린다.

## 계약

| | |
|---|---|
| 연결 | `wss://<host>/ws` (정본) · `wss://<host>/ws/consultation` (기존 계약 유지) |
| 토큰 | `POST /api/v1/realtime/ws-token` (정본) · `POST /api/v1/consultation/ws-token` (기존 계약 유지) |
| 보내기 | `SEND /app/world/chat` — `{ "content": "..." }` |
| 받기 | `SUBSCRIBE /topic/world/chat` |
| 오류 | `SUBSCRIBE /user/queue/world/chat/errors` — **보낸 세션에만** |

**보낸 사람과 시각을 받지 않는다.** 요청 record 에 자리가 없어 JSON 에 실려 와도 변환 경계에서 사라진다. 클라이언트가 정할 수 있는 값이면 사칭이 된다.

## 판단 기록

### 저장하지 않는다

표도 마이그레이션도 없다. 광장 잡담은 스크롤백 가치가 낮고, 남기면 **보존 기간 결정과 탈퇴 삭제 경로**가 함께 붙는다 — D11 의 "사용자별 상세 로그를 축적하지 않는다" 와도 맞는다.

딸린 결과를 숨기지 않는다: **재접속하면 이전 대화가 없고, 인스턴스가 죽으면 그 대화는 사라진다.**

### 토픽이 하나다

채널별로 가르지 않는다. **채널을 클라이언트가 지정하게 하면 서버가 검증할 수 없다** — 누가 어느 채널에 있는지 서버가 모르고, 그걸 아는 것이 `S15P21A604-499` 다. 그러면 아무나 남의 채널에 말을 넣는다.

지금 채널 식별자가 `11F-01` 상수라 사실상 전체 채팅이다. 채널이 실제로 생길 때 토픽을 쪼갠다.

### 길이는 code point 로 센다

`String.length()` 는 UTF-16 단위라 **이모지 하나가 2자**다. 그 기준이면 이모지로 쓴 50자가 거부되고, 상한이 사람이 보는 길이와 어긋난다. 100 code point 이고 이모지 100개는 통과한다.

방송되는 것은 `strip()` 을 거친 값이다 — 앞뒤 공백을 그대로 실으면 같은 말이 사람마다 다르게 보이고, 공백만으로 줄을 밀어 올리는 도배가 가능해진다.

### 도배 방지는 fail-closed

Redis `setIfAbsent(key, "1", 3초)` **한 번의 원자 연산**이다. `SETNX` 와 `EXPIRE` 를 따로 부르면 그 사이에 죽었을 때 TTL 없는 키가 남고 그 사람은 영영 말을 못 한다.

**판정할 수 없으면 막는다.** 열어 두는 쪽이 사용자 경험은 낫지만, 도배 방지가 이 기능의 필수 조건이라 Redis 가 흔들리는 순간 광장이 도배된다.

키에 환경 namespace 를 붙인다 — dev 와 demo 가 Redis 하나를 공유한다.

### 금칙어는 닉네임과 같은 목록이다 (2026-09-15, `S15P21A604-792`)

> **개정.** 이전 판은 금칙어를 "안 하는 것" 에 두고 사유를 *"운영 인력을 전제하는 기능"* 이라 적었다.
> 그 사유는 **신고·차단에는 맞지만 정적 목록 대조에는 맞지 않는다** — 운영 인력도 신고 큐도 필요
> 없다. 금칙어만 계약으로 들어온다. 신고·차단은 그대로 범위 밖이다.

`ProfanityFilter` 하나를 닉네임과 채팅이 함께 쓴다. 정책 정본은 `specs/001-auth-user/contracts/nickname-policy.md` 다. **채팅용 목록을 따로 두지 않는다** — 둘로 두면 갈리고, 어느 쪽이 정본인지 알 수 없게 된다. 운영자 사칭 예약어(`관리자`·`admin`)는 닉네임에만 걸린다. 채팅에 걸면 "관리자님 계신가요" 가 막힌다.

판정은 **정규화 → 예외 제거 → 대조**다. 예외를 먼저 지우면 `F_U_C_K` 같은 우회 표기를 예외 목록이 알아보지 못한다.

| | |
|---|---|
| 응답 | `VALIDATION_FAILED` — **신규 코드 없음.** 빈 내용·길이 초과와 같은 자리다 |
| 프런트엔드 | **변경 0줄.** 이미 `VALIDATION_FAILED` 를 "보낼 수 없는 내용입니다" 로 그린다 |
| 방송 | 원문(`strip()` 적용본). 검사용 정규화본은 나가지 않는다 |
| 쿨다운 | 소비하지 않는다 — 내용 검증이 도배 판정보다 먼저다 |

**마스킹하지 않는다.** 정규화에서 공백과 기호가 지워져 일치 위치를 원문으로 되돌릴 수 없고, `씨---1---발` 은 애초에 원문에 가릴 자리가 없다. 결국 메시지 전체를 별표로 덮게 되는데, 그건 차단과 같고 설명만 어려워진다.

**걸린 단어를 알려 주지 않는다.** 알려 주면 통과하는 표기를 찾는 데 쓰인다 (`nickname-policy.md` 4항).

**프런트엔드에 같은 검사를 두지 않는다.** 위의 "회원 전용은 공짜로 성립한다" 와 같은 이유다 — 같은 판정을 두 곳에 두면 둘이 갈린다. 목록이 서버에만 있어야 브라우저로 나가지도 않는다.

### 검증 순서가 계약이다

**내용 검증(빈 값 → 길이 → 금칙어) → 도배 판정 → 신원 확인 → 방송.**

도배 판정을 먼저 하면 빈 문자열을 보낸 사람이 3초를 기다려야 하고, 신원을 먼저 확인하면 거부될 요청이 DB 를 읽는다. 금칙어가 도배 판정 앞에 있는 것도 같은 이유다 — 오탐 한 번에 3초를 기다리게 하면, 막힌 이유를 모르는 사람은 그 3초 동안 같은 말을 다시 친다.

### 계정 상태를 매번 본다

WS Token 은 5분을 살고 연결은 그보다 오래 간다 — **발급 뒤 정지되거나 탈퇴한 사람의 경로가 남는다.** 닉네임을 조회하면서 `ACTIVE` 인지 함께 보고, 아니면 `MEMBER_ONLY` 다.

### 거부가 연결을 끊는다

`StompAuthChannelInterceptor` 가 allowlist 밖 `SEND` 에 예외를 던지면 ERROR 프레임과 함께 **세션이 닫힌다.** 의도한 동작이다 — 목록 밖으로 보내는 쪽은 공격자이거나 고장난 클라이언트이고, 조용히 버리면 후자는 자기가 깨진 줄 모른 채 계속 돈다.

**대가는 알고 있다.** 한 소켓이 상담 알림과 채팅을 함께 나르므로, FE 오타 하나가 둘 다 끊는다. 실제로 정상 클라이언트가 여기 걸리면 버리는 쪽(`preSend` 가 `null` 반환)으로 바꾼다 — 한 줄이다.

## 한계

- **단일 인스턴스 전제.** in-memory simple broker 라 서버를 둘로 늘리면 서로의 말이 보이지 않는다
- **월드 접속 여부를 보지 않는다.** "유효한 WS Token 을 가진 회원" 이면 월드 밖에서도 보낼 수 있다. 서버가 접속 상태를 모르기 때문이며(`-499` 범위), 지금 범위에서는 수용한다
- **금칙어 오탐이 남는다.** 예외 목록이 대표형만 덮는다 — `-아/어보지` 는 어미라 끝없이 만들어진다(`뛰어보지`·`물러보지` …). 보고되는 대로 한 줄씩 늘린다
- **예외 단어를 욕 사이에 끼우면 통과한다.** `씨class발` 이 그렇다. 예외를 지운 자리에 공백 하나를 남기기 때문인데, 그러지 않으면 반대로 멀쩡한 문장에서 없던 금칙어가 만들어진다(`씨class발` 의 `class` 를 빈 문자열로 지우면 `씨발` 이 된다). 우연히 막는 쪽보다 일부러 뚫는 쪽을 택했다
