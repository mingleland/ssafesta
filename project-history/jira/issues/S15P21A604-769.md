## 설명

### 작업 목적

타이밍 스톱의 소비자가 Unity 에서 FE 로 바뀌었는데(GitLab #166, 2026-09-10 확정 · FE 수신부 `!617` / `S15P21A604-601`), `S15P21A604-502` 를 만들 때 내가 쓴 근거 문장이 전부 Unity 를 가리킨 채 남아 있다. 2026-09-11 에 GitLab #134 에서 고치겠다고 적고 아직 안 했다.

`origin/develop` 실측 — Unity 언급 잔존:

```
specs/014-minigame/contracts/minigame-api.yaml   3건
specs/014-minigame/spec.md                        5건
specs/014-minigame/tasks.md                       1건
```

`MinigameController` 의 같은 문장은 `@Operation` description 에 들어 있어 **Swagger 문서에 그대로 노출된다.** 계약을 읽는 사람이 없는 소비자를 근거로 읽게 된다.

### 작업 내용

**동작은 바꾸지 않는다.** 문서·주석만 고친다.

1. `specs/014-minigame/contracts/minigame-api.yaml` — "배포된 Unity 클라이언트가 보내서 무시한다"(세션 발급 절·`SubmitCommand`), "Unity 의 429 분기", "Unity WebGL 의 IMGUI" 근거
2. `backend/.../minigame/MinigameController.java:62,80` — 같은 문장이 `@Operation` description 에 있다
3. `backend/.../minigame/TimerStopService.java:199,282-285` — `message` ASCII 근거 주석
4. `specs/014-minigame/spec.md:6` — 주 담당 `Unity + Backend` → `FE + Backend`
5. `specs/014-minigame/tasks.md:31` T013 — "WebGL IMGUI 한글 미표시 **또는 React 오버레이 검토**" 가 GitLab #166 · `-601` 로 확정됐으므로 닫는다

**그대로 두는 것 둘 — 근거만 고친다**

- **추가 필드 관용** (`targetSeconds`·`errorSeconds`·`timedOut`·`gameId` 를 받아만 두고 무시): 지금은 아무도 안 보내지만 거부로 바꾸면 호환만 깨지고 얻는 것이 없다
- `message` ASCII 유지: IMGUI 근거는 사라졌지만 FE 가 `resultCopy.ts` 로 자체 한글 문구를 만들고 서버 `message` 를 쓰지 않는다. 소비자가 없으니 한글로 바꿔도 화면에 뜨지 않는다. 주석의 근거만 "현재 소비자 없음 — 로그·디버깅용" 으로 고친다

**곁들여 — **`docs/26` 슬롯머신 행 갱신

GitLab #134 에서 약속한 것이다. 리드가 한 번에 보고 고를 수 있게 세 가지를 반영한다.

- 현재 Mock 실측값 정정 — 이슈 본문의 `낙첨 64% / ×2 25% / ×3 8% / ×5 3%, RTP≈89%` 는 옛 값이다. develop 의 `MockSlotMachineClient.cs:27-33` 은 `낙첨 78% · ×2 15% · ×3 5% · ×5 2% → RTP 0.55`
- 제안값 `×10 @0.8%` 의 미정 구간 — 기댓값 기여가 `0.008 × 10 = 0.08` 이라 RTP 0.504 를 맞추려면 나머지 셋이 0.424 를 나눠 가져야 하는데 그 조합이 하나가 아니다. **낙첨 포함 5줄 전부**가 있어야 구현한다
- 계약 형태 두 갈래 — `tier` 유지(Unity 변경 0) 대 `outcome` 채택(Unity DTO·연출 분기 수정)
