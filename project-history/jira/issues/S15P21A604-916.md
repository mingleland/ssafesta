## 설명

CharacterLobbyController.IsUsableAppearance 가 hairId/shoesId 와 상·하의를 모두 요구해, UI 에서 '없음' 으로 고른 뒤 저장한 외형을 불러오기에서 거부한다. 항목 그리드는 얼굴을 뺀 모든 카테고리에 '없음' 버튼을 제공하므로, UI 가 허용해 저장까지 되는 외형을 불러오기만 막는 상태다.

같은 게이트를 저장 외형 복원(LoadPersistedAppearanceAsync)·씬 핸드오프 복원·현재 외형 승계도 함께 쓰므로 그 경로에서도 같은 외형이 조용히 버려진다.

조치: 게이트를 headId != 0 으로 좁힌다. 얼굴에는 '없음' 버튼이 없어 headId == 0 은 모듈러 코드 디코드 실패를 뜻한다. 속옷 노출은 AvatarCatalog.EnsureRequiredClothing 이 한벌옷이 없을 때 상·하의를 기본값으로 채우므로 이미 막혀 있다.
