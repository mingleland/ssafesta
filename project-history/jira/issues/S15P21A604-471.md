## 설명

### 작업 목적

엘리베이터로 11F 에 들어가는 순간 11층 트랙(Algorithmic Morning) 대신 축제 트랙(Midnight Circus)이 약 0.3초 울리는 것을 없앤다.

### 원인

WorldBgm.Update 가 Camera.main 위치로 구역을 판정하는데, 로컬 플레이어가 스폰되기 전의 카메라는 원점(0,0,0)에 있다. 원점은 구역 판정상 복도라 t=InverseLerp(-110,100,0)=0.5238 이 되고 circus 가중치 0.1022 가 나온다. 프런트 실측(GitLab #140)의 gain 궤적과 일치한다.

### 작업 내용

- 구역 판정 기준을 카메라에서 로컬 플레이어(NetworkManager.LocalClient.PlayerObject)로 바꾼다. 카메라와 달리 스폰 전에는 아예 존재하지 않으므로 잘못된 좌표를 읽을 수가 없다.
- 위치를 모르는 동안(접속 전·스폰 전·연결 해제 후)에는 양쪽 트랙 모두 0 으로 수렴시킨다.
- 네트워크가 없는 씬 미리보기(에디터)에서만 카메라로 물러난다.
- scene 의 _morningVolume 값을 0.5 로 되돌린다. 0.1 은 무관한 커밋(f837aa0c 로비 소파 리모델)에 씬 저장으로 섞여 들어간 값이고 결정 기록이 없다. 0.1 에서 11F 실효 출력은 -36.8 dBFS 로 축제 부지(-22.4)와 14.4 dB 차이가 난다.

### 완료 조건

- 11F 진입 직후 첫 프레임부터 축제 트랙 gain 이 0 이다.
- 프런트가 화면 BGM 볼륨을 다시 맞출 수 있도록 바뀐 값을 GitLab #140 에 알린다.

### 테스트 방법

프런트가 쓴 방식대로 AudioSource gain 을 20ms 간격으로 샘플링해 11F 진입 궤적을 다시 잰다.
