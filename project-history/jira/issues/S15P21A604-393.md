## 설명

# 작업 목적

- 대화 편집기에서 화자/대사/선택지 텍스트를 입력할 때 focus를 유지한 채로도 즉시 반영되도록 하여 편집 경험 개선



# 작업 내용

- `DialogueEditor.tsx`에서 화자/대사/선택지 텍스트 입력에 쓰이는 `CommitInput` 사용처에 실시간 draft 값을 상위로 전달하는 콜백(`onDraftChange` 등) 추가
- LIVE PREVIEW 영역(화자명, 대사 텍스트, 선택지 버튼)이 draft 값을 즉시 반영하도록 상태 연결
- 좌측 노드 목록 요약 텍스트(`<small>{node.text}</small>`)도 draft 값 반영
- 실제 프로젝트 상태 커밋(undo/redo 히스토리 기록)은 기존과 동일하게 blur/Enter 시점에만 발생 — 변경 없음



# 완료 조건

- [ ] 화자/대사/선택지 텍스트 입력 시 focus 유지 상태에서 LIVE PREVIEW가 키 입력마다 즉시 갱신된다
- [ ] 좌측 노드 목록 요약 텍스트도 키 입력마다 즉시 갱신된다
- [ ] undo/redo 히스토리는 기존과 동일하게 blur/Enter 시점에만 기록된다 (회귀 없음)
