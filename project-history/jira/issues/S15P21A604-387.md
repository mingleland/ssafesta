## 설명

# 작업 목적

- Game Studio 에디터의 좌/중앙/우 패널이 전부 고정폭이라, 사용자가 구분선을 드래그해서  
   폭을 조절할 수 없는 문제(QA id 5)를 해결한다.



# 작업 내용

- `.gss-layout`(좌-중앙-우 3분할)에 좌↔중앙, 중앙↔우 두 구분선에 대한 드래그 리사이즈  
   UI를 신규 추가
- 각 패널 폭을 React state로 관리하고, `grid-template-columns`를 인라인 스타일로  
   덮어써서 렌더링(기존 고정 CSS 규칙 대체)
- 최소값: 좌 150px, 우 230px — 기존 반응형 브레이크포인트(1250px/1039px/760px)들 중  
   가장 작은 값으로 고정
- 최대값: 각 패널 기본폭 대비 +25% — 좌 226px→약 283px, 우 350px→약 438px
- 조절한 폭은 localStorage에 저장. 게임(gameId)별이 아니라 에디터 전역 키로 저장 —  
   패널 폭은 특정 프로젝트가 아니라 에디터 자체에 대한 개인 UI 선호도라고 판단
- 반응형 브레이크포인트 전환 시, 저장된 폭이 그 시점의 min/max 범위를 벗어나 있어도  
   레이아웃이 깨지지 않도록 렌더링 폭을 항상 clamp



# 완료 조건

- [ ] 좌↔중앙, 중앙↔우 구분선을 마우스로 드래그해서 각 패널 폭을 조절할 수 있다
- [ ] 각 패널의 폭은 최소값(브레이크포인트 중 가장 작은 값 고정)과 최대값(기본폭의 +25%) 사이로 제한된다
- [ ] 조절한 폭은 localStorage에 저장되어 새로고침 후에도 유지된다
- [ ] 반응형 브레이크포인트 전환 시에도 레이아웃이 깨지지 않는다
- [ ] 포커스 모드(`is-focus-mode`, 사이드바 숨김)와 함께 써도 이상 없다



# 선행 작업 / Dependency

- 없음



# 테스트 방법

1. 좌↔중앙 구분선을 드래그해 좌측 사이드바 폭이 실제로 늘어나는지 확인
2. 중앙↔우 구분선을 드래그해 우측 패널 폭이 실제로 늘어나는지 확인
3. 각 방향으로 최소값 이하/최대값 이상으로는 움직이지 않는지 확인
4. 폭 조절 후 새로고침(F5)해도 조절한 폭이 유지되는지 확인(localStorage)
5. 브라우저 창 폭을 줄여 반응형 브레이크포인트를 넘을 때 레이아웃이 깨지지 않는지 확인
6. 포커스 모드와 함께 써도 이상 없는지 확인
