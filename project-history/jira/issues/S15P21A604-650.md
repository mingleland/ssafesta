## 설명

h3. 증상

2026-09-11 14:40 develop 파이프라인 189742 failed. MR !705 에서 3회 연속 같은 테스트만 실패 — 코드 변경 무관.

{code}
FAIL gameStudioShellMultiAssetUpload.test.tsx > 자산 300개 상한에 도달하면 상한까지만 처리하고 초과분은 실패로 안내한다
Error: Test timed out in 5000ms.
{code}

S15P21A604-630(박준우, 오늘 11:20 develop)이 넣은 테스트다. develop 자체가 red 라 모든 MR 이 막힌다.

h3. 원인

#168(S15P21A604-626)과 같은 계열 — 절대 시간 예산에 걸리는 무거운 기능 테스트. 이미 O(n²)는 피해 뒀지만(테스트 주석), 298개 자산 프로젝트를 마운트하고 업로드 5건을 순차 처리하며 각 건마다 parseGameProject 가 자산 전체를 검증한다.

로컬 22코어 5회: 2313 · 1927 · 2063 · 2158 · 2074 ms. CI 가 로컬의 2~4배면 4~9초 — 5000ms 경계에 걸린다. 3회 연속 실패이므로 flaky 가 아니라 결정적이다.

h3. 수정 — 이 케이스만 timeout 상향

{{it(..., { timeout: 15_000 })}} — 로컬 최대 2.3초의 6.5배. 기능 테스트라 timeout 은 성능 계약이 아니고, 검증 내용(상한까지만 처리·초과분 실패 안내)은 그대로다. 전역 testTimeout 은 건드리지 않는다.
