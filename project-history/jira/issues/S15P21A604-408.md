## 설명

## 작업 목적

- 점프 키를 얼마나 오래 누르느냐에 비례해서 점프 높이가 달라지도록(마리오 스타일 가변 점프) 개선 — 지금은 짧게 탭하나 길게 누르나 항상 같은 높이로 점프됨

## 작업 내용

- `ReferenceRuntimeState`에 `jumpHoldTicks: number` 필드 추가 — 진행 중인 점프의 유지 틱 수(0이면 점프 중 아님)
- `platformerJumpFrom`을 "점프 시작"(그라운드에서 UP 새로 눌림 → 1칸 상승 + `jumpHoldTicks = 1`)과 "점프 유지"(공중이고 UP이 계속 눌려 있고 `jumpHoldTicks < 4`면 1칸 더 상승 + `jumpHoldTicks` 증가)로 분리 — `movePlayerFromHeldKeys`에서 매 틱 판단
- UP을 놓거나 `jumpHoldTicks`가 4에 도달하면 그 순간부터 `tickReferenceWorld`의 기존 중력 하강 로직(현재도 있는 감속 하강 적분)으로 전환, 전환 시점에 `jumpHoldTicks`를 0으로 리셋
- `jumpHoldTicks > 0`인 동안은 `tickReferenceWorld`의 자동 상승 처리를 건너뛰어, 트리거 틱에 두 번 상승하던 기존 구조와 겹치지 않게 함
- 결과: N틱 홀드 시 N칸 상승(1~4, 선형비례), 4틱 이상 유지해도 4칸(=현재 점프 높이)에서 상한, 아주 짧은 탭도 최소 1칸은 상승

## 완료 조건

- [ ] UP을 짧게 탭하면 낮게, 길게(최대 4틱) 유지하면 지금과 동일한 최대 높이(4칸)까지 선형 비례로 점프한다
- [ ] 4틱을 넘겨 눌러도 더 높이 올라가지 않는다(현재 높이가 새 상한)
- [ ] 상승 도중 UP을 놓으면 그 즉시 자연스럽게 하강으로 전환된다
- [ ] 좌우+점프 동시 입력(대각선 점프), 발판 가장자리에서의 대각선 점프 등 기존 PLATFORMER 동작에 회귀가 없다
