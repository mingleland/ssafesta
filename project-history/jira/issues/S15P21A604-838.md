## 설명

S15P21A604-450에서 Tab 잠금을 넣을 때 HUD 버튼 간 키보드 이동(Tab) 접근성을 지키려고 실제 Unity canvas가 keydown 타깃일 때만 preventDefault 하도록 좁혔다. 그런데 실제 요구는 반대다 — 월드 화면에서는 Unity가 Tab을 전담해야 하고, 웹(DOM) 쪽 Tab 탐색은 막아야 한다.

변경 대상: festa-frontend/src/pages/world/WorldPage.tsx의 Tab 잠금 useEffect. getWorldScreen() === 'world'인 동안에는 keydown 타깃과 무관하게 Tab을 preventDefault해서 브라우저 기본 포커스 이동을 막는다. ESC 메뉴 등 다른 화면이 주인일 때는 그대로 둔다(그 안에서는 Tab으로 항목 이동해야 하므로).

주의: 이 변경은 -450에서 의도적으로 만든 HUD 버튼 간 Tab 키보드 접근성을 되돌린다 — 제품 결정으로 확인됨.
