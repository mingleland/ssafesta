## 설명

## 발생 환경

- Branch: develop (game-studio 최신)
- Build: 로컬 개발 서버 (VITE_USE_MOCK=true, 브라우저 로컬 저장소 모드)
- Browser / OS: Chrome, Windows 11
- Account: 해당 없음 (로컬 Mock 인증)

## 재현 방법

1. Game Studio 편집기에서 대화(Dialogue) Scene을 하나 연다.
2. 오른쪽 "데이터" 탭에서 "이미지 추가"로 정상 비율의 사진(스프라이트 시트가 아닌, 세로/가로 어느 쪽이든 일반 사진 1장)을 업로드한다.
3. 대화 노드의 "인물 이미지 / 표정"에서 방금 올린 이미지를 선택한다.
4. 에디터 라이브 프리뷰 또는 "플레이 테스트"로 해당 노드를 확인한다.

## 기대 결과

- 업로드한 원본 사진의 가로세로 비율 그대로 인물 이미지가 표시된다.

## 실제 결과

- 인물 이미지가 가로 방향으로 눌린 것처럼 찌그러져 표시된다. 원본 파일 자체는 정상 비율인데도 발생한다.
- 빌트인 인물 이미지(4×3 스프라이트 시트 기반)는 정상적으로 보이고, 커스텀(직접 업로드한) 이미지에서만 재현된다.

## 로그 / Screenshot

- 재현 화면 캡처는 별도 첨부 예정.
- 코드 기준 원인 위치는 확인 완료:
   
   - `festa-frontend/src/game-studio/studio/assets/staticImageVisual.ts` — `staticImageBackgroundStyle()`가 이미지 종류와 무관하게 `backgroundSize: '${columns*100}% ${rows*100}%'`를 계산. 커스텀 단일 이미지는 `columns:1, rows:1`로 취급돼 `100% 100%`(비율 무시하고 박스에 강제로 채우기)가 됨.
   - `festa-frontend/src/game-studio/studio/ui/GameStudioShell.css:740`(`.gss-dialogue-preview-portrait`), `festa-frontend/src/game-studio/runtime/reference/ReferenceGamePlayer.css:137`(`.grp-dialogue-portrait`) — 두 박스 모두 `aspect-ratio: 1/2`로 고정.
   - 이 `1/2` 값은 빌트인 시트 한 칸(256×512px)의 비율과 맞춘 값이라, 그 비율과 다른 일반 사진을 "채워서 늘리기"로 넣으면 가로가 눌려 보임.

## 관련 Issue

- S15P21A604-406 (당시 반대 방향 왜곡 — 인물 이미지가 가로로 "늘어나" 보이던 문제를 `aspect-ratio: 1/2` 고정으로 해결. 이번 결함은 그 수정이 커스텀 이미지 케이스를 고려하지 않아 생긴 재발 성격)

## 완료 조건

- [ ] 커스텀(단일 파일) 인물 이미지가 에디터 라이브 프리뷰에서 원본 비율대로 표시된다
- [ ] 커스텀 인물 이미지가 실제 플레이(런타임)에서도 원본 비율대로 표시된다
- [ ] 빌트인 4×3 시트 인물 이미지는 수정 전후 동일하게 표시된다 (회귀 없음)
- [ ] `staticImageBackgroundStyle`을 공유하는 다른 화면(배경, 맵 스프라이트, 팔레트 썸네일 등)은 영향받지 않는다
- [ ] 세로로 긴 사진 / 정사각형 사진 / 가로로 넓은 사진 각각으로 테스트했을 때 전부 원본 비율이 유지된다
