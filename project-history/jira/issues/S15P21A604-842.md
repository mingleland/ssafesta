## 설명

S15P21A604-836(BE 이벤트 상점) 계약 확인 완료. 방문객용 Overlay(EventRewardShopOverlay, 현재 PREPARING 하드코딩 상태)를 실제 API에 연결한다.

즉시교환 — 실 연동:
- GET /api/v1/event-shop/prizes → { prizeId, name, priceCoin, stock, active }
- POST /api/v1/event-shop/purchases (헤더 Idempotency-Key: UUID, 클릭마다 새로 생성해 재시도 시 재사용) → { prizeId, quantity? }
- 응답: { purchaseId, prizeId, prizeName, quantity, coinSpent, fulfillment, purchasedAt }
- 에러: 400 VALIDATION_FAILED, 403 MEMBER_ONLY, 404 EVENT_PRIZE_NOT_FOUND/WALLET_NOT_FOUND, 409 EVENT_PRIZE_INACTIVE/EVENT_PRIZE_OUT_OF_STOCK/INSUFFICIENT_COIN/IDEMPOTENCY_CONFLICT 화면에 노출
- 프리즈 응답에 이미지 URL이 없다 — 상품명↔이미지 매핑은 FE 정적 테이블로 처리

응모권 — 이번 스코프 아님, mock으로 유지:
- 백엔드에 대응 API 없음(-836 스펙에 추첨/응모 개념 없음). 담당자 확인 결과 추후 BE에 추가 예정
- 그때까지 UI는 두되 mock adapter로 동작(-828 admin 콘솔의 미도달 계약 mock 패턴과 동일한 방식). 실 계약 나오면 이 이슈 후속으로 교체

디자인은 세션에서 합의한 mockup 레이아웃 기준 — 기존 overlay 톤(--ov-* 토큰, OverlayFrame/OverlayCardGrid) 그대로 재사용, 카드 구성은 이미지 좌측 큰 사진 + 우측 이름/코인/재고(+응모권은 마감카운트다운)/버튼 세로 나열.
