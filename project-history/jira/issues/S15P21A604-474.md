## 설명

CiBuild.BuildWeb 은 Development 와 API 환경은 강제하는데 WebGL 압축은 지정하지 않는다. 그래서 커밋된 ProjectSettings 값이 그대로 배포본에 실린다.

현재 커밋값:

- webGLCompressionFormat: 2 (Disabled)
- webGLDecompressionFallback: 0 (OFF)

즉 Jenkins 가 CiBuild 로 뽑는 배포 산출물은 비압축이고 폴백도 없다. GitLab #127 에서 인프라(정승욱)가 임시 산출물을 최종 배포본으로 쓸 수 없다고 한 사유 네 가지 중 하나가 이것이다.

메뉴 빌더(FestaReleaseBuilder)는 Brotli + Decompression Fallback 을 켜고 finally 로 복원한다. 그 지식이 CI 경로에는 없다. 사람이 메뉴로 뽑으면 맞고 CI 가 뽑으면 틀리다.

Brotli 만으로는 부족하다. 정적 서버가 Content-Encoding: br 을 붙여 줘야 로드되는데, 헤더가 없는 경로에서는 Fallback 이 있어야 산다. 그래서 둘을 같이 켠다.

수정: CiBuild.BuildWeb 이 Brotli + Fallback 을 명시로 강제하고 finally 로 이전 값을 되돌린다. ApiConfig 환경을 강제하고 되돌리는 기존 관용구와 같은 모양으로 둔다.

검증: 배치모드로 뽑은 산출물의 Build 폴더에 .br 확장자가 있고 index.html 에 폴백 경로가 들어 있는지 확인한다.
