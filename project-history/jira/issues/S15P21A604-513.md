## 설명

## 작업 목적

대화 씬 편집기(`DialogueEditor.tsx`)에서 좌측 NODES rail이 보여주는 정보(화자/대사 요약, START 배지)가 FLOW OVERVIEW 섹션이 보여주는 정보(같은 요약 + 도달 가능 여부 + 선택 후 결과)의 완전한 부분집합이라 정보가 중복 표시되고 있음(Notion QA id=34). NODES rail을 없애고 그 기능(드래그 정렬/시작 설정/삭제)을 FLOW OVERVIEW에 통합하며, 자주 참조하는 상단 정보(씬 이름, 흐름 개요)를 스크롤과 무관하게 화면 상단에 고정한다.

## 작업 내용

- NODES rail(`aside.gss-node-rail`) 전체 제거
- FLOW OVERVIEW(`.gss-dialogue-flow`)의 각 행에 드래그 핸들(☰)/"시작으로 설정"(★)/삭제(×) 이식 — 기존 NODES rail이 쓰던 `reorderDialogueNode`/`setStartNode`/`removeDialogueNode` 로직 그대로 재사용(`analyzeDialogueFlow`의 반환 순서가 `scene.nodes` 원본 배열 순서와 동일함을 확인해 인덱스 충돌 없음)
- FLOW OVERVIEW 항목의 번호 배지(`{index+1}`) 제거 — 드래그로 순서가 바뀌는 목록에 고정 번호를 붙이면 S15P21A604-494에서 NODES rail에 있었던 것과 같은 오인 문제가 생기므로 같은 이유로 뺌
- `DialogueEditor`의 2단 레이아웃(rail + editor)을 1단으로 정리
- "DIALOGUE SCENE" 헤더 + "FLOW OVERVIEW" 섹션을 하나의 상단 고정(sticky) 영역으로 묶고, 그 아래(LIVE PREVIEW / NODE 카드 / 선택지)는 독립적으로 스크롤되도록 레이아웃 변경
- FLOW OVERVIEW 목록 자체는 상단 고정 영역 안에서 무한정 커지지 않도록 내부 스크롤 유지(계약상 씬당 최대 300개 노드까지 허용)
- 계약(`contracts/gameProject.ts`) 변경 없음 — 순수 UI/레이아웃 정리

## 완료 조건

- [ ] NODES 사이드바가 화면에서 사라진다
- [ ] FLOW OVERVIEW 각 행에서 드래그로 순서를 바꿀 수 있다
- [ ] FLOW OVERVIEW 각 행에 "시작으로 설정"/"삭제" 기능이 있고, 기존 차단 규칙(시작 노드/참조 중/마지막 1개)이 그대로 적용된다
- [ ] FLOW OVERVIEW에 번호가 더 이상 표시되지 않는다
- [ ] 씬 헤더 + FLOW OVERVIEW가 화면 상단에 고정되어 스크롤해도 움직이지 않는다
- [ ] LIVE PREVIEW 이하(NODE 카드, 선택지)만 스크롤된다
- [ ] 관련 테스트 통과 + `tsc --noEmit` 통과
