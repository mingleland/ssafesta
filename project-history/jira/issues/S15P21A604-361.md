## 설명

# 작업 목적

- 편집기에서 특정 Scene을 시작 Scene(START)으로 지정/변경할 수 있게 한다.



# 작업 내용

- authoringCommands.ts에 startSceneId를 바꾸는 커맨드 함수 신설(현재 GameStudioShell.tsx:887 배지 표시, authoringCommands.ts:215 삭제 가드에서만 읽고 쓰는 곳 없음)
- Scene 목록/에디터에 “시작 Scene으로 설정” UI 추가



# 완료 조건

- [ ] Scene 목록에서 임의의 Scene을 시작 Scene으로 지정할 수 있다
- [ ] 지정한 Scene에 시작 배지가 표시된다
- [ ] 변경 사항이 저장·재로드 후에도 유지된다
- [ ] 삭제 가드(시작 Scene 삭제 방지)가 계속 정상 동작한다



# 테스트 방법

- Scene 2개 이상 있는 프로젝트에서 시작 Scene이 아닌 Scene을 선택 → 시작 Scene으로 지정 → 배지 이동 확인 → 저장·재로드로 유지 확인 → 새 시작 Scene 삭제 시도 시 가드 동작 확인.
