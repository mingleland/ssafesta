## 설명

로그인 화면에서 BGM 을 끄고 월드에 들어가면 소리가 다시 난다. 월드 안에는 끄는 수단이 없어 탭을 닫는 것 말고 방법이 없다 (게임 파트 보고, GitLab #151).

원인: 오디오 소유권 이관(-463, MR !350)이 재생·볼륨 축만 다루고 사용자의 mute 선호를 Unity 로 넘기는 경로를 만들지 않았다. screenAudio.ts 가 festa.settings.music.muted 를 유지하지만 소비자가 화면 안에만 있다.

Unity 수신부는 이미 있다 — AudioBridge (게임 파트 커밋 f7b6258f, AuthBridge·InputBridge 와 같은 규약). FE 가 보내기만 하면 된다.

[범위]
- React muted 상태 → Unity AudioBridge.SetMuted
- Unity instance ready 직후 현재 상태 1회 전달
- mute 상태 변경 시 재전달
- 기존 BGM volume 정책은 건드리지 않는다

[범위 밖]
- SetVolume 및 7 dB 볼륨 튜닝 — -463 · GitLab #140 축이다
- Unity 코드 수정 (festa-unity 무변경)

[완료 조건]
1. Unity 인스턴스 준비 직후 현재 mute 값이 1회 전달된다
2. 이후 mute 변경마다 AudioBridge.SetMuted("1"|"0") 가 전달된다
3. 인스턴스 미준비 상태에서 SendMessage 를 호출하지 않는다
4. AuthBridge·InputBridge 기존 동작에 회귀가 없다
5. 이번 diff 에 SetVolume 관련 추가·변경이 0건이다

완료 조건 5개 충족 + MR 이 develop 에 반영되면 구현 완료다. 실 WebGL 왕복(화면에서 mute → 월드 진입 → 무음 유지)은 로컬 통합 스택이 필요하므로 별도 acceptance 로 분리한다 — 그래서 Closes 를 쓰지 않는다.
