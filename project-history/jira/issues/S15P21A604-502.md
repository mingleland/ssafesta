## 설명

작업 목적

docs/08 §14 의 POST /minigames/{gameType}/sessions 와 POST /minigames/{gameType}/results 를 구현한다. spec 014 는 있으나 BE 티켓이 없었다.

작업 내용

- 세션 발급: 1회용 세션을 만들고 재사용을 막는다.
- 결과 제출: 멱등하게 받고, 같은 세션의 재제출이 보상을 두 번 주지 않게 한다.
- Coin 보상은 서버 로직에서만 계산한다. 클라이언트가 금액이나 지급 대상을 지시할 수 없다 (헌법 16조, specs/003-wallet-coin/contracts/wallet-api.md 에 차감 API 를 두지 않는 것과 같은 이유).
- 결과 payload 는 GitLab #134 에 올린 BE 요청(목표·정지 시각·오차)을 따른다.

완료 조건

- 같은 세션으로 두 번 결과를 제출해도 보상이 한 번만 지급된다.
- 클라이언트가 보낸 점수·보상액을 그대로 신뢰하지 않는다.
- 없는 gameType 요청이 거부된다.

선행 작업 / Dependency

- GitLab #134 회신. 서버 권위 판정 범위(슬롯머신 스핀·타이밍 스톱)가 아직 확정되지 않았고 그 이슈에 코멘트가 0건이다.
- S15P21A604-294 (Unity 쪽 결과 서버 전달 — 목표·정지 시각·오차 payload)

참고

- docs/08_Backend_API_명세서.md §14
- specs/014-minigame/spec.md, plan.md, tasks.md
- specs/003-wallet-coin/contracts/wallet-api.md (차감·지급 규칙)

비고

spec 019 Game Studio 와는 별개 기능이다 (specs/019-game-studio/spec.md 21행: 019 는 사용자 제작 웹 2D UGC, 014 는 Unity 관리자 부스의 타이머 정지 게임 1종).
