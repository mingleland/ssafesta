## 설명

h3. 현상 (2026-09-06 Development WebGL, -207 QA 중 발견)

아바타 1기를 조립할 때마다 브라우저 console 에 error 4줄:

{code}
Material 'mat_eyelashes' with Shader 'Unlit/Color' doesn't have a texture property '_MainTex'
Material 'mat_eye_highlight' with Shader 'Shader Graphs/Rukha93/ShaderGraph_ToonBasic' doesn't have a texture property '_MainTex'
{code}

Development build 은 error 가 있으면 화면 좌하단에 console 을 그리는데, 그것이 로비의 "월드 입장" button 위를 뒤덮어 click 이 막혔다(IMGUI 가 event 를 소모). release build 에서는 화면 console 이 없어 가림은 없지만 console spam 은 그대로다.

h3. 원인

{{AvatarAssembler}} 가 소스 material 의 {{mainTexture}} 를 읽는다. Unity 는 shader 에 {{_MainTex}} 가 없으면 **읽기만 해도** error 를 남긴다. vendor eyelash(Unlit/Color), eye highlight(ToonBasic) material 이 그 경우.

h3. 수정

{{HasProperty("_MainTex")}} 일 때만 읽고 없으면 null ({{MainTextureOrNull}}). 동작 변화 없음 — 이전에도 그 material 은 texture 없이 진행되었다.

h3. 검증

editor Host Play: avatar 조립(modular=True, renderer 26) 후 console error 0.
