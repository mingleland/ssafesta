## 설명

## 증상

캐릭터 커스터마이징(CharacterLobby)에서 월드로 입장하면 **엘리베이터 게이트가 뜨지 않고** 월드가 그대로 보인다. 접속까지 실패하면 축제 통로(나무 벽·자갈 바닥) 화면이 뜬다.

## 원인 — 등록 훅을 잘못 골랐다 (내 결함)

`WorldEntryGate.AutoStart` 가 `[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterSceneLoad)]` 로 걸려 있다.

```csharp
[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterSceneLoad)]
static void AutoStart()
{
    if (SceneManager.GetActiveScene().name != AvatarSceneHandoff.WorldSceneName)
        return;                       // ← 여기서 항상 빠져나간다
    ...
}
```

이 훅은 **앱 기동 시 첫 씬이 로드된 직후 딱 한 번** 돈다. 빌드의 첫 씬은 `CharacterLobby` 이므로 이름 검사에서 걸러지고, 이후 `main` 으로 넘어가도 훅이 다시 돌지 않는다. → **게이트가 영원히 생성되지 않는다.**

## 왜 여태 못 잡았나

게이트 검증을 전부 `main.unity` 에서 직접 Play 로 했다. 그 경우에만 훅 시점의 활성 씬이 `main` 이라 게이트가 생긴다. **실사용자가 절대 타지 않는 경로에서만 검증한 것**이고, "개방 3경로 검증됨" 보고는 그 잘못된 시나리오 안에서만 참이었다.

교훈: 진입 흐름이 있는 기능은 **진입점부터** 검증해야 한다. 대상 씬에서 Play 를 누르는 것은 검증이 아니다.

## 실측

에디터에서 `CharacterLobby` 로 Play 시작 → 월드 입장:

```
씬 = main
WorldEntryGate 개수 = 0     ← 게이트 없음
IsConnected = True
활성 카메라 = Main Camera pos=(-29.50, 26.87, -268.05)
```

(스폰 좌표 자체는 정상이다 — 엘리베이터 정면 확인됨)

## 고칠 방향

`AfterSceneLoad` 훅 대신 **씬 로드마다 도는 지점**으로 옮긴다. `SceneManager.sceneLoaded` 구독(`SubsystemRegistration`/`BeforeSceneLoad` 에서 1회 등록) 이 자연스럽다. 이미 있는 중복 생성 가드(`FindFirstObjectByType<WorldEntryGate>() != null`)는 그대로 유효하다.

캐릭터 커스터마이징 → "월드 입장" 실경로로 확인:

```
[WorldEntryGate] 개방 — 준비 완료 (1.2s)
```

타임아웃 강제 개방이 아니라 **정상 "준비 완료" 경로**로 열렸다. [[S15P21A604-313]] 도 같은 빌드에서 확인 — `CLIENT connected`, 아바타 스폰·카메라 추적 정상, `ConnectionApprovalCallback` 예외 0건.

같은 검증 과정에서 발견된 월드 렌더링 붕괴는 이 건과 무관한 별건이었고 [[S15P21A604-316]] 에서 해결했다 (게이트를 완전히 끈 빌드에서도 재현돼 무관함이 확인됨).
