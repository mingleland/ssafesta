## 설명

## 목적

EC2 확보 후 OCI에서 검증한 구성을 x86_64 환경에 재구축하고, 데이터와 배포 경로를 확인한 뒤 OCI 임시 자원을 안전하게 정리한다.

## 작업 범위

- EC2 OS·CPU·메모리·디스크·Security Group 확인
- OCI 설정과 EC2 설정 차이 기록
- OCI ARM 이미지를 복사하지 않고 EC2에서 소스 기반 재빌드
- PostgreSQL 데이터 이관·복구 검증
- Redis는 영구 데이터로 이관하지 않고 재생성
- Nginx·Spring·FastAPI·Unity 서버 실행 검증
- 도메인·TLS 적용 후 HTTPS/WSS 검증
- OCI 백업·보존 대상을 확인한 뒤 임시 리소스 철거

## 완료 조건

- [ ] EC2에서 필수 Compose 서비스 기동
- [ ] PostgreSQL 데이터 정합성 확인
- [ ] Web/API/AI/Unity 사용자 경로 검증
- [ ] HTTPS 페이지에서 WSS 연결 확인
- [ ] EC2 정상 동작 및 복구 근거 확보 후에만 OCI 철거
- [ ] 철거 대상과 복구 가능 여부 기록
- [ ] 실제 Secret·토큰이 이슈와 저장소에 없음

## 주의사항

OCI 철거는 EC2 검증 전 수행하지 않는다. Redis 데이터는 유실 허용 경계만 사용하며 영구 데이터 이관 대상으로 간주하지 않는다.
