## 설명

### 작업 목적

S15P21A604-107 이 develop 에 남긴 문서 검사 실패 2건을 닫는다. GameAssetController 에 Swagger 주석이 아예 없어 endpoint 3개가 OpenApiDocumentationTest 를 깬다. 현재 develop 은 724건 중 2건 red 다.

### 실패 내용

`everyOperationExplainsItself` — summary·description 없음

- `POST /api/v1/games/{gameId}/assets`
- `POST /api/v1/games/{gameId}/assets/{assetId}/complete`
- `GET /api/v1/games/{gameId}/assets/{assetId}/content`

`everyOperationSitsUnderADeclaredTag` — 선언되지 않은 태그 `game-asset-controller` (같은 3개)

### 작업 내용

- GameAssetController 3개 endpoint 에 `@Operation(summary, description)` + 4xx `@ApiResponse`
- OpenApiConfiguration 태그 목록에 `Game Asset` 추가 + 클래스에 `@Tag`
- `401` 과 오류 봉투 `$ref` 는 OpenApiConfiguration customizer 가 자동으로 붙인다 — 컨트롤러에 적지 않는다
