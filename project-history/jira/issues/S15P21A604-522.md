## 설명

## 작업 목적

- 대화 씬 편집 시 우측 속성/이벤트/데이터 패널에 유용한 정보가 거의 없어(속성 탭: 표시방식/노드 수/시작 노드 정도, 이벤트 탭: 안내 카드 하나) 화면 공간만 차지하는 문제를 해결한다.
- 맵 씬에서는 이 패널이 오브젝트 속성·이벤트 편집에 필수적이므로 삭제하지 않고, 씬 타입에 따라 접었다 펼 수 있는 토글 기능으로 양쪽을 다 만족시킨다.

## 작업 내용

- 우측 구분선(`.gss-panel-divider`, side='right')에 접기/펼치기 화살표(‹/›) 버튼을 추가한다. 구분선이 이미 `position: relative`라 버튼을 그 위에 절대 위치로 얹으면 폭 드래그 시 자동으로 같이 움직인다.
- 씬별 우측 패널 접힘 상태를 관리하는 state를 추가한다(`Record<sceneId, boolean>`, 브라우저 세션 한정 — 새로고침엔 남고 탭을 닫으면 사라지는 형태).
- 아직 저장된 상태가 없는 씬은 씬 타입 기본값을 따른다: TOP_DOWN/PLATFORMER → 펼침, DIALOGUE → 접힘(새로 추가한 씬 포함, 즉시 적용).
- 접힌 상태일 때는 우측 grid 컬럼(`--gss-right-width`) 폭을 0으로 만들어 패널 내용을 완전히 숨기되(포커스 모드와 동일한 방식), 구분선(6px)과 그 위 버튼은 그대로 유지해 계속 클릭 가능하게 한다.
- 접힌 상태에서는 구분선 드래그(폭 조절)를 무시하고, 버튼 클릭으로만 펼쳐지게 한다.
- 기존 패널 폭 조절 기능(`panelWidths`, localStorage 저장)과는 별개 개념으로 두어 충돌 없이 함께 동작하게 한다.

## 완료 조건

- [ ] 우측 구분선에 접기/펼치기 화살표(‹/›) 버튼이 추가된다
- [ ] 버튼 클릭 시 우측 패널(속성/이벤트/데이터)이 접히고, 접힌 상태에서도 구분선+버튼은 계속 보이고 클릭 가능하다
- [ ] 접힌 상태에서는 캔버스 영역이 그만큼 넓어진다
- [ ] 맵 타입 씬은 기본 펼침, 대화 타입 씬은 기본 접힘 상태로 시작한다(새로 추가한 씬 포함)
- [ ] 씬별 접힘/펼침 상태가 씬을 오갈 때 같은 브라우저 세션 내에서 유지된다
- [ ] 접힌 상태에서 구분선을 드래그해도 폭 조절이 되지 않는다(클릭으로만 펼침)
- [ ] 기존 패널 폭 조절(panelWidths, localStorage 저장) 기능과 충돌 없이 동작한다
