## 설명

2.5D 조사·논의 결과를 정본 문서 하나로 통합하고, 계약 변경이 필요 없는 FE 내부 범위(Asset Library 구조 전환, Booth Template)를 착수한다.

정본 문서: docs/LJH/ui-design/04_prototypes/booth-studio-2_5d-canonical-design.md

이번에 확정하는 것
- Asset Domain / UI Category / ObjectType 세 축 분리
- canonical assetCode 명명 규칙과 실제 후보 전체 표 (Booth Interior 28종 + Facade 18종)
- 기존 충돌 해소 (DECORATION_DEFAULT 중복, FURNITURE 타입 기본 불일치)
- 좌측 Asset Library 를 runtime manifest + 실제 thumbnail 소비 구조로 전환
- Booth Template — 기존 assetCode 조합 recipe. 새 3D 자산이 아니다
- Runtime Manifest v2 (domain + booth/facade 블록)

범위 밖 (타 파트 합의 선행)
- Layout 계약 assetCode 범위 확장 (현재 FURNITURE·DECORATION 한정)
- facadeAssetCode 저장 필드
- Spring 부스 카탈로그 seed
- Unity Registry 데이터 채우기

기준 develop 21c5a4be (S15P21A604-527 다중 재질 · -550 테스트 안정화 반영 후).
