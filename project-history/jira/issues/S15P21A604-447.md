## 설명

### 증상

월드 화면 우상단에 IMGUI 버튼 `Customize (C)` 가 모든 사용자에게(릴리스 포함) 떠 있고, AI 도우미 이름표를 가린다. C 를 누르면 옛 'Character Creator' 안내 패널이 열린다. 2026-09-06 09:40 WebGL 검증 스크린샷에서 발견했다.

### 판단

아바타 커스터마이징은 로비와 React 오버레이 전용이다(avatar-customization-contract.md). 이 HUD 는 남은 데모 흔적이다.

### 조치

컴포넌트는 에디터 전용으로 남기고(`Application.isEditor`), 빌드에서는 버튼도 C 키도 동작하지 않게 한다.

### 관련 파일

`Scripts/World/Avatar/AvatarCustomizationHud.cs`
