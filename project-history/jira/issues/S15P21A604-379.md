## 설명

확정된 Landing/Login 이미지 자산(landing-background.png·login-background.png·ssafesta-logo.png)을 사용해 실제 브라우저 화면의 reference fidelity를 검증한다.

범위:
- Landing 화면 신규(배경 자산 + 로고 + 시작 인터랙션). 게임 타이틀 화면 문법 — navbar/header 없음
- LoginPage restyle — 기존 provider registry(-366)·auth 흐름(-53) 동작 보존, 중앙 로그인 패널만 React UI
- 자산은 CSS/SVG로 재현하지 않고 이미지 그대로 사용, 로고 원본 비율 유지
- Playwright 데스크톱 viewport 5종(1920·1600·1440·1366·1280) 실측과 reference(landing.png·login.png) 대비 보정

제외: Foundation 토큰 확정, GameShell, OAuth semantics 변경, 모바일 대응(Desktop-first, D-02)

MR !349 머지 완료 (develop). reference fidelity 작업에서 들어간 회귀 2건.

[1. 저해상도 넘침]
패널 시작점 58.8% 는 레퍼런스 비율이지만 그 아래 패널·푸터가 들어갈 높이가 없으면 패널이 푸터를 뚫는다. vh 500 에서 푸터와 67px 겹치고 게스트 버튼이 뷰포트 밖으로 나갔다.
min(58.8%, calc(100% - 300px)) 으로 바꿈 — 임계는 vh 728 이고 그 이상에서는 58.8% 가 그대로 나온다.

실측 (패널 시작점 / 푸터 여유, 음수 = 겹침):
  vh 500  40.00% / +28px  (이전 -67px)
  vh 720  58.33% / +10px
  vh 800  58.80% / +32px  무변화
  vh 900  58.80% / +47px  무변화
  vh 1080 58.80% / +64px  무변화
1920x1080 에서 버튼 4종 x 38.8% · w 22.4% · y 58.8/66.7/74.59/82.49% 는 기존 확정값과 같다.

[2. SSAFY 라벨 정렬]
준비 중 배지가 flex 항목이라 SSAFY 버튼에서만 라벨 가용 폭이 줄어 글자가 왼쪽으로 밀렸다. 배지를 absolute 로 흐름에서 빼 네 버튼의 라벨 중심 오프셋이 모두 +6px 로 같아졌다.

[검증] vitest 586/586 · tsc 0 · oxlint 신규 경고 0

[남은 acceptance — Closes 미사용 사유]
login.png 에 맞는 배경 원본 크롭 확보 후 fidelity 재대조가 남아 있다. vh 500 에서 패널 상단이 로고 bounding box 와 9px 겹치는데, 로고 PNG 의 투명 여백 안이라 시각적으로는 떨어져 보인다 — 그 크롭이 들어오면 함께 재대조한다.
