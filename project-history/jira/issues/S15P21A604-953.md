## 배경

사용자 요청 3건을 한 이슈로 묶는다.

## 1. 코인 지급 안내 유실 수정 (버그)

`coinGrantNotification.ts` 주석에 이미 명시된 알려진 유실: 구독 전에 발행된 지급(가입 INITIAL_GRANT, 첫 접속 DAILY_GRANT)은 STOMP 재전송이 없어 토스트가 안 뜬다. 현재는 구독 후 REST catch-up으로 잔액만 조용히 맞추고 토스트는 안 띄운다.

- 수정: catch-up REST 조회에서 아직 안 본 INITIAL_GRANT/DAILY_GRANT 건이 있으면 동일한 토스트(`showToast`)를 띄운다.
- 재접속마다 재노출되지 않도록 "이미 본 지급" 표시를 둔다(localStorage 등).
- BE 값은 이미 정확함(application.yml: initial-grant 200, daily-grant 50) — BE 변경 없음.

## 2. 피드백 버튼 + 관리자 콘솔 관리

- FE: 월드 HUD/ESC 메뉴에 피드백 버튼 → 텍스트 입력 폼 → 제출
- BE: Feedback 엔티티/테이블 + `POST /api/v1/feedback`(회원 제출) + 관리자용 목록·상태 조회 API
- 관리자 콘솔: 기존 admin 섹션 패턴(MembersSection 등) 따라 FeedbackSection 신설 — 목록 확인, "최초 발견" 표시
- 보상: 새 코인 지급 로직 만들지 않는다 — 기존 관리자 수동 코인 조정(AdminWalletController/CoinAdminAdjustCommand) 재사용해 해당 회원에게 지급
- 제출 시 Mattermost 웹훅으로 관리자 알림(선택) — `MATTERMOST_FEEDBACK_WEBHOOK_URL` env, 미설정 시 스킵(값은 커밋 금지)

## 3. 조작 안내 개선 — 휠 확대/축소

Unity `PlayerCameraFollow.cs`에 이미 구현된 휠 줌을 FE 조작 안내에서 빠뜨림.

- `ControlGuideList.tsx` "이동" 그룹에 휠 항목 추가

## 범위 밖

- 신규 코인 지급 정책/금액 변경 없음
- 기존 관리자 권한 모델 변경 없음
