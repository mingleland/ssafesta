## 설명

demo 실측: /assets/* 에 Cache-Control 이 없어 CF 기본 4h, index.html 이 no-store 라 304 불가, 옛 chunk 요청이 try_files 로 200 text/html 을 받음, booth-runtime .glb 가 application/octet-stream + 헤더 없음(heuristic 캐시), origin gzip off.

변경(festa-frontend/docker/nginx.conf): /assets/booth-runtime/ no-cache + mime.types 재포함 + glb→model/gltf-binary · /assets/ try_files =404 + 1y immutable · index.html no-cache · gzip on.
변경(main.tsx): vite:preloadError → preventDefault → 세션·번들 버전 키로 1회만 reload, 재실패 시 오류 기록.

완료: 로컬 docker prod 이미지 curl -I 8종 실측 + 배포 후 demo 동일 + 직전 배포 chunk 404. 무한 reload 없음.
