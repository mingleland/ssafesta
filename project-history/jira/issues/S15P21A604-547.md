- Account: -

## 재현 방법

1. 게임 스튜디오 에디터에서 시작(START) 씬이 아닌 다른 씬을 선택한다.
2. 상단의 "플레이 테스트" 버튼을 눌러 플레이 화면으로 이동한다.
3. 플레이 화면에서 나가기(편집기로 돌아가기)를 누른다.

## 기대 결과

- 나가기 전에 보고 있던 씬이 그대로 유지된다.

## 실제 결과

- 선택 씬이 항상 시작(START) 씬으로 초기화되어 있다.

## 원인 분석

- "플레이 테스트"는 별도 라우트(`/app/games/:id/play`)로 이동하는 구조라, 나갔다 돌아오면 에디터(`GameStudioShell`)가 통째로 새로 마운트된다.
- 이때 초안을 다시 불러오는 정상 로드 경로(`GameStudioShell.tsx` 400번째 줄)가 무조건 `project.startSceneId`로 선택 씬을 되돌리게 돼 있다 — 프로젝트 내용은 하나도 안 바뀌었는데(같은 초안을 그대로 다시 불러온 것뿐) 씬 선택만 매번 리셋된다.
- 선택 씬(`selectedSceneId`)이 저장되지 않는 순수 컴포넌트 로컬 state라서, 컴포넌트가 새로 마운트되는 모든 경우(플레이 테스트 왕복, 새로고침 등)에 공통으로 발생한다.

## 관련 Issue

- 없음

## 완료 조건

- [ ] 플레이 테스트 왕복 후에도 이전에 보고 있던 씬이 그대로 유지된다.
- [ ] 새로고침 후에도 마지막 선택 씬이 유지된다.
- [ ] 게임 초기화 / JSON 가져오기 / 템플릿 적용 / 씬 삭제 시에는 기존처럼 시작 씬으로 돌아간다(회귀 없음).
- [ ] 저장된 선택 씬 기록이 없는(처음 여는) 게임은 시작 씬이 보인다.
- [ ] 선택 씬 기억은 게임(gameId)별로 독립적으로 동작한다.
