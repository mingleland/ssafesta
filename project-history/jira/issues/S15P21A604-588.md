## 설명

## 작업 목적

Booth Studio 의 Gate 화면(소유자 확인·로딩·오류)은 Shell 없이 카드만 그린다. 그래서 툴바의 '뒤로'가 없고, ESC Game Menu 는 World 전용이라 여기서 열리지 않는다.

Gate 4종 중 **3종에 링크가 하나도 없어** 주소창 말고는 나갈 방법이 없다. 세션이 만료돼 재로그인하면 returnTo 가 `/app/studio/:boothId` 로 되돌리는데, 그 목적지가 실패 상태면 사용자가 그대로 갇힌다 (2026-09-10 플레이 중 실측).

## 작업 내용

`pages/studio/StudioPage.tsx` 의 Gate 분기에 공통 탈출구(`GateActions`)를 준다.

- `ownerGate.status === 'error'` — 다시 시도 + 부스 관리로
- `gates.draftLeaseExpired` — 부스 관리로 (되물어도 답이 같으므로 재시도는 주지 않는다)
- `draftQuery.isError` — 다시 시도 + 부스 관리로
- `not-owner` — 기존 부스 슬롯 목록 링크를 같은 컴포넌트로 통일

`features/booth/model/useOwnerGate.ts` 가 `retry` 를 노출한다 — 화면이 queryClient 를 직접 만지면 같은 키를 아는 곳이 둘로 늘어난다.

`features/studio/ui/shell/boothStudio.css` 에 `.studio-gate-actions` 배치를 더한다.

1. Gate 4종 모두에서 앱 내부 경로로 나가는 링크가 렌더된다

3. 임대 만료에는 '다시 시도'가 없다 — 눌러도 그대로면 고장으로 읽힌다(-458 과 같은 원칙)
