## 설명

### 작업 목적

boothId+agentId 격리 위반을 릴리스 차단 조건으로 Jenkins 파이프라인에 연결한다.

### 작업 내용

- 기존 AI 격리 테스트 스위트를 Jenkins 검증 단계에서 실행
- 1건의 교차 검색도 실패로 판정
- 실패 시 이미지 publish/배포 차단
- 테스트 결과와 실행 링크 보존

### 완료 조건

- 정상 격리 시 게이트 통과
- 의도적 교차 데이터 시 게이트 실패
- 실패 이후 publish와 배포가 실행되지 않음
- 민감한 문서 본문·Secret이 로그에 노출되지 않음

### 선행 작업

AI 격리 스위트, Jenkins AI 파이프라인

- 헌법 17조

### 테스트 방법
