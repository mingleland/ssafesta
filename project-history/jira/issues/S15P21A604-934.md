## 설명

주먹은 상체 마스크 레이어에서만 재생되는데 ApplyAnimState 가 이모트가 있으면 Base Layer 갱신을 건너뛴다. 그래서 주먹이 도는 동안 들어온 Run·JumpLaunch·Jump·JumpLand 가 전부 버려지고 다리가 주먹을 시작한 순간의 포즈에 굳는다. 달리다 점프하며 치면 선 자세 그대로 미끄러져 보인다. 상체 전용 이모트일 때는 하체가 계속 이동 상태를 따라가게 하고, 전신 이모트에서 주먹으로 넘어오는 경우에도 Base Layer 를 현재 이동 상태로 되돌린다.
