## 설명

목표

비개발자가 웹 편집기에서 2D 게임을 만들고 저장·게시하며, 다른 사용자가 웹 런타임에서 플레이할 수 있는 독립 UGC 제작 도구를 완성한다.

제품 경계

- Game Studio 편집기와 2D Runtime은 프론트 웹 모듈이다. 게임 실행에 Unity WebGL이 필요하지 않다.

- Unity는 Booth의 GAME_PORTAL 상호작용으로 웹 게임 오버레이를 여는 선택적 진입점만 담당한다.

- 직접 URL/웹 목록에서 Published 게임을 실행하는 경로는 Unity와 독립적으로 동작해야 한다.

- specs/014 미니게임과 specs/019 Game Studio는 별도 범위로 관리한다.

핵심 범위

- TOP_DOWN·PLATFORMER Runtime과 DIALOGUE·PUZZLE 연출

- 공통 Component/Event/Variable/Inventory/Scene 전환 계약

- Draft revision 저장, 불변 Published version, 사용자 Asset stable asset://

- 템플릿·튜토리얼·복구 UX·접근성·성능·오류 격리

활성화 게이트

- 계약 MR !1 승인과 FE·BE·AI 스키마 동치

- GitLab #48·#55·#56·#69 해결

- Unity 없는 Published E2E와 선택적 Booth Portal E2E를 각각 통과

현재 근거

GitLab MR !8·!9·!12 병합 완료. Host/API/계약 활성화 경계는 GitLab #104에서 추적한다.
