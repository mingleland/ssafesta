## 설명

FE 가 부스 안에서 나가기 버튼을 React HUD 로 띄우기 위해 요청한 계약 둘을 Unity 에 붙인다 (GitLab #174, 2026-09-11 확정).

1. Unity -> FE: WORLD_BOOTH_CONTEXT 이벤트. payload 는 insideBooth(bool) 과 boothId(안에 있을 때만). 기존 onBoothInteract 채널, WORLD_ 규칙. 월드 진입 직후(로컬 플레이어 스폰) 현재 값 1회, 이후 바뀔 때마다. 판정은 로컬 플레이어가 Interior_NN 방 영역 안에 있는가로 Unity 가 자기 상태로 한다. WorldUiState 에는 넣지 않는다 (hasUnityModal 회귀).

2. FE -> Unity: SendMessage(WorldUiBridge, RequestExitBooth). 기존 WorldUiBridge 오브젝트에 메서드 하나 추가. 부스 밖이면 무시하고 여러 번 와도 한 번만 실행한다. 퇴장은 기존 Portal_Int_NN -> ReturnPoint_NN 경로를 그대로 탄다. 성공 콜백은 없고 다음 insideBooth false 가 결과 자체다.

역할 경계: Unity 는 컨텍스트 판정과 실제 퇴장, FE 는 버튼 UI 와 클릭 -> 요청.
