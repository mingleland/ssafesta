## 설명

관리자 콘솔 3건. 1·3번은 FE 단독이고 2번은 GitLab #263(BE S15P21A604-959) 계약에 맞춘 선구현이다.

1. adblock 이 관리자 콘솔을 지운다
- 원인이 두 겹이었다. 네트워크 쪽은 dev 에서 URL 로 그대로 요청되는 admin.css 이고, 실제로 화면을 비운 것은 ad- 접두 CSS 클래스 53종이다 — uBlock/AdBlock 의 제네릭 코스메틱 필터가 .ad-table, .ad-bar, .ad-head, .ad-toolbar 같은 이름을 숨긴다. 관리자 목록만 비고 바깥 카드(sc-*)는 멀쩡한 증상이 그것이다.
- ad- 를 ac- 로 기계 치환(75건, 관리자 UI 13파일 + 테스트 1)하고 admin.css 를 console.css 로 옮겼다. 로직 변경은 없다.
- 치환 전에 [a-z]ad- 로 substring 위험을 확인했고 관리자 폴더 안에는 없었다. 폴더 밖 매치(upload-, preload-reload, pad-y)는 전부 오탐이라 건드리지 않았다.

2. 회원 부스·미게시 부스도 콘솔에서 다룬다 (GitLab #263 선구현)
- AdminBoothView 에 adminOwned, leaseEndsAt 을 더하고 slotId·slotCode 를 nullable 로 넓혔다.
- 두 필드는 optional 이고 adminOwned 는 없을 때 참으로 읽는다. BE MR !1322 전에는 목록에 관리자 부스만 오므로 그 기본값이 사실이고, 들어온 뒤에는 서버 값이 이긴다 — 두 시점 모두에서 분기가 맞는다.
- 강제 비공개 확인문을 adminOwned 로 갈랐다. 관리자 부스는 반납이 곧 삭제이고 회원 부스는 Draft·게시 이력이 보존된다 — 같은 버튼이 두 종류에서 다르게 끝난다.
- 안내문·빈 상태 문구를 사실에 맞췄고, 자리 없는 행은 슬롯 칸을 — 로 채운다. slotId 가 null 이면 월드에 칸이 없으므로 notifyBoothSlotChanged 를 부르지 않는다.
- OverviewSection 의 "공개 중인 관리자 부스" 통계에 adminOwned 필터를 걸었다.
- mock 에 회원 부스 2행을 더했다 — 임대 중인 행과 만료돼 자리가 빈 행.

3. 임대와 게시를 한 동작으로 묶는다
- 전에는 임대만 하면 자리는 잡히는데 월드에는 아무것도 보이지 않았고, 관리창에서 게시를 한 번 더 눌러야 부스가 섰다.
- 임대 성공 직후 기존 게시 엔진(useBoothPublish)으로 빈 전시를 게시한다. BE 계약 변경은 없다 — draft 저장과 publish 는 이미 있는 endpoint 다.
- 게시가 실패해도 관리 화면으로 보낸다. 자리는 이미 잡혔고 그 화면이 게시 버튼으로 남은 일을 말한다. 실패는 토스트로 드러낸다.
