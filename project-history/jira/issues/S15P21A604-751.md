## 설명

부스 스튜디오에서 사용자가 배치한 노트북은 렌더링 위치에 정상 표시되지만, 멀티플레이 환경에서 상호작용 프롬프트와 판정 범위가 노트북 주변이 아닌 부스 중앙 또는 이전 원점 쪽에서 활성화된다. 실제 노트북 앞에서는 상호작용이 잘 되지 않고, 떨어진 위치에서 프롬프트가 나타나는 경우가 있다.

재현 관찰
- 사용자 배치 노트북은 테이블 위 등 Layout 좌표에 렌더링됨
- 노트북 앞에 접근해도 F 프롬프트가 없거나 반응하지 않음
- 부스 중앙/다른 위치에서 '노트북으로 홈페이지 열기' 프롬프트가 나타남
- 멀티플레이 환경에서 확인된 오류이며 각 클라이언트 화면에서 판정 위치 비교 필요

조사 범위
- Spring Published Layout → BoothRuntime → BoothObjectFactory Local Spawn 이후 노트북 root/local/world transform을 host와 client에서 각각 기록
- BoothRuntimeObject, LaptopInteractable, BoothInteractionTarget이 같은 배치 오브젝트 계층에 붙는지 확인
- BoothInteractionTarget.Active에 원점의 중복·잔존 타깃이 등록되는지 확인
- WorldBounds 캐시의 localToWorldMatrix와 실제 자식 Collider/Renderer bounds를 Layout 적용 전후로 비교
- Layout 재적용·라이브 동기화에서 자식 구성/좌표 변경 후 InvalidateBounds 호출 누락 여부 확인
- 렌더 노트북과 프롬프트 대상의 objectId, boothId가 일치하는지 검증

완료 조건
- 호스트와 원격 클라이언트 모두 렌더링된 노트북 표면 근처에서만 동일한 프롬프트가 표시됨
- 부스 중앙이나 옛 배치 위치에 유령 상호작용 범위가 남지 않음
- F 입력 시 화면에 보이는 노트북의 boothId/objectId로 홈페이지 트리거가 한 번만 전송됨
- 노트북 이동·회전·Layout 재적용 후에도 판정 범위가 즉시 따라감
- 다른 부스 상호작용 대상의 표면 거리 판정에는 회귀가 없음
