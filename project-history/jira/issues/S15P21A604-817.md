## 설명

부스 관리창을 레퍼런스 사진 레이아웃으로 다시 그린다. 왼쪽은 부스 미리보기(슬롯별 정적 스크린샷), 오른쪽은 프로젝트 정체성 카드 → AI 전시 에셋 관리(잠금, 플래그로 격리) → 운영 관리 2×2 → 반납.

전제 — 부스 공간·기능형 에셋 배치는 Unity 의 부스별 고정 구성을 정본으로 한다. 이번 FE 개편은 layout publish/rebuild 를 호출하거나 변경하지 않는다. 기존 Studio·2.5D·게시 파이프라인은 숨김 보존만 하며 관리창 신규 흐름에서는 의존하지 않는다.

변경
- BoothManagementOverlay 재구성. 스튜디오 진입 버튼 제거(route·패널·features/studio 는 그대로).
- 부스 이름 인라인 편집을 관리창으로 이동. facade 확보 전 disabled, mutation 직전 캐시에서 facade 4필드를 다시 읽어 payload 구성.
- BoothPreview 신설 — /booth-preview/{slotCode}.png → default.png → placeholder 문구. BoothMiniPreview 는 폴백에 넣지 않는다.
- AiAssetSection 신설 + boothManagementFlags.ts 의 SHOW_AI_ASSET_SECTION 한 줄. 버튼은 전부 disabled.
- 레퍼런스 2장 반입(docs/LJH/ui-design/00_context/sources), 임시 미리보기 1장(public/booth-preview/default.png).

슬롯별 캡처는 게임 파트에 GitLab 이슈로 요청한다. 12장이 오면 코드 수정 없이 파일만 추가.

완료 조건
- 스튜디오 진입 0건, 운영 관리 4카드 + 반납 행
- 이름 편집 정책(trim·미변경 미전송·facade 로딩 중 disabled·최신 캐시 payload) 테스트
- AI 섹션 플래그 mock 으로 on/off 테스트
- 미리보기 폴백 사슬 테스트
- vitest / tsc / build green
