## 설명

### 작업 목적

R2 장애 시 쓰기를 안전하게 차단하고 운영자 검증 후 단일 활성 저장소를 MinIO로 전환한다.

### 작업 내용

- R2 장애 감지 시 업로드 차단
- 운영자 검증·승인 후 수동 MinIO fallback
- 한 시점에 활성 저장소 하나만 허용
- R2 복구 후 명시적 reconcile과 원복 절차
- 자동 failover는 구현하지 않음

### 완료 조건

- R2 장애 중 신규 업로드가 조용히 유실되지 않고 명확히 실패한다.
- 승인 전 MinIO로 자동 전환되지 않는다.
- 수동 전환 후 읽기/쓰기 대상이 하나로 유지된다.
- reconcile 결과와 미해결 객체가 기록된다.

### 선행 작업

R2·MinIO 구성과 저장소 어댑터

### 참고

- `specs/infra-002-runtime-environments`
- 확정 결정: operator-validated manual fallback

### 테스트 방법

R2 차단→업로드 실패 확인→수동 전환→MinIO 쓰기→R2 복구→reconcile 순으로 검증한다.
