## 설명

매표소 NPC 상호작용 시 우상단에 흰 판때기가 반쯤 가린 채로 보인다는 지적(2026-09-14). InteractionFocusCamera 가 IMGUI 로 그리는 [Esc] 나가기 알약이고, Unity 캔버스라 React HUD(z-index 20) 아래로 깔려 상담 버튼에 가린 것이다.

임베드에서는 기능도 중복이다 — 오버레이의 X·배경 클릭·ESC 가 RequestExitWorldUi 로 초점까지 함께 끝낸다(GitLab #132). 토스트(GitLab #141)와 같은 ControlsHintHud.HostProvidesUi 게이트를 건다. 단독 실행에는 대체 경로가 없어 그대로 남긴다 — 통째로 지우면 QA #54(갇힘)가 돌아온다.
