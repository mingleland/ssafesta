## 설명

-116 이 만든 createApiGameAssetRepository 가 develop 에서 비테스트 소비자 0 이다. 어댑터는 있는데 아무 데도 꽂혀 있지 않다.

결함: PublishedGameSurface 는 assetResolver prop 을 받아 useResolvedAssetUrls 에 넘기는데, 유일한 호출자인 PlayGamePage 가 그 prop 을 넘기지 않는다. 기본값이 null 이라 익명 Published 플레이에서 assetUrls 가 항상 빈 객체고, 업로드된 Asset 이 아예 렌더될 수 없다.

범위
1) PlayGamePage 의 PublishedGameSurface 에 createApiGameAssetRepository() 를 넘긴다. defaultFetchContent 가 token null 을 이미 처리하므로 익명에서도 동작한다.
2) LocalPreviewSurface 는 createApiGameAssetRepository({ local: createBrowserAssetRepository() }) 로 바꾼다. asset://local 위임과 asset://game 원격 조회 합성은 어댑터 안에 이미 있다.
3) 두 저장소 모두 useMemo 로 참조를 고정한다 — useResolvedAssetUrls 의 useEffect 의존성에 repository 가 들어 있어 매 렌더 새 객체를 주면 재해석 루프가 된다.

서버 미구현 구간 동작: -107 이 없는 동안 /content 는 404 이고 resolve 가 throw 하면 useResolvedAssetUrls 의 catch 가 빈 객체로 되돌린다. 현재 화면과 같고 나빠지지 않는다.

회귀 테스트는 S15P21A604-187 이 담당한다.

대상 브랜치: develop.
