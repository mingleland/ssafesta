## 설명

증상
- 하이 스트라이커를 연속으로 치면 F 입력이 씹히고, 연출이 끝난 뒤 같은 자리에 서 있어도 상호작용 표시가 바로 돌아오지 않는다.

원인(코드 실측)
- 서버 쿨다운 MachineCooldown 3.2초, 화면 연출은 ImpactDelay 0.46 + SequenceSeconds 1.64 = 2.10초로 끝난다. 그 사이 1.1초 동안은 프롬프트가 떠 있고 F 도 받지만 서버가 조용히 거절한다(Debug.Log 만 남고 클라이언트 회신 없음).
- 거절된 입력도 누른 사람 화면에서는 BeginLocalInteractionLock 으로 이동을 1.5초 잠그고 machine.BeginBusy 로 기계를 2.10초 더 가린다. BeginBusy 가 Mathf.Max 라 연타할수록 잠금이 계속 연장된다.

해결 방향
- 서버 쿨다운을 실제 연출 길이 기준으로 계산해 사각지대를 없앤다.
- 쿨다운으로 거절하면 요청한 클라이언트에만 회신해 이동 잠금을 즉시 풀고 남은 시간을 안내한다.
- 승인 전 로컬 선점 잠금은 요청 제한시간만큼만 건다.

검증
- 연출 종료 직후 F 가 바로 먹는다. 거절 시 즉시 안내가 뜨고 이동이 풀린다. 연타해도 잠금이 누적되지 않는다.
