## 설명

## 작업 목적

- 지금은 상호작용 가능 거리가 "같은 칸 또는 정면 한 칸"으로 고정돼 있어, 오브젝트  
   크기나 연출에 따라 더 넓거나 좁은 상호작용 범위가 필요한 경우에 대응할 수 없다.

## 작업 내용

- `contracts/gameProject.ts`
   
   - `Component` 유니온의 `INTERACTABLE`에 `range?: number` 필드를 추가한다(정수  
      1~100, 없으면 기본값 1로 취급). `validateComponentShape`의 INTERACTABLE  
      분기에 range 검증을 추가한다.
- `InspectorPanel.tsx`
   
   - INTERACTABLE 컴포넌트 편집 UI(상호작용 안내 문구 입력 옆)에 "상호작용 거리"  
      숫자 입력을 추가한다(1~100, 정수).
- `referenceRuntime.ts`
   
   - `interactionCandidates()`의 판정 로직을 확장한다. `INTERACTABLE` 컴포넌트가  
      있으면 그 `range`(없으면 기본값 1)를 맨해튼 거리 기준으로 판정한다(방향 무관,  
      `|플레이어.x - 오브젝트.x| + |플레이어.y - 오브젝트.y| <= range`). `INTERACTABLE`  
      컴포넌트 없이 `ON_INTERACT` 이벤트로만 상호작용 가능한 오브젝트는 거리 설정이  
      없으므로 기존처럼 고정 1칸(같은 칸 또는 정면 한 칸)을 유지한다.
   - S15P21A604-532에서 만든 `currentInteractionTarget`/오브젝트 위 안내 문구  
      힌트는 같은 함수를 재사용하므로 별도 수정 없이 자동으로 반영된다(하단 버튼과  
      힌트 표시 거리가 항상 일치).

## 완료 조건

- [ ] `INTERACTABLE` 컴포넌트에 "상호작용 거리"를 설정할 수 있다(기본값 1, 최대값  
       100, 정수)
- [ ] 설정한 거리 이내(맨해튼 거리, 방향 무관)에서 상호작용이 가능하다
- [ ] 거리를 벗어나면 상호작용이 불가능하다
- [ ] 오브젝트 위 안내 문구도 같은 거리 기준으로 뜨고 사라진다(하단 버튼과의 일치 유지)
- [ ] `range`를 설정하지 않은 기존 오브젝트는 기본값 1로 기존과 동일하게 동작한다
- [ ] `ON_INTERACT` 이벤트로만 상호작용 가능한(`INTERACTABLE` 컴포넌트 없는)  
       오브젝트는 영향받지 않는다
