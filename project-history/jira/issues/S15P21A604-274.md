## 설명

### 무엇이 필요한가

로컬·개발 환경에서 **회원 세션을 만들 수 있는 Google·Kakao 개발용 자격증명 6개**.

```text
GOOGLE_CLIENT_ID
GOOGLE_CLIENT_SECRET
GOOGLE_REDIRECT_URI
KAKAO_REST_API_KEY
KAKAO_CLIENT_SECRET
KAKAO_REDIRECT_URI
```

값 자체는 이 이슈에 적지 않는다. Secret 저장소·전달 경로를 정하고 그 위치를 알려주는 것이 이 이슈의 완료 조건이다.

### 왜 blocker 인가 — 실측

FESTA 에서 **회원 계정을 만드는 경로는 OAuth 하나뿐이다.** 게스트는 회원 전용 기능을 전부 거부당한다(2026-08-27 로컬 BE 실측).

```text
GET /api/v1/wallets/me            게스트 → 403 MEMBER_ONLY
GET /api/v1/wallets/me/transactions  게스트 → 403 MEMBER_ONLY
GET /api/v1/booths/mine           게스트 → 403 MEMBER_ONLY
GET /api/v1/booths/1              → 404 BOOTH_NOT_FOUND  (부스가 0건 — 부스는 회원 임대로만 생긴다)
```

그래서 아래가 **코드는 다 있는데 검증만 못 하고 멈춰 있다.**

| 티켓 | 막힌 것 |
|---|---|
| S15P21A604-86 | Booth Facade — 검증할 부스 자체가 존재할 수 없다 |
| S15P21A604-88 | Coin Wallet — 잔액·거래내역 2종 전부 member-only |
| S15P21A604-89 | Owner/Staff 라우트 가드 — member-only 경로 전부 |
| S15P21A604-87 | 슬롯 `OCCUPIED`·`mine` 상태. 회원 임대가 있어야 생긴다 |
| S15P21A604-90 | 회원 refresh 성공·만료·재사용 탐지. `refresh_token` 최초 발급처가 `OAuthCompletionController` 하나뿐이다 |
| S15P21A604-171 | 임대 실서버 왕복(차감·`ACTIVE_LEASE_LIMIT`·경합) |

real adapter(`facadeApi.ts`·`leaseApi.ts`·`wallet/api.ts`·`layout/api.ts`)는 이미 구현돼 있어 **추가 설계 없이 실측만 하면 되는 상태**다.

### 우회하지 않는 이유

DB 에 회원·임대 행을 직접 넣으면 화면 렌더는 볼 수 있지만 **OAuth 콜백·토큰 발급·권한 판정 경로가 검증되지 않는다.** 그건 "검증했다"고 적을 수 없는 종류라 하지 않았다.

### 완료 조건

- [ ] Google·Kakao 개발용 앱 등록(또는 기존 앱의 개발용 redirect URI 추가)
- [ ] Secret 전달 경로 확정 — 저장소에 커밋하지 않는다(헌법 15조)
- [ ] 로컬에서 OAuth 로그인 관통 1회 성공

### 참고

`-90` 에 D5 로 올려 둔 항목이며, 별도 추적 티켓이 없어 여기 만든다. `docs/LJH/verify/87-booth-slot-real-api.md` 에 실측 원자료가 있다.
