## 설명

### 작업 목적

정적·업로드 객체를 R2에 저장하고 장애 대응용 MinIO를 준비하면서 용량·권한 오용을 방지한다.

### 작업 내용

- 환경별 bucket/prefix와 최소 권한 credential
- CORS·lifecycle·업로드 크기/형식 제한
- 사용량·오류율 관측과 임계치 알림
- MinIO 대기 구성과 단일 활성 저장소 원칙 반영

### 완료 조건

- dev/demo 객체가 경로와 권한에서 분리된다.
- 허용되지 않은 origin/credential/크기 요청이 거부된다.
- 사용량과 실패율을 확인할 수 있다.
- MinIO는 운영자 승인 전 활성화되지 않는다.

### 선행 작업

R2 계정·도메인·Secret 저장소

### 참고

- `specs/infra-002-runtime-environments`

### 테스트 방법

환경별 업로드/조회, 교차 접근 거부, 제한 초과, 사용량 알림을 검증한다.
