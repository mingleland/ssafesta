## 설명

### 작업 목적

외부 브라우저의 회원·게스트가 Unity Dedicated Server에 안전하게 접속할 수 있는 공개 WSS 경로를 제공한다.

### 작업 내용

- Cloudflare → Nginx → 내부 7777 경로 구성
- 기존 Unity Linux Server 빌드·Docker 기준선 재사용
- game 파트 단독 배포·known-good 롤백
- 120초 서명 Connection Token 연동 및 replay 방어는 기존 BE/Unity 이슈와 통합
- P0 접속·10분 유휴·정리/재연결 검증과 P1 1→40명 부하 검증

### 완료 조건

- `wss://world.<domain>:443` 종단 접속이 성공한다.
- 회원 1명+게스트 1명이 10분 유휴 후 이동 동기화를 계속한다.
- 비정상 종료 후 서버 정리와 수동 재연결이 확인된다.
- 최고 성공 동시 접속 구간을 2회 재현하고 증적을 남긴다.

### 선행 작업

- BE world-session/Connection Token: S15P21A604-84, S15P21A604-85, S15P21A604-170
- runtime DNS/TLS/Nginx 환경

### 참고

- `specs/infra-003-unity-server-runtime`

### 테스트 방법

외부 HTTPS WebGL에서 P0 시나리오를 수행한 뒤 1→10→20→30→40명, 구간별 10분 부하를 측정한다.
