## 설명

작업 목적

Published 게임을 유료로 시작하는 경우에만 Coin 차감을 멱등한 서버 세션으로 처리한다.

범위 원칙

- 무료 Published 플레이와 기본 게시 기능의 선행 조건으로 두지 않는다.

- 보상 지급·정산은 별도 경제 정책이며 이 작업에 포함하지 않는다.

작업 내용

- 차감 금액, idempotency key, 재입장·재시도 규칙 확정

- Ledger와 세션 생성을 단일 트랜잭션으로 연결

- 동일 요청·동시 요청·잔액 부족 응답 고정

완료 조건

[ ] GitLab #81의 미결정 질문에 FE·BE 합의가 기록된다.

[ ] 동일 idempotency key 재요청에서 이중 차감이 없다.

[ ] 잔액 부족·비로그인·이미 처리됨이 승인된 계약으로 구분된다.

[ ] Ledger와 게임 세션 결과가 항상 일치한다.
