## 설명

## 작업 목적

게임 완성도 점검(PLAYABILITY CHECK)이 줄글 나열식이라 사용자가 자기 게임의 전체 흐름(플레이어가 어디서 시작해서 어떤 경로로 진행되고 어디서 끝나는지)을 한눈에 파악하기 어려움(Notion QA id=31). 씬 단위 흐름을 노드+화살표 그래프로 시각화하는 화면을 추가하되, 편집 작업을 막지 않도록 화면 어디든 자유롭게 옮기고 크기 조절 가능한 플로팅 윈도우로 제공한다. 로컬 실험 브랜치에서 1단계(씬 단위 그래프 + 모달)와 2단계(플로팅 윈도우 전환)까지 구현해 동작을 이미 확인함.

## 작업 내용

- `studio/model/sceneGraph.ts`: `buildSceneGraph` — 씬을 노드로, `GO_TO_SCENE`/`SHOW_DIALOGUE` 액션을 간선으로 뽑고 `COMPLETE_GAME` 액션이 있으면 가상의 "게임 완료" 노드 추가. `computeSceneGraphDepths` — 시작 씬 기준 BFS 깊이 계산(미연결 씬은 -1)
- `studio/ui/SceneFlowGraph.tsx`: 새 라이브러리 없이 BFS 깊이를 열로 삼아 노드 배치, 간선은 SVG로 직접 렌더링. 노드 클릭 시 해당 씬으로 이동
- `studio/ui/FloatingPanel.tsx`: 제목 표시줄 드래그로 이동, 모서리 핸들 드래그로 크기 조절(최소 크기·화면 밖 이탈 clamp), 배경 덮개 없이 편집 화면 위에 떠 있음 — 좌/우 패널 폭 조절(`startPanelResize`)이 쓰는 pointerdown~pointerup + `setPointerCapture` 패턴을 재사용
- 상단 툴바 "🔀 게임 흐름" 버튼을 토글로 추가(다시 누르면 닫힘), 노드 클릭 후에도 창은 열린 채로 유지(여러 씬을 옮겨 다니며 계속 확인 가능)
- 스코프는 씬 단위로 한정 — 씬 내부 오브젝트/트리거 단위까지 노드로 확장하는 것은 이번 범위 밖(규모가 훨씬 커서 별도 검토 필요)
- 계약(`contracts/gameProject.ts`) 변경 없음

## 완료 조건

- [ ] 씬 단위 흐름이 노드+화살표 그래프로 표시된다(시작 씬, 게임 완료 지점 포함)
- [ ] 그래프 창은 화면 전체를 막지 않고, 제목 표시줄 드래그로 자유롭게 옮길 수 있다
- [ ] 창 모서리를 드래그해 크기를 조절할 수 있다(최소 크기 미만으로는 안 줄어듦)
- [ ] 노드를 클릭하면 해당 씬으로 이동하고, 창은 닫히지 않고 계속 열려 있다
- [ ] 상단 툴바 버튼을 다시 누르거나 닫기(×) 버튼으로 창을 닫을 수 있다
- [ ] 관련 테스트 통과 + `tsc --noEmit` 통과
