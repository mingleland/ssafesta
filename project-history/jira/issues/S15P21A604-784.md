## 설명

Booth Studio 의 Gate 카드(부스 소유 정보 조회 실패 · 임대 만료 등)에서 탈출 버튼 글자가 보이지 않는다.

원인: CSS 명시도 충돌.
  .studio-gate-card a { color: var(--studio-accent) }      /* #b8ff3b, 0-1-1, boothStudio.css:573 */
  .studio-btn-primary { color: var(--studio-accent-ink) }   /* #14210a, 0-1-0, boothStudio.css:163 */
GateActions 의 탈출 버튼은 <Link className="studio-btn studio-btn-primary">, 즉 <a> 다.
카드 안 a 규칙이 명시도에서도 이기고 소스 순서에서도 뒤라 이중으로 이긴다.
결과적으로 글자색이 배경색과 같은 연두가 되어 '부스 관리로' 가 초록 덩어리로만 보인다.
버튼은 정상 동작하고 글자만 사라진다.

범위: S15P21A604-763(bm-gate-backdrop z-index)과 다른 건이다. 그쪽은 내 부스 관리의
AI 직원 게이트 팝업이고 boothManagement.css 를 만진다. 이 건은 Booth Studio 의 gate 카드다.

수정 방향: 카드 안 링크 색 규칙이 버튼 클래스를 덮지 않게 한다. 기본·hover·focus·disabled 상태를 함께 확인한다.
