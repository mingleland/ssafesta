## 설명

### 작업 목적

WebGL 대용량 정적 자산의 로딩 시간을 줄이면서 새 배포와 롤백의 캐시 정합성을 보장한다.

### 작업 내용

- fingerprint 자산 장기 캐시와 HTML/manifest 단기 캐시 분리
- CDN cache key·purge/invalidation 절차
- 압축·MIME·Content-Encoding 유지
- 이전 release 자산 보존과 롤백 경로

### 완료 조건

- 반복 접속의 정적 자산 cache hit가 확인된다.
- 새 릴리스에서 오래된 manifest와 새 자산이 섞이지 않는다.
- purge와 롤백 후 기대 버전이 로드된다.

### 선행 작업

WebGL 정적 HTTPS 서빙

### 참고

- `specs/infra-002-runtime-environments` P1
- T-19, T-23

### 테스트 방법

첫/재접속 waterfall 비교, 신규 배포, purge, 롤백의 헤더와 버전을 확인한다.
