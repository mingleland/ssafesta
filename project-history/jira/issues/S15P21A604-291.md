### 강형순 · 2026-08-28 09:45 KST

상태 정정: 완료 → 진행 중. (한 번 완료로 넘겼다가 되돌립니다 — Unity 몫만 보고 판단한 실수입니다.)

**Unity 몫 완료** (MR !85, develop 도달)

- `FestaUnityBridge.jslib` 에 `FestaNotifyWorldGateReady` 추가
- `WorldEntryGate` 가 개방 시점에 호출 — 준비 완료·단독 실행·강제 개방 **세 경로 모두** 동일하게 호출한다 (호스트가 어떤 경우에도 오버레이를 내릴 수 있어야 하므로)
- 송신 실패가 게이트 개방을 막지 않도록 try/catch (FR-014)

**남은 것 — 이 이슈가 열려 있는 이유**

- FE 오버레이의 독립 타임아웃(잠정 60초)이 아직 없다. **Unity 강제 개방 30초보다 길어야** 순서가 맞는데, 대조할 상대가 없어 정합 확인이 불가능하다.
- WebGL 빌드에서 `window.FestaUnity.onWorldGateReady` 가 실제로 불리는지 미검증 (에디터에서는 송신 생략 경로).

FE 오버레이 구현 후 ①WebGL 빌드에서 호출 확인 ②30초/60초 순서 검증까지 되면 닫는다.
