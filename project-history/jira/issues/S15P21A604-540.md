## 설명

## 작업 목적

- 플레이 테스트 화면이 사이드바 때문에 복잡하게 느껴진다는 사용성 피드백을 반영해, HUD를 게임 캔버스 안쪽 오버레이로 축소·재배치한다.

## 작업 내용

- 오른쪽 사이드바(`aside.grp-hud`)를 제거하고, 상태(체력·점수)·게임 목표·인벤토리·상호작용/발사 안내를 캔버스(`.grp-map`) 내부 오버레이로 옮긴다.
- 체력은 `maxPlayerHealth`개의 하트 아이콘으로, 점수는 `★ 숫자` 형식으로 캔버스 우측 상단에 표시한다(체력이 깎이면 하트가 왼쪽부터 사라진다).
- 인벤토리는 캔버스 좌측 상단에 목록형으로 표시한다.
- 게임 목표 진행은 캔버스 상단의 얇고 가로로 긴 바에 라벨로 표시한다(목표 미설정 시 미표시, 기존 조건 유지).
- 방향키 클릭 버튼을 제거하고 키보드 이동만 남긴다. 상호작용(E)·발사(F) 버튼은 클릭 불가능한 순수 안내 라벨로 바꿔 캔버스 좌측 하단에 표시한다(발사는 가능한 Scene에서만).

## 완료 조건

- [ ] 오른쪽 사이드바가 사라지고, 상태(하트/점수)·목표·인벤토리·조작 안내가 게임 캔버스 안쪽 오버레이로 표시된다.
- [ ] 방향키 클릭 버튼이 없어지고 키보드 이동만 남는다(회귀 없음).
- [ ] E(및 발사 가능한 Scene의 F)가 클릭 불가능한 순수 안내 라벨로 좌측 하단에 표시되고, 키보드 상호작용/발사는 그대로 동작한다.
- [ ] 체력은 하트 아이콘으로 표시되고 깎이면 왼쪽부터 사라지며, 점수는 `★ 숫자` 형식으로 하트 아래에 표시된다.
- [ ] 인벤토리는 좌측 상단에 목록형으로 표시된다.

## 선행 작업 / Dependency

- 없음

## 테스트 방법

1. 목표가 설정된 프로젝트/설정 안 된 프로젝트 각각에서 상단 바가 목표 있을 때만 보이는지 확인한다.
2. 피격으로 체력을 깎아가며 하트가 왼쪽부터 사라지는지, 점수 획득 시 `★` 숫자가 갱신되는지 확인한다.
3. 아이템 습득 후 좌측 상단 인벤토리 목록에 반영되는지 확인한다.
4. 발사 가능한 Scene/불가능한 Scene 각각에서 좌측 하단에 E만 보이는지, E+F가 같이 보이는지 확인한다.
5. 방향키 클릭 버튼이 사라졌는지, 키보드(방향키/WASD)로는 이동이 정상 동작하는지 확인한다(회귀 없음).
6. E/F 라벨을 클릭해도 아무 반응 없는지, 키보드 E(Enter/Space)·F로는 상호작용/발사가 그대로 동작하는지 확인한다.
7. 대화 진행 중 라벨들이 다른 오버레이(대화창)와 겹치거나 오작동하지 않는지 확인한다.
8. 다양한 Scene 크기에서 새 오버레이가 캔버스 밖으로 넘치거나 완료/실패 결과 화면과 겹치지 않는지(z-index) 확인한다.
