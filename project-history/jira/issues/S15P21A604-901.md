## 설명

영상 링크와 대표이미지를 둘 다 등록한 부스 화면이 검은 화면으로 남았다. 영상은 DOM iframe 오버레이라 WebGL 캔버스 위에 얹히고 깊이 버퍼에 참여하지 않아 앞에 선 아바타를 덮으며, 에디터에는 DOM 이 없어 확인도 빌드로만 가능했다. iframe 경로를 걷어내고 정지 이미지 한 장으로 통일한다. 순서는 유튜브 썸네일(videoUrl 이 유튜브면) → 프로젝트 대표이미지(thumbnailUrl) → 부스 로고(facade.logoUrl) → 검은 화면. img.youtube.com 은 Access-Control-Allow-Origin 이 * 라 WebGL 에서 안전함을 실측으로 확인했다.
