## 설명

### 작업 목적

EC2 지연으로 인프라가 OCI Ampere A1(ARM64)에서 임시 검증을 진행 — Unity 산출물 지원 (GitLab #111).

### 작업 내용

- Linux ARM64 Dedicated Server 빌드 가능 여부 판정 — **불가 확정**: Unity 6000.0.78f1 모듈 카탈로그에 Linux ARM64 모듈 부재 (이후 6000.x 마이너에서 도입). 근거를 #111 에 기록
- OCI 검증 범위 합의: WebGL 정적 배포까지, Dedicated Server 는 EC2 x86_64 확보 후
- WebGL 개발 빌드 전달 — commit e448c703, 비압축, 파일명 해시, `/unity/` 하위 서빙 가능, DevConnectionHud 수동 접속, Mock API 모드

### 완료 조건

- [x] ARM64 가능/불가 판정과 근거 기록 (#111 코멘트)
- [ ] WebGL 산출물 인프라 전달 (전달 방법 회신 대기)
- [ ] OCI 정적 서빙에서 접속 확인 (인프라 검증 지원)
