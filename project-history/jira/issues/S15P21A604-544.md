## 설명

## 작업 목적

- 상호작용 가능한 오브젝트가 여러 개 겹칠 때 지금은 "에디터에서 먼저 만든 쪽"이 우선인데, 이는 플레이어가 알 수도 예측할 수도 없는 기준이라 비직관적이다. 플레이어와 더 가까운 오브젝트가 우선하도록 바꾼다.

## 작업 내용

- 여러 상호작용 후보 중 플레이어 기준 맨해튼 거리(`|dx|+|dy|`)가 가장 가까운 오브젝트를 우선 선택한다.
- 거리가 같으면 기존과 동일하게 배열 순서(먼저 만든 오브젝트)를 그대로 유지한다.
- INTERACTABLE 컴포넌트가 있는 오브젝트뿐 아니라, range 없이 `onCurrent`/`inFront`로만 후보가 되는 순수 이벤트 트리거 오브젝트도 같은 거리 기준으로 함께 비교한다.
- 상호작용 안내 문구 표시(`currentInteractionTarget`)와 실제 E 상호작용 대상은 계속 같은 로직을 공유해 항상 일치한다.

## 완료 조건

- [ ] 여러 상호작용 후보 중 플레이어와 가장 가까운(맨해튼 거리) 오브젝트가 우선 선택된다.
- [ ] 거리가 같으면 기존과 동일하게 배열 순서(먼저 만든 오브젝트)가 우선한다.
- [ ] INTERACTABLE 오브젝트와 순수 이벤트 트리거 오브젝트가 동일한 거리 기준으로 함께 비교된다.
- [ ] 상호작용 안내 문구 표시와 실제 E 상호작용 대상이 항상 일치한다(회귀 없음).

## 선행 작업 / Dependency

- 없음

## 테스트 방법

1. 서로 다른 두 INTERACTABLE 오브젝트가 동시에 후보가 될 때, 배열 순서와 무관하게 더 가까운 쪽이 선택되는지 확인한다(먼저 만든 쪽이 더 멀리 있는 경우로 검증).
2. INTERACTABLE 오브젝트와 순수 이벤트 트리거 오브젝트가 동시에 후보가 될 때도 같은 거리 기준으로 비교되는지 확인한다.
3. 두 후보가 정확히 같은 거리일 때 배열 순서(먼저 만든 쪽)가 유지되는지 확인한다(회귀).
4. 오브젝트 위 상호작용 안내 문구가 새로 선택된 대상 기준으로 뜨는지 확인한다.
