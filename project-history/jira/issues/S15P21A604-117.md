## 설명

작업 목적

유료 Published 게임에서만 세션 생성·Coin 차감을 실 API로 연결한다.

현재 상태

MR !8의 로컬 session port는 개발용 no-op이며 coinCharged=false를 반환한다. 운영 과금으로 사용하지 않는다.

작업 내용

- createPublishedGameSessionPort 실 API adapter

- 시작 전 금액·재입장 규칙 사전 고지

- 잔액 부족·중복 요청·세션 만료 복구

완료 조건

[ ] 서버가 세션과 차감을 승인한 뒤에만 유료 게임이 시작된다.

[ ] 같은 idempotency key 재시도에서 이중 차감이 없다.

[ ] 무료 게임은 Coin API 실패와 무관하게 실행된다.

[ ] 잔액 부족 시 지갑 이동과 취소 선택을 제공한다.
