## 설명

BE 관리자 API(S15P21A604-742 계열, V36·11개 endpoint)가 develop 에 도달했다. FE 는 BE 잔여분(관리자 여부 노출·회원 검색·대상 없음 404 통일)을 기다리지 않고 콘솔을 먼저 완성한다.

- /app/admin 독립 라우트 + RequireAdmin 가드 (UX 보조, 최종 권한 판정은 BE)
- 관리자 / 회원 / 지갑 / 부스 네 섹션, 목록→선택→상세→조치 흐름
- 실존 11개 API 는 real adapter, 없는 계약(capability·회원 검색)은 FE 정본 contract + mock adapter
- 오류 7종 의미 매핑, 마스터 보호 UX, 코인 조정 멱등키 lifecycle, 파괴적 조치 confirmation
- mock 시나리오로 전체 workflow 실화면 검증

BE 에 전달할 계약 셋: /users/me admin·master boolean, 회원 검색/상세 API, ADMIN_TARGET_NOT_FOUND 404 통일.
