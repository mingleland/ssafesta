h3. 2026-09-06 01:10 — 2클라이언트 외형 E2E 실측 (로컬, Docker festa-world:cf83e396)

* 둘 다 스폰 그리드(-30/-25, 0, -248)에 스폰, 서로의 아바타와 이름표가 양쪽에 보인다(에디터에서 원격 plate=게스트-3e0c, WebGL screen 에 아바타 2기).
* 에디터 쪽에서 RequestChange 로 외형을 바꾸면(gender F→M, skin/hair hex) 서버 NetworkVariable 이 갱신되고(enc {{fa|g=0|...|q=5A3219,00FF00}}), WebGL 쪽이 원격 아바타를 *M body* 로 재조립({{[AvatarMeshMerge] Merged_mat_base_M_body}}) — 외형 동기화 경로 확인.
* 개별 hex 색(q=)은 원격에서 시각적으로 드러나지 않았다 — 적용기가 팔레트 id(p=) 를 우선하는 것으로 보이며 정상 경로(lobby 팔레트 선택)는 id 를 바꾸므로 영향 없음. 재확인 가치는 낮음.
