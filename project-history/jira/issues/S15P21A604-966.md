## 설명

GitLab #265 대응.

증상

- Production 월드에서 접속 직후 여러 사용자가 동시에 disconnect
- 서버 로그: send queue full / pipeline error -5
- 클라이언트 ngoReason이 비어 원인 안내 불가

원인

- NetworkBootstrap은 MaximumTransmissionUnitSize=4096만 설정
- UnityTransport.MaxSendQueueSize를 명시하지 않아 접속 버스트에서 큐 포화
- 외형 동기화, 회원 grant, 위치 복원이 접속 직후 집중

완료 조건

- MaxSendQueueSize를 실측 근거와 함께 명시하고 적용값 로그 출력
- 동시 접속 테스트에서 send queue full 및 동시 disconnect 미발생
- 빈 disconnect reason의 사용자·운영 진단 경로 보강
- Unity Release Bundle로 Demo 검증 후 승격 가능 상태
