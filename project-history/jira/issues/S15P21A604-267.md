## 설명

## 목적

Unity 6000.0.78f1 기준으로 OCI Ampere A1 ARM64에서 Unity Dedicated Server 임시 검증이 가능한지 판정하고, 검증 계획의 진행 여부를 결정한다.

## 결정 상태 — 실행 취소 (2026-08-27)

OCI에서 진행하려던 Unity 배포·접속 검증 계획을 취소한다. 이 이슈와 확인 근거는 삭제하지 않고 기술적 제약과 취소 결정의 기록으로 보존한다.

## 기술적 제약

- Unity 6000.0.78f1에는 Linux ARM64 Dedicated Server 빌드 경로가 없다.
- 해당 버전의 `modules.json`에 있는 Linux 모듈과 설치된 `LinuxStandaloneSupport/Variations`는 x86_64 서버 경로만 제공한다.
- `com.unity.sdk.linux-arm64` sysroot는 이 버전에서 Embedded Linux 전용이므로 데스크톱 Linux Dedicated Server 타깃에 사용할 수 없다.
- Linux ARM64 Dedicated Server를 사용하려면 Unity 6000.2+ 업그레이드가 필요하지만 임시 검증을 위한 프로젝트 전체 업그레이드는 범위와 리스크가 크다.
- x86_64 에뮬레이션은 성능·운영 결과를 왜곡하므로 사용하지 않는다.

## 취소 사유

원래 목적은 실제 서버 환경에서 Dedicated Server 기동, WebSocket/WSS 연결, 브라우저 2개의 스폰·이동 동기화를 확인하는 것이었다.

OCI에서 WebGL 정적 파일만 제공하는 검증은 브라우저 로딩만 확인할 수 있고 원래 목적을 달성하지 못한다. x86_64 EC2를 받은 뒤 WebGL 정적 배포와 Dedicated Server 연결을 함께 검증해도 일정상 충분하다고 판단해 OCI Unity 검증 전체를 취소한다.

## 실행하지 않는 작업

- OCI ARM64 Dedicated Server 빌드 및 실행
- x86_64 에뮬레이션
- Unity 6000.2+ 임시 엔진 업그레이드
- OCI WebGL 산출물 전달 및 정적 배포
- OCI 내부 `game:7777` 연결
- OCI에서 브라우저 2개 스폰·이동 동기화 검증

Unity 담당자가 준비한 WebGL Development Build는 가능성 확인 과정의 참고 정보로만 남기며 전달·배포 완료 근거로 사용하지 않는다.

## 재개 조건

x86_64 EC2를 확보하면 동일한 clean commit을 기준으로 WebGL과 x86_64 Dedicated Server 산출물을 다시 준비한다. 이후 `festa-unity/Docs/deployment-handoff.md`와 infra-003/#52 절차에 따라 다음 순서로 검증한다.

1. x86_64 Dedicated Server 기동
2. 외부 WSS 연결
3. 브라우저 2개 접속
4. 캐릭터 스폰·상호 이동
5. 서버 로그와 승인 결과 확인

## 결정 완료 조건

- [x] Unity 6000.0.78f1 Linux ARM64 Dedicated Server 불가 근거 확보
- [x] 엔진 업그레이드와 x86_64 에뮬레이션 제외
- [x] OCI Unity 검증 계획 취소 결정
- [x] Dedicated Server 검증을 x86_64 EC2 확보 후 재개하기로 결정
- [x] 이슈·명세·작업일지·트러블슈팅에 취소 사유 보존

## 주의사항

- 이 이슈의 결론은 OCI Unity 배포 성공이 아니라 ARM64 불가 판정과 계획 취소다.
- `v0.0.1-poc` 동결 코드를 재설계하거나 리팩터링하지 않는다.
- 기존 `Builds/` 산출물을 Git 저장소에 커밋하지 않는다.

## 결정 정정 — OCI Unity 검증 계획 취소

초기에는 Dedicated Server가 불가능하더라도 OCI에서 WebGL 정적 배포까지만 검증하는 방안을 검토했습니다.

그러나 이 작업의 원래 목적은 실제 배포 환경에서 Dedicated Server 기동, WebSocket/WSS 연결, 브라우저 2개의 스폰·이동 동기화를 확인하는 것이었습니다. WebGL 정적 파일 로딩만으로는 이 목적을 달성할 수 없고, x86_64 EC2를 받은 뒤 클라이언트와 서버를 함께 검증해도 일정상 충분하다고 판단했습니다.

따라서 OCI에서의 Unity 검증 계획 전체를 취소합니다.

- WebGL 산출물 전달·OCI 업로드를 진행하지 않습니다.
- ARM64 Dedicated Server 빌드, x86_64 에뮬레이션, 임시 엔진 업그레이드를 진행하지 않습니다.
- 기존 WebGL Development Build는 가능성 검토 기록으로만 남기며 배포 완료 근거로 사용하지 않습니다.
- x86_64 EC2 확보 후 clean commit 기준으로 WebGL과 Dedicated Server 산출물을 다시 준비해 infra-003/#52 절차를 재개합니다.

이 이슈는 삭제하지 않고 Unity 6000.0.78f1의 Linux ARM64 미지원 근거와 계획 취소 결정의 이력으로 보존합니다. Jira 상태는 저장소 워크플로 규칙에 따라 자동 전환하며 수동 변경하지 않습니다.
