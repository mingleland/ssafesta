## 설명

### 작업 목적

레지스트리·배포·알림·Unity 라이선스 자격증명을 Jenkins Credentials로만 주입하고 유출을 차단한다.

### 작업 내용

- 필요한 credential ID와 최소 권한 정의
- 환경 변수·파일 credential의 단계별 주입
- 콘솔·산출물·Docker history 마스킹 검증
- 저장소의 평문 Secret 탐지와 실패 게이트

### 완료 조건

- 실제 값이 저장소/JCasC/로그/산출물에 존재하지 않는다.
- 의도적 Secret 출력 시 마스킹 또는 작업 실패가 확인된다.
- credential rotation 후 코드 변경 없이 재실행된다.

### 선행 작업

Jenkins Controller와 Secret 저장소

### 참고

- `specs/infra-001-ci-cd-pipelines`
- 헌법 15조

### 테스트 방법

테스트 credential을 주입해 성공·오출력·rotation 시나리오를 검증한다.
