## 설명

## 작업 목적

Booth Studio 의 편집 조작이 에디터 관행과 어긋나 있다(2026-09-10 플레이 중 실측).

- 개별 삭제는 Inspector 맨 아래 버튼 하나뿐이다. 캔버스에서 `Delete`·`Backspace` 를 눌러도 아무 일이 없다 — `features/studio` 전체에 keydown 구독이 0건이다
- 배치를 한 번에 비우는 수단이 없다
- 이동·회전이 툴 모드 토글로만 갈린다. `ctrlKey`·`metaKey` 를 읽는 코드가 두 렌더러 어디에도 없다

## 작업 내용

Game Studio 에 이미 있는 패턴을 옮긴다. 새 패턴을 만들지 않는다.

- 캔버스 포커스 맥락에서 `Delete`/`Backspace` → `REMOVE_OBJECT`. 입력 필드 안에서는 가로채지 않는다(`GameStudioShell` 의 `editingText` 판정 그대로)
- 툴바에 '전체 초기화' — 확인 다이얼로그 필수. `resetToBlankProject` 패턴을 따르고, 교체는 `REPLACE_OBJECTS`(S15P21A604-589 로 이미 들어와 있다)를 그대로 쓴다
- 좌클릭 = 선택·이동, `Ctrl`+좌클릭 = 회전. R3F·SVG 두 렌더러에 같이 넣는다
- 툴바의 이동/회전 버튼은 남긴다 — 터치·접근성 대체 경로다

## 완료 조건

1. 캔버스에서 Delete/Backspace 로 선택 오브젝트가 지워진다
2. 입력 필드 편집 중에는 그 키가 가로채이지 않는다
3. 전체 초기화가 확인 다이얼로그를 거쳐 배치를 비운다
4. Ctrl+좌클릭 드래그가 회전, 그냥 좌클릭 드래그가 이동이다 (두 렌더러 모두)
5. 툴바 이동/회전 버튼 동작에 회귀가 없다
6. unit test / tsc 0 / vitest 전체 green / oxlint 신규 경고 0
