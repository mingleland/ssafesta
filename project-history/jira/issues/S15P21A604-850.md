## 설명

CDP 실측: WorldPage chunk(129K+CSS 29K)가 route 도달 후에야 시작돼 World cold 에서 1.3s 를 더 쓴다. 인증 후 목적지는 consumeReturnTo() = 저장값 ∥ /app/world.

변경: returnTo.ts 에 소비하지 않는 peekReturnTo() 추가, LoginPage 마운트 시 저장된 returnTo 가 없거나 /app/world 로 시작할 때만 void import('../world/WorldPage'). 다른 화면 딥링크 사용자는 선로드 없음.

완료: World cold waterfall 에서 WorldPage 가 route 전환 전 완료.
