## 설명

사용자 지시 2026-09-10 저녁 (사진: PF_High_Striker_Bell_Tower_Game_V1, 축제장 (-885,0,145), CarnivalKit 정적 메시 1개 + 벨).

요구
- F 키 -> 아바타가 망치를 내리찍는 애니메이션.
- 실제 기계처럼 쇠(퍽)가 기둥을 타고 올라가고, 오른쪽 별들이 높이에 맞춰 차례로 켜진다.
- 기계 위에 점수판을 만들어 별 개수에 맞는 점수를 표시.
- 멀티: 같은 채널의 모든 사용자가 퍽 상승·별·점수를 같이 본다.

구현 메모
- 메시가 정적 1개라 퍽은 새 오브젝트(실린더)를 기둥 앞에 두고 로컬 y 를 애니메이션, 별은 기존 별 위치에 발광 쿼드를 얹어 켠다(실측 배치). 점수판은 TMP SDF 3D 텍스트 + 판.
- 프로젝트에 망치 휘두르기 클립이 없다(Emotes: Cheer/Clap/Wave/Nod/Laugh/Sit/Drink/Reverence/Sleep 5종). 클립 확보 또는 절차적 스윙(양팔 위로 -> 아래로) 중 결정 필요.
- 동기화: 씬에 in-scene NetworkObject 가 0개이고 기준선(ConnectionManager) 은 동결이므로, 플레이어 프리팹의 별도 NetworkBehaviour(PlayerAppearanceController 방식) 로 소유자가 ServerRpc -> 서버가 판정값을 ClientRpc 로 전파. 새 접속자에게는 마지막 상태를 서버가 보내 준다.
- 부스 정적 오브젝트 Local Spawn 원칙과 NetworkPlayer 동결은 그대로.

확정 필요
1. 점수 규칙: (a) 무작위 가중, (b) 타이밍 — 기둥/별을 오르내리는 표식이 있고 F 순간에 따라 세기 결정, (c) F 길게 눌러 충전.
2. 보상: 장식만(BE 없음) / 코인 연동(BE 계약 필요).
3. 점수판 내용: 마지막 기록만 / 마지막 기록 + 서버 가동 중 최고 기록(닉네임).
4. 망치 클립 출처: 사용자가 애니메이션 팩 임포트 / 절차적 스윙.

완료 기준: F -> 애니메이션 -> 퍽 상승·별 점등 -> 점수판 갱신, 두 클라이언트에서 동일하게 보임. 씬 저장·develop 병합·작업일지.
