## 설명

### 작업 목적

로컬(5173)에서 월드에 들어가면 realtime STOMP 소켓이 연결되지 않고 5회 재시도 뒤 중단된다. 화면에는 "실시간 연결이 끊겼습니다. 새로고침해 주세요" 토스트만 남는다. 월드 채팅과 상담 알림을 로컬에서 검증할 수 없다.

### 원인

dev 게이트웨이(tools/devGateway.mjs)의 createGatewayProxy 에 /ws 항목이 없다. 로컬은 VITE_API_BASE_URL 이 비어 apiBaseUrl() 이 FE 오리진으로 떨어지고, realtimeClient 가 그 값을 ws 로 바꿔 ws://localhost:5173/ws 를 연다. 그 경로를 받을 프록시가 없어 Vite dev 서버 자신에게 붙었다가 끊긴다(code=1006).

배포본은 apiBaseUrl 이 절대 주소라 프록시를 타지 않아 영향이 없다. GitLab #210(Cloudflare 유휴 128초)과는 다른 건이다.

### 작업 내용

- createGatewayProxy 에 '/ws' 항목 추가. target 은 /api 와 같은 Spring, ws: true.
- tools/devGateway.test.mjs 에 계약 테스트 추가.

### 완료 조건

- [ ] 로컬에서 월드 진입 시 realtime 소켓이 연결된다(재연결 로그 0건)
- [ ] /ws 대상이 /api 와 같고 VITE_PROXY_API_TARGET 재지정을 따른다
- [ ] ws: true 가 빠지면 실패하는 테스트가 있다
