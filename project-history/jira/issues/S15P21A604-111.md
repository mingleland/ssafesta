## 설명

작업 목적

Game Studio Draft와 불변 Published version을 저장할 서버 기반을 구축한다.

작업 내용

- games, game_drafts, game_published_versions 마이그레이션
- 소유권·revision·현재 Published pointer·생성/수정 시각 제약
- game 패키지와 승인된 오류 code 정의

완료 조건

[x] Flyway 적용과 기존 환경 호환 검증이 통과한다.

[x] Draft는 game당 현재 revision을 보존하고 Published version은 수정 불가하다.

[x] 현재 Published pointer가 존재하는 version만 참조한다.

[x] 오류 이름과 필드가 S15P21A604-217 계약과 일치한다.

검증 근거 (2026-08-26, MR !33 develop 머지)

- Flyway: V13은 기존 테이블을 변경하지 않고 3개를 추가만 한다 → V12 환경과 호환. 317건 전부 Flyway를 태운 Testcontainers DB에서 돈다
- Draft revision: game_drafts PK가 game_id라 game당 1행. Published는 GamePublishedVersion의 모든 컬럼이 updatable=false
- pointer: (id, published_version) → (game_id, version_no) 복합 FK. ON DELETE SET NULL에 컬럼 목록을 명시했다 — 빠뜨리면 PostgreSQL이 PK까지 NULL로 만든다
