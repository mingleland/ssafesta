## 설명

관리 화면의 "부스 임대하기" 를 누르면 임대 창 대신 이용 안내가 뜬다.

원인: 이 버튼은 /app/booths 로 이동하고, 옛 주소가 /app/world?panel=rental 로 되돌아오면서 WorldPage 만 다시 마운트된다. Unity 월드는 라우트 밖(PersistentWorld)에 살아 있어 이미 ready 인데, 입장 안내 로직(S15P21A604-958)이 "마운트했더니 월드 안" 을 입장으로 읽었다. 1.1초 뒤 안내를 열면서 openVisitorOverlay 가 다른 창을 비워 방금 연 임대 창까지 닫혔다.

수정: 입장 판정을 "이 마운트 동안 ready 로 바뀌었는가" 로 좁힌다. 마운트 시점에 이미 월드 안이면 라우트 복귀로 보고 안내를 띄우지 않으며, 붙들어 둔 코인 토스트만 바로 푼다. 재접속·재부팅으로 ready 가 풀렸다 다시 들어오면 입장으로 친다.

완료 조건
- 관리 화면에서 부스 임대하기를 누르면 임대 창이 그대로 남는다
- 첫 입장·재입장 시 안내는 종전대로 문이 열린 뒤 뜬다
- 라우트 복귀 뒤에도 코인 토스트가 붙들린 채 남지 않는다
