## 설명

증상

- 본인 캐릭터와 카메라는 부드럽지만 다른 플레이어의 이동만 멈췄다가 따라잡는 형태로 끊겨 보임
- - 새 release 배포본에서도 동일하게 재현됨
- 확인 사항
- - Network TickRate 30Hz
   - - ClientAuthoritativeNetworkTransform 보간 활성화 및 Unreliable Delta 사용
      - - 현재 위치/회전 최대 보간 시간이 0.1초라 100ms 이상의 서버 틱 지연 또는 WebSocket 지터에서 버퍼가 고갈될 수 있음
      - 작업 범위
      - - 원격 이동 위치·회전 보간 여유를 0.25초로 조정
         - - 클라이언트 RTT 및 transport 데이터 수신 공백 진단 로그 추가
            - - 전용 서버 tick p50/p95/max 로그와 함께 원인을 구분할 수 있게 함
               - - Unity Editor 컴파일 및 Console 오류 검증
