## 설명

### 작업 목적

GitLab #173 의 부탁 ④ 다. FE 가 요청한 네 가지 중 ①②③ 은 `S15P21A604-621` 로 develop 에 들어갔고 ④ 만 남았다.

추첨이 참여자를 특정해야 하므로 운영이 "누가 언제 무엇을 답했는가" 를 읽을 수 있어야 한다. 지금은 읽을 경로가 없다.

```
GET /internal/event-surveys/{surveyKey}/results                 서비스 토큰. 집계
GET /internal/event-surveys/{surveyKey}/responses?page=&size=   서비스 토큰. 응답 원본
    { responseId, userId, nickname, submittedAt,
      answers: [{ questionId, prompt, type, text?, rating?, optionIds?, optionLabels? }] }
```

### 착수 보류 — 두 가지가 먼저 닫혀야 한다

**1. 지금 만들 필요가 있는지 미회신 (GitLab #173 질문 1)**

부르는 쪽이 "축제 뒤 명단을 한 번 뽑는 사람" 이면 endpoint 보다 SQL 한 번이 작다. 상시 화면이나 스크립트가 붙을 예정이면 만든다. **데이터는 어차피 남으므로 나중에 붙여도 늦지 않다.**

**2. 네 번째 내부 토큰 집합이 필요하다 — 인프라 왕복이 붙는다**

`/internal/event-surveys/**` 는 지금 무조건 403 이다. `AiInternalSecurityConfiguration` 이 `/internal/**` 전체를 먼저 삼키고 마지막이 `.anyRequest().denyAll()`(`:76`) 이며, 규칙이 있는 것은 `/internal/ai/**` 와 `/internal/storage/**` 둘뿐이다. 각각 자기 토큰 집합 + 자기 authority 로만 열린다.

`InternalTokenProperties` 는 세 집합 사이에 같은 값이 있으면 **기동을 거부**한다 — 기존 토큰 재사용 우회가 막혀 있고 막아 둔 이유가 GitLab #102 다. AI 토큰으로 응답자 실명이 열리면 그 분리가 무의미해지므로 재사용하지 않는다.

그래서 필요한 것: 새 authority + 필터 인스턴스 1개 + `app.internal.<new>-to-spring-tokens` + **배포 변수 주입**. 세 번째인 `INTERNAL_INFRA_TO_SPRING_TOKENS` 도 `application.yml:191` 에서 기본값 없이 필수인데 `infra/deploy/compose/dev/back.compose.yaml` 에 아직 없다(GitLab #117). 자격증명 추가는 인프라 파트와 한 번 왕복하는 일이다.

### 작업 내용 (승인되면)

1. 네 번째 내부 토큰 집합 + authority + 필터 — 인프라에 주입 요청을 함께 낸다
2. 집계: `SurveyResultService.results(surveyId, userId)` 를 그대로 쓰고 권한만 우회한다. 가드가 private `requireEditableSurvey`(`:213`) 한 곳에 모여 있어 **package-private 오버로드 하나**면 계산 로직·`REPEATABLE_READ`·`ResultsView` 를 건드리지 않는다. `textAnswers` 도 같다
3. 새로 필요한 것은 **응답 단위 원본 조회 쿼리 1개**뿐이다
4. 컨트롤러를 부스 설문과 분리한다 — 부스 설문 id 로 이 경로를 부르면 거부

**지켜야 할 두 가지 (FE 요청, 동의함)**

- `ResultsView` 의 익명 계약(*"No respondent field anywhere in it"*, spec 010 FR-009 · SC-003)은 **부스 설문 쪽에 그대로 둔다.** 응답자 식별은 이벤트 설문 `/internal` 경로에만 두고 두 축이 섞이지 않게 한다
- `/internal/**` 은 **서버측 seam** 이다. 나중에 운영 화면이 필요해지면 브라우저가 서비스 토큰을 들고 이 경로를 부르는 구조로 넓히지 않고, 관리자 인증 + 그 역할로 가드되는 별도 공개 경로를 그때 설계한다

### 완료 조건 (승인되면)
