## 설명

### 작업 목적

Swagger 문서가 프론트에 실재하지 않는 오류코드를 알려주고 있다.

컨트롤러 `@ApiResponse` 설명 10곳이 `BOOTH_FORBIDDEN` 을 약속하는데 `ErrorCode` enum 에 그 값이 없다. 실제 응답의 `code` 는 `BOOTH_EDITOR_FORBIDDEN` 이고 통합 테스트 8건이 그 값을 고정하고 있다. FE 가 Swagger 대로 분기를 짜면 그 분기는 영원히 걸리지 않는다.

`OpenApiDocumentationTest` 는 operation 에 설명이 있는지만 검사한다. 설명이 참인지는 아무도 검사하지 않는다.

### 작업 내용

1. `OpenApiDocumentationTest` 에 검사 하나 추가 — `@ApiResponse` 설명에 백틱으로 적힌 SCREAMING_CASE 토큰은 전부 `ErrorCode` 에 실재해야 한다. **테스트를 먼저 넣고 red 를 확인한다.**
2. 확인된 불일치 정정 — `BOOTH_FORBIDDEN` 을 `BOOTH_EDITOR_FORBIDDEN` 으로. AiAgentController 5곳, AiDocumentController 2곳, BoothFacadeController, BoothHomepageController, BoothLayoutController.
3. 같은 검사에 걸리는 다른 코드가 있으면 함께 정정한다.

### 완료 조건

- 검사 테스트가 존재하고, 정정 전 red 였다가 정정 후 green 이 된다
- /v3/api-docs 가 언급하는 모든 오류코드가 ErrorCode 에 실재한다
- 응답의 code 값 자체는 바꾸지 않는다 — 문서만 정정한다 (헌법 24조)

### 테스트 방법

./mvnw test -Dtest=OpenApiDocumentationTest
