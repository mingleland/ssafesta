## 설명

재현 방법

1. 로그인 후 app/games/9302/edit?fixture=max 접속 (100x100 맵, Object 500/500, Tile 10000/10000)
   
   1. 상단 “성능 점검” 활성화 후 “플레이 테스트” 클릭 → play?source=local&perf=1 진입
      
      1. 탭을 최전면에 두고 5~10초 대기 → 상단 오버레이의 FPS, p95 frame time, 느린 frame 비율 확인
         
         1. 시간 간격을 두고 3회 반복 측정
      2. 기대 결과
      3. p95 frame time 18.2ms 이하, 느린 frame 비율 5% 이하 (specs/019-game-studio/FE/quickstart.md #18 목표, 55fps 기준 역산값)
   2. 실제 결과
   3. 1차: FPS 80  p95 41.7ms  끊김 11.1%
   4. 2차: FPS 75  p95 50.1ms  끊김 12%
   5. 3차: FPS 77  p95 49.9ms  끊김 11.7%
   6. FPS 자체는 목표를 넘지만 p95, 끊김 비율은 3회 모두 일관되게 목표의 약 2.3~2.7배를 초과함. 노이즈가 아니라 재현되는 병목으로 판단.
2. 로그  Screenshot
3. 없음 (오버레이 실측값 기준, 콘솔 에러는 0건)

관련 Issue

https://ssafy.atlassian.net/browse/S15P21A604-156 - 이 티켓의 완료조건(p95 100ms 이하, 55fps 이상)은 실측으로 충족했으나, 검증 과정에서 이 후속 이슈를 발견함



완료 조건

1. 병목 원인 규명 (렌더링 방식, 오브젝트 수, 타일 렌더링 등)
2. 1. p95 frame time 18.2ms 이하, 느린 frame 비율 5% 이하로 재측정 통과, 또는 목표치 재조정에 대한 팀 합의
   2. 1. 관련 기능 Regression 없음
