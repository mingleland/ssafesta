## 설명

# 작업 목적

- 미니맵을 드래그해서 캔버스 뷰를 연속으로 이동시킬 수 있게 한다.



# 작업 내용

- CanvasMinimap.tsx에 드래그(mousedown→mousemove→mouseup) 추적 로직 추가
- 필요시 GameStudioShell.css의 .gss-canvas-minimap 스타일 조정



# 완료 조건

- [ ] 미니맵을 드래그하는 동안 캔버스 뷰가 마우스 위치를 실시간으로 따라간다
- [ ] 드래그 없이 클릭만 해도 기존과 동일하게 해당 위치로 이동한다
- [ ] Scene 경계 밖으로 드래그해도 좌표가 clamp되어 오류 없이 동작한다



# 테스트 방법

- Scene을 줌인해 미니맵 뷰포트 사각형을 작게 만든 뒤, 미니맵을 드래그해 캔버스가 실시간으로 따라오는지 확인. 단순 클릭 회귀도 확인.
