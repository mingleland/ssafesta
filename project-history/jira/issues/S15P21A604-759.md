증상
브라우저 탭이 비활성화되어 NGO 연결이 끊긴 뒤 자동 재접속하면 동일 사용자의 외형과 이름은 유지되지만 서버 승인이 항상 스폰 좌표를 배정해 기존 자리를 잃는다.

선행 결정
A. 재접속 시 스폰 위치로 복귀 유지
B. 서버가 연결 종료 전 마지막 위치를 짧은 TTL(제안 2분)로 보관하고 동일 사용자 재접속 시 복원
C. 위치는 복원하지 않고 FE에서 안내

헌법 30조에 따라 구현 전에 게임·기획이 정책과 TTL을 확정한다.

완료 조건
- 선택한 정책과 TTL/예외 조건을 계약 문서에 기록
- 45초 및 3분 백그라운드 후 재접속 시나리오 검증
- 구현 선택 시 동일 사용자만 위치가 복원되고 다른 사용자/새 세션에 좌표가 섞이지 않음
