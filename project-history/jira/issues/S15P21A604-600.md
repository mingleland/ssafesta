## 설명

GitLab 이슈 #120 §8-2 로 남아 있던 가격표 확정 회신이 2026-09-10 게임 파트/기획에서 도착했다. V16 시드의 임시값(유료 전량 100 코인, 무료 12종)을 확정값으로 교체한다.

계약 변경은 없다. `GET /api/v1/catalog/items` 응답 형식, `owned` 판정식(`price == 0 || 보유행 존재`), 오류 코드 모두 그대로다. FE·Unity 는 `price` 를 표시용으로만 쓰므로 클라이언트 변경이 없다. 시드 `UPDATE` 마이그레이션 한 개가 작업 범위다.

## 1. 가격 — 슬롯별 3단

| 슬롯 | 가격 |
|---|---|
| HAIR, GLASSES | 30 |
| TOP, BOTTOM, SHOES, HEAD | 40 |
| OUTFIT, HAT | 50 |

근거: 코인 유입이 신규 200 / 일일 50 이고 현금 충전은 영구 제외(2026-08-19 확정)라 임시값 100 은 일일 지급 이틀치였다. 30~50 이면 신규 200 으로 4~6종을 바로 고르고 이후 하루 1~1.6종씩 늘어난다.

## 2. 무료 20종 (현재 12종)

- HEAD 8종 전량 — 얼굴형은 코스튬이 아니라 캐릭터 본체다. 판매 대상으로 보지 않는다.
- HAIR 4 / 31 — `2119104882`, `817213556`, `463374136`, `2055903654`
- TOP 4 / 26 — `2018826405`, `884777048`, `1335128787`, `411197940`
- BOTTOM 2 / 12 — `656603128`, `1361764366`
- SHOES 2 / 7 — `1012069418`, `1416813526`
- OUTFIT, HAT, GLASSES 전량 유료 — 한 벌을 갖추는 데 필수가 아니라 꾸미는 쪽이다.

합계 무료 20 / 유료 77 = 97.

기획이 같은 날 무료 42종 안을 먼저 올렸다가 20종으로 재확정했다. 42종 안은 채택하지 않는다.

## 3. 무료에서 유료로 올라가는 4종

현재 무료 12종 중 4종이 새 목록에 없어 `price 0` 에서 유료로 바뀐다.

| 품목 | asset_key | 새 가격 |
|---|---|---|
| Shared_Glasses.001 | 2107176923 | 30 |
| Shared_Hat.001 (family) | 1001 | 50 |
| F_Outfit.01 | 512024387 | 50 |
| M_Outfit.01 | 1164919338 | 50 |

무료 품목은 보유 행을 만들지 않으므로(#120 §6) 유료 전환은 `owned` 를 true 에서 false 로 뒤집는다. 이 4종을 착용한 `avatar_code` 는 다음 저장에서 `409 AVATAR_ITEM_NOT_OWNED` 를 받는다.

실제 위험은 없다고 판단한다. Unity `AvatarCatalog.CreateDefault` 는 OUTFIT 을 0(미착용)으로 두고 HAT, GLASSES 는 아예 설정하지 않으므로 기본 아바타가 이 4종을 입지 않는다. 슬롯 값 0 은 서버 검사에서 제외된다(#120 §5). 또 `GetSelectableItems` 가 판정 준비 후에는 해제된 항목만 후보로 쓰므로 기본 조합이 유료 품목을 고르지도 않는다. dev/demo 서버가 아직 배포되지 않아(T-110) 저장된 사용자 아바타도 없다.
