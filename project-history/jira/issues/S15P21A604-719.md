## 설명

### 작업 목적

**방문자가 상담을 끝내면 직원 화면은 아무 알림도 받지 못한다.**

상담 계약이 자기모순이었다. `POST .../sessions/{sessionId}/end` 절은 "방문자·직원 누구나 종료할 수 있다. **상대에게** `ended` 이벤트가 간다(FR-010)" 라고 적는데, 이벤트 표에는 `ended` 가 **방문자 큐에만** 있고 직원 토픽(`requested`·`cancelled`·`expired`·`taken`)에는 없다. 구현은 표를 따랐다 — `ConsultationService.end` 가 `/user/queue/consultation` 으로만 보낸다.

`S15P21A604-693` 리뷰에서 발견해 `docs/26_팀_결정_필요사항.md` 에 결정 요청으로 올렸고, **2026-09-14 FE 가 선택지 1번(직원 토픽에 **`ended` 추가)으로 회신했다 (GitLab #133).

### 결정 근거 (FE 회신)

- **어휘가 대칭이 된다.** `VisitorChannelEvent` 에는 `ended` 가 이미 있다. 2번으로 가면 같은 사건을 방문자 쪽에서만 `ended` 라 부르고 직원 쪽에는 이름이 없는 채로 굳는다.
- `taken` 을 미리 넣은 사정이 종료에도 그대로 있다. 방문자는 나갔는데 직원 화면에는 "진행 중" 이 남고, 그 카드로 뭔가를 더 하면 터진다.
- **FE 비용은 타입 한 줄이다.** 직원 토픽을 구독하는 코드가 아직 없어 소비처 변경이 0이다. FE 는 **BE 가 develop 에 닿은 뒤** 타입을 추가하겠다고 했다 — 서버가 보내지 않는 이벤트를 타입에 먼저 올리면 한 번도 안 타는 분기가 생기기 때문이다.

### 작업 내용

`ConsultationEventPublisher.expired` 가 **이미 두 곳에 보내는 선례**다. `ended` 를 같은 모양으로 맞춘다.

```java
public void ended(Long boothId, Long visitorUserId, Long requestId) {
    toStaff(boothId, envelope("ended", requestId));
    toVisitor(visitorUserId, envelope("ended", requestId));
}
```

- 봉투는 `{ type: "ended", requestId, occurredAt }` — **추가 필드 없음** (FE 확정)
- 호출부는 `ConsultationService.end` 하나뿐이고 `consultation.getBoothId()` 를 이미 들고 있다
- **종료한 직원 본인도 받는다.** 직원 토픽으로 보내기 때문이고, `taken` 이 이미 같은 성질이다(수락한 본인도 받는다). 계약의 "**상대에게** `ended` 가 간다" 문장은 그래서 함께 고쳐야 한다

### 완료 조건

- [ ] 방문자가 종료하면 **그 부스 직원 토픽에도** `ended` 가 간다
- [ ] 직원이 종료해도 같다 (종료자 본인 포함)
- [ ] 방문자 큐의 `ended` 는 그대로 간다 (회귀 없음)
- [ ] 봉투에 추가 필드가 없다
- [ ] 계약 문서 6곳이 새 동작과 일치한다
- [ ] `docs/26` 의 해당 미결 항목이 **확정**으로 바뀌고 근거(#133, 2026-09-14)가 적혀 있다

### 선행 작업 / Dependency

없다. FE 회신으로 게이트가 열렸다.

후속(FE 몫): `StaffChannelEvent` 에 타입 한 줄 추가. **develop 도달 후** 하겠다고 회신돼 있으므로 병합되면 #133 에 통보한다.

### 테스트 방법

`cd backend && ./mvnw test -Dtest=ConsultationEventPublisherTest,ConsultationApiIntegrationTest`

`ConsultationEventPublisherTest.acceptingTellsBothTheQueueAndTheVisitor` 가 **두 destination 을 순서로 단정하는 패턴**을 이미 갖고 있다. 그대로 베껴 종료용 테스트를 만든다.
