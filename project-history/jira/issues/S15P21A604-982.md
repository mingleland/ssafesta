## 설명

### 작업 목적

`@Scheduled` 12개 중 다중 인스턴스에서 안전하지 않은 4개를 고친다. 스위퍼가 STOMP heartbeat 스케줄러(`messageBrokerTaskScheduler`)와 같은 스레드풀에서 도는지 실측하고, 같으면 분리한다.

### 범위

- 스케줄러 풀: 실행 스레드를 측정한다. broker 스케줄러와 공유하면 `SchedulingConfigurer` 로 전용 풀을 둔다.
- 상담 만료(`ConsultationService.expireStale`): SKIP LOCKED 로 잠근 행만 만료하고 그 행에만 `expired` 를 푸시한다. 지금은 SELECT 와 UPDATE 사이에 수락된 상담에도 `expired` 가 나간다(단일 인스턴스에서도 경합).
- 경품 마감(`EventPrizeRepository.findIdsToClose/findIdsToDraw`): `order by id` 로 락 순서를 고정한다(두 인스턴스 데드락 제거).
- advisory lock 헬퍼: 두 정수 키 `pg_try_advisory_lock`. 원본 삭제·정합 점검·로고 정리의 예약 실행 진입점에만 적용한다.
- 로고 정리 `ProjectLogoCleanup.collect`: 자기호출이라 무효인 `@Transactional` 을 `TransactionTemplate` 으로 고친다.
