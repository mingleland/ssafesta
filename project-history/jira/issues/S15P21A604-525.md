## 설명

develop 2ee5269d (-522 right panel collapse 병합) 에서 npm run build 가 실패한다.

src/game-studio/__tests__/unit/gameStudioShellRightPanelCollapse.test.tsx(33,7): error TS6133: 'MAP_SCENE_NAME' is declared but its value is never read.

확인 사항
- 작업 트리 깨끗한 상태의 develop tip 에서 재현된다. 내 변경과 무관하다
- vitest 는 통과한다. tsc 가 테스트 파일까지 포함해 타입체크하므로 build 만 깨진다
- MAP_SCENE_NAME 은 선언만 되고 파일 어디서도 참조되지 않는다 (같은 블록의 DIALOGUE_SCENE_NAME · OTHER_DIALOGUE_SCENE_NAME 은 사용된다)

조치
- 죽은 상수 한 줄 제거. 테스트 단언은 건드리지 않는다
- 맵 씨에 대한 케이스를 의도했던 것이라면 그 케이스는 작성자가 추가한다 — 내가 발명하지 않는다

09-08 사용자 테스트 당일이고 develop 이 빌드되지 않는 상태라 먼저 뚜다.
