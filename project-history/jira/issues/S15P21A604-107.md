## 설명

작업 목적

사용자 Asset을 서버에 보관해 브라우저 세션이 바뀌어도 유지되는 stable asset:// 참조를 만든다.

작업 내용

- 승인된 이미지 allow-list와 파일당 5MiB 상한 검증

- 게임 Owner 권한 검증, R2 저장, gameId/assetId/type/size/status 메타데이터 기록

- 저장 성공 뒤 stable assetId 반환, 실패 시 고아 파일·메타데이터 정리

완료 조건

[ ] 형식·크기·권한 위반이 승인된 GAME_* 오류 계약으로 거부된다.

[ ] 업로드 결과가 asset:// 참조로 저장되고 새 세션에서도 해석된다.

[ ] 미완료 업로드가 Publish에 포함되지 않는다.

[ ] 저장 실패·재시도에서 중복 메타데이터와 고아 객체가 남지 않는다.
