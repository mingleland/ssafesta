## 설명

GitLab #210 · #211.

두 가지를 한 MR 에 커밋 둘로 나눠 넣는다.

1. shared/realtime/realtimeClient.ts — CONNECT 헤더의 heart-beat 를 0,0 에서 0,20000 으로 바꾼다. 소켓에 트래픽이 0 이라 유휴 프록시 타임아웃(nginx proxy_read_timeout 180s 또는 Cloudflare)에 끊기고 있다. BE 의 setHeartbeatValue 와 짝이어야 효과가 난다.

2. features/auth/model/unauthorizedHandler.ts — refresh 실패 두 지점(첫 실패 비-ROTATED, ROTATED 재시도 실패)에서 오류를 통째로 버리고 있어 INVALID_MEMBER_TOKEN 과 REFRESH_TOKEN_ROTATED 를 가를 수 없다. code·status·requestId·hasAccessToken 을 남긴다. 토큰 값은 남기지 않는다(헌법 13조·15조). 동작은 바꾸지 않는다.
