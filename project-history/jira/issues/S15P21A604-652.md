## 설명

2026-09-11 오후 회차. MR !695 가 Jira 키 충돌로 BE 티켓(-645)에 연동됐다 — 이 티켓이 실제 근거다 (GitLab #178).

1) 축제 입구를 막던 보이지 않는 벽
정적 병합본에 합쳐진 경계로 만든 BoxCollider 가 붙어 있었다. 가로등 기둥 몇 개짜리 메시(삼각형 160개)에 2x56x110 짜리 판이 서 있어 빈 공간까지 막혔다. 복도 출구가 통째로 닫혀 있었다(z 120·150·180 전부 x=-235 에서 정지). 병합본 18개의 BoxCollider 를 MeshCollider 로 교체(삼각형 합계 15,648).

2) 로비 차단벽이 벽면에서 떨어져 있고 단차를 무시했다
Block_N_East 방 쪽 면 z=-130.38 하나가 실제 뒷벽 두 조각(-120.71 / -124.38)을 덮고 있었다. 벽까지 6.0~9.7u 를 남기고 멈췄다. 실측 좌표로 구간을 쪼개 벽면 바로 뒤에 세웠다 — 캐슐 스윙 검증에서 세 지점 모두 차이 0.00u.

3) 판넬 글자가 깨지던 것 — 원인은 FBX 원본
임포터 설정(weld·optimize 끄고 UInt32)을 바꿔 재임포트해도 메시가 한 개도 바뀌지 않았고, 글자를 면보다 0.5u 앞으로 띄워도 렌더 결과가 픽셀 단위로 동일했다(z-fighting 아님). 큰 제목은 멀줦하고 작은 글자만 깨지는 삼각형 유실의 전형이다. 깨진 글자 지오메트리를 메시에서 걷어내고(12,398 삼각형) 같은 내용을 TMP 로 다시 세웠다. FestaPanelTextBuilder 는 정규화 좌표 표 하나로 문구·위치를 관리한다.

4) 그 밖
- 정적 병합으로 대체된 축제 부스 원본 716개 제거(참조 걸린 36개는 보존)
- 막힘 애니메이션 로직 철거 — 사용감 판단
- MSAA Mobile 2x / PC 4x
