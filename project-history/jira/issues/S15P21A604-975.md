## 설명

SSAFY 제출 규격(포팅 매뉴얼)에 맞춰 저장소 루트 exec/ 폴더에 4개 산출물을 만든다. 기존 문서는 재작성하지 않고 링크한다.

- exec/02_외부_서비스_정보.md: Google·Kakao·SSAFY OAuth, SSAFY GMS, Cloudflare R2, Mattermost 가입·발급 절차
- exec/03_db_dump.sql: demo DB 기준, 개인정보 마스킹, flyway_schema_history 포함
- exec/04_시연_시나리오.md: 현재 UI 기준 시연 흐름 (Booth Studio 제외)

완료 조건: 4개 파일이 develop 에 병합되고 Secret·개인정보 노출이 없다.
