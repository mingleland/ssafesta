## 설명

이전 설명 참고 — 오타 수정만 한다. AI 직원을 등록하고 문서도 올렸는데 월드에서 AI NPC에게 말을 걸면 "이 부스의 AI 도우미는 아직 준비 중이에요"가 뜨는 QA 제보.

원인: Unity AiNpcInteractable.cs가 configId==0(HasConfig=false)이면 대화를 안 연다. 부스 스튜디오(PropertiesPanel.tsx)에 AI_AGENT 오브젝t(object)를 놓으면 "연결 콘텐츠 ID"라는 숫자 직접 입력 칸이 뜨고, 여기에 AI 직원의 실제 agentId 숫자를 타이핑해야 연결된다. 문제는 AiAgentManagementTab 어디에도 등록된 agentId 숫자를 화면에 보여주는 곳이 없어 사용자가 입력할 수가 없다는 것.

해결: 부스당 AI 직원은 항상 한 명뿐이라(V15__agent_one_per_booth, 409 AGENT_LIMIT_EXCEEDED) 수동 입력을 없애고 자동 연결한다 — StudioPage가 부스의 등록된 AI 직원(getAiAgent)을 조회해 AI_AGENT 타입 오브젝t(object)의 configId를 항상 그 agentId와 일치시킨다(미연결이든 잘못된 값이든 자가치유). PropertiesPanel은 AI_AGENT 타입일 때 숫자 입력 대신 연결된 AI 직원 이름을 읽기 전용으로 보여준다.

범위 밖: PROJECT_PANEL·SURVEY_KIOSK 등 다른 연결형 타입은 같은 구조적 UX 구멍이 있지만(모두 숫자 ID 직접 입력, 화면에 ID 노출 안함) 이번 작업은 AI_AGENT만 고친다 — AI_AGENT는 부스당 1명 제약이 있어 자동 연결이 모호성 없이 가능하지만 다른 타입은 복수가 가능해 드롭다운 설계가 필요해 별도 논의 대상.
