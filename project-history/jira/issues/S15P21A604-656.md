## 설명

Jenkins festa-webgl-package-deploy #5·#6 이 같은 산출물(886b04ca8503)로 연달아 실패했다. 실패 지점은 배포가 아니라 공개 URL 검증이다.

verify failed: https://demo.ssafesta.world/unity/manifest.json / HTTP/2 403 / content-type: text/html / server: cloudflare / cf-ray: a3954ef6584eea20-ICN

인프라 확인 결과 상시 차단이 아니다 — 같은 에이전트에서 같은 URL 이 지금은 200 을 준다. 엣지가 간헐적으로 검증 요청만 막는데, 그때마다 배포물을 롤백해 버린다. 검증 경로의 문제로 배포물을 되돌리는 것은 틀렸다.

고칠 것 (infra/jenkins/scripts/deploy-webgl-release.sh)
1. 일시 실패(403·429·5xx·네트워크 오류)는 백오프를 두고 재시도한다. 2xx 인데 Content-Type·Cache-Control 이 어긋난 것은 진짜 배포 결함이므로 재시도하지 않는다.
2. 재시도까지 실패하고 응답에 cf-ray 가 있으면 엣지 차단으로 보고, 같은 경로를 오리진(로컬 nginx)에 직접 물어본다. 오리진이 정상이면 릴리스를 유지하고 엣지 검증이 막혔다는 경고만 남긴다.
3. 어느 경로로 검증했는지 evidence JSON 에 남긴다.
