[이 티켓의 범위 — 지금 측정 가능한 것]
1. 성능: 외부 Chromium 활성 탭 1920x1080, 최대 상한 fixture(?fixture=max, 100x100 · Object 500 · Tile 10000)에서 편집 반응 p95 100ms 이하, 플레이 55fps 이상
2. 접근성: 키보드만으로 저장/undo/redo/레이어/선택 Object 1칸 이동과 focus 표시
3. 오류 복구 UX: 손상 프로젝트 · schema 미지원 · Draft 409 · 로컬 Asset Publish 차단
장치·브라우저 버전을 함께 기록한다.

[이 티켓의 범위가 아닌 것 — 명시적 잔여]
개발 경험 없는 한국인 참가자 5명의 20분 완주 사용성 테스트는 사람이 필요하므로 이 티켓이 대체하지 않는다. 자동화로 갈음하지 않고 미실시로 명시해 남긴다(이슈 원문도 T090 을 그렇게 두었다).

[완료조건 — 이슈 종결과 같지 않다]

- 기록지는 이슈가 지정한 specs/019-game-studio/FE/usability-test.md 를 쓴다
- GitLab #73 은 5인 사용성이 남아 있어 닫지 않는다. 이 티켓은 기술 검증분만 닫는다

[GitLab #55 와 분리한 이유]
실행 환경(로컬 스택 + gameId 1)을 공유해도 완료조건이 다르다. #55 는 E2E 통과가 완료조건이고 이쪽은 측정 원자료 첨부와 P0/P1 분리가 완료조건이라 한 키로 묶지 않는다(S15P21A604-517 별건).
