## 설명

## 작업 목적

부스 슬롯 임대 확인 모달만 스타일이 하나도 적용되지 않아 흰 배경·기본 폰트로 뜬다. 결제 직전 화면이라 눈에 띈다. (2026-09-10 플레이 중 실측)

원인은 화면(`SlotListPage`)이 Screen Local Baseline(`PageShell` + `sc-*`)으로 이관될 때 **모달만 그 이관에서 빠진 것**이다. `LeaseConfirmDialog` 는 이 저장소 유일의 네이티브 `<dialog>` 이고 className 이 하나도 없으며 짝이 되는 CSS 파일도 없다. 기능·에러 매핑은 정상이고 표현만 남았다.

## 작업 내용

`features/booth/ui/leaseConfirmDialog.css` 를 신설하고 `LeaseConfirmDialog.tsx` 에 클래스를 붙인다.

- 토큰은 새로 정의하지 않는다 — `<dialog>` 가 top layer 로 승격돼도 커스텀 속성 상속은 DOM 트리 기준이라 `.festa-screen` 안에 있는 한 `--sc-*` 가 그대로 닿는다
- 버튼은 기존 `sc-btn` · `sc-btn-primary` 를 쓴다
- `::backdrop` 도 준다 — 브라우저 기본 backdrop 은 거의 투명해 뒤 화면과 구분이 안 된다
- 차감 코인·보유 코인은 세로로 맞춰 비교가 되게 한다(`tabular-nums`)

## 완료 조건

1. 모달이 슬롯 카드와 같은 토큰 계열로 그려진다
2. `<dialog>` 의 Esc 닫기·포커스 가둠·backdrop 동작에 회귀가 없다
3. 잔액 부족·잔액 조회 실패 안내(`role="alert"`)가 그대로 보인다
4. tsc 0 / vitest 전체 green / oxlint 신규 경고 0
