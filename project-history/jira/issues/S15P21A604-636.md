## 설명

### 작업 목적

docs/26에 BE 소관으로 남아 있는 미결 2건을 닫는다. 둘 다 같은 파일을 고치므로 텍스트 충돌을 피하려고 한 MR로 묶는다.

### 작업 내용

**1. FAILED 문서 원본 삭제 정책 — 확정 등재**

- 결정: FAILED 상태 문서의 원본은 `updated_at` 기준 **7일 유예** 후 EXPIRED와 같은 스윕 경로에서 자동 삭제한다. 조사·재처리는 유예 기간 안에 한다
- 수동 검토 후 삭제 방식은 채택하지 않는다 — 상시 감시할 운영 인력이 없어 원본이 무기한 남는다
- 재처리로 상태가 FAILED를 벗어나면 대상에서 자동으로 빠진다. 기존 스윕이 이미 스냅샷 전체(`processing_status`·좌표·`s3_key`) 일치를 조건으로 갱신하므로 추가 장치가 필요 없다
- 구현은 별도 티켓으로 분리한다

**2. AI 문서 결과 API 계약 행 — 닫는다**

- docs/26 "AI 문서 처리 계약 후속 합의" 표의 첫 행이 heartbeat·batch·finalize·failed의 **endpoint 경로·DTO 이름·공통 오류 봉투**를 "남은 결정"으로 적어 두었다
- 실제로는 `AiDocumentResultController`가 네 경로를 전부 구현해 develop에 있고, FastAPI와 결선도 끝났다. 태깅된 S15P21A604-449도 완료 상태다
- 미결로 남겨두면 다음 사람이 이미 닫힌 결정을 다시 연다. 구현을 정본으로 못박고 행을 결정 기록으로 옮긴다
