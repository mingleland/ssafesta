## 설명

## 현상

Jenkins develop Pipeline의 Frontend build 단계가 TypeScript 컴파일 오류로 실패합니다.

Backend test·build·Docker package 단계는 통과했으며, 현재 CI 병목은 Frontend입니다.

## 재현 경로

1. Jenkins `festa-gitlab-rehearsal`의 develop Pipeline 실행
2. Frontend `ci/build` 단계에서 `npm run build` 실행
3. `tsc -b && vite build`의 TypeScript 검사에서 실패

## 오류 위치

`festa-frontend/src/game-studio/__tests__/unit/canvasMinimapDrag.test.tsx`

## 오류 내용

```text
TS2322: DIALOGUE 타입이 WorldScene에 할당될 수 없음
TS2339: WorldScene의 일부 타입에는 width 속성이 없음
TS2339: WorldScene의 일부 타입에는 height 속성이 없음
```

`WorldScene`은 `TOP_DOWN`, `PLATFORMER`, `DIALOGUE` 등을 포함하는 union type입니다. 현재 테스트는 `width`, `height`가 있는 씬만 전제하지만 `DIALOGUE` 씬에는 해당 속성이 없습니다.

## 기대 결과

- 테스트 fixture·변수 타입을 실제 테스트 대상 scene 타입으로 좁히거나,
- `width`, `height` 접근 전 scene type guard를 적용
- `npm run build` 및 Jenkins develop Pipeline 통과

## 영향 범위

- Frontend CI build 실패
- develop Pipeline이 Frontend 단계에서 중단되어 이후 배포 단계로 진행 불가
- Backend Docker image 생성까지는 정상 통과
