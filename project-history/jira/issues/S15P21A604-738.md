## 설명

증상 - 멀티플레이에서 다른 플레이어의 이동 시작·정지가 즉시 반영되지 않고 약 1~2초 늦게 보인다. - 누적된 위치 차이를 따라잡는 구간에서 원격 캐릭터가 순간적으로 매우 빠르게 움직인다. - 가까이 붙어 같은 컴퓨터/오브젝트를 사용할 때 특히 눈에 띈다.  조사·수정 범위 - ClientAuthoritativeNetworkTransform의 동기화 주기, 임계값, 보간 설정과 실제 프리팹 직렬화 값을 확인한다. - 소유자 이동 상태의 전송 빈도와 원격 수신 보간 버퍼를 계측해 지연이 전송 단계인지 표현 단계인지 분리한다. - 정상 보행에서는 낮은 지연으로 부드럽게 반영하고, 큰 위치 보정·텔레포트만 즉시 처리하도록 조정한다. - 2클라이언트에서 이동 시작/정지 지연과 따라잡기 급가속을 재검증한다.  관련 사용자 제보 1. 다른 플레이어를 바라볼 때 간헐적으로 확확 빠르게 움직임 2. 움직임 반영이 1~2초 늦어 가까이 협업할 때 눈에 띔
