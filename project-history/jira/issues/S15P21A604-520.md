## 설명

BE 가 GitLab #133 (2026-09-07 18:16) 에서 알려온 결함이다.

S15P21A604-192 로 서버는 설문 응답 보상 Coin 지급을 준비하는데, Survey Builder 에 rewardCoin 입력 필드가 없어 운영자가 값을 넣을 화면이 없다. 서버 기능이 제품에서 닿지 않는다.

BE 확정 사항
- 보상 상한 기본값 10 Coin (app.survey.* 설정). 기획 결정 대기 중이며 정해지면 값만 바뀐다 (docs/26 row 21)
- C-05 게스트 응답은 허용하되 rewardCoin > 0 설문은 게스트 403 MEMBER_ONLY. 즉 Builder 에서 이 값을 0 보다 크게 넣는 순간 그 설문은 회원 전용이 된다 — 그 사실이 작성 화면에 드러나야 한다
- submitAnswers 응답은 { responseId, rewardedCoin } 이고 보상이 없으면 rewardedCoin 은 0 이다 (키 부재가 아니다)

작업 범위
1. Survey Builder 에 rewardCoin 입력 추가 (0 = 보상 없음)
2. 0 보다 큰 값을 넣으면 게스트가 응답할 수 없다는 안내 노출
3. 상한 초과 시 서버가 400 VALIDATION_FAILED + errors[0].field 로 거부하므로 그 오류를 해당 필드에 붙여 표시

선행 조건: BE 계약 문서 specs/010-survey/contracts/ 도착. 그 전에는 상한 값의 정본이 없다.
