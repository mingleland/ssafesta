## 설명

GitLab #171 (게임 파트 요청 (a), 2026-09-10 19:54) 의 BE 몫. Unity 가 축제장 진입 시 부스 12개 간판을 채우는 데 지금은 /booth-slots 1회 + 부스당 GET /booths/{id} 로 최대 13요청이 든다. 슬롯 목록에 facade 를 실으면 1요청으로 끝난다.

## 범위

- GET /api/v1/booth-slots 의 SlotView 에 facade 추가: { themeCode, primaryColor, signText, logoUrl } (BoothFacadeService.FacadeView 와 같은 모양, GET /booths/{boothId}.facade 와 값 동일)
- OCCUPIED 슬롯만 채우고 AVAILABLE 은 null. 기존 필드는 그대로 (순수 추가 변경)
- listSlots 가 이미 하는 booth 조회에 얹어 쿼리 수를 늘리지 않는다 (N+1 금지)
- specs/004 (부스 임대) contracts/lease-api.md §GET /api/v1/booth-slots 응답 표 갱신

## 테스트

| 이름 | 확인 |
|---|---|
| slotListCarriesFacadeForOccupiedSlots | 임대·facade 가 저장된 슬롯이 facade 4필드를 돌려준다 |
| slotListFacadeIsNullForAvailableSlots | 빈 슬롯은 facade null |
| slotListFacadeMatchesPublicBoothView | 같은 부스의 GET /booths/{id}.facade 와 값이 같다 |
| 기존 BoothSlot* 스위트 | 회귀 0 |

## 범위 밖

- 프로젝트 대표 이름·이미지 동봉 — 게임 파트와 "시야에 든 부스만 lazy 로드" 로 합의
- CORS 허용 origin 리스트화 — 별건
