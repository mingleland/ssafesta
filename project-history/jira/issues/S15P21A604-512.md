## 설명

## 작업 목적

대화 씬 편집기(`DialogueEditor.tsx`)에 볼 필요 없는 화면 요소들이 남아있음(Notion QA id=36). 특히 씬 표시 방식(Overlay/Fullscreen)이 캔버스 상단 툴바(친숙한 라벨)와 `DialogueEditor` 자체 씬 헤더(원시값)에서 이중으로 노출되는 정보 중복이 있고, LIVE PREVIEW 배지와 NODE 카드에도 같은 성격의 불필요한 원시 정보가 남아있음.

## 작업 내용

- `DialogueEditor.tsx` 씬 헤더의 `<span className="gss-type-badge">{scene.presentation}</span>` 제거 — 캔버스 상단 툴바가 이미 `describeSceneType()`로 같은 정보를 친숙하게("대화-Overlay"/"대화-Fullscreen") 보여주고 있어서 중복
- LIVE PREVIEW 배지(`LIVE PREVIEW · {scene.presentation}`)에서 원시 `scene.presentation` 노출 제거
- "NODE" 카드 헤더의 내부 식별자 노출(`selectedNode.id`, 예: "node3") 제거 — 사용자에게 의미 없는 기술적 정보
- 계약(`contracts/gameProject.ts`)이나 데이터 모델 변경 없음 — 순수 표시(UI) 정리
- 캔버스 상단 툴바의 친숙한 라벨(대화-Overlay/대화-Fullscreen)은 그대로 유지 — 정보 자체를 없애는 게 아니라 중복·불필요한 노출만 제거

## 완료 조건

- [ ] `DialogueEditor` 씬 헤더에 `scene.presentation` 원시값(OVERLAY/FULL_SCREEN)이 더 이상 표시되지 않는다
- [ ] LIVE PREVIEW 배지에 원시 presentation 값이 더 이상 표시되지 않는다
- [ ] NODE 카드 헤더에 내부 식별자(node id)가 더 이상 노출되지 않는다
- [ ] 캔버스 툴바의 친숙한 라벨(대화-Overlay/대화-Fullscreen)은 그대로 유지된다
- [ ] 관련 테스트 통과 + `tsc --noEmit` 통과
