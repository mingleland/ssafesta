## 설명

local 브라우저 접근을 FE gateway 로 통일한다. BE seam(S15P21A604-646, !701) 이 develop 에 도달한 뒤 붙이는 FE 쪽 작업.

- tools/devGateway.mjs — /oauth2 를 API target 으로 프록시 (rewrite 없음). local 개발용 auth gateway 보정이며 dev/demo/prod nginx 계약 변경이 아님을 주석으로 남긴다
- src/pages/login/LoginPage.tsx — OAuth 시작 URL 에 ?return=<window.location.origin>
- .env.example — local VITE_AUTH_BASE_URL=8080 직행 권고 제거, local 기본은 FE gateway 경유, VITE_PROXY_API_TARGET 은 shell env 기준임을 명시

수정하지 않는 것: dev/demo/prod nginx · /login/oauth2/code/* 콜백 프록시 · provider redirect URI · SecurityConfiguration/CORS · auth cookie 계약.

완료 기준: tsc·vitest·build green + local Chrome 에서 5175 OAuth 시작 → 5175/auth/callback 복귀·session·refresh·logout, 5173 회귀.
