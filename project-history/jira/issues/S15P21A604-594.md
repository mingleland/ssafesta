## 설명

## 증상  dev EC2에서 R2 단독 배포로 FastAPI를 기동하면 `MINIO_ENDPOINT`, `MINIO_BUCKET`, `MINIO_ACCESS_KEY_ID`, `MINIO_SECRET_ACCESS_KEY` 누락으로 Settings 검증이 실패하고 컨테이너가 재시작합니다.  ## 재현  - R2 설정은 완전하게 주입 - MinIO는 아직 구성하지 않음 - FastAPI `Settings()` 생성 시 MinIO 네 필드를 모두 필수로 요구하여 기동 실패  ## 기대 동작  P0 결정(GitLab #100)은 R2 단일 활성 저장소이며 MinIO는 운영자 승인 기반 fallback입니다. R2 단독 배포는 정상 기동해야 합니다.  - MinIO 네 값이 전부 비어 있음: 미구성 provider로 허용 - 일부만 입력: 오설정으로 기동 실패 - 네 값 전부 존재: `MINIO_LOCAL` fallback provider 사용 가능  BE 설정도 위 규칙을 이미 사용합니다. AI 설정·테스트·`.env.example`을 같은 정책으로 맞춰 주세요.  ## 완료 조건  - R2 단독 설정에서 FastAPI 기동 테스트 통과 - MinIO 부분 입력은 기동 실패 테스트 존재 - MinIO 전체 입력 시 기존 fallback adapter 회귀 없음 - 수정 이미지로 dev AI healthy 확인 후 Back↔AI 내부 통신 재검증
