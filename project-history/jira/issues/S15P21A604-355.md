## 설명

## 배경

축제존 걷기에서 사용자 요구 5건: 벽 조명 추가, 부스 내부 조명(프리팹 내장), 부스별 직원 NPC 를 통한 입장, 상호작용 사거리 축소, 노트북 F UI 를 부스 입장 UI 에 통일.

## 변경 사항

### 1. 상호작용 UI 통일 (`InteractPromptUI` 신설)

포털(부스 입장)은 키캡 패널 + 발밑 링(IMGUI), 부스 오브젝트(노트북·AI)는 화면 하단 uGUI 텍스트였다 — **같은 F 조작인데 화면이 달라 다른 기능처럼 보였다.**

그리기를 `InteractPromptUI`(프롬프트·토스트) + `InteractRing`(발밑 링) 한 곳으로 모으고, `PortalInteractor` 와 `BoothInteractionInput` 이 **둘 다 그것만** 쓰게 했다. 각자 갖고 있던 중복 구현(GUIStyle·텍스처·링 생성)은 삭제. 노트북 프롬프트도 `"노트북으로 홈페이지 열기"` 처럼 포털과 같은 어투로 바꿨다.

### 2. 사거리 — 피벗 → **콜라이더 표면** 기준

`BoothInteractionTarget.DistanceFrom` 을 추가해 표면까지 재도록 바꿨다(포털이 쓰던 방식과 동일). 피벗 기준일 때는 큰 오브젝트일수록 표면에 닿아도 피벗이 멀어 사거리를 크게 잡아야 했고(노트북 6.8 unit — T-232), 그러면 반대로 멀리서도 잡혔다.

표면 기준이면 값이 오브젝트 크기와 무관해져 한 숫자로 걸 수 있다: **40f → 13f(≈1 m)**, 비상호작용 29f → 10f. 포털도 직원 기준 24f(≈1.8 m).

### 3. 축제존 벽 조명 (`Festival_WallLights`)

벽 안쪽 면을 따라 **둥근 발광 구체 + 포인트 라이트 20개** (북·남 8개씩, 서 4개). y=40, intensity 2600, range 190, 그림자 없음(다수 광원이라 비용만 크다).

### 4. 부스 내부 조명 — **프리팹에 내장**

축제 부스 프리팹 12종 각각에 `@BoothInteriorLight`(Point, 전구색 1,0.90,0.72) 삽입. 슬롯의 부스가 교체돼도 조명이 따라오게 하기 위해 씬이 아니라 프리팹에 넣었다. range·위치는 프리팹 로컬 바운즈에서 계산(부스마다 크기가 달라 상수 불가).

### 5. 부스 직원 NPC (`BoothStaff`)

12개 슬롯 각각에 직원을 세우고, **입장 판정을 부스 구조물에서 직원으로 옮겼다**. 전에는 구조물 전체가 판정 대상이라 어디에 서든 입장이 됐다.

- 플레이어와 **같은 아바타 파이프라인**(모듈 카탈로그 조립)을 쓴다 — 별도 NPC 모델을 들이면 스케일·셰이더가 또 갈라진다 (T-235 와 같은 종류의 사고)
- 복장 `M_Outfit.03`(어두운 정장 계열), 시각 높이 22.375로 플레이어와 동일
- 배치: 부스 **안쪽**(정면 가장자리에서 깊이의 45% 안), 통로(손님) 쪽을 바라봄 — 카운터 뒤에 선 형태
- `Portal_Ext_NN` 위치를 직원으로 옮기고 프롬프트를 `"N번 부스 직원에게 말 걸기"` 로 변경

## 검증

- 컴파일 통과, 플레이 모드에서 직원 12/12 조립 (높이 22.3 u = 플레이어와 동일, 발 접지 y=0)
- 렌더 확인: `probe_festival_walllights.png`(벽등 20개 점등) · `probe_festival_boothlights.png`(부스 내부 점등) · `probe_staff3.png`(카운터 뒤 직원, 손님 시점)
