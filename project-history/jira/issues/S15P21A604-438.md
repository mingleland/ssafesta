## 설명

h3. 문제

{{FestaReleaseBuilder}} 는 Docker 이미지 태그를 3/3 단계에서 {{SourceStamp()}} 로 계산한다. 그런데 1/3 전에 {{ForceApiEnvironment(Prod)}} 가 {{ApiConfig.asset}} 을 디스크에 저장하므로(-419), clean checkout 에서 뽑아도 {{git status --porcelain}} 에 수정이 하나 있어 태그가 언제나 {{<sha>-dirty}} 가 된다. 런북의 "clean tree 이면 -dirty 가 안 붙는다" 가 성립하지 않았다.

h3. 조치

* {{Run()}} 시작 시점(어떤 에셋도 수정하기 전)에 stamp 를 한 번 계산해 {{BuildImage(stamp)}} 로 넘긴다.
* "Docker 이미지만 갱신" 메뉴는 지금처럼 호출 시점에 계산(그 경우 에셋은 수정하지 않으므로 정확).

h3. 완료 조건

clean tree(잔여 수정 파일 stash)에서 {{Festa/배포/배포 build}} → 이미지 태그가 {{festa-world:<sha>}} (dirty 없음).
