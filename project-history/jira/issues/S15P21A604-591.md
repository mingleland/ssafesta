## 설명

## 작업 목적

부스 슬롯 선택 화면에서 내 부스가 카드로 보이는데 **카드 자체는 클릭되지 않는다**. Studio 진입은 페이지 위쪽 '내 부스' 배너의 링크 하나뿐이라, 목록에서 제 부스를 찾아 눌러도 아무 일이 없다. (2026-09-10 플레이 중 실측)

목표: 내 부스 카드/영역 자체를 클릭하면 Booth Studio 로 바로 들어간다.

## 작업 내용

`pages/booth/SlotListPage.tsx` — `slot.mine` 이고 `boothId` 가 있으면 카드 내용을 `/app/studio/{boothId}` 링크로 감싼다. 카드 안에 '스튜디오에서 편집 →' 힌트를 둬 발견성을 준다.

`pages/booth/slotListPage.css` — 링크가 카드의 세로 흐름을 그대로 잇게 하고 `:focus-visible` 을 준다.

임대 가능 카드에는 임대 버튼이 따로 있고 그 카드는 `mine` 이 아니므로 클릭이 겹치지 않는다.

## 완료 조건

1. 내 부스 카드 전체가 `/app/studio/{boothId}` 링크다
2. 남의 부스 카드에는 그 링크가 없다
3. 임대 가능한 빈 카드는 임대 버튼만 갖는다 — 클릭이 겹치지 않는다
4. 키보드 포커스가 보인다
5. unit test / tsc 0 / vitest 전체 green / oxlint 신규 경고 0
