## 설명

## 작업 목적

Game Studio 대화 편집기(Overlay/Fullscreen 공용)에서 대화 노드(Node)를 관리하는 기능이 불완전함 — 노드는 생성 순서로만 나열되고 순서를 바꿀 수 없으며, 시작 노드(START)는 최초 생성 시 고정된 뒤 바꿀 방법이 없고, 노드 삭제 기능 자체가 없음(Notion QA id=30). 씬(Scene) 목록에는 이미 정렬/시작 지정/삭제 차단이 전부 구현돼 있는데 대화 노드에는 대응 기능이 없어 편집기 내 일관성도 없었음. 씬 목록의 기존 패턴을 그대로 미러링해 대화 노드에도 동일한 관리 기능을 추가한다.

## 작업 내용

- `authoringCommands.ts`에 신규 함수 추가(기존 씬 목록 함수와 1:1 대응):
   
   - `reorderDialogueNode(project, sceneId, nodeId, targetIndex)` ↔ `reorderScene`
   - `startNodeChangeReason` / `setStartNode` ↔ `startSceneChangeReason` / `setStartScene`
   - `dialogueNodeRemovalReason` / `removeDialogueNode` ↔ `sceneRemovalReason` / `removeScene`
- 삭제 차단 사유 3가지: START 노드 자체, 다른 노드의 선택지가 `nextNodeId`로 참조 중, 노드가 1개만 남음(계약상 최소 1개 강제)
- `DialogueEditor.tsx`의 NODES rail 각 행에 드래그 핸들(☰, 씬 목록과 동일한 `gss-drag-handle`)·"시작으로 설정" 버튼·삭제(×) 버튼 추가. 사유가 있으면 버튼이 `disabled` + `title`로 이유 표시(씬 목록과 동일한 UX)
- 계약(`contracts/gameProject.ts`) 변경 없음 — 기존 `startNodeId`/`nodes` 필드 그대로 사용

## 완료 조건

- [ ] 대화 노드를 드래그로 순서를 바꿀 수 있다(Overlay/Fullscreen 모두)
- [ ] 각 노드에 "시작으로 설정" 버튼이 있고, 누르면 해당 노드가 새 START가 된다(이미 START인 노드는 버튼이 비활성화된다)
- [ ] 각 노드에 삭제(×) 버튼이 있고, 일반 노드는 정상적으로 삭제된다
- [ ] START 노드는 삭제 버튼이 비활성화되고 이유가 표시된다
- [ ] 다른 노드의 선택지가 `nextNodeId`로 참조 중인 노드는 삭제가 차단되고 이유가 표시된다
- [ ] 노드가 1개만 남은 경우 그 노드는 삭제할 수 없다
- [ ] 관련 테스트 통과 + `tsc --noEmit` 통과
