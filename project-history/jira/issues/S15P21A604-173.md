## 설명

### 작업 목적

AI Agent 관리가 Booth 소유권 경계를 넘지 못함을 테스트로 고정한다.

2026-09-02 범위 확대 — GitLab 이슈 #119에서 AI 문서 DB 소유권이 Spring으로 넘어오면서 Spring이 Job 큐·chunk 저장·벡터 검색을 전부 갖게 됐다. 새 경계에서 깨질 수 있는 케이스를 이 티켓의 통합 테스트에 포함한다.

### 작업 내용

- 타 Booth Agent 조회/수정/삭제 차단 통합 테스트
- Staff/게스트 권한 매트릭스

### 추가 케이스 (GitLab 이슈 #119)

- **중복 배치** — 같은 `(job_id, batch_seq)` 재전송 시 chunk가 중복 적재되지 않는다
- **out-of-order batch** — batch가 순서 없이 도착해도 finalize 개수 검증이 걸러낸다
- **finalize 직전 장애** — 트랜잭션 중간에 실패하면 기존 chunk가 남고 Document가 READY로 넘어가지 않는다
- **cancel 경합** — cancel 전달이 실패해도 늦게 도착한 결과가 `attempt_no` fencing으로 반영되지 않는다
- **잘못된 scope** — `/internal/ai/chunk-search`가 다른 booth·agent의 chunk를 절대 섞지 않는다. 요청으로 필터를 우회할 수 없다
- **worker 재시작** — lease 만료 Job이 회수되어 `attempt_no`가 오르고, 이전 attempt의 결과가 409로 거부된다
- **내부 API 인증** — 토큰 4종(정상·누락·오류·반대 방향)과 사용자 Access Token 접근 차단
