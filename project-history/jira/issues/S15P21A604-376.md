## 설명

h3. 작업 목적
오버레이 열림 중 WASD/F가 월드로 계속 입력되는 문제(Input Lock 양측 미구현)를 풀기 위해 Unity 수신부가 필요하다. 계약 초안은 specs/019-game-studio/contracts/game-portal-bridge.md:64 (SendMessage(receiverObjectName, 'OnOverlayStateChanged', json)) — receiverObjectName이 미확정(#56)이다.

h3. FE 현황 (참고)
* FE는 송신 seam을 이미 마련했다 — festa-frontend/src/unity/bridge/overlayState.ts 의 notifyOverlayState(state, overlay), 현재 no-op (S15P21A604-365, develop 반입)
* payload 어휘는 {state: OPENED|CLOSED|FAILED, overlay} — 계약 초안 그대로. FE가 임의 확장하지 않는다

h3. Unity 파트가 결정할 것
* 수신 GameObject 이름(receiverObjectName)
* 수신 시 동작: captureAllKeyboardInput 해제/복구 범위·이동 입력 차단 범위
* FAILED 시 복구 정책

h3. 완료 조건
* [ ] receiverObjectName 확정 통보 — FE는 그 값으로 no-op을 SendMessage 구현으로 교체한다
* [ ] 오버레이 열림 중 월드 입력 차단·닫힘 후 복구
