## 설명

### 배경

2026-09-06 FE 임베드 왕복 실측(localhost:5173, 게스트 입장)에서 발견했다. FE `WorldHud` 가 이미 좌상단에 조작 카드(W A S D 이동 / F 상호작용 / Esc 닫기)를 그린다. S15P21A604-451 의 Unity `ControlsHintHud` 는 배포본에서 좌하단에 두 번째 카드를 그리게 된다.

### 규칙

타 파트를 따른다 — 오버레이 UI 는 FE 소관이다.

### 조치

FE 호스트 브리지가 있으면(`window.FestaUnity.onBoothInteract` 정의) Unity 는 카드와 칩을 숨기고, 단독 실행·probe 에서는 그대로 그린다. 함께 FE 에 Shift 달리기·Space 점프·우클릭 드래그·Alt+클릭 감정 표현 행을 추가해 달라고 요청한다(GitLab #132).
