## 설명

## 작업 목적

Game Studio에 "게임을 초기화(빈 상태로 되돌리기)"할 방법이 없고, JSON 가져오기/내보내기도 좌측 사이드바 하단에 다른 편집 UI와 섞여 있어 파일 단위 조작으로 발견하기 어렵다. 좌상단 "Game Studio" 라벨을 클릭 가능한 요소로 바꿔 팝업 메뉴를 띄우고, 그 안에 관련 기능을 모은다.

## 작업 내용

- `studio/model/createBlankProject.ts` 신설 — `createBlankProject(gameId)`: TOP_DOWN 씬 1개(배경/타일 없음), `PLAYER_SPAWN` 오브젝트 1개(컴포넌트 없음), `variables`/`items`/`events` 빈 배열, 빌트인 에셋 카탈로그는 전체 등록(`createStarterProject`와 동일한 방식), `schemaVersion: '1.1.0'` + `rules: DEFAULT_GAME_RULES`
- `studio/ui/GameStudioShell.tsx`
   
   - `.gss-logo`(현재 `<div>`)를 `<button>`으로 변경 — 클릭 시 팝업 메뉴 토글, `aria-haspopup="menu"`/`aria-expanded` 추가, hover 등 클릭 가능함을 드러내는 시각 요소 추가
   - 팝업 메뉴에 "게임 초기화" / "시작 템플릿" / "JSON 가져오기" / "JSON 내보내기" 4개를 **별개 항목**으로 배치(하나로 묶지 않음)
   - "게임 초기화" — 확인/취소 다이얼로그를 거친 뒤에만 `store.reset(createBlankProject(gameId))` 실행
   - "시작 템플릿" — 기존 6개 카드 모달은 그대로 두고 트리거 버튼만 헤더에서 팝업 메뉴로 이동
   - "JSON 가져오기/내보내기" — 기존 로직(`importProject`/`downloadProject`) 재사용, 트리거 버튼만 팝업 메뉴로 이동
   - 기존 헤더의 "▦ 시작 템플릿" 버튼, 좌측 사이드바 하단 `.gss-import-export` 블록 제거
- `GameStudioShell.css`에 팝업 메뉴 위치/스타일, 라벨 클릭 가능 표시 스타일 추가

## 완료 조건

- [ ] "Game Studio" 라벨이 클릭 가능한 버튼으로 바뀌고, 클릭 가능함이 시각적으로 드러난다
- [ ] 라벨 클릭 시 팝업 메뉴가 뜨고, "게임 초기화"/"시작 템플릿"/"JSON 가져오기"/"JSON 내보내기"가 별개 항목으로 존재한다
- [ ] "게임 초기화"는 확인 단계를 거친 뒤에만 실행되며, 실행 시 씬 1개+`PLAYER_SPAWN` 1개+빌트인 에셋만 남긴 완전히 빈 프로젝트로 바뀐다
- [ ] "시작 템플릿"은 기존 6개 카드 모달을 그대로 열고 동작에 회귀가 없다
- [ ] "JSON 가져오기/내보내기"는 새 위치에서도 기존 로직 그대로(회귀 없이) 동작한다
- [ ] 기존 사이드바 하단 JSON 버튼과 헤더의 "시작 템플릿" 버튼은 제거되어 중복 노출이 없다
- [ ] `npx tsc --noEmit`, `npx vitest run src/game-studio` 전체 통과
