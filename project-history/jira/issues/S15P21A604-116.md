## 설명

작업 목적

로컬 전용 Asset 저장소를 서버 업로드·조회 포트로 교체해 게시 뒤에도 이미지를 유지한다.

작업 내용

- GameAssetRepository 원격 adapter

- 업로드 진행·취소·재시도·오류 UX

- local URL을 stable asset://로 교체하고 참조 위치 추적

- 오프라인/로컬 fallback은 편집용으로만 허용

완료 조건

[ ] 새 브라우저 세션과 Published Runtime에서 이미지가 표시된다.

[ ] 5MiB·형식·권한 오류가 사용자 행동과 함께 안내된다.

[ ] 로컬 전용 이미지가 남으면 Publish를 막고 scene/object 위치를 보여준다.

[ ] retry가 중복 Asset을 만들지 않는다.

선행 작업 / Dependency

BLOCKED BY: S15P21A604-107·176·217, GitLab #69

후속

S15P21A604-187

테스트 방법

업로드→저장→새 세션→Publish→익명 플레이 왕복과 실패 재시도를 검증한다.
