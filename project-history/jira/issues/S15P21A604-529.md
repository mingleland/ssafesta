## 설명

## 작업 목적

- 에디터에서 배치한 오브젝트를 구분할 방법이 내부 ID뿐이고, 플레이 중에도 어떤  
   오브젝트인지 알려주는 표시가 전혀 없어 제작자가 각 캐릭터/오브젝트를 식별하기  
   어려운 문제를 해결한다.

## 작업 내용

- `contracts/gameProject.ts`
   
   - `GameObject`에 선택적 필드를 추가한다(예: `name?: string`,  
      `showNameInPlay?: boolean`). `parseGameProject` 검증 로직에 이름 길이 제한 등을  
      추가한다. PLAYER_SPAWN 프리셋에는 이 필드들이 없거나 무시되도록 계약/검증에서  
      명시한다(플레이 중 렌더링 자체가 되지 않는 마커라 이름표를 붙일 대상이 없음).
- `authoringCommands.ts`
   
   - `renameScene`과 같은 패턴으로 `renameObject`/`setObjectNameVisible` 같은 커맨드  
      함수를 추가한다.
- `InspectorPanel.tsx`
   
   - OBJECT 뷰의 '속성' 탭에 이름 입력과 "플레이 중 표시" 체크박스를 추가한다.  
      새로 배치한 오브젝트는 표시 체크박스가 기본으로 꺼진 상태다. PLAYER_SPAWN  
      프리셋일 때는 이 UI 자체를 렌더링하지 않는다.
- `ReferenceGamePlayer.tsx` / `.css`
   
   - 오브젝트 렌더링 부분에 이름이 있고 표시가 켜져 있는 경우에만 그 위에 상시  
      떠 있는 이름표(닉네임 태그 형태)를 그린다. 이름이 비어 있으면 표시가 켜져  
      있어도 아무것도 그리지 않는다.

## 완료 조건

- [ ] 오브젝트 속성('속성' 탭)에 이름 입력칸이 추가된다
- [ ] "플레이 중 표시" 체크박스가 추가되고, 새로 배치한 오브젝트는 기본값이 꺼짐이다
- [ ] 이름을 비워두면 표시를 켜도 이름표가 뜨지 않는다
- [ ] 이름을 입력하고 표시를 켜면 플레이 화면에서 그 오브젝트 위에 이름표가 상시 떠 있다
- [ ] PLAYER_SPAWN 프리셋에는 이름/표시 설정 UI가 아예 노출되지 않는다
- [ ] PLAYER_SPAWN을 제외한 모든 프리셋에서 이름 짓기/표시가 정상 동작한다
