## 설명

게임 파트가 #197 에 in-place 아바타 커스터마이징 수신부 계약을 회신했다(월드·NGO·NetworkObject·좌표 유지, 외형만 변경).

FE 는 브릿지 계층만 맡는다. GameMenu 버튼은 S15P21A604-798 소유라 건드리지 않는다.

1. unity/bridge/worldUiState.ts — WorldUiState 에 avatar 필드를 더하고 hasUnityModal 이 그것을 본다. 지금 readFlag 가 모르는 필드를 조용히 버려서 Unity 가 avatar:true 를 보내도 ESC 2단계가 서지 않는다 — 아바타 화면 위에 GameMenu 가 열린다(#132 가 고쳤던 결함).

2. unity/host/worldUiBridge.ts — requestAvatarCustomization 을 더한다. SendMessage('WorldUiBridge','RequestAvatarCustomization','esc-menu').

닫기는 기존 RequestExitWorldUi('esc') 경로를 그대로 쓴다.
