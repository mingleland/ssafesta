## 설명

기본 3인칭 카메라가 캐릭터 정중앙을 바라봐 시야가 답답하게 느껴지는 문제를 개선한다. 캐릭터를 따라다니는 기본 카메라의 추적 기준점 또는 LookAt 높이를 현재보다 약간 높여 상체와 주변 공간이 함께 보이도록 조정한다.

작업 내용:
- 현재 카메라 추적·LookAt 기준과 플레이어 화면 구성을 확인
- 기본 추적 위치/LookAt 높이를 상향 조정
- 걷기·달리기·점프·상호작용 카메라에서 시야가 과도하게 흔들리거나 대상이 잘리지 않는지 확인
- 부스 내부와 일반 필드 모두에서 주변 시야와 조작감을 검증

완료 조건:
- 캐릭터 정중앙 고정 시점보다 자연스럽게 높은 시야를 제공한다.
- 캐릭터 머리·발·상호작용 UI가 화면에서 부자연스럽게 잘리지 않는다.
- 기존 카메라 회전 및 이동 조작과 충돌하지 않는다.
- 일반 필드와 부스 내부에서 답답함이 완화되었는지 확인한다.

우선순위: 후속 작업(Low)
