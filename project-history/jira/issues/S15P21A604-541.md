## 설명

S15P21A604-538 FE 전체 회귀 실측(실 Chrome + 실 BE 8081)에서 나온 FAIL 4건. 전부 -528 시점 누락이다.

근거 문서: docs/LJH/verify/fe-full-regression-0908.md §2

=== F-1. 서버 오류 코드·문구를 버리고 일반 문구만 낸다 (제출·저장 양쪽) ===

제출: 서버 409 SURVEY_ALREADY_RESPONDED "이미 응답한 설문입니다."
      화면 "제출하지 못했습니다. 다시 시도해 주세요."
저장: 서버 409 SURVEY_LOCKED "응답이 있는 설문은 문항을 바꿀 수 없습니다."
      화면 "저장하지 못했습니다."

features/survey/model/run.ts:117 과 builder.ts 의 catch {} 가 오류를 통째로 버리고
features/survey/ui/SurveyOverlay.tsx:133 이 문구 하나만 낸다.
서버는 사용자에게 그대로 보여줄 한국어 문구를 이미 주고 있다.
특히 "다시 시도해 주세요" 는 재시도해도 절대 성공하지 않는 오류에 재시도를 권한다.

-528 계획의 "오류 문구를 코드별로 가른다 — SURVEY_CLOSED·SURVEY_ALREADY_RESPONDED·MEMBER_ONLY·SURVEY_LOCKED"
가 구현되지 않았다.

=== F-2. 마감된 설문에서 문항이 사라진다 — 계약 §5 위반 ===

계약: "closed: true 면 문항은 그대로 싫는다 — 화면이 '마감된 설문입니다' 를 보여주되
      무엇을 물었는지는 남는다"
실측: 서버는 6문항을 실는데 화면의 li 0개 · 입력 요소 0개.
SurveyOverlay.tsx 가 문항을 run.status === 'ready' 일 때만 렌더하고 closed 는 OverlayEmpty 만 그린다.
(게스트 차단 상태에서는 문항이 정상으로 보인다 — closed 에만 있는 문제다)

=== F-3. 마감 상태인데 "참여하면 N 코인을 받습니다" 를 동시에 띄운다 ===

화면: "마감된 설문입니다 / 응답을 더 받지 않습니다." 와
      "참여하면 5 코인을 받습니다 · Esc 로 월드로 돌아갑니다" 가 함께 뜼다.
SurveyOverlay.tsx:130-142 의 상단 안내 체인에 closed 분기가 없다.

=== F-4. 제출 성공 뒤에도 "참여하면 N 코인을 받습니다" 가 남는다 ===

화면: "응답을 제출했습니다 / 7 코인을 받았습니다" 와 "참여하면 7 코인을 받습니다" 가 동시 표시.
F-3 과 같은 뿌리 — 그 체인에 submitted 분기도 없다.

=== 수정 방향 ===

서버 오류 코드를 Port → state 까지 옮기고(지금 catch 가 버린다) 상태 기계에 errorCode 를 둔다.
UI 의 status 체인을 종료 상태(closed·submitted) 우선으로 재정렬하고, closed 에서도 문항을 렌더한다.
서버 message 를 그대로 쓸지, FE 가 코드별 문구를 가질지는 구현 시 판단한다
(계약이 message 를 사용자 노출용으로 보장하는지 확인 필요).
