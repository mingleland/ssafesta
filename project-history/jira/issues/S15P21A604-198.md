## 설명

### 작업 목적

Jenkins에서 Unity(game)와 AI 파트의 검증·이미지 빌드·publish를 독립 실행한다.

### 작업 내용

- AI 테스트·이미지 빌드와 commit SHA/digest 기록
- Unity batchmode CI 진입점과 Linux Server 빌드
- `festa-unity/ci/` 검증 스크립트 및 빌드 컨텍스트 확인
- 경로 기반 실행, 실패 시 publish/배포 차단
- Unity 라이선스·레지스트리·AI 키 Secret 마스킹

### 완료 조건

- AI와 Unity 변경이 해당 잡만 실행한다.
- Unity CI 진입점과 `festa-unity/ci/`가 실제 저장소에 존재하고 테스트된다.
- 실패 시 이미지가 publish/배포되지 않는다.
- 이미지 tag/digest/commit SHA를 조회할 수 있다.
- Secret 평문이 로그와 산출물에 없다.

### 선행 작업

Jenkins Controller·Agent·JCasC, Credentials 구성

### 참고

- `specs/infra-001-ci-cd-pipelines`
- Unity CI 진입점은 현재 미구현 상태이므로 완료 처리 금지

### 테스트 방법

AI/Unity 각각 성공·컴파일/테스트 실패·Secret 마스킹 시나리오를 실행한다.
