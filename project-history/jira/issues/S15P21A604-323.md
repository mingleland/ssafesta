## 설명

## 배경

docs/26 §② 에 팀 결정 대기로 올려뒀던 항목이다. 게임 파트 오너가 2026-08-29 F키 전용으로 확정했다.

기존에는 클릭과 F 를 둘 다 받았다. 클릭을 못 뺐던 이유는 docs/02 RUNTIME-06(P0) 과 spec 016 이
"노트북을 클릭하면" 으로 명시하고 있어서다 — 문서와 어긋나는 설계 변경을 단독으로 못 정해
docs/26 에 올려뒀다.

3인칭에서 클릭은 카메라 조작·UI 클릭과 경쟁해 오조작이 난다 (S15P21A604-319 의 미니게임
클릭 누출과 같은 부류).

## 변경

- BoothInteractionInput 에서 클릭 실행 경로 제거, TryReadPress() 삭제 (-57줄 / +11줄)
- 포인터는 조준·호버에만 사용. 실행 입력은 F 하나
- 안내 문구 정합화: 부스 간판 "클릭해서 시작" → "F 키로 시작" (씬 + AdminGameBoothBuilder 양쪽)
- MinigameInteractable / AiNpcInteractable 문서 주석 갱신
- 화면 힌트 `F — 상호작용` 은 기존 그대로

## 남은 일 (헌법 24조)

docs/02 RUNTIME-06(P0) 과 spec 016 FR/AC 가 아직 "클릭하면" 이다. 계약 문서 갱신과 FE 통보가
따라가야 한다.

다만 FE 계약 자체는 무변경이다 — BOOTH_LAPTOP_INTERACT 이벤트와 payload 는 그대로고,
바뀐 것은 그 이벤트를 유발하는 조작뿐이다. FE 코드 수정은 필요 없다.
