## 설명

## 작업 목적

Booth Studio 에 되돌리기가 없다. `editorReducer` 상단 주석이 스스로 "history 는 지금 구현하지 않음" 이라 밝히고, 툴바의 실행취소·다시실행 아이콘은 `disabled` 목업 어포던스다(2026-09-10 플레이 중 실측).

되돌릴 수단이 없어서 S15P21A604-589(템플릿 교체)에 확인 다이얼로그를 유일한 안전망으로 세워야 했다.

## 작업 내용

- 편집 액션이 이미 이산화돼 있어 스냅샷 스택으로 붙는다
- `Ctrl+Z` / `Ctrl+Y` / `Ctrl+Shift+Z`. 입력 필드 편집 중에는 가로채지 않는다
- 툴바의 `disabled` 버튼 두 개를 살린다 — `canUndo`/`canRedo` 로 활성 상태를 만든다

## 완료 조건

1. 배치 추가·이동·회전·삭제·교체가 undo/redo 된다
2. 툴바 버튼이 가능 여부에 따라 활성/비활성된다
3. 입력 필드 편집 중에는 단축키가 가로채이지 않는다
4. 저장 상태(dirty)가 undo/redo 뒤에도 일관된다
5. unit test / tsc 0 / vitest 전체 green / oxlint 신규 경고 0

- 없음
