## 설명

판넬 뒤 자는 직원에게 상호작용 키를 눌러도 반응이 전혀 없다는 보고(2026-09-14). 다른 NPC 는 정상.

원인 후보: NappingStaffNetwork.ServerNow() 가 비접속 시 0 을 돌려줘, 복귀 판정 ServerNow() >= _returnAtServerTime 이 영원히 거짓이 된다. 그러면 _caught 가 true 로 굳고 Interact() 맨 앞의 조기 반환에 걸려 영구 무반응이 된다. 재접속으로 ServerTime 이 리셋되는 경우도 같은 곳으로 떨어진다.

조치: ServerNow() 오프라인 기준을 Time.unscaledTimeAsDouble 로, 조용한 실패 경로 전부 로그로 노출, 상태가 어긋나면 자가 복구.

미확인: 라이브 재현으로 잡은 것이 아니라 코드 경로 추적 결과다. 배포본에서 F 반응과 5분 복귀를 실측해야 확정된다.
