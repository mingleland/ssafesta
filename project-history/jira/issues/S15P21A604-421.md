## 설명

h3. 증상
2026-09-05 FE(5173)+Spring+게임 서버 통합 로컬 실측에서 게스트 로그인 → /app/world 진입 시 Unity 로더·데이터는 정상 로드되지만 _main 진입 직후 아래 예외로 멈추고 캔버스가 진남색으로만 남는다.
{code}
SyntaxError: Failed to execute 'querySelector' on 'Document': '#' is not a valid selector.
    at findEventTarget ... at registerKeyEventCallback ... at _emscripten_set_keydown_callback_on_thread ... at Module._main
{code}

h3. 원인
src/unity/host/UnityHost.tsx 의 <canvas> 에 id 가 없다. Unity 6 WebGL 은 키보드 이벤트 타깃을 "#" + canvas.id 선택자로 찾는다 → id 가 비면 "#" 이 되어 SyntaxError. Unity 기본 템플릿은 <canvas id="unity-canvas" tabindex="-1"> 이다. mock 로더(VITE_USE_MOCK=true)로는 재현되지 않아 지금까지 드러나지 않았다.

h3. 수정
<canvas id="unity-canvas" tabIndex={-1} ref={canvasRef} ... /> — id 는 Unity 기본 템플릿과 같게, tabIndex=-1 은 캔버스가 키 입력을 받도록. 게임 파트가 통합 실측 중 로컬 패치로 기동 확인 후 MR 을 올린다(머지는 FE 리뷰).

h3. 함께 발견 (별건, GitLab #127 에 제안)
manifest.json 의 URL 4종이 상대경로인데 resolver/loader 가 값을 그대로 script.src 에 넘겨 FE 오리진 기준으로 해석된다 → VITE_UNITY_BUILD_BASE 가 다른 오리진이면 404. new URL(v, BUILD_BASE + '/') 로 해석해야 한다.
