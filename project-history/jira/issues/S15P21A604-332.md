## 설명

### 증상

월드에 들어갔다가 로비로 돌아온 뒤 **다시 월드로 들어가면 접속이 되지 않는다.** 씬은 `main` 으로 넘어가지만 클라이언트가 붙지 않는다 (`IsClient=False`). 에러도 뜨지 않아 원인이 드러나지 않는다.

### 재현 (2026-08-31 실측, 전용 서버 + 에디터 클라이언트)

1. `main` 에서 접속 → `IsConnectedClient=True, LocalClientId=1` (정상)
2. `DevConnectionHud.ReturnToCustomization` → `Shutdown()` + `LoadScene(CharacterLobby)` → 활성 씬 `CharacterLobby`, NetworkManager 1개 생존
3. `CharacterLobbyController.EnterWorld()` → `LoadScene("main")`
4. 결과: 활성 씬 `main`, `IsClient=False, IsConnectedClient=False`

### 원인 (실측 확인)

```
DevConnectionHud 개수=1 | DevConnectionHud 씬=DontDestroyOnLoad
ConnectionManager 씬=DontDestroyOnLoad | 두 컴포넌트가 같은 오브젝트=True
pending-world-connection=1  (1이면 미소비)
```

- `@Network` 오브젝트는 `NetworkManager`·`ConnectionManager`·`DevConnectionHud` 를 **한 오브젝트에** 갖고 있고, 첫 `main` 로드 때 `DontDestroyOnLoad` 로 옮겨진다.
- 재진입 시 새 `main` 씬에도 `@Network` 가 있지만 **NGO 의 NetworkManager 싱글턴 중복 제거가 그 오브젝트를 파괴**한다 — 새 `DevConnectionHud` 도 같이 사라진다.
- 살아남은 **옛** `DevConnectionHud` 는 `Start()` 가 이미 한 번 돌았으므로 다시 돌지 않는다. `Start()` 안의 `AvatarSceneHandoff.ConsumeWorldConnectionRequest()` 가 호출되지 않아 **접속 요청이 영영 소비되지 않는다.**
- 그 증거가 `pending-world-connection=1` 로 남아 있는 것이다.

### 같은 유형의 선례

S15P21A604-312 가 `WorldEntryGate` 에서 똑같은 함정을 고쳤다 — 그 파일 주석:

> 그 훅은 앱 기동 시 첫 씬 직후 딱 한 번만 돈다 (…) **게이트가 영원히 생성되지 않았다**

**"한 번만 도는 진입 훅" 이 이 코드베이스에서 두 번째로 같은 사고를 냈다.**

### 작업 내용

- `DevConnectionHud` 가 접속 요청을 `Start()` 한 번이 아니라 `main` 씬이 로드될 때마다 확인하도록 변경 (`SceneManager.sceneLoaded` 구독 — `WorldEntryGate` 가 쓰는 방식과 같게)
- 요청이 남아 있는데 접속하지 못하는 경우를 조용히 넘기지 말 것 (T-24)

### 완료 조건

- [ ] 월드 → 로비 → 월드 재진입에서 `IsConnectedClient=True` — 실측
- [ ] 서버 로그에 2회차 승인 기록 확인
- [ ] 1회차 접속 경로 무회귀
