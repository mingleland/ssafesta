## 설명

월드 채팅 P1. 기능을 늘리지 않고 현재 채팅을 경량 인게임 채팅 UX 로 마감한다.

범위
- Passive(최근 3~5줄·입력창 없음·fade) / Active(패널·로그·입력·스크롤) 상태 구분
- 최신 위치면 자동 하단 스크롤, 위로 읽는 중이면 위치 유지 + '새 메시지 N개' 안내
- Passive fade — 데이터는 지우지 않고 표시만 흐려진다. Active 진입 시 다시 선명
- 접근성 — 새 메시지는 별도 aria-live polite 영역, 오류는 assertive. 로그 전체 반복 낭독 금지
- notice lifecycle — 영구 잔류 제거
- React key 안정화 — 수신 시 로컬 단조 증가 식별자 부여
- 패널 열림과 입력 focus 상태 정합 — canvas 클릭 뒤 Enter 재진입
- 100 code point counter 노출 기준

범위 밖: 말풍선(-782), 상담 송수신, 게스트 정책(BE 회신 대기), 채널·DM·히스토리
