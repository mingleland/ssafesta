## 설명

증상
- 월드에 진입해도 화면이 검게만 보인다.
- 화면이 보이는 경우에도 이동·시야 회전·F 상호작용이 동작하지 않는다.

원인
S15P21A604-620 에서 Unity 캔버스를 WorldPage 밖(라우트 밖 PersistentWorld)으로 옮기면서, 같은 자리를 차지하는 .world-scene 이 캔버스 위 레이어가 됐다. 두 선언이 그대로 남아 결함이 됐다.
1) background: #0e1430 — 불투명 배경이라 캔버스를 통째로 덮는다(검은 화면).
2) pointer-events 기본값 auto — 뷰포트 전체를 덮은 채 포인터를 받아 캔버스에 닿지 않는다(조작 불가).
.persistent-world 는 z-index:0 이고 DOM 상 앞이라 항상 .world-scene 아래에 그려진다. 오버레이가 위에 와야 하므로 순서 자체는 의도대로다.

조치
- worldPage.css: .world-scene 의 background 제거, pointer-events: none 추가.
- worldPage.css: .world-scene > *:not(.world-hud) 에 pointer-events: auto. pointer-events 는 상속되므로 이 줄이 없으면 Overlay·Game Menu 까지 죽는다. .world-hud 는 스스로 none 을 선언하고 자기 자식만 여는 구조라 제외한다.
- index.css: body 에 background #0e1430. .world-scene 이 배경을 놓은 뒤 PersistentWorld 마운트 이전 첫 프레임에 흰 화면이 비치는 것을 막는다.

검증 (로컬 Chrome 실측)
- 로컬 Spring 8080 + festa-world-01(7777) + WebGL 정적 8001 + vite 5175.
- 게스트 진입 후 월드 렌더 확인 — 캐릭터 스폰·부스 내부·간판 표시.
- elementFromPoint(뷰포트 중앙) 이 CANVAS 를 반환.
- W 30회로 아바타가 엘리베이터 앞에서 게임기 앞까지 실제 이동.
- ESC 로 Game Menu 열림/닫힘, HUD 버튼 전부 hit-test 도달.
- tsc 통과, vitest 206 파일 1347건 통과.
- CSS 회귀 테스트 신규 3건(worldSceneLayering.test.ts) — 화면 테스트로는 못 잡는 계열이라 스타일시트를 직접 읽어 잠근다.
