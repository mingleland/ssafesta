## 설명

작업 목적
- 월드 로딩의 숫자 퍼센트를 제거하고 실제 WebGL progress와 lifecycle milestone을 결합한 단계형 게이지를 제공한다.

작업 내용
- 사용자 노출 퍼센트 텍스트 전부 제거
- createUnityInstance progress를 내부 30~75 구간에 매핑
- instance 생성, 월드 로드 시작, ready 신호를 82/90/100 milestone으로 반영
- 상태별 자연스러운 한국어 문구
- 게이지 역행 방지 및 CSS transition
- StrictMode 재마운트 시 최신 progress listener가 진행률을 받도록 sessionManager 수정

완료 조건
- 숫자 퍼센트가 노출되지 않는다.
- 게이지가 뒤로 가지 않는다.
- 100%는 실제 world ready에서만 도달한다.
- 준비 구간별 문구가 상태에 맞게 바뀐다.
- StrictMode에서 0% 고정 회귀가 없다.
- 테스트, 타입체크, 빌드 통과
