## 설명

# 작업 목적

- Game Studio 에디터 좌측 Scene 목록의 순서 변경이 ↑/↓ 버튼 클릭 방식이라 여러 칸  
   옮기려면 여러 번 클릭해야 하는 불편함(QA id 8)을 해결한다. 드래그로 순서를 조절할  
   수 있게 한다.



# 작업 내용

- Scene 목록(`gss-scene-list`)에 드래그 앤 드롭 재정렬 UI 신규 추가 — 기존 ↑/↓ 버튼은  
   제거
- `EventEditor.tsx`(S15P21A604-360, 이벤트 액션 순서 변경)에 이미 구현된 HTML5  
   Drag-and-Drop 패턴(`draggable` + `onDragStart`/`onDragOver`/`onDrop` +  
   `gss-drag-handle` 클래스 드래그 핸들)을 그대로 재사용
- drop 시 `project.scenes` 배열을 재정렬하는 커맨드를 `authoringCommands.ts`에 추가  
   (또는 기존 `moveScene`을 인덱스 기반으로 반복 호출)
- Scene 타입 아이콘 정의(`TOP_DOWN='▦'`, `PLATFORMER='▰'`, `DIALOGUE='☰'`)에서  
   DIALOGUE(대화·연출 공통) 아이콘이 새로 추가되는 드래그 핸들 아이콘(☰)과 겹치므로,  
   DIALOGUE 아이콘을 텍스트를 의미하는 'T' 계열 아이콘으로 교체



# 완료 조건

- [ ]  Scene 목록 항목을 마우스로 드래그해서 순서를 조절할 수 있다
- [ ] 기존 ↑/↓ 버튼은 제거된다
- [ ] 각 Scene 항목 앞에 드래그 가능함을 나타내는 핸들 아이콘이 표시된다
- [ ] DIALOGUE 타입(대화·연출 공통) Scene 아이콘이 드래그 핸들과 겹치지 않는 T 계열  
    아이콘으로 바뀐다
- [ ] 드래그 후 실제 게임 시작 시 Scene 순서(인덱스, START 표시)가 정확히 반영된다
- [ ] Scene이 1개뿐이거나 맨 위/맨 아래 항목을 드래그해도 예외 없이 동작한다



# 선행 작업 / Dependency

- 없음



# 테스트 방법

1. Scene 목록에서 항목을 드래그해서 원하는 위치로 순서를 옮겨본다
2. 드래그 후 실제 게임 시작 화면에서 Scene 순서가 정확히 반영되는지 확인한다
3. 기존 ↑/↓ 버튼이 화면에서 사라졌는지 확인한다
4. TOP_DOWN(▦)·PLATFORMER(▰) 아이콘은 그대로인지, DIALOGUE(대화·연출) 아이콘이 T 계열로  
   바뀌었는지 확인한다
5. 드래그 핸들 아이콘이 다른 타입 아이콘과 겹치지 않는지 확인한다
6. Scene이 1개뿐이거나 맨 위/맨 아래 항목을 드래그할 때 예외 없이 동작하는지 확인한다
