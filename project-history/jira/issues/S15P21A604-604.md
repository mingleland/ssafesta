## 설명

## 작업 목적

Booth Studio 의 줌이 `ZOOM_STEPS = [0.8, 1, 1.2]` 3단계를 툴바 버튼으로 순환하는 것뿐이다. 캔버스에 `wheel` 리스너가 0건이라 **Ctrl+휠이 브라우저 페이지 줌으로 새어 나간다**(2026-09-10 플레이 중 실측).

편집창 안에서만 Ctrl 을 가져와 확대·축소를 제어해야 한다.

## 작업 내용

- 캔버스 영역에서만 `wheel` 을 네이티브 `addEventListener(..., { passive: false })` 로 받아 `preventDefault`. **React 의 `onWheel` 은 passive 로 등록돼 `preventDefault` 가 동작하지 않는다** — `TopDownCanvas` 가 같은 함정을 주석까지 남겨 뒀다
- 영역 밖에서는 브라우저 기본 줌을 건드리지 않는다
- 커서 위치를 기준으로 확대·축소한다

## 완료 조건

1. 캔버스 위에서 Ctrl+휠이 편집기 줌을 바꾸고 브라우저 페이지 줌은 바뀌지 않는다
2. 캔버스 밖에서는 브라우저 기본 동작이 그대로다
3. 툴바 줌 버튼과 값이 어긋나지 않는다
4. unit test / tsc 0 / vitest 전체 green / oxlint 신규 경고 0
