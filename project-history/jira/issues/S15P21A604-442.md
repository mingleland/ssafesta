## 설명

h3. 발견 (2026-09-06 06:10, Development WebGL 7f964d28, -207 QA)

*① popup shadow 잔상* — slot machine HUD 를 open 하면 화면 가운데 왼쪽에 회색 반투명 둥근 사각형이 항상 떠 있다. {{FestaUiKit.Panel}} 이 그림자를 카드의 **형제**로 만들기 때문(자식이면 카드 위에 그려진다). popup 을 SetActive(false) 해도 shadow 는 혼자 남아 FollowRect 로 popup 자리를 따라다닌다. editor 에서도 같은데 밝은 배경에서는 잘 드러나지 않았다.

*② focus mode 잔류* — focus 중(HUD open) 탭이 hidden 으로 넘어가 disconnect -> WorldReconnector 자동 재접속 -> 새 player 스폰. 새 player 의 PlayerCameraFollow 가 켜지므로 화면은 3인칭으로 돌아가는데 focus mode, 입력 lock, HUD 만 그대로 남는다(server log: client 12 -> 13 -> 14 -> 15 반복 스폰 실측).

부수: WorldReconnector 성공 log 가 "0회차" 로 나온다(시도 log 는 1회차).

h3. 수정

* FollowRect 가 매 LateUpdate 대상의 activeInHierarchy 를 Image.enabled 에 반영 — 카드가 숨으면 shadow 도 숨는다.
* InteractionFocusCamera: focus 중 로컬 follow 가 사라지면(재스폰) EndFocus -> Released 로 HUD 도 닫힌다.
* 성공 log 회차 +1.

h3. 검증

editor Host: HUD open 시 Popup_Shadow imageEnabled=False, guest Spin -> popup 표시되면 True(screenshot). 재스폰 guard 는 logic 검토(재현은 WebGL hidden tab 경로).
