## 설명

festa-inbox 전수조사에서 남은 4건을 닫는다. 세 가지 성격이 섞여 있고 실물 작업은 docs/26 등재 1건이다.

[#110 — 실물 작업]
specs/009-project-exhibition/spec.md 의 Clarification 중 C-01·C-03~C-07 은 전부 확정인데 C-02(지원 영상 제공자 범위)만 기획 미결로 남아 S15P21A604-195(YouTube 임베드)를 막고 있다. 그 미결이 spec 문서 안에만 있어 팀이 볼 자리가 없다 — docs/26 ① 표에 23번으로 등재한다. 결정값은 미확정으로 두고 FE 제안(YouTube 단독)만 근거와 함께 적는다. spec 009 FE 서명은 문서가 'C-02 가 닫힌 뒤 함께' 라고 적어 둔 의도된 보류라 건드리지 않는다.

[#127 — FE 준비 완료 확인 회신]
Infra 가 https://demo.ssafesta.world/unity/ 로 경로·Nginx·Front 연동·EC2 검증까지 끝냈다. FE 변경은 0 이고 근거는 테스트로 고정돼 있다 — resolveAssetUrl.test.ts 의 '오리진 상대 base(/unity/)는 현재 오리진 기준으로 절대화한다 — same-origin 서빙(#127 안 A)' 케이스가 그것이다. 현재 EC2 산출물이 Development 빌드이고 API 주소가 localhost:8000 고정이라는 점만 되짪는다.

[#122 — 접수·종결 제안]
Project 좋아요 정책 2건(임대 만료 중 DELETE 409 유지 · 본인 프로젝트 좋아요 허용)이 현행 유지로 닫혔다. 서버 0 · FE 0.

[#120 — FE 몫 없음 확인]
마지막 코멘트가 게임↔BE 교환이다. entities/catalog 가 owned·onSale 을 이미 처리하고 V20 으로 3종이 is_on_sale FALSE 가 되면 잠금·구매버튼 없음 경로를 그대로 탄다(catalog.test.ts 가 덮고 있다).

[검증]
문서만 바뀌므로 착수 전후 수치가 같아야 한다. 기준선 실측: vitest 129파일 중 1 failed(AiChatOverlay 2건, develop 기존 red·LJH T-58) · 792 passed · npm run build 통과.
