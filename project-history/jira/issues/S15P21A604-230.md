## 설명

### 작업 목적

dev/demo 배포 전 호스트·권한·네트워크 전제를 자동 점검해 중간 실패를 줄인다.

### 작업 내용

- Docker/Compose 버전·디스크·메모리·시간 동기화 확인
- 레지스트리·R2·DNS 접근 권한 확인
- 필수/충돌 포트와 기존 컨테이너 확인
- 결과를 사람이 판독 가능한 리포트로 출력

### 완료 조건

- 누락 권한·도구·용량·포트 충돌을 배포 전에 실패 처리한다.
- 정상 호스트에서 멱등적으로 통과한다.
- 점검 과정에서 Secret 값을 출력하지 않는다.

### 선행 작업

EC2 접속과 최소 운영 권한

### 참고

- `specs/infra-002-runtime-environments`
- T-25

### 테스트 방법

정상 호스트와 의도적 포트 충돌/권한 누락 환경에서 판정 메시지를 확인한다.
