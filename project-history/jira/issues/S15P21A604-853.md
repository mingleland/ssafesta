## 설명

GitLab #217 4번. BE 가 !1064(-836)로 이벤트 상점을 develop 에 넣었다.

응답 대조 결과 FE 가 먼저 정한 계약과 필드 단위로 일치한다(AdminPurchaseView 12필드 · PurchasePageResponse 5필드 · fulfillment body). 어댑터 수정은 없다.

남은 것은 BE 가 새로 정한 전이 규칙이다 — PURCHASED → PENDING/FULFILLED/CANCELLED, PENDING → FULFILLED/CANCELLED 만 허용하고 FULFILLED·CANCELLED 는 종단이다. 위반 시 409 EVENT_PURCHASE_FULFILLMENT_INVALID 가 온다. 화면이 이 오류를 사용자 문구로 드러내고, 허용되지 않는 전이 버튼을 애초에 내리도록 맞춘다.
