GitLab work_items#118에서 확정된 상담 정책(C-01~C-03)을 관련 계약 문서에 반영한다.

확정 내용:
- C-01 상담 요청 만료 시간: 10분. REQUESTED -> EXPIRED, FE는 만료 전 잔여 시간 안내 + 재요청 버튼 제공.
- C-02 오프라인 비동기 문의: 선택안 A 채택 — P1 제외, P2 후속 이슈로 분리.
- C-03 상담 기록 보존 기간: P1 메타데이터·Handoff Summary는 프로젝트 종료 시 일괄 삭제(docs/21 Conversation 정책과 동일선상). P2 원문 메시지는 P2 spec 착수 시 재검토(보류).

specs/011-staff-consultation/spec.md Clarifications 표는 반영 완료.

남은 작업:
- docs/08 (Backend API 명세서) — 상담 요청 만료 관련 API/이벤트 반영 범위 확인
- docs/09 (DB ERD/설계서) — 보존 기간 정책에 따른 삭제 배치/스키마 반영 범위 확인
- docs/16 (Realtime 통신 명세서) — CONSULTATION_REQUESTED 만료 이벤트, 상태 머신에 EXPIRED 타이밍 반영
