## 설명

h3. 작업 목적

ESC GameMenu 의 "설정"이 {{disabled}} + "준비 중" 배지다. 그래서 소리를 끄는 수단이 화면(Landing·Login)의 mute 토글 하나뿐이고, 월드에 들어가면 그 토글이 있는 화면을 떠난 뒤다.

크기를 줄일 방법은 아예 없다 — 화면 BGM 은 {{TRACK_VOLUME = 0.25}} 상수로 고정이다.

h3. 범위 — FE 가 소유한 화면 오디오까지만

|| || 지금 || 이 작업 뒤 ||
| 설정 화면 | {{disabled}} "준비 중" | ESC 에서 열린다 |
| 화면 BGM 음소거 | 랜딩·로그인 화면의 토글에서만 | 설정에서도 |
| 화면 BGM 볼륨 | {{TRACK_VOLUME}} 상수 고정 | 설정에서 조절 |
| World BGM 볼륨 | Unity 소관 | *건드리지 않는다* |

h3. 하지 않는 것 (명시)

* *{{AudioBridge.SetVolume}} 호출 추가 0건.* Unity 는 {{SetMuted}} 만 받는다({{audioBridge.ts}} 가 "볼륨은 이 seam 이 다루지 않는다"고 명시). volume 계약은 S15P21A604-463 · GitLab #140 축이고, 그 계약이 도착하면 *같은 설정 UI 를 연결*한다.
* *새 저장 키를 만들지 않는다.* {{festa.settings.music.muted}} 는 이름부터 화면 전용이 아니라 설정 항목으로 지어져 있고, 그 주석이 "ESC Client Settings 의 Music 설정이 생기면 이 값을 그대로 승계"라고 예고한다. 볼륨도 같은 {{festa.settings.music.*}} 아래에 둔다.
* *Master / Screen / World 3단계를 만들지 않는다.* 나눌 단위는 Unity volume 계약이 올 때 최소 범위로 정한다.
* *{{TRACK_VOLUME}} 의 근거(11F 실효 출력 -29.6 dBFS 중점)를 바꾸지 않는다* — 사용자 조절값이 곱해지는 기준선으로 그대로 둔다.

h3. 완료 조건

# ESC 설정이 열리고 "준비 중" 배지가 없다.
# 음악 음소거·볼륨을 설정에서 바꿀 수 있고, 값이 새로고침 뒤에도 남는다.
# 볼륨 변경이 재생 중인 화면 BGM 에 즉시 반영된다.
# 화면의 기존 mute 토글과 설정이 같은 상태를 본다 — 한쪽에서 끄면 다른 쪽도 꺼져 보인다.
# 이번 diff 에 {{SetVolume}} 호출 추가가 0 건이다.
# {{npx tsc -b --noEmit}} · 전체 {{vitest run}} · {{npm run build}} · {{oxlint}} green.
