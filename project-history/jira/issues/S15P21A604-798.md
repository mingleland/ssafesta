## 설명

## 작업 목적
ESC 메뉴를 프로필/시스템 진입점 허브로 확장한다(요청자 정리, 2026-09-15). 지금은 프로필 요약 + 설정(스텁) + 로그아웃뿐이라 내 정보(현재 /app/profile 페이지 이동)·부스관리(World NPC 전용)·아바타설정(진입점 미정)이 ESC 밖에 흩어져 있다.

## 작업 내용
1. GameMenu.tsx 구조 재편 — 상단 프로필 요약(그대로) + 구분선 + 하단 리스트: 조작안내 · 부스관리(소유 부스 있을 때만 노출) · 아바타설정(진입점 미정, disabled 스텁 유지) · 설정(음량, -618 기 구현 확인) · 로그아웃.
2. 내 정보 오버레이화 — ProfilePage.tsx 내용(신원·지갑·거래내역·탈퇴)을 MyInfoPanel로 추출해 기존 /app/profile 페이지와 신규 MyInfoOverlay(OverlayFrame 재사용) 양쪽에서 공유. ESC → 내 정보 클릭 시 페이지 이동 대신 오버레이로 뜨게 변경.
3. gm-close/gm-myinfo 버튼 겹침 수정 — close 버튼을 summary와 분리된 상단 바로 이동해 내용 길이와 무관하게 겹치지 않는 구조로.
4. entities/wallet/types.ts REASON_LABELS에 MINIGAME_REWARD: '미니게임 보상' 추가 — 지금은 원문 코드 그대로 노출됨.
5. WorldHud.tsx 조작안내 보강 —
   a. tab-미니맵 안내: insideBooth === false(축제장)일 때만 노출.
   b. 마우스 우클릭 시야회전 안내 재추가 — S15P21A604-631에서 "손에 익어 안 읽힌다"며 의도적으로 제외했던 항목이나, 이번 요청으로 결정을 번복한다(요청자 확인 완료).

## 완료 조건
- ESC 메뉴에서 부스관리·아바타설정·조작안내가 진입 가능하다(권한 조건 포함)
- ESC·페이지 양쪽에서 내 정보 내용이 동일 컴포넌트를 공유한다

- 조작안내에 우클릭·조건부 tab-미니맵 항목이 보인다
