## 설명

부스 스튜디오 대폭 변경에 맞춰 12개 부스 내부를 빈 방으로 되돌린다. 각 Interior_NN 의 BoothSlot_N 아래 벤더 셸(BoothShell)에 벽 파티션 Panel02bCloth 6장과 벤더 바닥 Floor01 2장이 들어 있는데 이를 전부 제거한다. 남기는 것: Floor/Ceiling/Wall_Back/Wall_E/Wall_W/Wall_Front, ExitDoor 일습과 Portal_Int_NN, CeilingLamp_0~5 와 BoothLight_0~5, SpawnPoint. BoothSlot_N 앵커는 레이아웃 원점이므로 빈 채로 유지한다. BoothRuntime.ResolveShell 은 셸이 없으면 건너뛰는 정상 경로가 있어 셸 삭제로 깨지지 않는다. assetCode 계약은 이번 개편에서 고려하지 않는다.
