## 설명

# 작업 목적

‘화면 넓게’/'패널 열기' 토글 버튼을 텍스트 대신 아이콘 기반으로 바꿔 UI 일관성을 높인다.



# 작업 내용

- GameStudioShell.tsx:1140-1147의 단일 토글 버튼을 아이콘(예: 패널 확장/축소 아이콘)으로 교체
- 텍스트 레이블 제거 또는 보조 텍스트(툴팁)로 이동, aria-keyshortcuts=”Shift+F”와 접근성 속성 유지



# 완료 조건

- [ ] 버튼이 텍스트 대신 아이콘으로 표시된다
- [ ] 포커스 모드 on/off에 따라 아이콘이 바뀜다
- [ ] 툴팁 또는 aria-label로 기능이 텍스트로도 확인 가능하다
- [ ] Shift+F 단축키 동작에 회귀가 없다



# 테스트 방법

에디터에서 ‘화면 넓게’ 버튼 클릭 → 아이콘 및 상태 변경 확인 → Shift+F로 토글 확인 → 툴팁/aria-label 확인.
