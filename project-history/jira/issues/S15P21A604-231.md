## 설명

### 작업 목적

브라우저 종료·네트워크 단절 후 서버의 stale session을 정리하고 사용자가 명시적으로 다시 접속할 수 있게 한다.

### 작업 내용

- disconnect/timeout 시 플레이어·replay ledger 정리 기준
- 자동 무한 재시도 없이 수동 재연결 경로
- 만료 또는 재사용 token 거부 후 새 world-session 발급 연동
- 서버·Nginx·브라우저 로그로 종료 원인 식별

### 완료 조건

- 비정상 종료 후 제한 시간 내 서버 상태가 정리된다.
- 같은 token 재사용은 거부되고 새 token으로 재연결된다.
- 재연결 후 중복 플레이어/세션이 남지 않는다.
- 실패가 UI와 로그에 명시적으로 드러난다.

### 선행 작업

S15P21A604-84, S15P21A604-85, S15P21A604-170 및 외부 WSS 경로

### 참고

- `specs/infra-003-unity-server-runtime`
- 담당자는 Unity 파트와 확인 필요

### 테스트 방법

탭 종료·네트워크 차단·token 만료/재사용 후 정리와 새 token 재연결을 검증한다.
