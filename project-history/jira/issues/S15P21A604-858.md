## 설명

## 작업 목적 GitLab #237의 아바타 커스터마이징 프리셋 3슬롯 저장·조회·삭제 API를 구현한다.  ## 변경 사항 - avatar_presets(user_id, slot, avatar_code TEXT, updated_at) 마이그레이션과 (user_id, slot) 기본 키 추가 - GET /api/v1/users/me/avatar/presets 및 PUT·DELETE /api/v1/users/me/avatar/presets/{slot} 구현 - 슬롯은 1~3, 오름차순 조회·빈 슬롯 생략, DELETE는 멱등 204 - 기존 AvatarCodePolicy의 3,800자·ASCII 검증과 TEXT 저장을 재사용하고 문자열을 변형하지 않음 - users.avatar_code는 이미 TEXT이므로 변경하지 않음  ## 테스트 방법 생성·덮어쓰기·조회·삭제, 슬롯 범위, 게스트 거부, 길이 경계, 사용자 간 격리 통합 테스트와 backend Maven 테스트를 통과한다.  ## 영향 범위 BE 마이그레이션·내 정보 API 계약·spec 013 BE 문서.
