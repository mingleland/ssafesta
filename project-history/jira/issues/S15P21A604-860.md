## 설명

작업 목적
- BE 프로젝트 로고 업로드 계약 도착 전에도 UI와 연결 지점을 완성한다.

작업 내용
- 파일 picker, 이미지 형식/용량 검증, 로컬 preview
- 기존 thumbnailUrl preview 유지
- 프로젝트 이름/소개를 로고 오른쪽에 배치
- uploadProjectLogo(file) adapter 경계 추가
- 계약 전에는 서버 업로드와 영구 저장을 호출하지 않고 명확한 준비 중 상태를 표시

완료 조건
- 허용 이미지 선택 시 로컬 preview가 보인다.
- 잘못된 형식/용량은 FE에서 거부된다.
- 기존 thumbnailUrl이 표시된다.
- 선택 파일이 저장 성공으로 오인되지 않는다.
- BE adapter 교체 지점이 단일 함수로 남는다.
- 테스트, 타입체크, 빌드 통과

선행 작업 / Dependency
- 실제 업로드와 영구 저장은 프로젝트 로고 전용 BE 계약 확정 후 연결
- Game Asset API 재사용 금지

참고
- specs/009-project-exhibition/spec.md C-03 계약 변경 필요
