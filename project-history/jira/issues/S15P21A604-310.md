## 배포 WebGL 빌드 실측 (2026-08-29)

`Festa/배포/배포 빌드` 로 만든 릴리즈 빌드(Brotli, Development OFF)를 로컬 서버에 올려 브라우저에서 쟀다.

### 렌더링 정상성 — 통과

캐릭터 커스터마이징 → 월드 입장 → 로비 렌더링까지 정상. **사물함 자물쇠·**`LOCKER` 간판·SSAFY 입체 글자 전부 보이고 흰 뭉개짐 없다. [[S15P21A604-320]] 수정이 빌드에도 반영됐다.

### 성능 실측 (로비 SSAFY 지점, 캔버스 1920×1200 백킹 / DPR 2)

| 항목 | 값 |
|---|---|
| 드로우콜 | **483** (300프레임 전부 동일) |
| 삼각형 | **346,477** |
| FPS 중앙값 | **104.2** |
| 프레임시간 중앙값 / p95 / 최악 | 9.6 / 11.8 / 13.3 ms |

`document.hidden = false` 확인하고 측정했다 (T-211 규칙).

### 측정 방법 — 빌드를 수정하지 않았다

`PerfHud` 는 릴리즈 빌드에서 의도적으로 꺼진다 (`ToolsEnabled => Application.isEditor || Debug.isDebugBuild`). 실사용자가 F6 으로 아바타 40기를 소환하면 안 되므로 올바른 설계다.

그래서 빌드를 건드리지 않고 `WebGL2RenderingContext` 의 draw 계열을 프로토타입에서 가로채 프레임당 호출·삼각형을 셌다. 릴리즈 산출물 그대로를 잰 값이다.

### 빌드 용량

|  |  |
|---|---|
| 배포 빌드 합계 | **138.78 MB** |
| `.data.unityweb` | 129.76 MB |
| `.wasm.unityweb` | 8.81 MB |
| 오클루전 데이터 | 160.5 KB (에셋) / 69 KB (umbra) |

오클루전 데이터는 전체의 **0.1%** 다. 드로우콜 이득 대비 용량 비용은 무시할 수준이다.

### 에디터 실측과의 대조

|  | 에디터 (UnityStats) | 빌드 (WebGL 계측) |
|---|---|---|
| 로비 드로우콜 | 451 | 483 |

**같은 지표가 아니다** — 에디터는 Unity 의 `Draw Calls Count`, 빌드는 WebGL API 호출 수(그림자·UI 패스 포함)다. 그래도 같은 자릿수라 에디터 측정이 빌드에서도 유효함을 뒷받침한다.

### 못 한 것 — 빌드 내 오클루전 A/B

**빌드 안에서 오클루전 on/off 비교는 못 한다.** 런타임 토글 훅이 없고 `PerfHud` 도 꺼져 있어, 진짜 A/B 를 하려면 **오클루전 데이터를 뺀 빌드를 한 번 더** 떠야 한다.

79%/90% 절감 수치는 **에디터 플레이 모드 실측**으로 남는다 (카메라 고정 확인, 재현 130→618→130). 빌드 실측은 그 값이 터무니없지 않음을 뒷받침하는 수준이다.

`Closes` 는 넣지 않는다 — 위 A/B 가 남았다.

## 정정·보강 — 실제 크롬으로 다시 측정 (시점 4곳)

앞 코멘트는 인앱 브라우저(패널 폭 560px)에서 잰 것이고 **시점을 못 옮겨 1곳뿐**이었다. 실제 크롬으로 다시 하니 이동·측정이 정상 동작해 **시점 4곳**을 얻었다.

### 시점별 실측 (릴리즈 빌드, 캔버스 1920×1200 / DPR 2)

| 시점 | 드로우콜 | 삼각형 |
|---|---|---|
| ① 로비 — 사물함 벽 방향 | 568 | 443,122 |
| ② **사물함 벽 근접** | **248** | 338,661 |
| ③ 뒤로 물러남 — 로비 개방 | 660 | 469,452 |
| ④ 우측 이동 | 654 | 462,666 |

각 시점 350~400프레임, `document.hidden = false` 확인.

### 오클루전이 빌드에서 실제로 동작한다

**①(568) → ②(248), −56%.** 벽에 붙어 정면을 보면 뒤쪽 로비가 통째로 컬링된다. 물러나면(③) 660으로 되돌아온다.

이건 **런타임 토글 없이도** 오클루전 효과를 보여준다 — 시점에 따라 드로우콜이 2.7배 차이 난다. 정적 씬에서 이 폭의 변동은 컬링이 살아 있다는 뜻이다.

다만 **on/off A/B 는 여전히 아니다.** 컬링을 끈 빌드와 비교한 게 아니라 시점 간 비교다. 79%/90% 는 에디터 실측값으로 남는다.

### 프레임률

|  |  |
|---|---|
| FPS 중앙값 | **122** |
| 프레임시간 중앙/p95/최악 | 8.2 / 11.1 / 15.8 ms |

### 부수 확인 — 멀티플레이

인앱 브라우저 세션이 아직 접속해 있어 **아바타 2명이 동시에 렌더링**됐다. 원격 아바타 표시·동기화가 릴리즈 빌드에서 정상 동작한다.

### 렌더링 정상성

사물함 자물쇠 5×5 격자가 키패드까지 선명하다. `LOCKER` 간판·SSAFY 입체 글자·펙보드 텍스처 모두 정상, 흰 뭉개짐 없다.
