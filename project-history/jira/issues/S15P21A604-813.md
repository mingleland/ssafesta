## 설명

BE 가 S15P21A604-719 / !974 로 ConsultationEventPublisher.ended 를 직원 토픽과 방문자 큐 두 곳에 보내게 했다. 봉투는 { type: ended, requestId, occurredAt } 이고 추가 필드가 없다. 종료한 직원 본인도 받는다 — 직원 토픽으로 보내기 때문이고 taken 이 이미 같은 성질이다.

변경
- entities/consultation/channel.port.ts 의 StaffChannelEvent 에 ended 멤버를 더한다. 소비자가 0건이라 유니온 확장이 안전하다.
- 같은 파일 주석의 타입을 아직 안 늘린 이유 서술을 도달 사실로 고친다. 안 고치면 다음 사람이 그 줄을 근거로 되돌린다.

타입 한 줄이라 별도 테스트를 만들지 않는다. tsc 가 유일한 검사다.
