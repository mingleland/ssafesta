## 설명

## 작업 목적

현재 플레이어 이동속도는 `REFERENCE_TICK_MS`(120ms 고정) 하나로 전 세계 시스템이 공용으로 묶여 있어, Scene 마다 원하는 이동 페이스를 줄 수 없고 이를 조절할 UI도 없다. TOP_DOWN 이동과 PLATFORMER 좌우 이동에 한해 Scene 별로 "초당 이동 칸수"를 설정할 수 있게 한다.

## 작업 내용

- `contracts/gameProject.ts`: `TopDownScene`/`PlatformerScene`에 `playerSpeed?: number`(초당 이동 칸수) 필드 추가. optional로 두어 기존 저장 프로젝트와 하위 호환 유지(없으면 기본값 3)
- 프로젝트 파서/검증 로직에 `playerSpeed` 유효성 검사 추가(양수, 합리적 범위)
- Scene 속성 패널(TOP_DOWN·PLATFORMER)에 "이동 속도(칸/초)" 입력칸 추가, 기본값 3
- `ReferenceGamePlayer.tsx`: 플레이어 이동을 세계 틱(`tickReferenceWorld`, 120ms 고정)에서 분리해 `scene.playerSpeed` 기반 간격(`1000 / playerSpeed`)의 별도 타이머로 이동. 기존 첫 입력 즉시 반응 특수 처리(S15P21A604-363)는 제거하고, 첫 탭부터 이 간격을 균일하게 따르도록 변경
- 적 순찰(AUTO_MOVE)·터렛(SHOOTER)·스포너 등은 그대로 기존 120ms 세계 틱을 사용 — 변경 없음
- PLATFORMER의 점프(수직 물리)는 영향받지 않음(기존 그대로)
- Scene 전환 시 새 Scene 의 `playerSpeed` 로 타이머 간격 갱신

## 완료 조건

- [ ] TOP_DOWN·PLATFORMER Scene 속성 패널에 "이동 속도(칸/초)" 입력칸이 있고, Scene 마다 독립적으로 저장·적용된다
- [ ] 값이 없는 기존 Scene 은 기본값 3칸/초로 동작한다(하위 호환)
- [ ] 플레이어 이동(TOP_DOWN 이동, PLATFORMER 좌우 이동)만 이 값을 따르고, 적 순찰·터렛·스포너 등 다른 시스템은 영향받지 않는다(회귀 없음)
- [ ] 짧게 탭하든 길게 누르든 설정된 속도로 균일하게 이동한다(첫 탭 즉시 반응 특수 처리 제거)
- [ ] PLATFORMER 점프(수직 물리)는 이 변경으로 영향받지 않는다
- [ ] `npx tsc --noEmit`, `npx vitest run src/game-studio` 통과
