## 설명

GitLab #115 (spec 016 정본화)가 FE 몫으로 지목한 4건을 처리한다.

1) docs/26 'LAPTOP 홈페이지 주소 저장 위치' 행 — FE 의견/미결 표기를 확정문으로 교체. booths.homepage_url 은 V1__initial_schema.sql 부터 존재하므로 '컬럼 신규 추가'는 오기이고, C-02(여러 개 허용 여부)는 #97 에서 부스당 1개로 확정·종료됐다.
2) docs/26 'Booth Layout JSON 최종 스키마' 행 — '미검증 잔여 1건 BOOTH_LAPTOP_INTERACT 브라우저 왕복' 문구가 stale. 검증은 2026-08-21 완료(docs/sdd/parts/FE.md, 커밋 462c4a2).
3) entities/layout/objectTypes.ts — LAPTOP warnOnMissingConfig 를 false 로. 계약 §3-1 재해석으로 판정 근거가 configId 부재에서 홈페이지 URL 미등록으로 바뀌었다.
4) features/studio/ui/PropertiesPanel.tsx — LAPTOP 에 configId 입력을 띄우지 않는다. 보내면 CONFIG_UNVERIFIED 가 붙는다. 판정표에 linksConfigId 를 추가해 게이트하고, UI 하드코딩을 피한다.

회귀: validate.test.ts 에 LAPTOP 미경고 케이스 1건 추가.
대상 브랜치: develop.
