## 설명

현재 기본 부스 셸이 지나치게 단순해 비어 있는 상태에서 완성도가 낮아 보인다. 구매·반입된 Stand Expo Pack(Asset Store 114974)의 패널·트러스 계열을 활용해, 부스 스튜디오에서 내부 오브젝트를 하나도 배치하지 않아도 기본 전시 부스처럼 보이는 고정 구조를 추가한다.

설계 경계
- 부스 내부 콘텐츠와 가구·전시물은 기존처럼 부스 스튜디오 Layout으로만 배치한다.
- FE 카탈로그에 등록된 배치 가능 오브젝트는 기본 셸 장식으로 중복 사용하지 않는다. 현재 STRUCT_TRUSS_BASE, STRUCT_TRUSS_VERTICAL, STRUCT_TRUSS_HORIZONTAL_LAMP는 등록 상태이므로 우선 제외한다.
- Stand Expo Pack에서 FE에 등록되지 않은 프레임·패널·구조 파츠를 조사하거나, 허용되는 원본 파츠를 별도의 고정 셸 조합으로 만들어 사용한다.
- 고정 장식은 BoothShell 계층의 로컬 정적 오브젝트로 두고 NetworkObject 및 Layout JSON 오브젝트 수에 포함하지 않는다.
- 출입구, 카메라 시야, 플레이어 이동, 스튜디오 배치 가능 영역과 충돌하지 않게 한다.

시각 목표
- 전면 또는 상부 프레임, 코너 기둥, 얇은 패널/림 등으로 외곽 실루엣과 깊이감을 만든다.
- 비어 있어도 행사 부스처럼 보이되 내부 배치의 주목도를 빼앗지 않는 중립 재질과 색을 사용한다.
- 부스명이 표시되는 간판 및 출입구와 일관된 형태로 정리한다.

검증
- 빈 부스와 내부 오브젝트가 배치된 부스 양쪽에서 시각 QA
- 충돌체와 렌더 메시 정합성, 출입 동선 확인
- 기존 Layout 좌표계·12개 제한·FE 카탈로그 계약에 영향 없음 확인
- WebGL 성능을 위해 불필요한 실시간 Light와 과도한 머티리얼/드로우콜을 피한다.

근거 에셋: Stand Expo Pack / AndragorInc / Asset Store package 114974. 저장소 ExpoKit 경로의 AssetOrigin 22/22와 기존 라이선스 판정 문서로 출처가 확인되어 있다.
