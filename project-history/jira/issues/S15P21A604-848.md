## 설명

CDP 실측: Landing 최초 진입에서 midnight-circus-soft-login.mp3 4.66MB 가 마운트 즉시 내려온다(enterScreen→unlockAndPlay→ensureElement 가 new Audio + preload=auto). 자동재생이 거부돼도 다운로드는 진행되고 Landing 최장 요청(2.3~3.2s)이 된다.

변경: unlockAndPlay 에서 navigator.userActivation.hasBeenActive 가 true 가 아니면 element 를 만들지 않고 pendingGesture 로 둔다. 기존 pointerdown/keydown 재시도·Landing 시작 클릭·음소거 해제가 그 시점에 생성+play. SPA 이동 뒤(hasBeenActive true)는 기존대로.

완료: 제스처 전 mp3 요청 0건, 제스처 후 재생 성공, loop·mute·fade 회귀 0.
