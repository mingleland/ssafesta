## 설명

BE 가 S15P21A604-765 / !974 로 PROJECT_PANEL 게시 검증을 부스 단위로 옮겼다. 프로젝트가 있는 부스의 그래픽 패널은 configId 유무와 무관하게 경고가 없고, 없는 부스에만 CONFIG_NOT_LINKED 가 붙는다. CONFIG_UNVERIFIED 는 더 붙지 않는다.

변경
- entities/layout/objectTypes.ts 의 PROJECT_PANEL 을 warnOnMissingConfig: false, linksConfigId: false 로 내린다. 이 한 줄이 사전 경고(lib/validate.ts)·mock 서버 경고(api.mock.ts)·인스펙터 입력칸(PropertiesPanel)을 동시에 바꾼다.
- linksConfigId 를 내리면 인스펙터가 마지막 else 로 떨어지는데 그 문구가 LAPTOP 전용이라 타입별로 가른다. PROJECT_PANEL 은 전시 프로젝트를 부스 관리에서 등록한다는 안내로 바꾼다.

관람 대역 검사는 서버가 needsViewingBand 로 분리해 응답 어휘가 그대로다 — FE 변경 없음.

완료 조건
- PROJECT_PANEL 이 configId 없이도 경고하지 않는 회귀 테스트 (LAPTOP 회귀와 같은 모양)
- 인스펙터에서 연결 콘텐츠 ID 입력칸이 사라지고 프로젝트 안내문이 뜨는 테스트
- vitest / tsc / build green
