## 설명

## 작업 목적

광장 슬롯머신의 체감 당첨률이 낮아 확률표를 상향한다. 밸런스 노브는 yml 설정이므로 코드 변경이 아니라 설정 편집이다 (GitLab #205 확정값 1).

## 변경 내용

`backend/src/main/resources/application.yml` 의 `app.minigame.slot-machine.tiers`:

| tier | 배수 | 기존 weight | 변경 weight |
|---|---|---|---|
| 1 | x2 | 0.20 | 0.25 |
| 2 | x3 | 0.01 | 0.02 |
| 3 | x10 | 0.009 | 0.012 |
| 0 | 낙첨 | 0.781 | 0.718 |

- 당첨률 21.9% → 28.2%
- RTP 0.52 → 0.68 (10코인 한 판 기대손실 4.8 → 3.2 코인)
- RTP < 1 유지 — 슬롯머신은 여전히 코인 소각처다

부수 정리: `SlotMachineService` javadoc 이 RTP 를 0.55 로 적고 있는데 실제 설정값과 다르다. 함께 교정한다.

## 영향 범위

- 서버 설정만. API 계약(tier 0..3, 고정 베팅 10코인), Unity 릴 프리셋, 10연패 보장 규칙은 그대로다.
- tier 개수는 3개 유지 — Unity 가 tier 를 0..3 으로 자르므로 4번째를 추가하면 안 된다.
