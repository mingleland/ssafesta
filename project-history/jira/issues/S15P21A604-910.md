## 설명

배경
AI 직원 채팅 오버레이(AiChatOverlay)의 '사람 상담 요청' 버튼이 부스의 '사람 상담으로 연결 허용'(handoffEnabled) 설정과 무관하게 회원이면 항상 노출된다. 리뷰 코멘트: handoff 미허용 부스에서는 버튼을 사전 차단해야 함.

현재 제약
- handoffEnabled 는 소유자 전용 엔드포인트(GET /booths/{id}/agents, BOOTH_EDITOR_FORBIDDEN)에만 있어 방문자 FE 가 받을 수 없다.
- AI_AGENT_INTERACT payload({boothId, agentId}) · 대화 생성 응답({conversationId, expiresAt}) · BoothDetail 어디에도 없다.

제안 계약(BE 협의 필요)
- GET /booths/{id} (방문자 공개 뷰)에 handoffEnabled 를 추가한다. FE 는 이미 마운트 시 facadeApi.getBooth(boothId) 를 호출하므로 추가 왕복 없이 값을 얻는다. Unity/AI 파트 변경 불필요.
- 미공개/미등록 부스는 방문자가 채팅 진입 자체가 없으므로 기본값 처리만 합의.

FE 작업
- BoothDetail 타입 + facadeApi(mock 포함)에 handoffEnabled 반영.
- AiChatOverlay: handoffEnabled === false 이면 '사람 상담 요청' 버튼 숨김(또는 disable + 안내 툴팁). 값 로딩 전에는 버튼을 노출하지 않는다.
- 단위 테스트: 허용/미허용 각각 버튼 노출 여부.

의존성
- BE: GET /booths/{id} 응답에 handoffEnabled 추가(별도 BE 이슈 필요 여부는 협의). 계약 확정 전까지 FE 배선은 mock 기준으로 선행 가능하나 develop 완료는 BE 계약 반영 후.
