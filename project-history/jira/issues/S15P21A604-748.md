## 설명

기존에 꺼 둔 앞마당 줄전구 두 가닥을 다시 켜고, 열린 서쪽 끝에 앞·뒤 목재 벽을 잇는 지지선을 추가해 실제로 매달린 형태로 정리한다.

작업 범위
- Festoon_05, Festoon_low1 활성화
- 낮은 줄 전선 좌표계 정렬
- 서쪽 벽-벽 지지선 생성
- z=185에서 살짝 끊긴 전선 끝점 연결
- Unity Editor 컴파일 및 씬 저장 상태 확인

기존 S15P21A604-717은 허공 줄을 끄는 작업으로 완료되었으므로, 사용자 후속 요구인 복원/재배치를 별도 이슈로 추적한다.
