## 설명

카메라 화면의 좌측·우측·상단 경계에 아바타가 걸릴 때 몸체 일부는 보이지만 옷 파츠가 먼저 사라지거나 잘려 보인다. 특정 방향이 아니라 프러스텀 가장자리라는 공통 조건에서 재현된다.

관찰
- 좌측, 우측, 상단 화면 경계에서 동일 증상
- 아바타 전체가 아니라 일부 의상 SkinnedMeshRenderer가 먼저 컬링됨
- 화면 중앙으로 돌아오면 다시 표시됨

유력 가설(구현 전에 실측 필요)
- 런타임 조립된 의상 파츠의 SkinnedMeshRenderer.localBounds 또는 rootBone 기준이 실제 애니메이션 위치와 맞지 않아 프러스텀 컬링 판정이 잘못됨
- 여러 의상 파츠가 부정확한 공유 고정 AABB를 사용하는지 확인 필요

조사·수정 범위
- 문제 파츠별 localBounds, world bounds, rootBone, updateWhenOffscreen 값을 정상/경계 프레임에서 비교
- 신체와 의상 파츠의 bounds 중심·크기 차이 계측
- 무조건 updateWhenOffscreen=true로 두는 성능 우회보다 런타임 조립 시 올바른 bounds를 계산·설정하는 방향 우선
- 좌·우·상단 및 여러 애니메이션 자세에서 재현 방지 확인
- WebGL 빌드에서 최종 확인
