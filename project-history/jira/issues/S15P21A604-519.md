## 설명

GitLab #133 에서 BE(황덕)가 2026-09-07 17:22 에 G-7 Consultation 계약을 전부 확정했고, 일정과 무관하게 지금 확정이므로 FE 는 이 이름·경로로 어댑터를 미리 맞춰 두어도 나중에 바뀌지 않는다고 명시했다. 그 선반영을 한다.

[확정된 계약]
1. handoffSummary: string 또는 null. null 은 AI 대화 없이 바로 상담 요청한 경우다. 요약은 FastAPI 가 만들고 Spring 이 저장하며 요청 생성 시점에 스냅샷으로 괳는다. 요약 생성 실패는 요청을 막지 않고 null 로 들어간다
2. 요청 body 는 { boothId, conversationId? } 다. FE 가 마지막 AI 답변 텍스트를 보내지 않는다 — 서버가 conversationId 로 FastAPI 에 요약을 요청한다. 현재 AiChatOverlay 는 aiHandoffContext(boothId, lastAgentTurn.text) 로 텍스트를 넘기고 있다
3. STOMP: wss 로 /ws/consultation, WS Token 은 POST /api/v1/consultation/ws-token 으로 5분짜리를 받아 CONNECT 헤더에 싣는다. URL query 로 토큰을 보내지 않는다
4. 구독 2개: 방문자는 /user/queue/consultation, 직원은 /topic/booths/{boothId}/consultation. SEND destination 은 P1 에 없다 — 서버에서 클라이언트 단방향 알림 전용이고 행동은 전부 REST 다
5. 이벤트 봉투 { type, requestId, occurredAt, ... }. 방문자 accepted·expired·ended, 직원 requested·cancelled·expired·taken. taken 은 현재 Port 에 없다
6. 재연결 직후 getQueue 와 요청 상태를 REST 로 다시 읽는다. 이벤트 재전송은 P1 에 없다
7. REST 5경로 확정 — requestConsultation·cancelRequest·getQueue·accept·end. accept 의 C-06 위반은 409 CONSULTATION_ALREADY_ACTIVE

[범위]
Port 타입·mock 을 확정된 이름·경로에 맞춘다. 실 transport 는 붙이지 않는다 — BE 구현이 아직 스프린트 미배정이다(S15P21A604-136 5SP, -137 8SP).

[완료조건]
- entities/consultation/channel.port.ts 가 확정 계약과 일치한다(taken 추가, 재연결 REST 재조회 정책 명시)
- AiChatOverlay 의 handoff 가 텍스트 대신 conversationId 를 실는다. S15P21A604-516 에서 넣은 conversationIdRef 를 그대로 쓴다
- REST 5경로와 오류 코드를 Port 주석에 고정한다
- 변경이 닿는 테스트가 함께 갱신된다
