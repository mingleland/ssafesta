## 설명

GitLab #221 §4 (BE 요청) 반영. 테스트 동작 변화 없이 SpringBootTest 컨텍스트 캐시 분기 수를 줄여 back-test job 시간 단축.

대상:

1. @AutoConfigureMockMvc 미적용 26개 파일 통일 → 컨텍스트 분기 -1
2. FakeObjectStorageConfiguration / FakeDocumentProcessingClientConfiguration 을 TestcontainersConfiguration 이 항상 import → 4개 분기를 1개로
3. statement_inspector, minigame timer @TestPropertySource 검토 → 가능하면 기본 컨텍스트 속성으로 통일
4. AiDocumentUploadBlockedIntegrationTest 중첩 3종 → 1 컨텍스트로 통합 가능한지 검토
5. @MockitoSpyBean 5종 재검토 — spy 없이 되는 것부터
6. BoothTestSupport.createMember 사용처를 createMemberWithWallet 으로 교체 — WalletNotFoundException 로그 스팸(트레이스 49%) 제거

인프라(.gitlab-ci.yml) §3 항목은 별도 담당(@powerful7305) 범위로 이번 작업에서 제외.
