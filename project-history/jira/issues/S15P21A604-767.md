## 설명

### 작업 목적

이벤트 설문(`SSAFESTA_2026`)이 **문항 0개**로 서 있다. `V29__event_survey.sql:43-44` 가 설문 행만 넣고 "문항이 된다. 도착하면 별도 마이그레이션으로 얹는다 — 그때까지 run 응답의 questions 는 [] 다" 로 남겨 둔 자리다.

**문항 확정본은 2026-09-11 에 GitLab #173 으로 이미 도착했다**(`docs/26` 에도 기록, `!672` / `dc13e5ae`). BE 가 아직 얹지 않았다. `S15P21A604-621` 은 ①②③(스키마·run·제출 분기)까지로 완료됐고 문항 시드는 그 범위 밖이었다.

지금 상태에서는 이벤트 상점의 `[설문 참여하기]` 가 열려도 답할 것이 없다. 문항이 0개인 설문은 `404` 라 화면에 서버 문장이 뜬다.

### 작업 내용

새 Flyway 마이그레이션 하나. `surveys` 의 `survey_key = 'SSAFESTA_2026'` 행에 문항 6개와 선택지를 얹는다.

**문항 — 6개 (필수 4 · 선택 2)**

| # | `display_order` | `question_type` | `is_required` | `question_text` |
|---|---|---|---|---|
| Q1 | 0 | `RATING` (1~5) | true | 전시 부스에서 다른 팀의 프로젝트를 둘러보는 과정이 얼마나 편리했나요? (1 = 매우 불편했다 · 5 = 매우 편리했다) |
| Q2 | 1 | `RATING` (1~5) | true | SSAFESTA를 다시 이용할 의향이 있나요? (1 = 전혀 없다 · 5 = 매우 있다) |
| Q3 | 2 | `MULTIPLE_CHOICE` | true | SSAFESTA를 다시 이용한다면 어떤 기능을 가장 기대하시나요? 모두 선택해주세요. |
| Q4 | 3 | `MULTIPLE_CHOICE` | true | 이용하면서 아쉽거나 부족하다고 느낀 점을 모두 선택해주세요. |
| Q5 | 4 | `LONG_TEXT` | false | 추가로 개선했으면 하는 점이 있다면 자유롭게 적어주세요. |
| Q6 | 5 | `SHORT_TEXT` | false | 이벤트 상점에 추가되었으면 하는 경품이나 물품이 있다면 적어주세요. |

Q1·Q2 는 둘 다 `rating_min = 1`, `rating_max = 5`. 눈금별 라벨 칼럼이 `survey_questions` 에 없고 FE `QuestionInput` 도 `aria-label="N점"` 만 그리므로, **눈금 설명을 문구 안에 넣어 코드 변경 0 으로** 같은 정보를 전달한다.

**Q3 선택지** (`display_order` 0부터)

```
0  다른 팀의 프로젝트·부스 둘러보기
1  미니게임
2  AI NPC·상담
3  이벤트·경품 콘텐츠
4  캐릭터·월드 탐색
5  부스 꾸미기·프로젝트 전시
6  다른 참가자와의 소통
```

**Q4 선택지** (`display_order` 0부터)

```
0  월드 이동·조작이 불편했다
1  원하는 부스나 프로젝트를 찾기 어려웠다
2  즐길 콘텐츠가 부족했다
3  미니게임이 부족했다
4  다른 참가자와 상호작용할 요소가 부족했다
5  채팅이나 음성채팅 기능이 필요하다고 생각한다
6  로딩·성능이 불편했다
7  UI가 이해하기 어려웠다
8  특별히 아쉬운 점이 없었다
```

**Q5·Q6 은 선택지와 **`rating_min`/`rating_max` 를 둘 다 비운다. 선택형이 아닌 문항에 선택지를 넣거나 `RATING` 이 아닌 문항에 rating 범위를 넣으면 `validateQuestion` 이 400 을 낸다.

기존 6유형만 쓰고 `APPLICATION` 은 쓰지 않는다. 조건부 분기 없다.
