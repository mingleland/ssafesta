## 설명

프로젝트 관리·설문 관리·상담 운영 세 화면이 입력칸과 버튼을 평면 나열하고 있어 화면 목적이 드러나지 않는다.

- 프로젝트: 7필드를 기본 정보 / 대표·미디어 / 외부 링크 세 섹션으로 묶고 대표 이미지 썸네일 확인을 붙인다. 저장 상태를 저장 버튼 옆으로 올린다
- 설문: actions 가 footer 로 내려가는 탓에 탭이 화면 맨 아래 있었다. 탭을 본문 최상단으로 올리고 footer 에는 저장만 둔다. 항상 펼쳐진 6유형 버튼을 '문항 추가 → 유형 선택' 으로 접는다
- 상담: 대기·진행 요약 + 요청 단위 카드 리스트. 새로고침을 목록 헤더 보조 액션으로 옮긴다
- sc-* 유틸의 --sc-* 토큰이 .festa-screen 에만 선언돼 오버레이 표면에서 카드 배경·버튼이 통째로 무효였다. 토큰 선언만 두 표면이 공유하도록 분리한다
- 프로젝트 저장이 내 부스 관리창의 ['booth-projects'] 를 무효화하지 않아 이름이 갱신되지 않던 것도 함께 고친다
