## 설명

## 목적

OCI ARM64 임시 서버에 공통 데이터 계층과 공개 진입점을 구축하고, 구축 절차를 재현 가능한 문서로 남긴다.

## 작업 범위

- OCI VCN·Security List·서버 방화벽 확인
- VS Code Remote Tunnel 관리 경로 구성
- Docker Engine·Compose 설치
- 공용 Docker 네트워크 `festa-net` 구성
- PostgreSQL(pgvector) 영속 볼륨 구성
- Redis 유실 허용 데이터 경계 구성
- Nginx 80 공개 진입점 구성
- `docs/JSW/OCI_구축_기록.md`에 구축·실측·트러블슈팅 기록

## 완료 조건

- [ ] `http://129.213.24.228` 외부 접속 확인
- [ ] PostgreSQL 컨테이너 healthy 및 vector extension 확인
- [ ] Redis 기동과 PostgreSQL 이름 해석 확인
- [ ] 5432·6379 등 내부 포트 외부 비노출 확인
- [ ] Nginx만 승인된 공개 포트에 바인딩
- [ ] 구축 기록에 실제 명령, 결과, ARM/x86 이관 주의사항 반영
- [ ] Secret 원문이 저장소·이슈·로그에 없음

## 참고

IP 기반 HTTP 환경은 임시 dev 검증이며 최종 HTTPS/WSS 완료 근거로 사용하지 않는다.
