## 설명

## 작업 목적

- 대화 인물/표정 이미지가 표시 박스와 원본 셀 비율이 안 맞아 가로로 늘어나 보이는 문제 수정

## 작업 내용

- `GameStudioShell.css`의 `.gss-dialogue-preview-portrait`(에디터 LIVE PREVIEW)와 `ReferenceGamePlayer.css`의 `.grp-dialogue-portrait`(실제 게임 실행 화면), 두 곳의 고정 `width: %` 값을 지우고 `aspect-ratio: 1 / 2`(원본 스프라이트 셀 256×512 비율)로 교체
- `height: %` 값은 기존 그대로 유지 — `aspect-ratio`가 그 높이에 맞춰 폭을 정확한 비율로 자동 계산
- 원본 이미지 asset(`dialogue-portrait-pack-4x3.webp`)은 수정하지 않음 — 그림 자체는 문제 없음, 표시 박스 CSS만 수정

## 완료 조건

- [ ] 에디터 LIVE PREVIEW에서 인물 이미지가 원본 셀(1:2) 비율 그대로 보이고 가로로 늘어나 보이지 않는다
- [ ] 실제 게임 플레이 화면에서도 동일하게 정상 비율로 보인다
- [ ] 브라우저 창 크기를 바꿔도(에디터는 16:9 고정, 게임 화면은 창 비율에 따라 가변) 비율이 깨지지 않는다

## 선행 작업 / Dependency

- 없음

## 참고

- 상위 항목: S15P21A604-383
- 원인: `staticImageBackgroundStyle`의 셀 슬라이싱 계산 자체는 정확하나, 그걸 담는 표시 박스의 width/height가 원본 셀 비율과 무관하게 개별 % 값으로 정해져 있어 박스 비율이 어긋났음(에디터 기준 실측 약 0.81:1, 원본은 1:2)
