## 설명

부스 선택 맵은 사용 중이라 하는데 월드의 그 방은 직원·조명·포털이 꺼진 빈 칸이었다. 두 화면이 서로 다른 것을 읽었다 — 맵은 임대 상태, 월드는 게시본 유무.

2026-09-10 에 임대되지 않은 부스는 비워 둔다를 구현하면서 임대 여부를 BoothRuntime.IsLoaded 로 대신 읽은 것이 원인이다. 임대 뒤 게시를 미루거나 안 하는 사용자가 있어 그 사이 두 화면이 갈린다.

점유 표시(직원·조명·포털)의 근거를 GET /booth-slots 의 status === OCCUPIED 로 바꾸고, 내부 배치만 게시본으로 그린다. 간판이 이미 같은 목록을 읽고 있어 데이터 소스가 늘지 않는다. 슬롯 목록을 못 받은 동안은 옛 근거로 버텨 조회 실패가 월드를 통째로 비우지 않게 한다.
