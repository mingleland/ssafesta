## 설명

## 작업 목적

같은 규칙이 여러 곳에 복제된 자리를 한 곳으로 모은다. 복제 자체가 목적이 아니라, 복제 중 하나가 이미 갈라져 검증 구멍이 생겼기 때문이다. S15P21A604-402 와 같은 뿌리다 — 규칙이 호출자마다 흩어져 있으면 새 호출자가 빠뜨린다.

동작이 바뀌는 곳은 파사드 로고 URL 한 곳뿐이고 나머지는 순수 정리다.

## 작업 내용

### 1. 임대 만료 가드 8사본 통합

아래 3줄이 8개 파일에 글자 그대로 있다.

```java
leases.findValidByBoothId(boothId, Instant.now())
        .orElseThrow(() -> new BoothExpiredException(boothId));
```

`AiAgentService` · `AiDocumentService` · `BoothFacadeService` · `BoothHomepageService` · `BoothLayoutService` · `BoothLayoutQueryService` · `BoothQueryService` · `ProjectService`. 그중 `requireValidLease` 라는 private 사본이 3개다.

앞의 6개 서비스는 `BoothLeaseRepository` 를 **이 한 줄 때문에만** 주입한다. 그리고 5개는 바로 위 줄이 `editorGuard.requireEditor(...)` 다.

이미 있는 `BoothEditorGuard` 에 메서드 2개를 더한다.

- `requireActiveLease(boothId)` — 만료만 본다. `ProjectService` 의 공개 조회 경로처럼 편집자 검사가 없는 자리에 쓴다
- `requireActiveEditor(boothId, userId)` — 편집자 + 만료. 짝으로 부르던 5곳이 쓴다

사본 8개, private 3개, 생성자 파라미터 · 필드 · import 각 6개가 사라진다. `BoothLayoutQueryService` 와 `BoothQueryService` 는 `leases` 를 다른 용도로도 쓰므로 필드는 남기고 가드만 공유한다.

새 부스 편집 기능이 만료 검사를 빠뜨릴 수 없게 되는 것이 실질 효과다. 예정된 S15P21A604-152(Lease 만료 상태 전이 스케줄러)도 가드를 한 곳에서 쓴다.

### 2. 파사드 로고 URL 검증 이탈 교정 — 동작 변경

URL 필드 6개는 `HttpUrlValidator` 를 쓰는데 `BoothFacadeService.validateLogoUrl` 만 `logoUrl.startsWith("https://")` 로 자체 판정한다.

그래서 `"https://"` 자체(8자, 호스트 없음)가 통과해 그대로 저장된다. `HttpUrlValidator` 는 호스트 없는 절대 URI 를 거부한다.

`HttpUrlValidator.validate` 에 https 전용 플래그를 더해 파사드도 그것을 쓰게 하고, private 메서드 12줄을 지운다. `HttpUrlValidator` 클래스 주석이 이미 "어느 쪽 규칙이 이길지 먼저 정해야 하는 별개 변경"이라 적어 두었다 — https 전용을 유지하는 쪽으로 정한다. 로고는 우리 페이지에 임베드되므로 http 를 허용할 이유가 없다.

거부 메시지가 "로고 URL은 https로 시작해야 합니다." 에서 `HttpUrlValidator` 의 규칙별 문장으로 바뀐다. 오류 봉투의 `code` 는 `VALIDATION_FAILED` 로 종전과 같고 `field` 도 그대로다.

### 3. 참조 0건 접근자 삭제

호출자가 없는 것 18개. 엔티티는 `@Id` 가 필드에 있어 필드 접근이므로 Hibernate 에 게터가 필요하지 않다.

`GameAsset` 의 `getSha256` · `getCreatedByUserId` · `getDeclaredContentType` · `getUploadExpiresAt`, `UserInventoryItem` 게터 4개, `CatalogItem.getItemType` · `isStackable`, `CoinReconciliationRun.getStartedAt` · `getFailureReason`, `BoothStaff.getJoinedAt`, `OAuthIdentity.getProviderSubject`, `BoothLease.isValidAt`, `LayoutJson.raw`, `InsufficientCoinException.getShortfall`, `ActiveLeaseLimitException.getExistingLeaseId`.

`getRequired` · `getBalance` 는 `WalletServiceIntegrationTest` 가 단언하므로 남긴다. 삭제 전 각 항목이 Jackson 직렬화 대상 record 에서 참조되지 않는지 확인한다.
