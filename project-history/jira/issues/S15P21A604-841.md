## 설명

GitLab #221의 인프라 §3 범위.

- MR validate 단계의 `mr-status`가 수행하는 전체 secret scan을 유지하고, component test/build job의 중복 전체 scan을 제거한다.
- `back-test`, `back-build`에 backend Maven 의존성 캐시를 적용한다.
- Python 설치 제거는 stage summary JSON 생성 의존성이 있어 이번 범위에서 제외하고, 적용 후 실측으로 별도 판단한다.

완료 조건:

- MR pipeline에서 secret scan은 `mr-status` validate 단계에 1회만 수행된다.
- backend/pom.xml 또는 Maven wrapper 변경 시에만 Maven 캐시가 갱신된다.
- GitLab CI acceptance 검증이 통과한다.
