## 설명

목적
부스를 임대하면 새로고침 없이 그 즉시 다른 접속자 화면에서도 런타임 조립되어야 한다. 사용자 확정 2026-09-14: 부스가 임대됐다는 통신이 오면 그 즉시 런타임에서 조립되야 하고, 이게 우리 프로젝트 기본 전제 조건이다.

무엇이 빠져 있었나
런타임 조립 경로(WorldBoothPublishedBootstrap.RequestReload 간판·외벽 재조회 + BoothRuntime.Rebuild)는 이미 완성돼 있고 잘 돌았다. 그것을 부르는 신호가 FE 브리지 하나뿐이었고, 그 브리지(boothLayoutBridge.ts 의 notifyBoothSlotChanged)는 getReadyUnityInstance 로 자기 브라우저 탭의 Unity 인스턴스에만 SendMessage 한다. 그래서 임대한 본인만 즉시 보고 다른 접속자는 아무 신호도 받지 못했다. 렌더링 결함이 아니라 신호가 한 탭을 벗어나지 못한 것이다.

오래 적혔던 전제가 틀렸다
BoothLayoutBridge 주석의 부스 오브젝트는 NetworkObject 가 아니라 클라이언트별 Local Spawn 이라 월드 서버가 알려 줄 길도 없다 는 틀렸다. 복제할 것은 오브젝트가 아니라 슬롯 번호 하나(int)다. 번호만 퍼뜨리면 각 클라이언트가 스스로 조회해 조립한다.

변경
1. BoothLiveSyncNetwork 신설 (Assets/_Project/Scripts/Booth/Runtime). 플레이어 프리팹에 붙는 NetworkBehaviour. ServerRpc(slotId) 로 올리고 ClientRpc 로 전원에게 내린다. NappingStaffNetwork · HighStrikerNetwork 와 같은 방식 — 씬에 NetworkObject 가 없고 ConnectionManager 는 동결이라 새 네트워크 프리팹을 등록할 수 없다.
2. 서버는 중계만 한다. 슬롯 범위 1~12 검사와 클라이언트당 1초 도배 방지만 건다. 전용 서버는 batchmode 라 부스 비주얼도 API 클라이언트도 없어 임대 사실을 되묻지 못한다. 거짓 번호가 와도 각 클라이언트 조회가 404 로 끝나 기존 모습이 유지되므로 피해는 헛조회 한 번이다.
3. ClientRpc 는 보낸 사람의 NetworkObject 를 타고 클라이언트마다 한 번만 도착한다. 40명이어도 중복 조립이 없다. 보낸 본인은 건너뛴다(FE 브리지로 이미 조립했다).
4. BoothLayoutBridge.ReloadBoothSlot 에서 Announce 호출. 틀린 전제를 적은 주석도 정정했다.
5. BoothLiveSyncInstaller (Editor) 로 PlayerAvatar 프리팹에 부착. 두 번 돌려도 컴포넌트가 늘지 않는다.

배포 조건 (중요)
NetworkBehaviour 를 추가하면 NGO 의 RPC 색인이 바뀐다. 전용 서버와 WebGL 클라이언트는 반드시 같은 커밋으로 함께 배포해야 한다. 한쪽만 올리면 RPC 가 어긋난다.

곁다리로 풀리는 것
전용 서버가 낡아 NappingStaffNetwork 의 RPC 가 서버에 아예 없었고, 그래서 자는 직원이 계속 로컬 폴백으로 빠졌다. 이번 서버 배포로 함께 풀린다.

남는 구멍 (이번 범위 밖)
1. PublishedSlotResolution.NeedsRetry 가 404 를 확정으로 못박아, 재시도 루프가 나중에 게시된 부스를 영영 다시 묻지 않는다. NGO 전파가 생겨 실사용에는 영향이 없지만 안전망이 없는 상태다.
2. RequestReload 는 layout 이 null 이면 조용히 반환해, 임대 해제로 부스가 사라져야 하는 역방향은 지워지지 않는다.
3. 임대자가 월드에 접속하지 않은 채 임대하면 보낼 곳이 없다. 경고 로그로 드러낸다.

BE 대안과의 관계
S15P21A604-727 (/topic/world/booths STOMP 방송)은 서버가 진실을 쥐는 더 튼튼한 길이지만 미착수다. 이 작업은 BE 변경 없이 오늘 돌아가게 하는 것이고, 둘은 배타적이지 않다.

검증 방법
두 브라우저로 같은 월드에 접속해 한쪽에서 부스를 임대하고, 다른 쪽 화면에서 새로고침 없이 간판·외벽이 나타나는지 본다.
