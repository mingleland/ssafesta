## 설명

이벤트 경품 상점(-599)의 [설문 참여하기] CTA 가 대상이 없어 비활성으로 남아 있다(features/event/model/surveyEntry.ts). 그 하나를 푼다.

이 설문은 부스 설문이 아니라 SSAFESTA 프로젝트 공용 이벤트 설문이다. 부스 설문은 부스 주인이 만들고 그 부스 방문자가 답하지만, 이벤트 설문은 운영이 하나 만들고 축제 참가자 전체가 답한다.

## 방식

새 OverlayType 을 만들지 않는다. 화면·상태 기계가 같고 다른 것은 설문을 어디서 찾는가 하나뿐이라, payload 안의 discriminated union 으로 흡수한다.

SurveySource = { kind: 'booth'; boothId } | { kind: 'event'; surveyKey }

기존 SURVEY 오버레이 하나를 두 source 가 공유한다. OverlayHost 분기도 늘리지 않는다.

## 범위

- shared/contracts/survey.ts — SurveySource
- entities/survey — Port 에 getEventRun(surveyKey), http·mock 어댑터
- features/survey/model/run.ts — 늦은 응답 가드를 boothId 에서 source 로 일반화, memberOnly·respondedAt 추가
- features/survey/ui/SurveyOverlay.tsx — payload 를 SurveySource 로
- features/interaction/dispatcher.ts — booth payload 모양 변경
- features/event/model/surveyEntry.ts — surveyKey 반환

## 하지 않는 것

가짜 boothId, raffleTicket 모델, 코인 지급, 이벤트 상점 상품·코인 로직 변경, 새 OverlayType, 새 오버레이 컴포넌트.

## 완료조건

회원이 상점 CTA 에서 이벤트 설문에 참여하고 저장·참여 완료 확인까지 왕복한다. 게스트는 제출 전에 로그인 안내로 막힌다. 재진입 시 참여 완료로 보인다. tsc·vitest·build green.

BE 엔드포인트(GET /api/v1/event-surveys/{surveyKey}/run)는 별도 요청으로 나가며, 도달 전에는 mock 어댑터로 진행한다(-368 에서 -528 로 간 것과 같은 순서).
