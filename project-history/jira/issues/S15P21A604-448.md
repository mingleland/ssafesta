## 설명

### 증상

2026-09-06 09:50 WebGL(부스 1 게시본 v10): AI_AGENT 오브젝트의 `configId` 가 0 이다 — Studio 에서 AI 설정을 연결하지 않았다. F 를 누르면 카메라가 NPC 에 초점을 맞추고 입력이 잠기는데, `BoothInteractBridge` 는 `AI_AGENT_INTERACT` 를 건너뛴다(콘솔 경고만). 방문자는 아무 변화도 보지 못한 채 Esc 를 눌러 빠져나와야 한다.

### 조치

일반적인 게임 관례대로, NPC 가 한 줄 토스트를 띄우고 **초점과 입력 잠금을 잡지 않는다**. GAME_PORTAL 의 `configId` 0 도 같은 규칙으로 처리한다.

### 관련 파일

`Content/AI/AiNpcInteractable.cs`, `Content/Arcade/GamePortalInteractable.cs`, `Integration/Bridge/BoothInteractBridge.cs`
