## 설명

## 목적 Dev·Demo 공개 진입점을 same-origin Gateway로 정리하고 HTTPS·런타임 설정 주입 계약을 적용한다. OAuth callback만 api.ssafesta.world를 유지한다.  ## 작업 범위 - Dev: /__dev/api → /api, WebGL은 /unity/, HTTPS 전환 - Demo/Prod: Nginx location /api/ 및 /ai/v1/ reverse proxy 추가 - /ai/v1/은 SSE를 위해 proxy_buffering off 적용 - PUBLIC_API_BASE_URL·PUBLIC_AI_API_BASE_URL은 same-origin fallback을 사용하고, PUBLIC_UNITY_BUILD_BASE=/unity/, PUBLIC_AUTH_BASE_URL=https://api.ssafesta.world를 배포 주입 - Nginx·Compose·Jenkins 주입 경로와 route 검증 절차 반영  ## 완료 조건 - Dev·Demo에서 /api/와 /ai/v1/ 요청이 각 upstream으로 전달된다. - Dev /unity/에서 WebGL 산출물을 HTTPS로 제공한다. - AI SSE 응답이 버퍼링되지 않는다. - OAuth redirect는 https://api.ssafesta.world를 유지한다. - PUBLIC_* runtime config와 실제 Gateway 경로가 일치한다.  ## 관련 - GitLab #163 - specs/infra-002-environments
