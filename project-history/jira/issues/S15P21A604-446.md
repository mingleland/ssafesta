h3. 발견 (2026-09-06 08:00, editor Host, DevTeleport 로 부스 내부 벽 밖 좌표에 서자)

player y 가 -111,829 까지 떨어질 동안 아무 복구가 없다. 실사용자도 콜라이더 틈·포털 경계에서 같은 상황이 될 수 있고, 그러면 사용자 테스트에서 세션을 버려야 한다.

h3. 검증

editor Host: 허공 좌표로 보냈을 때 log `낙하 한계 초과(y=-152) -> 마지막 접지 위치 복귀` -> 같은 자리를 기록했던 경우 다시 떨어지고 -> 2차 `(-29.5, 0.7, -248.0)`(서버 스폰) 복귀 확인.
