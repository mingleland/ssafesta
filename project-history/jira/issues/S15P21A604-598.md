## 설명

### 작업 목적

2026-09-10 구두 결정으로 게임이 부스 내부에서 월드 공용 공간(광장)으로 옮겨졌다. 이 결정이 어느 문서에도 기록되지 않아, 다음 착수자가 저장소만 보면 부스 GAME_PORTAL 경로로 설계하게 된다. docs/26_팀_결정_필요사항.md 의 결정 기록 로그에 한 줄을 남겨 그 반복을 막는다.

실제로 그 반복이 이미 한 번 일어났다. 2026-09-10 이 결정을 모르는 상태에서 부스 경로를 전제로 S15P21A604-108 설계와 구현을 진행했고 전부 폐기했다.

### 작업 내용

docs/26 결정 기록 로그에 행 하나를 추가한다. 담을 것:

- 게임은 전부 월드 공용 공간으로. 부스 내부 게임기는 소멸
- S15P21A604-158(GAME_PORTAL Binding·V26)·S15P21A604-204(configId Int32 경계·no-store) 보류. 폐기 판정은 나중에 — 지금 닫지 않는다
- 광장에는 현재 슬롯머신만 서 있어 Game Studio 게임을 걸 오락기가 없다. 그래서 광장 진입관(GET /api/v1/arcade-machines/{machineId}, GitLab #56 ⓐ 3파트 합의)과 S15P21A604-108(Published 게임 유료 입장)도 보류. 재개 조건은 광장에 해당 오락기가 놓이는 것
- 근거 링크: GitLab #56, GitLab #157, spec 019

### 완료 조건

- docs/26 결정 기록 로그에 위 결정이 있고, 보류 대상 티켓 3개(-158·-204·-108)와 재개 조건이 적혀 있다
- -158·-204·-108 은 닫지 않는다. 보류이지 폐기가 아니다

### 참고 / 별건

GitLab #157 에서 게임 파트가 2026-09-10 10:04 에 GAME_PORTAL 프리팹 AABB 를 실측해 회신했다 — LocalBounds(-0.37, 0, -0.35, 0.37, 1.97, 0.58), 프리팹은 ArcadeCabinet_GamePortal 하나. 부스 경로 보류로 당장 쓸 데가 없으므로, 그 사실을 알려야 게임 파트가 후속 작업(BoothObjectType 추가·Registry 프리팹 엔트리·진입 컴포넌트)을 잡고 있지 않게 된다. 이 티켓에 포함할지 별건으로 뺄지는 판단이 필요하다.

또한 GitLab #56 의 ⓑ(광장 진입 허용 기준 — Published 만·서버 매 요청 판정)·ⓒ(큐레이션 — 운영자 지정 목록) 는 3파트 권장안이 모두 같은 방향으로 올라가 있고 기획 확정 한 줄만 남은 상태다. 광장 오락기가 놓이는 시점에 그 확정 요청부터 나가야 한다.

### 참고

- GitLab #56 — GAME_PORTAL Binding·Booth Host 수직 구현. 2026-09-04 게임 파트 §5 가 광장 오락기 직접 진입을 제안하고, 2026-09-05 에 ⓐ(별도 endpoint) 가 3파트 합의로 확정됐다
- GitLab #157 — GAME_PORTAL 프리팹 AABB 실측 회신
