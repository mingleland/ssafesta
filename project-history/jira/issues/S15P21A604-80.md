## 설명

### 작업 목적

검증된 Unity Linux Server 산출물을 불변 이미지로 패키징해 game 파트 단독 배포의 기준선을 만든다.

### 작업 내용

- 동결된 `festa-unity/Docker/` 계약과 `Builds/linux-server` 컨텍스트를 재사용
- 커밋 SHA 기반 이미지 태그·digest 기록
- 내부 7777 포트와 실행 인자 검증
- 기존 이미지로 즉시 되돌릴 수 있는 배포 단위 마련

### 완료 조건

- `docker run`으로 서버가 기동하고 헬스 판정이 가능하다.
- 이미지 tag/digest/commit SHA가 배포 증적에 남는다.
- game-only 교체와 이전 known-good 이미지 복원이 가능하다.

### 선행 작업

Unity Linux Server 빌드 산출물

### 참고

- `specs/infra-001-ci-cd-pipelines`
- `specs/infra-003-unity-server-runtime`
- T-25, T-26

### 테스트 방법

이미지 빌드→기동→2클라이언트 접속→game-only 교체→known-good 복원 순으로 검증한다.
