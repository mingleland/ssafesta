## 설명

## 작업 목적

에셋이 서로 겹쳐도 아무 표시가 없다(2026-09-10 플레이 중 실측).

겹침 방지는 **추가할 때만** 돈다 — `findFreeSpot` 이 최소 간격 0.9 m 로 빈 자리를 찾는다. **드래그 이동은 경계 clamp 와 snap 만 거쳐** 다른 오브젝트를 통과해 올려놓을 수 있다. 사전 검증 규칙(`OBJECT_LIMIT`·`DUPLICATE_OBJECT_ID`·`AREA_OUT_OF_BOUNDS`·`CONFIG_NOT_LINKED`)에 충돌 항목 자체가 없다.

## 작업 내용

**경고 계층까지만 한다.** 게시 차단(`precheckErrors`)에는 넣지 않는다 — 공개 판정의 권위는 서버이고(헌법 16조), 서버가 겹침을 어떻게 다루는지 아직 확인되지 않았다. FE 가 서버보다 엄격해지면 서버가 허용하는 배치를 FE 가 막는다.

- 회전 반영 실물 AABB(`worldAABB`)를 재사용해 x·z 구간 교차로 판정한다 — 이미 있는 함수다
- 드래그 중 겹치는 오브젝트를 빨갛게 표시한다. 경계 이탈이 이미 같은 방식(`#ff8a8a`)이라 화면 언어가 이어진다
- `precheckWarnings` 에 겹침 경고를 더한다(게시는 막지 않는다)

## 완료 조건

1. 드래그로 다른 오브젝트 위에 겹치면 표시가 뜬다
2. 게시가 막히지 않는다 — 경고까지다
3. 경계 이탈 표시와 시각 언어가 일관된다
4. unit test / tsc 0 / vitest 전체 green / oxlint 신규 경고 0

## 선행 작업 / Dependency

- 없음(경고 계층 한정). 게시 차단 여부는 BE 권위 확인 뒤 별건으로 판단한다
