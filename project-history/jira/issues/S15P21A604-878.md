## 설명

40명 실측 부하테스트를 실제 사용자로 돌리는데 서버 빌드에 성능 계측이 하나도 없다. 로그를 떠도 접속·해제 줄만 나와 서버가 버텼는지 판단할 수치가 없다. PerfHud 가 #if UNITY_EDITOR || !UNITY_SERVER 라 데디케이티드 서버 빌드에서 컴파일 자체가 빠지는 것이 원인이다.

WorldTransportDiagnostics 에 주기 계측을 붙인다. 접속자가 1명 이상인 동안 기본 10초마다 stdout 에 한 줄을 남긴다: clients, tick p50/p95/max, net sent/recv KB/s, objects, heap, window.

접속자 0 이면 남기지 않는다 — 빈 줄로 덮이면 인프라가 구간을 못 찾는다. Application.isBatchMode 가드라 클라이언트 비용은 0 이고, #if UNITY_SERVER 로 감싸지 않아 모든 플랫폼에서 컴파일된다.
