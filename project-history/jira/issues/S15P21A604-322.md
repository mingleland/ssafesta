## 설명

## 배경

부스 셸(벽·천장) 렌더러 7개가 Occluder Static / Occludee Static 플래그를 갖고 있지 않았다.
오클루전 컬링이 셸을 "가리는 물체"로 보지 않으므로, 부스 안에 있어도 축제장 전체가 그려졌다.

## 변경

main.unity 의 셸 렌더러 7개에 staticEditorFlags 18(OccluderStatic|OccludeeStatic)을 부여하고
오클루전 데이터를 재베이크했다.

|---|---|---|---|
| 부스 내부 | 1088 | 231 | 79% |
| 벽 밀착 | 1088 | 109 | 90% |

Renderer.isVisible 로는 0.0% 로 나왔다 — isVisible 은 "어느 카메라에든" 보이면 true 라
수동 cam.Render() 결과를 반영하지 않는다. UnityStats 로 바꿔서야 실측이 잡혔다.
