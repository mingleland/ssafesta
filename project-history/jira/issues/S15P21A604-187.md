## 설명

작업 목적

로컬→원격 Asset 저장소 교체 뒤에도 기존 게임과 신규 Published 게임의 이미지 참조가 깨지지 않게 한다.

작업 내용

- asset:// parser·resolver 단위 테스트

- 로컬 전용 참조 탐지와 마이그레이션 회귀

- 공개/미공개/비Owner 접근 매트릭스

완료 조건

[ ] 기존 로컬 게임은 편집 가능하고 Publish 전 교체 위치가 안내된다.

[ ] 업로드된 Asset은 새 세션과 익명 Published 플레이에서 표시된다.

[ ] 미공개 Asset과 다른 게임 Asset은 노출되지 않는다.

[ ] 저장소 adapter 교체 뒤 기존 전체 회귀 스위트가 유지된다.

선행 작업 / Dependency
