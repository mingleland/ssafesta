## 막힌 지점 3건 (부딪힌 순서)

### 1. DATABASE_URL 스킴이 example 에 없다

`.env.example` 의 `DATABASE_URL=` 이 빈 값이라 스킴을 추측해야 한다. `postgresql+asyncpg://` 로 넣으면:

```
ModuleNotFoundError: No module named 'asyncpg'
```

의존성은 `psycopg[binary]` 다 — `postgresql+psycopg://` 여야 한다. example 주석 한 줄이면 막을 시행착오.

### 2. pgvector 확장을 마이그레이션이 만들지 않는다

```
psycopg.errors.UndefinedObject: type "vector" does not exist
```

`CREATE EXTENSION IF NOT EXISTS vector` 를 DB 에 수동 실행해야 alembic 이 통과한다. 의도라면(권한 분리) example 이나 README 에 선행 조건으로 명시 필요. backend 의 compose 는 `pgvector/pgvector:pg17` 이미지를 쓰므로 확장 자체는 사용 가능하다.

### 3. R2 와 MinIO 자격이 **둘 다** 필수라 로컬 기동이 원천 차단된다

Settings 검증이 `r2_*`·`minio_*` 전부에 min_length 1 을 요구한다. 임베딩은 `EMBEDDING_PROVIDER=mock` 이 있는데 **스토리지에는 로컬 대체가 없어**, 실 R2 계정 없이는 앱이 뜨지 않는다.

우회(오늘 동작 확인): MinIO 컨테이너를 띄우고 그 값을 R2 슬롯에도 채우면 뜬다 (R2 는 S3 호환).
