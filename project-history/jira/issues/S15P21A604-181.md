- Unity Portal 클릭→오버레이→종료 브라우저 E2E

- 중복 close와 예외 종료에서도 최종 상태 복원

[ ] 정상 종료·오류·라우트 이탈 후 입력이 복원된다.

[ ] Host 미활성 환경에서는 Unity 호출이 발생하지 않는다.
