## 설명

관리자가 경품 구매를 취소(CANCELLED)해도 구매자의 코인이 돌아오지 않고 경품 재고도 복구되지 않는다. 취소된 주문의 코인과 재고가 그대로 사라지는 상태다.

## 해야 할 일

- `AdminEventShopService.updateFulfillment` 가 `CANCELLED` 로 전이할 때 구매 대금을 구매자 지갑에 환불한다.
- 같은 트랜잭션에서 경품 재고를 구매 수량만큼 되돌린다. 무제한 재고(`stock = null`)는 애초에 차감되지 않으므로 건드리지 않는다.
- 환불 원장은 별도 사유 코드 `PRIZE_REFUND` 로 기록한다. 멱등키는 `PRIZE_REFUND:{purchaseId}` — 구매 한 건당 환불은 한 번뿐이다.
- 잠금 순서는 구매 경로와 동일하게 지갑 → 경품 행 순서를 지킨다. 뒤집으면 취소와 구매가 서로 데드락한다.

## 취소 차단

`FULFILLED`(지급 완료)와 `CANCELLED` 는 이미 종단 상태라 추가 작업 없이 취소·재취소가 막힌다. 상태 기계는 그대로 둔다.

## 테스트

- `AdminEventShopApiIntegrationTest.cancellingRefundsTheCoinsAndPutsTheStockBack` — 구매 후 취소 시 잔액 복구, 재고 복구, `PRIZE_REFUND` 원장 1건, 재취소는 409.

## 범위 밖

관리자 화면(`EventShopSection.tsx`)의 "코인 환불은 이 화면이 하지 않습니다" 안내 문구는 이제 사실과 다르다. FE 파트에 별도 통보 필요.
