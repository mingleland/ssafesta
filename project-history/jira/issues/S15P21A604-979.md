## 설명

증상: 탈퇴 확인 후 로그인 화면으로 가지만 계정·데이터가 그대로 남는다.

원인
1. BE AccountDeletionService 삭제 목록에 project_logo_uploads(V42) 가 빠져 DELETE FROM booths 가 project_logo_uploads_booth_id_fkey 로 실패 → 탈퇴 전체 500. 로고를 한 번이라도 올린 회원 전부 해당. 로컬 DB 에서 재현.
2. arcade_machine_bindings.owner_user_id(V45) 도 목록에 없다 — 자리 주인과 게임 주인이 다르면 같은 방식으로 실패(잠재).
3. FE MyInfoBody 가 confirmWithdrawal 실패 뒤에도 /login 으로 이동. 세션 유지, 오류 안내 소실, error 상태가 남아 재시도 버튼도 사라진다.

완료 조건
- 로고를 올린 회원·자리를 잡은 회원의 탈퇴가 성공하고 로고 바이트는 삭제 큐로 간다
- FE 는 성공 시에만 /login 으로 이동, 실패 시 안내와 재시도
