## 설명

프론트 월드 채팅으로 메시지가 들어오면 해당 발화 캐릭터 머리 위에 일정 시간 말풍선을 표시한다.

작업:
- FE 채팅 이벤트와 Unity 플레이어 식별자의 연결 계약을 확인한다.
- 발화자 캐릭터 위에 메시지 말풍선을 표시하고 일정 시간 뒤 숨긴다.
- 벽/거리/화면 밖/연속 메시지/긴 문장 처리 기준을 정한다.
- HTML·외부 입력은 안전하게 표시하고 과도한 길이는 제한한다.

완료 조건:
- 로컬/원격 플레이어의 채팅이 올바른 캐릭터 위에 표시되고 기존 채팅창은 유지된다.
