## 설명

## 작업 목적

Game Studio 플레이테스트 중 대화창(Overlay/Fullscreen 둘 다)의 선택지를 마우스 클릭으로만 고를 수 있어 불편함. 선택지 버튼에는 이미 번호 힌트(1, 2, 3...)가 표시되고 있었지만 실제 숫자키 입력과 연결돼 있지 않았음(Notion QA id=27). 화면에 이미 보이는 번호 그대로 키보드 숫자키로도 선택할 수 있게 한다.

## 작업 내용

- `ReferenceGamePlayer.tsx`의 keydown 핸들러에 `activeDialogue !== null`일 때만 동작하는 숫자키 분기 추가
- `event.key`가 '1'~'6'이고 `event.repeat`가 아닐 때(OS auto-repeat 무시, 최초 keydown에만 반응), 그 인덱스의 선택지가 존재하면 마우스 클릭과 동일하게 `chooseReferenceDialogue` 호출
- NumLock 꺼진 상태의 numpad 대응은 하지 않음(`event.key` 기반 — NumLock 켜진 상태에서는 일반 숫자키/numpad가 동일하게 인식되므로 별도 분기 불필요, 팀 결정)
- 존재하지 않는 번호(예: 선택지 3개인데 5 입력)는 무시
- 계약(`contracts/gameProject.ts`)상 선택지 최대 개수(6개)를 그대로 따름 — 1~6 범위만 커버

## 완료 조건

- [ ] 대화창이 열려 있을 때 숫자키(1~6, NumLock 켜진 상태의 numpad 포함)로 해당 번호의 선택지를 고를 수 있다
- [ ] 존재하지 않는 번호를 눌러도 아무 일도 일어나지 않는다
- [ ] 키를 누르고 있어도(OS auto-repeat) 최초 1회만 반응한다
- [ ] 대화창이 열려 있지 않을 때는 숫자키가 아무 영향을 주지 않는다
- [ ] 마우스 클릭 선택은 기존과 동일하게 계속 동작한다(회귀 없음)
- [ ] 관련 테스트 통과 + `tsc --noEmit` 통과
