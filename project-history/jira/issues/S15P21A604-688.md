## 설명

게임 파트가 11층 안내데스크를 상호작용 NPC 로 바꿨다(S15P21A604-674, 완료). F 입력 1회를 FE 로 넘긴다.

FE 에는 이용 안내 화면이 이미 있다 — Overlay Bus 키 WORLD_GUIDE, 컴포넌트 features/world/ui/WorldGuideOverlay.tsx, 최초 1회 자동 개방은 WorldGuideLauncher 가 한다. 없는 것은 Unity 이벤트 수신부 하나뿐이다.

범위
- unity/bridge/events.ts 의 이벤트 union 에 WORLD_GUIDE_INTERACT 추가. payload 없음 — 화면이 boothId 도 npcId 도 소비하지 않는다.
- features/interaction/dispatcher.ts 에 case 추가해 기존 WORLD_GUIDE 오버레이를 연다.
- MockInteractionBar 에 항목 추가(개발 트리거).

완료조건
- dispatcher 단위 테스트 1건: 이벤트 수신 시 WORLD_GUIDE 오버레이가 열린다.
- 전체 스위트 유지, tsc 0.
- Unity 송신부 도착 뒤의 실 WebGL 왕복은 이 티켓 범위 밖이다.

팀 공유·논의 정본: GitLab #184

수신부 구현과 실 경로 검증을 마쳤습니다. MR !796 (pipeline 191838 success).

변경은 네 파일입니다. unity/bridge/events.ts 의 상호작용 union 에 WORLD_GUIDE_INTERACT 를 더하고(payload 는 type 하나), features/interaction/dispatcher.ts 에서 openVisitorOverlay('WORLD_GUIDE', {}) 를 호출합니다. 새 화면은 만들지 않았습니다 — 월드 첫 진입에서 WorldGuideLauncher 가 1회 자동으로 여는 그 오버레이를 같은 키로 다시 엽니다. DEV 상호작용 바 항목 1개와 dispatcher 단위 테스트 1건이 함께 들어갑니다.

검증은 로컬 3빌드 통합에서 했습니다. FE dev 5175 · Spring 8080 · World Server festa-world:85ae541f 7777 · WebGL e9f2067e 8001. Unity 송신부(GuideDeskInteractable, S15P21A604-674)가 이미 이 WebGL 빌드에 들어 있어 DEV 상호작용 바를 끄고 실제 F 상호작용으로 확인했습니다.

- F → 이용 안내 오버레이 개방. [InteractionFocusCamera] 초점 시작 → @GuideDesk, [InputBridge] 월드 입력 잠금 (요청 'InteractionFocusCamera', 남은 주인 1)
- ESC → 오버레이 닫힘. [InputBridge] 월드 입력 해제 (요청 'InteractionFocusCamera', 남은 주인 0), [InteractionFocusCamera] 초점 해제
