## 설명

작업 목적

다른 사용자가 Unity 없이 Published 게임 URL에 직접 진입해 플레이할 수 있게 한다.

현재 상태

MR !8에 Runtime loader와 로컬 adapter 후보가 반입됐다. 전역 라우팅과 서버 Published 조회는 아직 활성화되지 않았다.

작업 내용

- Published game route와 로딩·재시도·종료 상태

- 서버 조회 adapter와 version/asset 해석

- 공개 중단·삭제·지원하지 않는 schema version 안내

완료 조건

[ ] 공개 게임을 새 브라우저·비로그인 조건에서 실행한다.

[ ] 미공개/삭제는 앱 오류가 아니라 명확한 안내로 종료한다.

[ ] Preview와 Published가 같은 GameProject 규칙으로 동일한 핵심 결과를 낸다.

[ ] 한 게임 오류가 목록·Booth·다른 게임으로 전파되지 않는다.

선행 작업 / Dependency

BLOCKED BY: S15P21A604-157·178·203·217

후속

S15P21A604-186 및 Unity 없는 Published E2E

테스트 방법

공개·미공개·삭제·손상·미지원 버전 fixture로 직접 URL E2E를 수행한다.
