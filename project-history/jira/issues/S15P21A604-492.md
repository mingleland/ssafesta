## 설명

## 작업 목적

Game Studio에서 TopDown/SideScroll 맵의 "맵 크기 설정"이 에디터 캔버스에는 정상 반영되지만, 플레이 테스트로 들어가면 반영되지 않음. 특히 세로가 긴 맵으로 설정해도 플레이 테스트에서는 항상 가로로 넓은 원래 비율처럼 보임(Notion QA id=29). 원인은 CSS 레이아웃 버그로 확인됨 — 화면 크기 자체는 물론, 실제 이동 가능 범위(충돌 판정)는 이미 정상 반영되어 있고, 순수하게 시각적 비율 표시만 깨지는 문제.

## 작업 내용

- `ReferenceGamePlayer.tsx`의 `.grp-map` 인라인 스타일 수정: `width`를 CSS 고정값(`100%`)이 아니라, 가로 제한(1120px)과 세로 제한(`calc(100vh - 130px)`을 씬 비율로 역산한 값) 중 작은 쪽으로 계산해서 세팅
- 원인: `width: 100%`(고정값) + `height: auto` + `aspect-ratio` + `max-height` 조합에서, 세로가 긴 맵은 계산된 높이가 `max-height`를 넘어 잘리는데, CSS 스펙상 폭이 이미 고정값이면 높이가 잘려도 폭을 다시 계산해 비율을 맞춰주지 않아 비율이 깨짐
- `aspectRatio`, CSS의 `max-width`/`max-height` 값 자체는 유지 — `width` 계산 로직만 교체
- TOP_DOWN/PLATFORMER(SideScroll) 둘 다 같은 렌더 경로를 타므로 함께 수정됨

## 완료 조건

- [ ] 세로가 긴 맵도 플레이 테스트에서 실제 비율대로 세로로 길게 보인다
- [ ] 가로가 긴 맵은 기존처럼 정상적으로 보인다(회귀 없음)
- [ ] 정사각형 맵도 정상적으로 보인다
- [ ] 화면 최대 크기(가로 1120px, 세로는 뷰포트 기준)를 벗어나지 않는다
- [ ] 관련 테스트 통과 + `tsc --noEmit` 통과
