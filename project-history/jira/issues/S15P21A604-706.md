## 설명

BE 가 월드 공용 텍스트 채팅 서버를 develop 에 넣었고(S15P21A604-687, MR !789·!795) 화면이 FE 몫이다. 계약은 specs/002-world-session/contracts/world-chat-api.md, 서술본은 docs/16 8-1.

채팅 전용 STOMP 를 따로 만들지 않는다. shared/realtime 에 공용 transport 를 세우고 채팅이 첫 소비자가 된다. 상담 real 어댑터가 나중에 같은 소켓 위에 올라온다.

완료 조건: 회원이 월드에서 Enter 로 채팅을 열어 보내고 받는다. 100 code point 상한과 3초 쿨다운을 보내기 전에 막는다. 한글 조합 확정 Enter 가 전송으로 오인되지 않는다. 허용 외 SEND/SUBSCRIBE 가 소켓에 나가지 않는다. 게스트는 안내만 받는다.
