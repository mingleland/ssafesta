## 설명

## 작업 목적

2026-09-13 `develop`(`dd03acf5`) 백엔드 전수 리뷰에서 나온 결함을 한 브랜치에서 정리한다. 전체 스위트는 1338건 통과 상태이며, 아래 항목은 전부 **테스트가 없어서 초록이던 자리**다. `S15P21A604-485`(코드리뷰 버그 3건)와 같은 묶음 방식이다.

## 작업 내용

### 에러 처리

- **E1 (상)** `SessionRevocationFilter`가 `response.sendError(401)`을 써서 오류 봉투(`code`·`message`·`requestId`) 밖으로 나간다. 로그아웃 뒤 남은 탭의 Access Token은 **본문이 빈 401**을 받는다 (프로브로 확인: `contentType=null body=[]`). 잘못된 토큰은 정상 봉투를 받으므로 이 필터만 예외다. `ApiErrorWriter`로 바꾼다.
- **E2 (상, 보안)** `StompAuthChannelInterceptor`가 `/topic/booths/{boothId}/consultation` SUBSCRIBE에 부스 구성원 검사를 하지 않는다. WS Token만 있으면 남의 부스 대기열(방문자 닉네임·AI 대화 요약)을 구독할 수 있다. GitLab #133(2026-09-07 BE 회신)에서 "그 부스 직원인지 검사하고 아니면 SUBSCRIBE를 거부한다"고 FE에 약속한 항목이다. `StaffAccessGuard.requireBoothMember`로 게이트를 세운다. 기존 테스트 `consultationContractSubscriptionsPassThrough`가 무조건 통과를 단정하고 있어 함께 뒤집는다.
- **E3 (중)** `ConsultationEventPublisher`는 Javadoc에 "발행 실패가 상담을 되돌리지 않는다"고 적혀 있지만 try/catch가 없다. `convertAndSend`가 던지면 `@Transactional` 서비스가 롤백된다. 커밋 후(`afterCommit`) 발행 + 실패 로그로 바꾼다.
- **E4 (저)** `WorldChatController.onFailure`가 `ApiException`이 아닌 실패를 `CHAT_UNAVAILABLE`로 바꾸면서 로그를 남기지 않는다(T-24 패턴). `log.error` 추가.

### 기능

- **F2 (중)** `CoinReconciliationService.run()`을 main 코드 어디서도 부르지 않는다. spec 003 FR-014·C-05의 정합성 점검이 테스트에서만 돈다. REST는 ADMIN 모델(docs/26 #19) 확정까지 보류가 맞지만, **스케줄 실행 + 불일치 ERROR 로그**는 그 결정에 걸리지 않으므로 스위퍼를 붙인다.
- **F3 (저)** `StaffInvitationService.accept`/`invite`가 read-then-write라 더블클릭 경합에서 `booth_staffs` PK·`ux_staff_invitations_pending` 위반이 **500**으로 나간다. `DataIntegrityViolationException`을 `STAFF_ALREADY_MEMBER`·`STAFF_INVITATION_PENDING`(409)로 번역한다 (`ConsultationService.accept`와 같은 모양).
- **F4 (저)** `ConsultationService.request`가 `requireActiveLease`만 봐서 없는 boothId가 `409 BOOTH_LEASE_EXPIRED`로 답한다. 부스 존재 확인을 앞에 둬 `404 BOOTH_NOT_FOUND`로 가른다.

### 테스트 공백 (결함 아님, 같은 브랜치에서 채움)

- 월드 채팅 Redis 장애 시 fail-closed(`CHAT_UNAVAILABLE`) 경로 미검증
- 탈퇴 삭제 그래프(`AccountDeletionService`)를 상담·직원·초대·방문 행을 가진 회원으로 돌리는 테스트 없음 — 2026-09-13에 그 표들이 셋 늘었다

### 결정 요청으로 분리 (이 티켓에서 구현하지 않음)

- **F1** 방문자가 상담을 종료하면 직원은 `ended` 이벤트를 받지 못한다. 계약(`staff-consultation-api.md`) 177행은 "상대에게 ended", 112·114행 표는 직원 구독에 `ended` 없음 — 문서 자기모순. GitLab #133에 FE 확인 요청.
- 계약 accept 오류표의 `403 BOOTH_FORBIDDEN`은 `ErrorCode`에 없는 이름이다(구현은 `STAFF_MANAGER_FORBIDDEN`). 같은 코멘트에서 정정 통보.
