## 설명

**작업 목적**  
사용자 업로드 고폴리 3D 부스 스캔 모델을 콜리전 안전·텍스처 보존·WebGL 클라이언트 실행 3조건으로 저폴리 변환하는 방법론을 조사·구현·검증한다.

**작업 내용**

- QEM 디시메이션·CGAL KSR·SIGGRAPH Robust Low-Poly Meshing·Voxel+Greedy Mesh 4개 방법론을 동일 모델(44.8만 폴리곤)로 실측 비교
- CGAL KSR: 콜리전은 만족하나 WASM rounding mode 이슈로 클라이언트 실행이 안 되는 것을 확인 — 파이프라인 버그 3건(non-manifold 처리·Y-up/Z-up 축 정렬·지면 오검출 튜닝) 수정 후에도 클라이언트 실행 불가는 해소되지 않음
- SIGGRAPH Robust Meshing: 처리 시간·메모리(20분+/24GB+)가 이 모델 규모엔 비현실적임을 실측으로 확인
- Voxel+Greedy Mesh 방식을 Unity C#으로 포팅해 실제 WebGL 빌드에서 텍스처 포함 전체 파이프라인 동작을 검증 — 0.05~0.2m 구간 41ms~755ms 실측
- Tier 1 텍스처 베이킹(복셀별 색상 샘플링) 구현 및 원본 대비 검증
- 원본 FBX 임베디드 텍스처(8192×8192) 유실 진단 및 Blender 헤드리스 추출로 복구
