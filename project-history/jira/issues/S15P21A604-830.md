## 설명

간헐적으로 월드에서 12슬롯 게시본·world-sessions·catalog 가 전부 401 이 되고 부스가 기본 프레임으로, 간판이 'N번 부스' 로 남는다. 같은 계정으로 다른 곳에서 접속할 때도 같은 증상이 난다.

원인은 하나다. Access Token 에 sid 가 실리고 SessionRevocationFilter 가 매 요청 활성 sid 와 대조하는데, MemberSessionService.issue 가 새 로그인과 refresh 모두에서 sessionId 를 새로 만든다. 즉 refresh 가 성공하는 순간 직전 토큰은 만료를 기다리지 않고 즉시 폐기된다. 그런데 그 토큰을 React 와 Unity 둘이 나눠 쓰고, Unity 는 4xx 를 최종 실패로 처리한다(재시도는 '토큰이 아직 없다' 경로에만 있다).

FE 쪽 두 결함을 고친다.

- 예약 갱신이 없어 401 을 맞아야만 갱신했다. AT 수명이 30분이라 만료 경계에 월드 부팅이 걸리면 Unity 가 12개 요청을 먼저 던지고 전부 죽는다. 만료 2분 전에 미리 갱신한다
- UnityHost 가 session.expiresAt 변화로만 재주입했다. 세션 store 가 토큰 값을 들고 있지 않아 만료 시각이 같은 갱신은 아무에게도 전달되지 않는다. tokenVersion 을 두어 토큰이 바뀌는 모든 경로가 재주입을 깨우게 한다

남는 구간과 파트 밖 사안은 Unity 401 재시도(game)와 sid 회전 유예(BE)로 별도 통보한다.
