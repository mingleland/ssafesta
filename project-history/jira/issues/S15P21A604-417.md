## 설명

[증상]
Jenkins 가 쓰는 CI 진입점 Festa.EditorTools.CiBuild.Build (-festaTarget webgl) 로 뽑은 Builds/webgl/ 에 manifest.json 이 없다. 2026-09-04 실제 빌드 산출물에서 확인 — Build/, TemplateData/, index.html 만 있다.

[예상 결과]
FE festa-frontend/src/unity/host/resolver.ts 는 ${VITE_UNITY_BUILD_BASE}/manifest.json 을 읽어 loaderUrl/dataUrl/frameworkUrl/codeUrl 4종을 얻는다 (GitLab #60 확정 계약). 파일이 없으므로 "Unity manifest.json을 불러오지 못했습니다 (404)" 로 월드 진입 자체가 실패한다. 빌드는 성공으로 보고되므로 CI 가 살아나는 순간 "배포했는데 안 열린다" 가 된다.

[원인]
manifest.json 을 쓰는 FestaWebBuilder.WriteManifest(outDir) 는 FestaWebBuilder(Builds/web)와 FestaReleaseBuilder(Builds/web-release) 만 부른다. CiBuild.BuildWeb(Builds/webgl) 은 부르지 않는다. #60 당시(2026-08-26) 구현은 메뉴 빌더 기준이었고 CiBuild 는 그 뒤에 추가됐다.

[작업]
CiBuild.BuildWeb 에서 RunBuild 성공 후 FestaWebBuilder.WriteManifest(WebOutDir) 를 부르고, manifest.json 부재를 산출물 검사(index.html·Build·TemplateData) 목록에 더해 없으면 Fail 로 빌드를 실패시킨다 — 조용히 초록으로 넘어가지 않게.

[완료 조건]
- CiBuild -festaTarget webgl 산출물에 manifest.json 이 있고 4종 URL 이 Build/ 의 실제 파일과 일치한다
- manifest 생성 실패 시 빌드가 0 이 아닌 코드로 종료한다

[관련]
GitLab #60(manifest 계약), Jira -82(WebGL 정적 서빙), -277(WebGL 산출물 전달). 월요일(09-08) 수동 배포 선행.
