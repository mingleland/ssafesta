검증 시 전제 3가지:

- 서명 키 = 전용 `CONNECTION_TOKEN_SECRET` (HS256). `JWT_SECRET` 이 아니다. `iss ssafesta-backend` / `aud ssafesta-world` 도 검증 대상.
- `jti` 소비 원장 = 게임 서버 소유 (`/var/lib/festa-world/used-grants.log`, infra-003 FR-014). BE 는 발급만 하고 저장소가 없다. 근거는 S15P21A604-170.
- `avatarCode` claim 크기 실측 요청 = [#99](https://lab.ssafy.com/s15-metaverse-game-sub1/S15P21A604/-/work_items/99) §3. 상한 3800자라 토큰이 5KB 까지 커질 수 있다.

C-01 (검증 방식) 은 이미 확정 상태다 — 헌법 14조 및 spec 002 Clarifications 표의 "서명 자체 검증 + 사용 토큰 식별자 기록". 완료 조건 "방식 결정이 spec 에 기록됨" 은 충족된 것으로 본다.
