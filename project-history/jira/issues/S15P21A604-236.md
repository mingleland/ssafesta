## 2026-08-26 상태 — 아틀라스 보류 결정 + 측정 수치 일부 철회

**아틀라스(셰이더 통합 + 텍스처 아틀라스)는 착수하지 않기로 했다.**
WebGL 40기 실측에서 드로우콜 −32%(990→676, 스킨메시 결합 효과)가 프레임을 −7.7%(38.8→35.8 ms)만 줄였다 → 드로우콜 1개당 약 0.01 ms. 아틀라스가 완벽히 성공해도 상한이 약 +3.7 FPS인데, 대가는 옷 마스크 16분의 1 해상도 + 셰이더·팔레트 전면 재작성이다. 근거: `docs/KHS/28_최적화_기법_정리.md` §15.

**완료된 것**

- 아바타 텍스처 1024 캡 — 카탈로그 런타임 메모리 490→194 MB (커밋 4a92ed9)
- 거리별 애니메이터 갱신 LOD(`AvatarAnimationLod`) 구현 + 빌드 내 F9 토글 (커밋 73112b1)

**철회한 것 (T-211)**
에디터에서 잰 "애니메이터 LOD −17%"와 비용 분해(스키닝 44/애니 36/드로우콜 20)는 워밍업 드리프트 오염으로 **근거 없음 처리**했다. 조건을 번갈아 재니 차이가 노이즈(0.09 ms)였다. WebGL에서 F9 ABAB 재측정 전까지 LOD 효과를 주장하지 않는다.

**주의** — 스킨메시 결합은 WebGL에서 렌더되지 않는 문제로 WebGL에 한해 껐다(T-214, 후속 -258). WebGL 드로우콜 수치는 다음 실측에서 갱신 필요.

### 강형순 · 2026-08-30 23:57 KST

MR !129 로 develop 반영. 완료 조건 3항목 전부 근거를 붙였다. 전문: `docs/KHS/measurements/avatar-cost-ab-30.md`

**① 30기 프레임타임 전/후** — **7.37 → 6.91 ms (−0.46 ms, 6.2%)**, 렌더러 338 → 218(아바타당 11 → 7, `-258` 값 재현). 회차 간 흔들림 ±0.11 / ±0.01.

**다만 이 숫자를 "3종 합쳐 6.2%" 로 읽으면 안 된다.** 손잡이를 하나씩 켜서 다시 쟀더니 값을 내는 건 병합뿐이었다.

|  | 회차 내 `전` 대비 |
|---|---|
| 병합만 | −0.73 / −0.38 / −1.23 → **3회차 모두 음수** |
| LOD만 | +0.26 / −0.71 / +2.80 |
| 컬링만 | +3.23 / −0.82 / +2.62 |

이유를 측정 중 좌표로 확인했다 — 30기 전부 카메라에서 **58~103 unit**, 절두체 안 210/210, `isVisible` 210/210. 그런데 `AvatarAnimationLod` 의 근거리 경계는 **220 unit** 이라 전원이 band 0(애니메이터 그대로 켬)이고, `CullUpdateTransforms` 는 화면 밖을 막는 장치인데 막을 것이 없다. **즉 완료 조건이 지정한 "30기 동시 표시" 는 3종 중 2종이 정의상 작동하지 않는 시나리오다.** −0.46 ms 는 사실상 병합 단독의 몫이다.

**② 외형 조합별 시각 회귀 없음** — 스크린샷으로는 판정할 수 없었다. `AvatarStressSpawner` 가 색만 흔들고 아이템 조합은 기본값 하나라 조합을 검사하지 못하고, 사람 눈은 폴리곤 한 덩이가 빠진 걸 못 잡는다(T-223·T-214 둘 다 유니티가 에러를 안 내서 눈으로만 발견됐다). 대신 불변식을 검사하는 도구를 만들었다(`AvatarMergeIntegrity`, F12) — `재질 이름 → 정점 수 합` 이 병합 ON/OFF 에서 같아야 한다. 카탈로그 전 아이템을 한 번씩 입혀 **158개 조합 전부 일치**.

**③ 근거리 애니메이션 품질 저하 없음** — 코드상 band 0(≤220 unit)은 `Animator.enabled` 를 건드리지 않고 본 가중치도 원복한다(Unity 기본 경로 그대로). 실측으로도 30기 전원이 band 0 인 조건에서 `LOD만` 이 `전` 과 구분되지 않았다.

**남는 것 (닫히면서 묻히면 안 되는 것):**

- **WebGL 실측이 없다.** 전부 에디터 값이라 배포 성능 근거로 쓸 수 없다.
- **먼 거리·화면 밖 시나리오를 안 쟀다.** LOD·컬링의 값은 거기서 나오는데 이번 조건이 그 상황을 안 만든다. 40인 부하 테스트(별도 머신 필요) 때 같이 재는 게 맞다.
