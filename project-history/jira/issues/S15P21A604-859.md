## 설명

GitLab #234 (계약 #233). ESC 메뉴에 미션 진입점 한 칸 + 일일 미션 패널.

- GET /api/v1/missions/daily 를 그린다. status LOCKED / CLAIMABLE / CLAIMED.
- 문구는 서버가 내려보내지 않는다 — missionId 9종을 FE 가 매핑한다.
- POST /api/v1/missions/daily/{missionId}/claims. 오류 4종: 400 NOT_COMPLETED / 409 ALREADY_CLAIMED / 409 DAILY_CAP_REACHED / 403 MEMBER_ONLY. 앞의 둘은 재조회가 정답.
- 상단 earnedToday / dailyCap 한 줄. 보상액·상한은 응답 값을 그대로 쓴다.
- 새 Unity 계약을 만들지 않는다.
