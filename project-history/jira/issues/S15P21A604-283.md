## 설명

## 배경 (spec 002-world-session FR-013·014, 폐기된 018 에서 이전)

접속 후 월드가 그려지기까지의 대기를 **11층에 붙인 엘리베이터 내부(입장 게이트)**가 가린다. 흰 화면·빈 월드를 보여주지 않는다. 엘리베이터 모델링은 -264 로 완료 — 이 이슈는 **연출·로직**이다.

## 요구사항

- FR-013: 월드 준비 진행 상황 인지 — 게이트 안에서 진행 표시(층수 연출 등)
- FR-014: **갇힘 방지** — 게이트는 밀폐 공간이므로 준비 실패 시 **Unity 30초 타임아웃 후 강제 개방** 필수
- WebGL 로드 자체가 실패한 경우는 React 오버레이의 독립 타임아웃(잠정 60초, Unity 강제 개방보다 길게)이 담당 — 계약: `window.FestaUnity.onWorldGateReady()` (GitHub Issue #31)

## 할 일

- 접속 흐름(로비 → 월드 씬 로드 → NGO 접속 → 스폰)을 게이트 내부 시점으로 감싸기
- 준비 완료 신호에서 문 열림 연출 → 플레이어 해방 + `onWorldGateReady()` 호출
- 30초 타임아웃 강제 개방 + 에러 상태 노출 (조용한 폴백 금지 — T-24 원칙)

관련: -264(모델링 완료), -259(스폰 실수신 — 게이트 해방 시점과 자연스럽게 연계), FE 오버레이 타임아웃(계약 #31)

**① 11층 엘리베이터 문 닫힘**
처음엔 열어 뒀는데 11층에 문 열린 엘리베이터가 방치된다. 개방 → 2.5초 유지(하차) → 닫힘 → 자기 파괴 로 확장. 카메라·조명·표시기는 문이 다 열린 순간 걷어(플레이어가 월드를 봄) 컴포넌트만 남아 문을 닫는다. FR-014(갇힘 방지)는 화면을 문이 다 열린 시점에 넘기므로 침해하지 않는다.

**② 숫자 중앙 정렬** (-289 후속)
자릿수마다 컨테이너를 두어 한 자리 숫자를 가운데로 모은다. 7세그먼트 `1`은 오른쪽 세로획만 켜져 칸 오른쪽에 붙으므로 칸 중앙으로 당겼다. 측정 어긋남: 5·8·11 = 0.00, 10 = 0.83(글리프 폭 차이).

**③ 시작층 5**
1층부터 세면 숫자가 정신없이 굴러간다. 5 시작, 단계별 6→8→10→11. 상승 속도도 3→2.5(기본) / 9→6(도착).

검증: 에디터 플레이에서 개방→유지→닫힘 완주 후 게이트 자기 파괴 확인. 손대지 않은 Elevator_01·03 과 문 상대 위치가 동일 = 정확히 닫힘.
