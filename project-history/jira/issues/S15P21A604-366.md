## 설명

h3. 작업 목적
SSAFY OAuth 도입 확정(BE S15P21A604-357 예정)에 대비해 FE 로그인 provider를 레지스트리로 추상화하고, SSAFY를 not-configured 슬롯으로 선난다. BE enum 추가 시 availability 전환만으로 활성화되는 구조가 목표.

h3. 작업 내용
* entities/auth/providers.ts 신설 — provider registry (google·kakao·guest·ssafy), startLogin 위임
* entities/auth/types.ts — AuthProviderId·ProviderAvailability 타입 추가
* pages/login/LoginPage.tsx — 하드코딩 버튼을 registry 기반 렌더로 전환 (기존 google/kakao/guest 동작 등가)
* 테스트 — registry 4종·not_configured no-op·available 위임

h3. 완료 조건
* [ ] 기존 Google/Kakao/Guest 로그인 경로 무변경 (동작 등가)
* [ ] SSAFY 버튼은 not_configured — 실제 OAuth 호출 없음
* [ ] OAuth URL·redirect·DTO 발명 없음 — BE 계약 확정 전 금지 유지

h3. 선행 작업 / Dependency
* S15P21A604-357 (BE SSAFY provider) — available 전환은 그 이후 별건

h3. 테스트 방법
# npm test — auth 테스트 + 신규 providers 테스트
# VITE_USE_MOCK=true 로그인 화면에서 3사 동작 확인
