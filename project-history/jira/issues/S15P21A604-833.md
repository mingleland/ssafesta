## 설명

월드 화면의 상시 HUD 를 줄이고 채팅 진입을 Enter 하나로 모은다.

- 조작 안내 상시 카드와 우하단 이용 안내 버튼 제거 — 조작 목록은 ESC 메뉴 오버레이가 그린다
- 우상단을 상담·전체화면 가로 배치로 정리하고 전체화면 버튼을 사각 컨트롤로 통일
- DEV 상호작용 바를 우하단 토글 리스트로 접는다 (F 키캡·라벨 제거)
- 채팅 런처 버튼 삭제, 입력창 상시 노출. 빈 입력 Enter 는 닫기, ESC 는 채팅과 무관
- 월드 입장 시 자동 전체화면 진입 폐기 — 진입 경로는 HUD 토글 하나
- 09-16 회차 작업일지 반영 (-826·-827·-829·-830 포함)
