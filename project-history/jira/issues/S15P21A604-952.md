## 설명

브랜드 포인터(S15P21A604-835)와 Game Studio 예외(S15P21A604-854)에 이어, 누르는 동안의 커서와 글자 입력칸 커서를 더한다.

- 좌클릭 동안에만 누름 커서로 바꾼다. CSS :active 는 우클릭·휠 클릭에도 걸려 왼쪽만 가리지 못하므로 판정은 main.tsx 가 button === 0 으로 하고, 그림은 index.css 가 body.is-pressing 으로 받는다.
- 떼는 것은 window 의 mouseup·blur 에서 받는다. 누른 채 창 밖에서 떼면 커서가 눌린 모양으로 굳는다.
- 입력칸은 브랜드 I빔을 주고 못 읽는 환경은 text 로 내려간다.
- Unity 캔버스는 id 선택자라 누름 규칙이 덮지 못해 같은 id 에 클래스를 더해 한 번 더 적는다.
