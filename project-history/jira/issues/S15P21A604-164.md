## 설명

### 작업 목적

외부 WSS 용량 검증을 반복 가능한 방식으로 실행할 부하 클라이언트와 측정 시나리오를 준비한다.

### 작업 내용

- 1→10→20→30→40명 단계 실행 방법 정의
- 회원/게스트 토큰·접속 수명과 재연결 조건 반영
- 구간별 10분 실행, 서버 CPU/메모리/네트워크/연결 수 수집
- 실패·중단 기준과 결과 기록 템플릿 준비

### 완료 조건

- 동일 입력으로 부하 시나리오를 재실행할 수 있다.
- 각 구간의 접속 성공률·지연·자원 지표가 수집된다.
- 테스트 계정·토큰·Secret이 저장소나 로그에 노출되지 않는다.

### 선행 작업

외부 WSS P0 종단 접속 성공

### 참고

- `specs/infra-003-unity-server-runtime` P1

### 테스트 방법

1명 smoke 실행 후 10명 구간을 10분 수행해 지표와 종료 정리를 검증한다.

### 완료 (2026-08-25)

부하 클라이언트와 시나리오가 모두 갖춰졌고 실제 실행까지 마쳤다.

- `LoadTestBot` — `-bot` 인자로 켜지는 봇. ConnectionManager 경유(승인 경로 동일), *PlayerMovement 합성 입력*으로 걷기/달리기 전환까지 생성해 AnimState 트래픽을 포함시킨다
- `FestaBotBuilder` — 봇 빌드(일반 플레이어 빌드·main 씬·빌드 후 타깃 복원)
- `Tools/loadtest/run-bots.ps1` — N기 실행/일괄 종료·봇별 로그·메모리 출력
- 실행 결과: 봇 5·12기 접속 및 대역폭 실측 완료 (docs/KHS/conference/09 §3-4)
- 한계 기록: 봇 1기당 약 400 MB 라 이 PC 는 12기가 상한. 30~40기 직접 실측은 별도 장비 필요
