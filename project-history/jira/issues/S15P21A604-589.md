## 설명

## 작업 목적

Booth Studio 좌측 '빠른 시작' 의 템플릿 버튼이 기존 배치를 지우지 않고 **그 위에 계속 쌓는다**. 같은 템플릿을 두 번 누르면 오브젝트가 두 벌이 되고, 상한(`maxObjects`)에 걸리면 조용히 중간에서 끊긴다. '빈 부스' 템플릿은 `objects: []` 라 눌러도 아무 일이 일어나지 않는다 — 초기화 버튼처럼 보이는 no-op 다. (2026-09-10 플레이 중 실측)

되돌릴 수단(Undo)이 아직 없어 사용자가 스스로 복구할 수 없다.

## 작업 내용

`features/studio/model/editorReducer.ts` 에 배치 전체 교체 액션 `REPLACE_OBJECTS` 를 더한다. 상한·검증·dirty 처리가 이미 그 경로에 있다.

`pages/studio/StudioPage.tsx`
- `handleApplyTemplate` 을 누적(ADD_OBJECT 반복)에서 **교체**로 바꾼다. 템플릿 좌표는 서로 겹치지 않으므로(boothTemplates 주석) 빈 자리 탐색이 필요 없다
- 기존 배치가 비어 있지 않으면 덮어쓰기 확인을 한 번 세운다 — Undo 가 없는 지금은 이 확인이 유일한 안전망이다
- 상한 초과로 잘린 개수를 toast 로 알린다. 화면에 없는 자산을 사용자가 찾게 만들지 않는다
- 확인 다이얼로그는 PublishDialog 와 같은 자리(Shell overlay 슬롯)·같은 마크업(`.studio-dialog`)을 쓴다

## 완료 조건

1. 같은 템플릿을 두 번 적용해도 결과가 한 번 적용한 것과 같다(멱등)
2. 다른 템플릿으로 바꾸면 앞의 배치가 남지 않는다
3. '빈 부스'가 실제로 배치를 비운다
4. 기존 배치가 있으면 확인을 거치고, 취소하면 배치가 그대로다
5. 상한 초과 시 잘린 개수를 사용자에게 알린다
6. 교체 뒤 선택은 새 배치 안에 있다 — Inspector 가 사라진 오브젝트를 가리키지 않는다
7. unit test / tsc 0 / vitest 전체 green / oxlint 신규 경고 0
