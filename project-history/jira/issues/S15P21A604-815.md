## 설명

로그인 화면 하단의 축제 안내·이벤트·고객센터·개인정보처리방침·이용약관 다섯 항목이 전부 갈 곳이 없다. 레퍼런스(login.png) 표시를 맞추려고 span 으로 세워 둔 것인데, 눌러도 아무 일이 없는 것을 사용자가 먼저 발견하게 두는 것보다 안 보이는 편이 낫다.

변경
- pages/login/LoginPage.tsx 의 footer 블록과 footerLinks·footerIcon 을 주석 처리한다. 지우지 않는 이유는 레퍼런스 대조 근거이고, 대상이 생기면 span 을 a 로 바꿔 그대로 되살리기 때문이다.
- CSS(.login-footer*)는 남겨 둔다.
- 구조 회귀 테스트 2건(좌측 3항목 아이콘·우측 약관 2항목)을 '푸터를 그리지 않는다' 하나로 뒤집는다.

완료 조건
- 로그인 화면에 다섯 문구가 하나도 없다
- vitest / tsc / build green
