## 설명

최신 demo(2026-09-14 16:10 실측)에서 월드 진입 직후 채팅을 열면 입력창 왼쪽이 좌하단 조작 안내 패널에 덮인다. 조작 안내는 진입 직후 기본으로 떠 있어 첫 사용자가 바로 만나는 구간이다.

수정 대상은 worldChat 오버레이의 레이아웃·배치뿐이다. 조작 안내 패널(S15P21A604-592 로 좌측 하단에 놓인 것)은 건드리지 않는다.

깨지면 안 되는 기존 계약: 채팅 패널은 .world-hud 바깥 레이어여야 하고(HUD 의 onMouseDown preventDefault 가 입력창 focus 를 막는다, S15P21A604-648), Enter 판정자는 WorldPage 한 곳이며, 조합 중 Enter(isComposing·keyCode 229)와 Shift+Enter 는 무동작이고, Esc 는 채팅을 먼저 닫고 canvas 로 focus 를 돌려준다. 이번 실측에서 이 넷은 정상 동작을 확인했다.

완료조건: 진입 직후 기본 HUD 상태에서 채팅 입력창 전체가 가리지 않고 보이며, 위 Enter·IME·Esc·focus 복귀 계약이 그대로 통과한다.

범위 밖: realtime 연결 끊김은 원인이 달라 별도 티켓이다. 두 건을 합치지 않는다.
