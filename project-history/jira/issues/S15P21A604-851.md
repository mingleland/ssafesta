## 설명

GitLab #203 게임 파트 계약 확정(2026-09-17). Unity 수신부는 develop f7800b79 에 이미 있고 FE 송신부만 비어 있다.

worldChat.ts 의 pushMessage 에서 서버가 /topic/world/chat 으로 방송한 객체를 그대로 SendMessage('WorldChatBridge','ReceiveChat', JSON) 로 넘긴다. payload 를 새로 만들지 않는다 — durationMs 를 넣지 않는다(표시 시간은 월드가 글자 수로 정한다: 3초 + 글자×0.09초, 3~7초 클램프).

JOIN 알림은 보내지 않는다(말풍선 대상이 아니다). 인스턴스가 없으면 조용히 건너뛴다(boothLayoutBridge 와 같은 관용구).
