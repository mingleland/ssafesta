## 설명

### 작업 목적

개발·시연 환경을 재현 가능하게 분리하고 데이터·정적 자산·공개 진입점을 안전하게 운영한다.

### 작업 내용

- dev/demo compose·network·volume·Secret 격리
- PostgreSQL·Redis·R2·MinIO와 외부 백업
- Nginx·DNS·TLS·Security Group·WebGL 정적 서빙
- 수동 fallback·reconcile과 최종 환경 동결

### 완료 조건

- dev와 demo의 데이터·네트워크·설정이 교차 오염되지 않는다.
- 공개 경로는 HTTPS/WSS로 동작하고 내부 포트는 차단된다.
- 저장소 장애와 DB 손실에서 문서화된 복구가 가능하다.
- 배포와 롤백 후 서비스 버전과 핵심 여정을 검증할 수 있다.

### 선행 작업

EC2·도메인·Cloudflare·R2 접근 권한

### 참고

- `specs/infra-002-runtime-environments`

### 테스트 방법

환경별 배포·격리·정적 로딩·TLS·백업/복구·fallback 시나리오를 실행한다.
