## 설명

h3. 배경

사용자 피드백(2026-09-06): "UI 글씨체가 이상하다". 기본 글꼴이 맑은고딕 Light 라 게임 UI 다운 맛이 없었다. 사용자가 글꼴 download 를 승인.

h3. 작업

* Jua-Regular.ttf(Google Fonts, OFL), NotoSansKR-Bold.otf(notofonts KR subset, OFL) 를 Resources/Fonts 에 반입, license 파일 동봉.
* TMP Dynamic SDF asset 2종 생성(Jua_SDF, NotoSansKRBold_SDF — Malgun 과 같은 1024/90pt/SDFAA/Dynamic).
* FestaUiKit: Font()=Noto Bold(본문), DisplayFont()=Jua(Title, TitleBanner, Chip, PillButton). Bold face 에 TMP fake bold 를 얹지 않도록 Bold flag 제거. close glyph ✕ -> ×.
* WorldNameplate -> Noto Bold, InteractPromptUI / PlayerEmoteController(IMGUI) -> Jua TTF.
* 로비(캐릭터 커스터마이징)는 사용자 지시대로 그대로(Malgun 유지).

h3. 검증

editor Host Play: slot machine HUD, popup 에서 두 글꼴 렌더, 한글 glyph 정상, missing glyph 없음(2x screenshot). WebGL 은 Malgun 과 같은 Dynamic SDF 경로라 다음 batch build 에서 확인(build-verify-checklist #9).
