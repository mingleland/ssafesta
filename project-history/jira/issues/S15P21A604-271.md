## 설명

### 증상

도메인 루트(`/`)로 들어오면 React Router 기본 ErrorBoundary 가 영어 404 화면을 그린다.

```text
No route matches URL "/"
Matched leaf route at location "/" does not have an element or Component.
```

주소창에 도메인만 입력한 첫 방문자가 보게 되는 화면이다.

### 원인

`festa-frontend/src/app/router/index.tsx` 의 `createBrowserRouter` 에 `path: '/'` 항목이 없다. 정의된 것은 `/login` · `/auth/callback` · `/app/*` 뿐이다.

### 처리 방향

`/` 를 `/app/home` 으로 replace redirect 한다. 목적지를 새로 정하는 것이 아니라 기존 가드에 위임하는 것이다 — `/app/home` 은 `RequireAuth level="guest-allowed"` 라 비로그인 방문자는 `/login` 으로 보내지고 returnTo 도 저장된다. `/` 를 곧바로 `/login` 으로 보내면 이미 로그인한 사용자가 로그인 화면을 한 번 보고 튕기게 된다.

### 완료 조건

- [ ] `/` 직접 진입 시 영어 404 가 나오지 않는다
- [ ] 비로그인 진입 → `/login`
- [ ] 게스트·회원 진입 → `/app/home`
- [ ] 회귀 테스트 추가

### 참고

- 2026-08-27 `-113` Authoring·Maker 스모크 테스트(`docs/PJW/verify/113-authoring-maker-smoke.md`)도 이 404 를 관측하고 "라우터 미정의로 인한 기존 동작, 신규 아님"으로 넘겼다. 기존 동작인 것은 맞지만 정상은 아니다.
