## 설명

h3. 작업 목적
LAPTOP 오버레이가 이벤트 payload의 url에 의존하나 Unity는 url을 보내지 않는다(016 확정 계약: URL 정본은 GET /booths/{id} homepageUrl, #97) — 현재 항상 "홈페이지 미준비"로 떨어지는 FE 배선 결함을 수정하고, 소유자 등록(PUT /homepage) 기능층을 구축한다.

h3. 작업 내용
* entities/booth: BoothDetail에 homepageUrl 추가(BE 응답 전사), homepage PUT real+mock
* features/overlay: LAPTOP 상호작용 시 booth 조회로 URL 확보 — loading/no_url/invalid/valid 상태
* features/studio: 홈페이지 등록 폼 상태 모델 (값 검증·저장·삭제(null)·오류)
* 테스트 — 배선 전환·등록/삭제·FIELD_INVALID 표시

h3. 완료 조건
* [ ] 이벤트 url 미의존 — booth 조회가 URL 정본 (Unity 수정 불요)
* [ ] PUT body는 키 필수·명시적 null=삭제 (BE PresenceField 준수)
* [ ] UI 폼 presentation 미포함 (UI Track)

h3. 참고
* BE 실물: BoothHomepageController·BoothHomepageService (develop 완결)
* 관련: S15P21A604-63(E2E 완료)·roleD ② 실측
