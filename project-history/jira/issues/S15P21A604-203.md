## 설명

작업 목적

Published 게임의 직접 웹 플레이를 위해 공개 상태별 조회·익명 접근 경계를 구현한다.

제품 경계

이 API는 Unity 없이 동작해야 하며 Booth Portal은 별도 소비자다.

작업 내용

- 승인된 Published 상태 모델에 따른 조회 API
- Owner·로그인 사용자·익명 사용자 가시성 매트릭스
- 현재 Published version만 반환하고 Draft는 노출하지 않음

완료 조건

[x] 공개·비공개·삭제/중단 상태의 조회 결과가 계약 매트릭스와 일치한다.

[x] 익명 공개 조회는 가능하고 Draft·미공개 문서는 노출되지 않는다.

[x] 캐시가 공개 상태 변경 뒤 오래된 문서를 제공하지 않는다.
