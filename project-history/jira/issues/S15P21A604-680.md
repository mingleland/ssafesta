## 설명

### 작업 목적

세 티켓의 착수를 막고 있는 미결 항목들이 `docs/26_팀_결정_필요사항.md` 에 등재되어 있지 않다. 헌법 30조는 구현자가 임의로 확정하지 말고 docs/26 에 올려 팀 결정을 받으라고 요구하는데, 티켓 본문에만 "미정" 으로 적혀 있어 보드에서도 결정 문서에서도 보이지 않는다. 2026-09-13 스프린트 점검에서 확인했다.

등재만 하는 작업이다. 결정 자체는 리드·기획 몫이며 이 티켓에서 값을 정하지 않는다.

### 등록할 항목 4건

**1. AI 상담 수익 정산 시점 — 즉시인가 일괄인가** (spec 012 C-04)

- 차단 중: S15P21A604-634
- 문서상 추천안은 즉시. docs/26 에 행 자체가 없다
- 결정에 따라 원장 기록 시점과 운영자 수익 조회의 의미가 갈린다

**2. AI 상담 과금 시점과 단위 — 대화 시작 단위인가 메시지 단위인가**

- 차단 중: S15P21A604-634
- spec 008 과 spec 012 어디에도 문면이 없다
- 단위가 정해지지 않으면 멱등 키의 범위(대화 단위 vs 메시지 단위)도 정할 수 없다

**3. Lease 만료 사전 알림의 전달 방식 — 폴링인가 푸시인가** (spec 004 D07)

- 차단 중: S15P21A604-151
- D07 의 "남은 시간 표시" 는 이미 구현되어 있다 — `BoothLease.remainingSecondsAt()` 이 `BoothQueryService`(2곳) · `AiBoothAccessService`(3곳) · `BoothSlotController`(1곳) 응답에 실려 있다. 남은 작업은 "만료 임박 알림" 하나이고, 전달 방식이 정해지지 않아 막혀 있다
- 참고: 월드 heartbeat 는 Unity 가 아니라 React 호스트가 보내는 구조다(2026-09-07 결정). 알림도 같은 경로를 쓸 수 있는지 함께 본다

**4. admin 권한 모델** (spec 001 Deferred)

- 차단 중: S15P21A604-165
- `AccountStatusHistory` 엔티티와 리포지토리는 이미 있다. 정지·해제 API 를 붙이려면 누가 admin 인지를 먼저 정해야 한다
- 현재 권한 판정은 부스 단위(`BoothAccessGuard`)뿐이고 전역 관리자 개념이 없다

### 등재하지 않는 것

플랫폼 수수료율은 docs/26 ② 표에 행이 이미 있고 결정값만 빈칸이다. 이번에는 상단 결정 요청 섹션으로 승격하지 않고 현행 유지한다(2026-09-13 판단). 따라서 S15P21A604-634 는 위 1·2 가 확정되어도 수수료율 때문에 계속 막혀 있다.
