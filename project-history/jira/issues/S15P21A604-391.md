## 설명

# 작업 목적

- 다른 Scene에 갔다가 돌아오면 선택했던 오브젝트/레이어, 캔버스 스크롤 위치가 매번  
   초기화돼 어디까지 작업했는지 다시 찾아야 하는 불편함(QA id 9)을 해결한다. Scene별로  
   마지막 편집 상태를 기억했다가 돌아왔을 때 복원한다.



# 작업 내용

- `GameStudioShell.tsx`의 Scene 목록 클릭 핸들러 — 지금은 Scene을 바꿀 때마다  
   `selectedObjectId`/`selectedObjectIds`/`placementPreset`/`tileBrush`/`selectedLayerId`를  
   무조건 초기화. Scene id별로 마지막 선택 상태를 기억하는 state를 추가하고, 클릭 시  
   무조건 초기화 대신 "그 Scene에 기억된 값이 있으면 복원, 없으면 기본값"으로 변경
- `TopDownCanvas.tsx`가 렌더링하는 `.gss-canvas-scroll`의 캔버스 팬(스크롤) 위치를  
   Scene id별로 기억했다가, 해당 Scene으로 돌아왔을 때 `scrollLeft`/`scrollTop`을  
   복원(현재는 React state가 아니라 DOM 네이티브 스크롤값이라 별도 저장 로직 필요)
- 줌(zoom)은 현재도 Scene별이 아니라 에디터 전체가 공유하는 단일 값이라 Scene을  
   바꿔도 초기화되지 않음 — **이번 작업에서는 전역 공유 상태를 그대로 유지**하고  
   손대지 않음(범위 확정)
- 상태 기억은 현재 세션(탭이 열려 있는 동안)에서만 유지 — localStorage 등 영속화는  
   이번 범위에서 제외
- Scene 불러오기/복구/템플릿 적용처럼 "새 컨텍스트로 진입"하는 다른 흐름은 기존대로  
   선택 상태를 초기화(이번 변경은 Scene 목록 클릭 전환에만 적용)



# 완료 조건

- [ ] Scene A에서 오브젝트를 선택하고 Scene B로 이동했다가 Scene A로 돌아오면, 같은 오브젝트가 선택된 상태로 복원된다
- [ ] Scene A에서 타일 레이어를 선택하고 다른 Scene에 갔다 왔을 때 레이어 선택이 복원된다
- [ ] Scene A의 캔버스를 팬(스크롤)한 뒤 다른 Scene에 갔다 왔을 때 스크롤 위치가 복원된다
- [ ] 처음 방문하는 Scene(기억된 상태 없음)은 오류 없이 기본 상태로 보인다
- [ ] Scene 삭제/복제 직후에는 기존대로 선택이 초기화된다(회귀 없음)
- [ ] 새로고침하면 기억된 상태가 초기화된다(세션 내 유지 범위 밖)
- [ ] 줌 값은 이번 변경으로 동작이 바뀌지 않는다(전역 공유 유지)

# 선행 작업 / Dependency

- 없음



# 테스트 방법

1. Scene A에서 오브젝트를 선택한 뒤 Scene B로 이동, 다시 Scene A로 돌아와서 선택이  
   복원되는지 확인한다
2. Scene A에서 타일 레이어를 선택한 뒤 다른 Scene에 갔다 와서 레이어 선택이 복원되는지  
   확인한다
3. Scene A의 캔버스를 드래그로 팬한 뒤 다른 Scene(TOP_DOWN/PLATFORMER/DIALOGUE 섞어서)에  
   갔다 와서 스크롤 위치가 복원되는지 확인한다
4. 처음 방문하는 Scene이 오류 없이 기본 상태로 보이는지 확인한다
5. Scene을 삭제/복제한 직후 선택이 초기화되는지 확인한다(불러오기/복구/템플릿 적용 등  
   다른 흐름도 함께 확인)
6. 새로고침 후 기억된 상태가 초기화되는지 확인한다
