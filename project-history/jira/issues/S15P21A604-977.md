## 설명

배경
demo 첫 로딩이 100초 이상 걸린다. 한국 접속이 Cloudflare SJC 엣지로 라우팅돼 실효 0.5 MB/s 다(GitLab #268). 경로 개선은 인프라가 맡고 이 이슈는 바이트를 줄인다.

실측
빌드 포함 텍스처는 467개 562.9 MB(활성 씬 의존성 + Resources 전량). 그중 Assets/_Project 무압축(RGB24/RGBA32)이 100개 134.4 MB.
- Arcade/MegaPackBreakout/Brick.png 1920x1920 RGB24 24.61 MB
- Arcade/MegaPackNeonRacer/Road.png 2000x500 RGB24 6.68 MB
- Arcade/TrickyCat/Sprites/** 512x512 RGBA32 다수, 각 2.00 MB

수정
대상 100개에 Compressed + Crunch(품질 50) 적용, Brick 512 / Road 1024 상한. 미니게임이 sprite.bounds 로 스케일을 정규화하므로 화면 크기는 불변.

결과
에디터 기준 134.4 MB -> 22.3 MB (112.2 MB 감소). 임포트·컴파일 오류 0건. 실제 .data 감소폭은 빌드로 확인.

관련: GitLab #267, GitLab #268
