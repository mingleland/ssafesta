## 설명

### 작업 목적

Unity 외부 WSS 서비스가 안정적으로 수용하는 동시 접속 상한을 재현 가능한 수치로 확정한다.

### 작업 내용

- 1→10→20→30→40명 순서로 단계 상승
- 각 구간 10분 유지하며 접속 성공률·지연·서버 자원·연결 수 기록
- 실패 시 직전 성공 구간으로 돌아가 2회 재현
- 외형 생성/해제와 종료 정리 포함
- 병목·안전 운영 상한·다음 조치 문서화

### 완료 조건

- 모든 시도와 실패 지점의 원시 지표가 남는다.
- 최고 성공 구간이 동일 조건에서 2회 성공한다.
- 안전 운영 상한과 병목 근거를 제시한다.
- 발표 자료에서 인용 가능한 결과 문서가 있다.
