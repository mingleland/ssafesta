## 설명

부스에 들어가면 그 부스의 이름이 안쪽 뒷벽 위쪽(트러스와 천장 사이 빈 구간)에 음각처럼 새겨져 보이게 한다.

- 이름 해석은 기존 바깥 간판과 같은 우선순위를 쓴다 (facade.signText → boothName → projects[0].name → "N번 부스"). BoothSignPresenter 가 이미 캐시하므로 추가 API 조회는 없다.
- 음각 표현은 새 셰이더 없이 TMP 세 겹(위로 밀린 그림자 · 아래로 밀린 하이라이트 · 벽색 면)으로 만든다. 기존 FasciaText 의 폰트·머티리얼을 그대로 재사용해 셰이더 변형이 늘지 않게 한다.
- 임대되지 않은 칸에는 표시하지 않는다.
