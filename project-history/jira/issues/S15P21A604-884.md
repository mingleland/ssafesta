## 설명

부스 프로젝트 전시 패널(ProjectPanel_LED)에 등록된 videoUrl 영상을 WebGL DOM 오버레이로 겹쳐 재생한다. 영상이 없으면 부스 로고 → 프로젝트 썸네일 → 검은 화면 순으로 대체한다. 패널 네 꼭짓점을 화면 좌표로 투영해 호모그래피(matrix3d)로 정합하고, 카메라 뒤·거리 밖·중심 가림 시 숨긴다.
