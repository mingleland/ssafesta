## 설명

FE(이정헌)가 GitLab #217에서 요청한 관리자 콘솔(`/app/admin`, `!1041`) 계약 5건.

1. `GET /api/v1/users/me` 응답에 `admin`·`master` boolean 추가 — 지금은 토큰 role이 관리자도 MEMBER라 FE가 메뉴 노출 여부를 판단할 근거가 없음
2. `GET /api/v1/admin/users?query=&page=&size=` (닉네임/userId 검색) + `GET /api/v1/admin/users/{userId}` (상세) — 기존 admin API들이 요구하는 {userId}를 얻을 경로가 없음 (-806에서 범위 제외됐던 부분)
3. 대상 없음 응답 코드 통일 — AdminWalletOperationService는 ADMIN_TARGET_NOT_FOUND(404)인데 AdminAccountService·AdminUserOperationService는 USER_NOT_FOUND(401)라서 FE의 401 인터셉터가 refresh token을 불필요하게 회전시킴. 세 서비스 모두 404 ADMIN_TARGET_NOT_FOUND로 통일
4. 이벤트 상점 관리자 API 신설 — 경품 목록/구매내역/구매확정 처리. 코인 차감(원장)과 경품 지급(처리상태)은 별개 사건이라 분리. BE가 상태값·지급 방식 설계 (FE 초안일 뿐 확정 아님)
5. 이벤트 설문 관리자 API — 설문 목록, 문항별 집계, 개별 응답 조회 (기존 회원용 run/entrants 요약과 별개)

계약 상세는 GitLab #217 본문 참조. 완료 시 그 스레드에 통보.
