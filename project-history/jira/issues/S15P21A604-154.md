## 설명

### 작업 목적

GitLab 저장소 변경을 Jenkins가 받아 BE·FE를 검증하고 불변 이미지를 생성하도록 한다.

### 작업 내용

- GitLab webhook/SCM을 Jenkins Multibranch Pipeline에 연결
- back/front 변경 경로별 검증·빌드·이미지 publish
- commit SHA 태그와 digest 기록
- 실패 시 배포 차단 및 Secret 마스킹
- GitLab CI는 Jira 상태·라벨 자동화 용도로만 유지

### 완료 조건

- BE·FE 변경이 각 파이프라인만 실행한다.
- 테스트 실패 시 이미지 publish와 배포가 수행되지 않는다.
- 성공 이미지의 commit SHA·digest·실행 링크를 조회할 수 있다.
- 로그와 산출물에 Secret 평문이 없다.

### 선행 작업

Jenkins Controller·Agent·JCasC, Credentials 구성

### 참고

- `specs/infra-001-ci-cd-pipelines`

### 테스트 방법

BE/FE 성공·테스트 실패·Secret 포함 로그 시나리오를 각각 실행해 게이트와 마스킹을 확인한다.
