## 설명

### 배경

사용자 테스트 준비 점검(2026-09-06). 월드 어디에도 조작 안내가 없다 — `Scripts` 전체 grep 에서 WASD·튜토리얼 HUD 0건. 처음 들어온 테스터는 WASD 이동, Shift 달리기, 우클릭 드래그 시야 회전, F 상호작용, Esc 초점 해제를 알 수 없다.

### 조치

일반적인 게임 관례대로 스폰 직후 약 10초 동안 닫을 수 있는 조작 카드를 띄우고, 그 뒤에는 키로 다시 열 수 있게 한다. 스타일은 기존 프롬프트와 같은 `FestaUiKit` 을 쓴다.

### 범위

로비 UI 는 손대지 않는다 — 메인 맵 전용이다.

### 테스트 방법

에디터에서 확인한 뒤 WebGL 빌드 확인 체크리스트로 넘긴다.
