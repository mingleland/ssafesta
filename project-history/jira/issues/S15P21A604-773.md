## 설명

미니맵을 상시 표시하지 않고 사용자가 Tab 키를 누르고 있는 동안에만 열리도록 변경한다.

작업 내용:
- Tab keydown 시 미니맵 표시
- Tab keyup 또는 포커스 손실 시 미니맵 숨김
- 키 반복 입력과 중복 이벤트로 상태가 꼬이지 않도록 처리
- 게임 캔버스 포커스 및 기존 HUD 입력과 충돌하지 않는지 확인

완료 조건:
- Tab을 누르는 동안에만 미니맵이 표시된다.
- Tab을 떼면 즉시 닫힌다.
- 다른 입력 및 멀티플레이 동작에 영향이 없다.
- 브라우저 포커스 이동·복귀 후 미니맵이 stuck 상태로 남지 않는다.

우선순위: 후속 작업(Low)
