## 설명

## 작업 목적

검색 파이프라인을 고정한 상태에서 GMS 사용 가능 LLM을 비교하여 NPC의 최종 답변 생성 모델을 선정한다.

## 선행 작업

- 청킹·검색·Reranker 기준 조합 확정
- 비교 시 모델 외 프롬프트·검색 결과·생성 파라미터를 동일하게 유지

## 평가 항목

- 검색 chunk에 근거한 답변인지(Groundedness)
- 질문에 직접 답하는지(Relevance)
- 문서에 없는 내용을 생성하지 않는지
- 답변 불가 질문을 적절히 거절하는지
- 한국어 자연스러움과 NPC 응답 형식 준수
- TTFT·전체 응답시간·GMS Credit
- 컨텍스트 길이 및 스트리밍 지원

## 진행 상황

GMS에서 제공하는 모델 중, 1회 호출에 10 Credit이하를 사용하는 모델을 선별

그 중, 응답 속도가 느린 모델을 제외하고 아래 모델에 대해서 테스트 진행

- gpt 4.1 nano → 응답 가능한 내용을 `NO_ANSWER`처리함
- gemini 2.5 flash lite → `PARTIAL`을 `NO_ANSWER`처리함
- gpt 4o mini → `PARTIAL`을 `NO_ANSWER`처리함
- gpt 4.1 mini
- gpt 5.4 nano → 답변 후 `NO_ANSWER`반환
