## 설명

AI 직원 관리 화면에 문서 삭제 버튼이 이미 붙어 있다 (festa-frontend/src/features/booth/ui/AiAgentManagementTab.tsx, entities/aiAgent/api.ts의 deleteAiDocument). FE는 DELETE /api/v1/documents/{documentId} 를 호출하지만 AiDocumentController 에 @DeleteMapping 이 없어 404 난다.

기존 '문서 삭제' 관련 이슈(-556, -637, -496 등)는 전부 FAILED/EXPIRED 상태 문서의 자동 만료 스윕(spec 007 FR-028)이고, 사용자가 직접 누르는 수동 삭제와는 별개다.

요구사항:
- DELETE /api/v1/documents/{documentId} 구현 (본인 소유 booth 문서만 삭제 가능하도록 권한 체크)
- 문서 DB row soft/hard delete 정책 결정 (기존 상태 전이·만료 스윕 정책과 정합)
- R2 원본 오브젝트 정리, 관련 Chunk/임베딩 정리 포함 여부 확정
- 처리 중(QUEUED/PROCESSING) 문서 삭제 시도 시 에러 처리

Spring 백엔드 담당자에게 구두로 작업 전달받음.
