## 설명

일일 미션 보상을 받으면 같은 지급이 토스트 두 줄로 겹쳐 뜬다.

원인: BE 의 미션 보상 지급 경로는 미션 창의 "받기" 하나다(DailyMissionService). FE 는 그 한 번을 두 곳에서 알렸다 — 미션 창이 받기 응답으로 "일일 미션 보상으로 N 코인을 받았습니다", 코인 실시간 알림이 같은 지급 이벤트로 "일일 미션 보상 +N 코인이 지급되었습니다".

수정: 미션 창 토스트를 남기고 실시간 알림의 무음 목록(SILENT_REASONS, 슬롯 당첨과 같은 자리)에 DAILY_MISSION 을 더한다. 받기 응답은 클릭과 순서가 확실하다. 감추는 것은 알림뿐이고 HUD 잔액·코인 내역 갱신은 그대로 간다.

완료 조건
- 미션 보상 받기 시 토스트가 한 줄만 뜬다
- 잔액·내역은 종전대로 갱신된다
