## 설명

월드 UX 결함 3건을 한 MR 로 고친다.

1. 부스 임대 성공 시 임대 오버레이가 남는다 → 성공 즉시 부스 관리 화면으로 넘어가고, 활성 임대가 있으면 임대 오버레이 진입 자체를 관리 화면으로 돌린다.
2. 월드 채팅이 닫힌 상태의 옅은 줄에 남의 STOMP 연결 알림(JOIN)이 뜬다 → 닫힌 상태에서는 JOIN 을 제외하고, 열었을 때만 보여 준다.
3. 부스 관리 화면이 프로젝트 미등록일 때 SSAFESTA 파비콘을 로고로 쓴다 → 텍스트 없는 빈 플레이스홀더로 바꾼다.

관련 GitLab: #199(반납 전파), 월드 점유 판정 계약 요청 이슈(별도 발급).
완료조건: BoothRentalOverlay 성공·차단 동선, WorldChatLayer 닫힘 상태 JOIN 제외, BoothManagementOverlay 플레이스홀더, 단위 테스트, vitest/tsc/build 통과, front 머지.
