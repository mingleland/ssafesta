## 설명

## 증상

부스 안에서 노트북·AI 직원에 아무리 가까이 붙어도 **F 상호작용이 발동하지 않는다.** S15P21A604-336 에서 "부스가 너무 커서 노트북에 갈 수가 없다" 고 보고된 것의 실제 원인이다 — 크기 문제로 보였지만 크기를 고친 뒤에도 남았다.

## 원인

`BoothObjectFactory.AttachCommonInteraction` 이 사거리를 이렇게 준다.

```csharp
target.Configure(interactive ? 3f : 2.2f, interactive);
```

`BoothInteractionInput.IsInRange` 는 이 값을 **월드 유닛**으로 비교한다.

```csharp
Vector3.Distance(origin.Value, target.transform.position) <= target.MaxDistance;
```

그런데 이 프로젝트의 월드 스케일은 **1 m = 10 unit** 이다. 즉 `3f` 는 3 m 로 읽히지만 실제로는 **0.3 m** 다. 같은 파일의 `PlayerCameraFollow._maxDistance = 45f`(= 4.5 m)는 유닛 규약을 제대로 쓰고 있어, 이 값만 미터로 적힌 것이다.

## 실측 (에디터 플레이 모드, 부스 7, 앵커 lossy 10)

판정 기준점은 `BoothInteractionTarget.transform.position` 이고, 플레이어는 콜라이더 **밖**에서만 접근할 수 있다 (CharacterController 반지름 2.75 unit).

| 대상 | 판정 기준점 | 밖에서 최단 접근 | 사거리(수정 전) | 결과 |
|---|---|---|---|---|
| AI_AGENT `ai-1` | (2070, 0, 710) | 4.3 unit | 3 unit | **도달 불가** |
| LAPTOP `laptop-1` | (2130, 8.5, 740) | 6.8 unit | 3 unit | **도달 불가** |

노트북은 기준점이 테이블 높이(0.85 m)에 있고 콜라이더가 그보다 위(1.59 m)에 있어 더 멀다. 두 경우 모두 **몸이 표면에 닿아도 사거리 안에 들어갈 수 없다** — 확률 문제가 아니라 기하학적으로 불가능하다.

## 수정

```csharp
target.Configure(interactive ? 30f : 22f, interactive);   // 3 m / 2.2 m
```

`BoothInteractionTarget._maxDistance` 기본값도 `3f` → `30f` 로 올리고 단위를 주석에 명시한다 (팩토리가 항상 `Configure` 를 부르지만, 같은 함정을 남겨 두지 않는다).

3 m 는 이 사거리 검사를 도입하게 만든 과잉 반응 거리(6.5 m)보다 작아 그 회귀를 일으키지 않는다.

## 검증 (수정 후, 같은 조건)

레이캐스트 → 사거리 판정 → `Interact()` → 브리지까지 실제 경로를 그대로 태웠다.

```
AiAgent 'ai-1'  — 레이 적중 True, 거리 5.8/30 unit → 사거리 안 → AiNpcInteractable.Interact()
Laptop 'laptop-1' — 레이 적중 True, 거리 10.9/30 unit → 사거리 안 → LaptopInteractable.Interact()

[BoothInteractBridge] onBoothInteract → {"type":"AI_AGENT_INTERACT","boothId":7,"objectId":"ai-1","configId":78}
[BoothInteractBridge] onBoothInteract → {"type":"BOOTH_LAPTOP_INTERACT","boothId":7,"objectId":"laptop-1"}
```
