## 설명

### 작업 목적

BoothInteractBridge.OnSent 토스트 7종이 FE 임베드 배포본에서 중복 안내로 보이는 것을 없앤다. FE 는 같은 이벤트를 받아 즉시 오버레이를 열기 때문에, 열린 화면 위에 '웹 화면에서 열립니다' 가 겹친다.

### 결정 (GitLab #141 선택지 A)

게이트는 빌드 종류(Debug.isDebugBuild, scripting define)가 아니라 조작 안내 카드와 같은 FE 존재 여부(ControlsHintHud.HostProvidesUi, S15P21A604-456)로 한다. 단독 실행이면 릴리스 빌드에서도 이 토스트가 필요하고(probe 검증 경로), FE 임베드면 개발 빌드에서도 불필요하다. 빌드 종류는 이 판단과 상관이 없다.

### 유지하는 것

BoothInteractionInput.Toast(text, seconds) (S15P21A604-448)는 그대로 둔다. configId 0 처럼 브리지 이벤트가 아예 나가지 않는 경우에 쓰는 것이라 FE 는 그 상황을 알 수 없고 대신 표시할 방법도 없다.

### 완료 조건

1. FE 임베드에서 F 상호작용 시 오버레이만 열리고 Unity 토스트는 표시되지 않는다.
2. probe 단독 실행에서는 그대로 표시된다.
3. ui-ownership-matrix 충돌 요약 2번을 어떻게 닫을지 GitLab #141 에 회신한다.
