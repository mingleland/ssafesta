## 설명

### 작업 목적

Jenkins를 제품 CI/CD의 단일 실행 주체로 두고 ai/back/front/game 파트별 검증부터 develop 통합 릴리스까지 추적한다.

### 작업 내용

- Controller·Agent·JCasC와 Credentials
- 파트별 경로 기반 검증·이미지 publish
- develop 통합 배포·핵심 여정 검증·known-good 롤백
- provenance, 현재 버전 조회, 관측성과 알림
- GitLab CI는 Jira 자동화 잡을 유지

### 완료 조건

- 네 파트가 독립 검증·빌드되고 실패 시 publish/배포가 차단된다.
- develop 릴리스가 재현되며 실패 시 known-good 복원이 가능하다.
- commit SHA·image digest·실행 링크와 현재 버전을 추적할 수 있다.
- Secret 평문이 로그·산출물에 남지 않는다.

### 선행 작업

Jenkins 실행 환경과 GitLab/Jira 연동 권한

### 참고

- `specs/infra-001-ci-cd-pipelines`

### 테스트 방법

파트별 성공/실패, 통합 배포/롤백, Secret 마스킹, provenance 조회 시나리오를 실행한다.
