## 설명

### 작업 목적

demo 환경에서 React/WebGL 산출물을 HTTPS로 제공하고 Unity WebGL 로딩 헤더 오류를 방지한다.

### 작업 내용

- Nginx 정적 경로와 SPA fallback 구성
- wasm/data/framework 파일의 MIME·Content-Encoding 검증
- 캐시 무효화 가능한 릴리스 경로 마련
- world WSS endpoint는 world-sessions 응답을 사용하며 하드코딩하지 않음

### 완료 조건

- 외부 HTTPS에서 React와 WebGL이 정상 로드된다.
- 압축 형식과 Content-Encoding 불일치가 없다.
- 새 릴리스와 롤백 후 브라우저 캐시를 포함한 버전 확인이 가능하다.

### 선행 작업

DNS/TLS/Nginx 기본 구성

### 참고

- `specs/infra-002-runtime-environments`
- T-19, T-23

### 테스트 방법

시크릿/일반 브라우저에서 WebGL 로드, 네트워크 헤더, 캐시 무효화와 이전 버전 복원을 확인한다.
