## 설명

## 작업 목적

FE WorldHud 의 조작 안내가 좌측 **상단**에 있는데, Unity `ControlsHintHud` 는 좌측 **하단**에 그린다. 단독 실행과 FE 임베드에서 같은 안내가 다른 자리에 떠 한 화면으로 읽히지 않는다. (2026-09-10 플레이 중 실측)

덤으로, 두 목록이 '같은 어휘를 쓴다'고 주석에 적혀 있으나 실제로는 다르다 — Unity 에는 "F 상호작용 · 부스 입장", "Esc 화면 닫기 · 나가기" 가 있는데 FE 에는 **부스 입장·나가기라는 말이 없다**. 사용자가 부스에서 나가는 방법을 안내에서 찾을 수 없다.

## 작업 내용

`features/world/ui/worldHud.css` — `.world-hud-guide` 와 접힘 버튼 `.world-hud-guide-open` 을 `top` 에서 `bottom` 으로 옮긴다.

`features/world/ui/WorldHud.tsx` — F·Esc 항목 문구를 Unity 카드 어휘에 맞춰 부스 입장·나가기를 포함시킨다. 없는 조작을 임의로 늘리지 않는다.

## 완료 조건

1. 조작 안내 카드와 접힘 버튼이 좌측 하단에 뜬다 — Unity 카드와 같은 자리
2. F·Esc 문구에 부스 입장·나가기가 포함된다
3. 기존 항목·접기/펼치기·mock 안내 문구에 회귀가 없다
4. mock dev 환경에서 좌하단 여백 실측 확인
5. tsc 0 / vitest 전체 green / oxlint 신규 경고 0
