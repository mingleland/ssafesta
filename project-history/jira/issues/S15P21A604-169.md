## 설명

### 작업 목적

demo와 world 공개 진입점을 TLS로 제공하되 애플리케이션·데이터 포트는 외부에 노출하지 않는다.

### 작업 내용

- demo/world DNS와 TLS 인증서 구성
- Cloudflare → Nginx 공개 443 경로 구성
- HTTP→HTTPS, 보안 헤더, WebSocket upgrade 설정
- SG/방화벽에서 7777·DB·Redis 직접 노출 차단
- 설정 검증과 만료·갱신 확인 절차 문서화

### 완료 조건

- demo와 world 도메인의 인증서 체인이 정상이다.
- 외부 공개 포트는 의도한 80/443뿐이다.
- world WSS가 Nginx를 거쳐 내부 7777로 전달된다.
- DB·Redis·내부 게임 포트는 외부 스캔에서 닫혀 있다.

### 선행 작업

EC2·네트워크·도메인 접근 권한

### 참고

- `specs/infra-002-runtime-environments`
- `specs/infra-003-unity-server-runtime`

### 테스트 방법

외부에서 DNS/TLS/HTTPS/WSS와 공개 포트를 확인하고 Nginx 설정 검사를 실행한다.
