## 설명

### 작업 목적

S15P21A604-161 에서 분리. `@Festival` 을 프리팹으로 빼려면 **선행 변경이 필요하다는 것이 실측으로 확인**되어 별도 이슈로 남긴다.

### 왜 지금 못 하나

`@Festival` 서브트리에는 **밖을 가리키는 씬 참조가 13건** 있다.

- `BoothPortal.destination` **12개** → `@BoothInteriors/Interior_NN/SpawnPoint`
- `FestivalAmbience._bobbers[9]` → `Corridor_Festival/PF_Loose_Balloon_Bunches`

포털 목적지는 축제 존에서 부스 내부로 가는 링크라 **정당하게 외부**다. 구조를 바꾸지 않으면 서브트리 안으로 넣을 수 없다.

프리팹 변환이 그 참조를 어떻게 처리하는지 격리 실험으로 확인했다 (2026-08-31):

```
프리팹 에셋 안 = null (끊김) | 씬 인스턴스 = SpawnPoint | 인스턴스 오버라이드 1건
```

즉 그대로 전환하면 지금은 돌지만 **에셋 안의 포털 12개는 죽어 있고**, 누가 Revert 를 누르거나 다시 인스턴스화하면 12개가 한꺼번에 **조용히** 끊긴다. 유니티는 에러를 내지 않는다.

### 작업 내용

- `BoothPortal` 이 목적지를 직렬화 `Transform` 참조가 아니라 **런타임에 이름·ID 로 해결**하도록 변경
- 해결 실패 시 조용히 넘어가지 말고 로그로 드러낼 것 (T-24 원칙)
- 그 뒤 `@Festival` 프리팹 전환

### 완료 조건

- [ ] `BoothPortal` 24개 전부 목적지 해결 — 플레이 모드 실측
- [ ] `@Festival` 프리팹 전환 후 **프리팹 에셋 자체**에 끊긴 참조 0건
- [ ] 시각·기능 회귀 없음 (동일 좌표 카메라 렌더 해시 비교 + 포털 통과 실측)

### 선행 작업 / Dependency

- 동결 기간(9/14~) 고려 — 포털 24개의 해결 방식을 바꾸는 변경이라 동결 직전 편성은 권장하지 않는다.
