## 설명

startWorldChat() 이 회원 세션에서 WorldPage 가 렌더될 때마다 실제 ws-token 요청을 던진다. vitest 에서도 그대로 나가 front-test 로그에 [worldChat] 실시간 연결 실패 — ECONNREFUSED 127.0.0.1:3000 이 반복 기록되고, 각 요청이 15초 AbortSignal 타임아웃을 물고 워커를 붙든다.

이 저장소에는 real 어댑터를 VITE_USE_MOCK 로 가르는 관행이 이미 있다(entities/consultation/channel.select.ts). 채팅에는 적용하지 않은 것이 원인이다.

완료 조건: 테스트 실행 중 외부 네트워크 호출 0건. front-test 로그에 해당 문자열이 남지 않는다.
