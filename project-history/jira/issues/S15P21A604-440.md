## 설명

h3. 요구(사용자 2026-09-06 01:15) — 게임 파트 범위만

* 새로 import 한 DS Arcade Pack 01(ArcadeCabinet) 에셋을 저장소에 반입하고 URP 재질로 쓸 수 있게 한다(vendor 폴더 원본 불변, _Project 에 prefab variant).
* Game Studio 에서 완성된 게임이 걸린 게임기에 상호작용하면 zoom-in + 조작 잠금 + 게임이 나온다. Unity 는 spec 019 FR-017 대로 *실행 요청만* 웹 레이어에 전달하고 GameProject 를 해석하지 않는다.

h3. 설계

* 광장 게임기: {{ArcadeMachineInteractable}} — scene 에서 정한 canonical {{machineId}} 를 가지고 F 시 {{WORLD_ARCADE_INTERACT {machineId}}} 를 BoothInteractBridge 로 송신(#56 안 1 — FE 가 GET /api/v1/arcade-machines/{machineId} 로 resolve). 이벤트 이름은 게임 파트 제안이므로 docs/26 에 미결로 올린다.
* 부스 배치용: BoothObjectType {{GamePortal}} ({{GAME_PORTAL}}) + BoothObjectRegistry 에 게임기 prefab 등록, F 시 {{BOOTH_GAME_INTERACT {boothId, objectId, configId}}} (specs/019 contracts/game-portal-bridge.md 그대로).
* 둘 다 {{InteractionFocusCamera}} 로 zoom-in + {{InputBridge.SetLocked(true)}}. FE 가 오버레이를 닫으며 SetInputLocked 0 을 보내면 복구, FE 응답이 없어도 Esc 로 복구(갇힘 방지).
* 게임 자체(2D Runtime)는 FE 오버레이 — 이 이슈 범위 밖.

h3. 완료 조건

에디터: 광장 게임기 F → zoom-in·잠금·{{OnSent WORLD_ARCADE_INTERACT}} → Esc 복구. GAME_PORTAL 배치 오브젝트 F → {{BOOTH_GAME_INTERACT}} payload 에 configId.
