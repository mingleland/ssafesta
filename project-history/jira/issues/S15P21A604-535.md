## 설명

## 작업 목적

- 에디터 캔버스에서는 배치한 asset(이미지)이 투명하게 잘 보이는데, 플레이  
   테스트 화면에서는 이미지 유무와 무관하게 항상 어두운 반투명 박스가 씌워져  
   이미지가 그 박스 안에 갇혀 보이는 문제를 해결한다.

## 작업 내용

- `ReferenceGamePlayer.tsx`
   
   - 오브젝트 렌더링(`.grp-object`) 시 `spriteVisual !== null` 여부에 따라  
      조건부 클래스(예: `has-visual`)를 추가한다. `spriteVisual`은 builtin  
      이미지든 사용자가 업로드한 커스텀 이미지든 동일하게 해석되므로 별도 분기  
      없이 이 값 하나로 충분하다.
- `ReferenceGamePlayer.css`
   
   - `.grp-object`에 이미지가 있는 경우(`.has-visual`) 배경/테두리/그림자를  
      전부 제거해 에디터 캔버스(`.gss-map-object`, 기본 투명)와 동일하게 만든다.  
      이미지가 없는 폴백(이모지) 경우는 지금의 어두운 배지 스타일을 그대로  
      유지한다.

## 완료 조건

- [ ] 커스텀/빌트인 이미지 asset이 설정된 오브젝트는 플레이 화면에서 어두운  
       배경 박스 없이 투명하게 보인다
- [ ] 이미지가 없는(이모지 폴백) 오브젝트는 기존처럼 어두운 배지 박스가  
       유지된다
- [ ] 에디터 캔버스와 플레이 화면의 배경 표현이 일치한다(이미지 있는 경우)
- [ ] 적/투사체 등 다른 요소는 영향받지 않는다(회귀 없음)

## 선행 작업 / Dependency

- 없음

   `GameStudioShell.css`의 `.gss-map-object`(에디터 캔버스, 기본 투명)
