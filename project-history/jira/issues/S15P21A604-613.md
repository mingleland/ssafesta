## 설명

## 작업 목적

Unity 캐릭터 선택 화면 위에 FE 의 World HUD 3종이 그대로 겹쳐 뜬다(2026-09-10 사용자 실측 스크린샷).

```
좌하단   조작 안내 카드      (WorldHud)
우상단   상담 Quick Access   (ConsultationQuickAccess)
우하단   도움말 버튼         (WorldGuideLauncher)
```

캐릭터를 고르는 화면에서 "W A S D 이동"·"부스 입장" 같은 월드 조작 안내가 떠 있으면 사실과 다르고, 상담·도움말도 그 맥락에서 열 수 있는 것이 아니다.

## 작업 내용

**새 계약이 필요 없다 — FE 가 이미 아는 상태다.** `UnityHost` 의 `HostStatus` 가 그 구분을 갖고 있다.

```
booting          인스턴스 부팅 중
waiting-gate     인스턴스는 섰고 Unity 가 로비·게이트를 그린다   <- 캐릭터 선택이 여기
preparing-world  로비에서 입장을 눌러 main 씬 로드 중
ready            onWorldGateReady 이후 = 월드 안
failed
```

- `HostStatus` 를 module-level store 로 노출한다(`worldUiState`·`gameClientUi` 와 같은 관례)
- `WorldPage` 는 **월드 안(`ready`)일 때만** `WorldHud` 를 그린다
- mock 월드(`IS_MOCK_WORLD`)는 `UnityHost` 자체가 뜨지 않으므로 예외로 둔다 — 그렇지 않으면 mock 개발에서 HUD 가 영영 안 뜬다

## 완료 조건

1. 캐릭터 선택(`waiting-gate`)에서 조작 안내·상담·도움말이 보이지 않는다
2. 부팅·월드 로딩(`booting`·`preparing-world`)에서도 보이지 않는다
3. 월드 진입(`ready`) 후에는 그대로 보인다
4. mock 월드에서는 지금처럼 보인다
5. unit test / tsc 0 / vitest 전체 green / oxlint 신규 경고 0

## 선행 작업 / Dependency

- 없음. Unity 계약 추가 없이 FE 내부에서 끝난다
