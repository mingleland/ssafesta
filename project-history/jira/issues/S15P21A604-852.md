## 설명

GitLab #197. 게임 파트 수신부(WorldUiBridge.RequestAvatarCustomization)가 develop 에 도달해 -820 으로 올린 FE 브릿지의 조건이 풀렸다.

GameMenu 의 disabled '준비 중' 스텁을 실제 버튼으로 바꾸고 requestAvatarCustomization(instance) 를 부른다. 게스트에게는 버튼을 감춘다 — Unity 가 거부하고 로그만 남기므로 눌리는 버튼을 두면 아무 일도 안 일어난 것처럼 보인다(게임 파트 요청).

메뉴를 닫는 것까지가 이 버튼의 몫이고, 아바타 화면을 닫는 경로는 기존 ESC 중재 2단계(RequestExitWorldUi('esc'))가 그대로 쓴다.
