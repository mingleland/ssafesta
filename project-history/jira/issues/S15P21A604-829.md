## 설명

ESC 메뉴가 항목마다 다른 방식으로 열리고 닫혀 구성이 흐트러져 있었다.

- 조작 안내·설정을 패널 안 토글에서 자식 오버레이로 바꾼다. 접었다 펴면 메뉴 높이가 튀고 항목마다 닫는 방법이 달라진다
- 메뉴에서 연 화면(내 정보·조작 안내·설정·부스 관리)은 메뉴를 배경에 남긴다. 닫으면 월드가 아니라 메뉴로 돌아온다 — 부스 관리를 열고 취소하면 ESC 계층이 통째로 사라지던 문제
- 내 정보는 별도 pill 버튼 대신 프로필 요약 행 전체를 진입점으로 만든다. 닫기 버튼과 같은 모서리에서 다투지 않는다
- 닫기 버튼을 요약 행 높이에 맞춰 내리고, 기능 없이 비어 있던 여백 블록을 없앤다
- 명칭을 조작 안내 / 부스 관리 / 아바타 변경으로 통일한다
