## 설명

마인크래프트를 레퍼런스로 한 조작감 재설계의 후속. "고개가 안 움직이고, 카메라에 따라 몸이 무조건 돌아 내 캐릭터 애니메이션을 볼 수 없다"는 지적에서 출발했다.

## 범위

1. **시선(고개) 회전** — `AvatarLook`
   
   - `OnAnimatorIK` 는 Animator 와 같은 GameObject 의 컴포넌트에만 호출된다. 우리 구조는 Animator 가 런타임 조립된 자식에 있어 콜백이 아예 불리지 않았다 (T-205).
   - IK 를 버리고 `LateUpdate` 에서 목·머리·상체 본을 직접 회전. 머리 50% / 목 32% / 상체 18%.
   - 한계(±55°)에서 하드 클램프로 확 꺾이던 문제 → 사인 포화 + 한계 밖 45° 폭에서 시선을 놓고 정면 복귀 (T-207).
   - 이모트 중 0 / 달리기·점프 0.30 / 걷기 0.55 / 정지 1.0 으로 세기 조절.
   - `LookAngles` NetworkVariable 로 원격 아바타에도 고개가 보인다 (임계 3°).
2. **정지 중 몸 회전 제거** — 서 있을 때는 몸을 돌리지 않는다. 카메라를 돌려 자기 캐릭터의 정면·측면 애니메이션을 볼 수 있어야 한다. 이동 중에는 카메라 정면 정렬 유지.
3. **점프 3단 재구성** — Kevin Iglesias 클립의 루트 Y 를 실측해 맞췄다.
   
   - `Jump01 - Begin`(0.667s): 서 있는 엉덩이 높이 1.056 통과 = 0.45s 가 이륙 → `Jump_Launch` speed 2.045 (= 0.45 / 발 구르기 0.22)
   - `Fall01`(1.000s 루프): 체공이 길어도 버틴다 → `Jump_Air` speed 1.0. 체공↔클립 speed 연동이 사라졌다.
   - `Jump01 - Land`(0.600s): 앞 0.15s 는 아직 하강이므로 그 지점부터 재생 → 새 상태 `Jump_Land`, `PlayerAnimState.JumpLand = 5` 추가.
4. **이모트 UI 방사형 휠** — 흩어진 사각 버튼 8개에서 중앙 허브 + 도넛 링 8칸 + 선택 웨지로 재작성. 링·웨지·허브 텍스처를 런타임에 1회 절차적으로 굽는다.
5. **접지 보정** — 접지 높이가 상수 `12.5f` 로 박혀 아바타가 1.10 m 떠 있었다 (T-206). BakeMesh 기반 측정 접지로 교체. 앉기 이모트는 최하단이 선 자세보다 0.117 낮아 포즈 진입 후 다시 잰다 (T-208).

## 검증

컴파일 오류 0. WebGL 빌드 접속·구동 확인. **감각·시각 확인은 남아 있다** — 고개 분배 비율, 휠 반경, 원거리 이모트 자연스러움은 실제 조작으로 봐야 한다.
