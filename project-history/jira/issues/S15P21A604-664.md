## 설명

WebGL 배포 검증이 Cloudflare 에서 403 으로 끊긴다. 지금 로그에는 상태줄과 cf-ray 뿐이라 어떤 규칙에 걸렸는지, 그리고 어느 IP 가 막혔는지를 모른다. 인프라가 허용 규칙을 넣으려면 바로 그 두 가지가 필요하다 (GitLab #165).

고칠 것:
1. 검증 실패 시 응답 본문을 같이 남긴다. 태그를 벗기고 앞부분만 잘라 쓴다.
2. cf-ray 가 찍혔을 때 /cdn-cgi/trace 를 한 번 물어 엣지가 본 ip 와 colo 를 남긴다.

배포 판정 규칙은 그대로다 — 진단 출력만 늘어난다.
