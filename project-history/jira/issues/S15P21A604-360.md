## 설명

# 작업 목적

Event의 Action 목록 순서를 드래그로 바꿀 수 있게 한다.



# 작업 내용

- authoringCommands.ts에 action 배열 순서를 바꾸는 커맨드 함수 신설(append/replace/remove만 있고 reorder 없음)
- EventEditor.tsx의 action 목록에 드래그 핸들(햄버거 아이콘) UI 추가



# 완료 조건

- [ ] 각 action 행에 드래그 핸들이 표시된다
- [ ] 드래그로 action 순서를 자유롭게 바꿀 수 있다
- [ ] 변경된 순서가 저장·재로드 후에도 유지된다
- [ ] 기존 action 추가/제거 기능에 회귀가 없다



# 테스트 방법

하나의 Event에 action 3개 이상 추가 → 드래그로 순서 변경 → 저장·재로드로 순서 유지 확인 → 기존 추가/제거 회귀 확인.
