## 설명

## 작업 목적

- 플레이 중 체력이 깎일 때 상단 "♥ N / M" 수치만 바뀔 뿐 캐릭터 주변에 아무 시각  
   피드백이 없어 피해를 입었다는 느낌이 잘 전달되지 않는 문제를 해결한다.

## 작업 내용

- `referenceRuntime.ts`
   
   - `ReferenceRuntimeState`에 마지막 피해 신호 필드를 추가한다(예: `lastDamageAmount`,  
      `lastDamageTick`).
   - `damagePlayer()`가 실제로 체력을 깎을 때(무적 시간 중이 아닐 때)마다 이 신호를  
      그 순간의 피해량으로 갱신한다. 무적 시간 중 호출은 기존처럼 완전히 무시해  
      신호도 갱신하지 않는다 — 연속 피격 시 표시가 중복으로 뜨지 않게 하기 위함.
   - 체력이 0이 되어 리스폰/게임오버로 이어지는 분기에서도 예외 없이 동일하게  
      신호를 갱신한다.
- `ReferenceGamePlayer.tsx`
   
   - `runtime.lastDamageTick` 변화를 감지하는 `useEffect`로 로컬 state(떠 있는 표시  
      목록)에 새 항목을 추가하고, 애니메이션 길이만큼 지난 뒤 자동으로 제거한다.
   - 캐릭터(`.grp-player`)와 같은 좌표(left/top %)를 기준으로 오프셋을 줘서 오른쪽  
      위에 "-N"(실제 감소량, 하트 아이콘이 아닌 숫자)을 표시한다.
- `ReferenceGamePlayer.css`
   
   - 표시 요소 스타일과, 위로 이동하며 페이드아웃하는 `@keyframes` 애니메이션을  
      추가한다.

## 완료 조건

- [ ] 체력이 깎일 때마다 캐릭터 오른쪽 위에 "-N"(실제 감소량) 텍스트가 나타난다
- [ ] 표시가 위로 서서히 이동하며 페이드아웃되다가 사라진다
- [ ] 무적 시간 중(연속 피격 무시 구간)에는 표시가 추가로 뜨지 않는다
- [ ] 체력이 0이 되는 마지막 피격에도 동일하게 표시가 뜬다
- [ ] 함정/적 투사체/낙사 등 체력이 깎이는 모든 경로에서 동일하게 동작한다
