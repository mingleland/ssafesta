## 설명

# 작업 목적

- 캔버스에서 확대/축소를 버튼 클릭 없이 마우스 휠로 빠르게 조작할 수 있도록 하고, 커서 위치를 기준으로 확대/축소되게 하여 편집 경험 개선

# 작업 내용

- `TopDownCanvas.tsx`의 `.gss-canvas-scroll`(캔버스 스크롤 컨테이너)에 `onWheel` 핸들러 추가 — 수정자 키 없이 휠 업/다운이 바로 확대/축소로 동작
- 휠 이벤트 시점 커서 아래 그리드 좌표를 계산해, 확대/축소 후에도 그 좌표가 화면상 같은 위치에 남도록 스크롤 위치 보정(커서 중심 확대/축소)
- `onWheel`에서 `preventDefault`로 브라우저 기본 스크롤(패닝) 제거
- 줌 범위는 기존 +/- 버튼과 동일하게 10~200%, 휠 한 틱은 5% 단위로 세밀하게 조정
- 마우스 가운데 버튼(휠클릭) 드래그 패닝은 이미 구현되어 있어 변경 없음(`event.button !== 1` 조건, 회귀 여부만 확인)

# 완료 조건

- [ ] 캔버스 위에서 마우스 휠 업/다운 시 수정자 키 없이 커서 중심으로 확대/축소된다
- [ ] +/- 버튼, 1:1, 비율 표시는 참고/보조 컨트롤로 그대로 유지되고 휠 확대/축소와 값이 연동된다
- [ ] 마우스 휠 스크롤을 이용한 기존 패닝은 사라지고, 휠클릭(가운데 버튼) 드래그 패닝은 회귀 없이 동작한다
- [ ] 10%/200% 경계값에서도 clamp가 깨지지 않는다
