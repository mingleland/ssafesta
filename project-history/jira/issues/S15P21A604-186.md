## 설명

작업 목적

한 Game Runtime 오류가 월드·목록·다른 Booth 경험을 깨지 않게 격리하고 사용자가 스스로 빠져나오게 한다.

작업 내용

- Runtime Error Boundary와 overlay/route 단위 격리

- 다시 시도·게임 닫기·목록으로 이동 UX

- 손상 프로젝트·지원하지 않는 버전·Asset 실패 메시지 구분

완료 조건

- [x] 강제 오류 fixture에서 해당 게임 영역만 실패한다.

[ ] 닫기 뒤 기존 앱과 선택적 Unity 입력이 정상이다.

- [x] 반복 실패가 무한 reload를 만들지 않는다.
- [x] 진단 ID는 제공하되 내부 stack·민감 정보는 노출하지 않는다.
