## 설명

### 작업 목적

- 월드 입장마다 Unity 가 12슬롯의 게시본을 병렬로 조회한다(`GET /api/v1/booth-slots/{slotId}/layouts/published`). 지금은 성공 경로 한 번에 SELECT 5개(슬롯·임대·부스·임대 재확인·게시본)가 나간다. 이것을 1문장으로 줄인다.
- 코인 정합 점검(`CoinReconciliationService`)이 `wallets.findAll()` 로 지갑 전체를 메모리에 올린다. DB 에서 불일치 행만 받게 바꾼다.

### 범위

- `BoothLayoutQueryService.findPublishedBySlot`: 성공 경로 1질의. 결과가 없을 때만 기존 경로로 404/409 를 가른다.
- `CoinReconciliationService`: `count` + 불일치 조회 두 문장. `WalletRepository` 의존 제거.
- 테스트 정리: 중복 `@Import` 제거(컨텍스트 1개 감소), 스테일 javadoc 수정.
