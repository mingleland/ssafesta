## 설명

11층 안내데스크에 서 있는 직원을 상호작용 NPC 로 바꿀다.

동작:
1. 머리 위에 말풍선을 띄운다. 문구는 두 줄로 짧게 — SSAFESTA 안내 데스크입니다 / 처음이시면 F 를 눌러 이용 안내를 보세요.
2. F 로 상호작용하면 FE 가 만든 가이드라인 화면을 열어준다.

계약:
- Unity 는 상호작용 이벤트만 보낸다. 화면은 FE 오버레이 몫이다 (#166 · #170 과 같은 결).
- 새 이벤트 종류를 만들지, 기존 것을 쓸지는 FE 와 정해야 한다. 화면이 boothId 를 소비하지 않으므로 접두사는 WORLD_ 가 맞다.
- 말풍선은 월드 안에서 그린다. FE 계약을 늘리지 않는다.

말풍선 문구는 느낌표를 줄이고 할 일만 남긴다 — 사용자가 직접 준 초안은 느낌표가 많아 다듬었다.

FE 에 GitLab 이슈로 수신부를 요청한다.
