## 설명

## 작업 목적

- 데이터 탭 "바로 쓰는 기본 재료"(`.gss-builtin-library`) 그리드의 썸네일이 전부 5~10px  
   높이의 가로 슬라이버로 찌부러져 뭐가 뭔지 알 수 없다. 썸네일 칸(`<span>`)만 정사각형이  
   아니라서 스프라이트 시트 크롭이 세로로 눌린다. 정사각형으로 고친다.

## 재현 방법

1. Game Studio → 데이터 탭 → "바로 쓰는 기본 재료" 그리드 확인
2. 모든 썸네일이 세로로 눌린 얇은 띠로 표시됨 (왼쪽 "배치할 요소" 팔레트·"재료함" 모달의  
   같은 스프라이트는 정상)

## 작업 내용

- `.gss-builtin-library > div > span`(GameStudioShell.css)을 정사각형으로 수정  
   (`aspect-ratio: 1 / 1; height: auto; width: 100%;` 또는 고정 `58×58 + margin: 0 auto`)
- `staticImageBackgroundStyle`(staticImageVisual.ts)은 정상 동작 중인 다른 3곳(왼쪽 팔레트  
   34×34, 재료함 모달 68×68, 데이터 탭 내 자산 목록 26×26)이 공유하므로 건드리지 않는다 —  
   CSS만 수정
- (조율) 배경 단일 이미지 2개(`library-room-map`, `visual-novel-library` — `columns:1 rows:1`)는 정사각형 칸에서 늘어나 보임. `columns===1 && rows===1`일 때 `background-size: contain` 분기를 이번에 같이 넣을지는 구현 단계에서 판단(공유 함수 변경이라 회귀 확인 추가)

## 완료 조건

- [ ] "바로 쓰는 기본 재료" 썸네일이 정사각형 칸에서 세로로 눌리지 않고 온전히 보인다
- [ ] 2열/3열 반응형 브레이크포인트 모두에서 정상이다
- [ ] 왼쪽 팔레트·재료함 모달·데이터 탭 내 자산 목록 썸네일에 회귀가 없다
- [ ] (조율 결과에 따라) 배경 단일 이미지 2개도 늘어나지 않고 표시된다
- [ ] `npx vitest run`, `npm run build`, `npx tsc --noEmit`, `npm run lint` 통과

## 선행 작업 / Dependency

- 없음(데이터 탭 "바로 쓰는 기본 재료" 썸네일이 세로로 뭉개져 얇은  
   띠로 나옴)

## 테스트 방법

1. 데이터 탭 "바로 쓰는 기본 재료" 그리드에서 캐릭터/오브젝트/배경/타일셋 썸네일이 정사각형  
   칸에 세로로 안 눌리고 보이는지 확인
2. 패널 폭을 줄여 2열 브레이크포인트에서도 정상인지 확인
3. 왼쪽 팔레트·재료함 모달·데이터 탭 내 자산 목록 썸네일 회귀 확인(공유 함수 미변경)
4. `npx vitest run`, `npm run build`, `npx tsc --noEmit`, `npm run lint` 통과
