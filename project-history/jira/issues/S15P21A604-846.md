## 설명

Booth Studio 는 -844 로 사용자 진입 경로가 전부 사라졌고(route 리다이렉트·ManagementPanel 'studio' 제거) 산출물에서도 StudioPage·R3FBoothRenderer chunk 가 소멸했다. 남은 것은 소스·테스트·의존성이다.

삭제: src/features/studio, src/pages/studio, src/entities/catalog, src/entities/layout(비테스트 외부 importer 0), features/booth/ui/BoothMiniPreview.tsx(소비자 0), tools/paletteAssetCodes.test.mjs, npm three·@react-three/fiber·@types/three.
유지: /app/studio 리다이렉트, facadeApi·homepageApi, unity/host·boothLayoutBridge, tools/assets·assets:build/verify·public/assets/booth-runtime·boothAssetBase(), public/booth-preview·BoothPreview.

FacadePanel(테마·대표색·간판·로고)은 현재 접근 가능한 기능이 아니라 함께 삭제한다. 그 편집 요구가 다시 확정되면 Studio 복원이 아니라 Booth Management 에서 새 feature 로 재설계한다.

완료: vitest·tsc·build green, 산출 chunk 목록 동일, 반납 ReloadBoothSlot 회귀 통과.
