## 설명

## 작업 목적

게임 흐름 플로팅 윈도우의 × 닫기 버튼을 눌러도 창이 닫히지 않음(Notion QA id=33). `FloatingPanel.tsx`의 제목 표시줄 드래그 핸들러가 자식 버튼에서 시작된 pointerdown도 구분 없이 처리해 버튼의 클릭 이벤트를 가로막는 것이 원인으로 확인됨.

## 작업 내용

- `FloatingPanel.tsx`의 `startDrag`에 `SceneFlowGraph.startPan`과 동일한 방어 추가 — pointerdown이 제목 표시줄 안의 버튼(닫기 ×)에서 시작된 경우 `event.target.closest('button')`으로 걸러내고 드래그(`preventDefault`/`setPointerCapture`)를 시작하지 않음
- 원인: header에 걸린 드래그 핸들러가 (1) `preventDefault()`로 이후 `click` 이벤트 합성을 막고, (2) `setPointerCapture()`로 pointerup을 header로 리다이렉트시켜 버튼의 `onClick`이 발화하지 않았음(S15P21A604-506부터 있던 버그)
- `floatingPanel.test.tsx`의 닫기 버튼 테스트를 `fireEvent.click` 직접 호출에서, 실제 브라우저와 같은 pointerdown→pointerup→click 순서로 재현하는 테스트로 교체(기존 테스트는 이 버그를 못 잡는 가짜 통과였음)
- 다른 드래그 핸들(`startResize`)은 안에 인터랙티브 자식이 없어 같은 문제가 없음 — 수정 범위 아님

## 완료 조건

- [ ] "게임 흐름" 창의 × 버튼을 클릭하면 창이 닫힌다
- [ ] 제목 표시줄의 버튼이 아닌 영역을 드래그하면 여전히 창이 이동한다(회귀 없음)
- [ ] 관련 테스트 통과 + `tsc --noEmit` 통과
