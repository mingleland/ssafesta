## 설명

축제장 부스 12칸 밖에서 어느 팀인지 알 수 있게 한다.

값의 출처는 기존 계약 둘이다. GET /booths/{id} 의 name 과 facade.signText, 그리고 GET /booths/{id}/projects/published 의 name 과 thumbnailUrl. 새로 정한 규약은 없다. GitLab 171 에서 값이 실제로 채워지는지와 WebGL CORS 헤더를 확인 요청했다.

표시 우선순위는 facade.signText, booths.name, projects[0].name, 그리고 기본값 순서다.

형태는 세 번 바뀌었다. 처음에는 지붕 위에 큰 판을 올렸는데 부스보다 판이 먼저 보이고 하늘을 가려서 지웠다. 다음으로 부스 자체 간판 위에 덮는 안을 봤는데, 12칸 중 4칸만 간판이 있고 05번과 07번은 천막이며 4개가 전부 다른 그림과 크기라 접었다. 지금은 카니벌 킷의 A프레임 입간판(PF_A_Frame_Sign)을 부스 앞 왼쪽, 부스 폭 바깥에 세운다.

한글 줄바꿈을 TMP 에 맡기면 글자 단위로 끊긴다. BoothSign.WrapByWord 가 어절 단위로 미리 접고 TMP 는 NoWrap 으로 둔다.

전시 카드는 이미지가 실제로 로드된 뒤에만 나타난다. 이름만 있는 빈 판이 하늘에 뜨는 것을 막기 위해서다.
