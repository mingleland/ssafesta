## 설명

## 문제

AI 직원 오버레이의 추천 질문 문구가 AI 서버의 정형답변 화이트리스트와 달라 추천 버튼을 눌러도 Embedding·RAG·LLM 경로를 탑니다.

- 화면: 어떤 프로젝트인가요? / 누구를 대상으로 한 서비스인가요? / 기술 스택이 궁금해요
- 서버 정형 질문: 프로젝트 소개 / 대상 사용자 / 기술 스택

## 실측

- 실제 정형답변 프로젝트 소개: 첫 답변 및 완료 0.71초
- LLM 질문 3건 평균: 첫 답변 1.85초, 완료 3.01초

## 작업

1. 추천 버튼 문구를 서버 정형답변 정본과 일치시킵니다.
2. 추천 버튼 클릭 시 전달 문자열을 회귀 테스트로 고정합니다.
3. 프로젝트 소개·대상 사용자·기술 스택의 생성·저장 경로를 확인하고 결과를 기록합니다.

## 완료 조건

- 추천 버튼 3개가 프로젝트 소개 / 대상 사용자 / 기술 스택으로 표시됩니다.
- 각 버튼이 동일 문자열을 질문으로 전달합니다.
- 관련 FE 단위 테스트가 통과합니다.
