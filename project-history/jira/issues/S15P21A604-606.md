## 설명

## 작업 목적

부스 슬롯 선택 화면이 카드 그리드라 "축제장 어디에 있는 자리인가" 가 드러나지 않는다. 위에서 본 그림 위에서 고르게 한다(2026-09-10 사용자 요청).

## 작업 내용

**좌표는 이미 확보했다 — Unity 에 요청하지 않는다.** `festa-unity` 의 `Assets/_Project/Scenes/main.unity` + `Prefabs/World/Festival.prefab` 에서 `Portal_Ext_01~12` 의 boothId ↔ Transform 을 추출했다.

```
배치   6열 × 2행 통로형
x     -887.34 ~ -278.68   (폭 608.66)
z     홀수 부스 ≈ 230 / 짝수 부스 ≈ 55   (폭 192.60)
```

- `slotId → 정규화 좌표` 매핑을 FE 상수로 든다. `SlotView` 계약 확장(3파트)은 하지 않는다 — 슬롯 12개 고정, `floorNo` 11 고정이라 상수 표의 유지비가 더 싸다
- 평면도는 실사 렌더 없이 **SVG 로 직접 그린다**. 저장소에 top-down 자산이 없고, 통로형 배치라 추상 평면도로 성립한다
- 슬롯 상태(임대 가능·내 부스·사용 중)를 평면도 위에서 구분한다

## 완료 조건

1. 평면도 위에서 12개 슬롯의 위치·상태가 읽힌다
2. 내 부스는 평면도에서도 Studio 로 진입된다(S15P21A604-591 과 같은 목적지)
3. **카드 목록을 접근성 대체 경로로 남긴다** — 평면도 위 핫스팟만 두면 키보드 사용자가 막힌다
4. unit test / tsc 0 / vitest 전체 green / oxlint 신규 경고 0

## 선행 작업 / Dependency

- 없음. 실사 렌더 이미지가 나중에 오면 SVG 를 그것으로 교체한다
