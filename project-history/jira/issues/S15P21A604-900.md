## 설명

게시본 objects 에 AI_AGENT·LAPTOP·SURVEY_KIOSK·PROJECT_PANEL 이 있으면 BoothObjectFactory 가 캡슐 placeholder 를 세우고 AuthoredBoothContentBinder 도 같은 configId 를 씬 오브젝트에 물려, 한 부스에 저작 NPC 와 스폰 캡슐이 동시에 서고 둘 다 상호작용이 된다. 저작 인테리어(@BoothInteriors) 안에서는 이 네 타입을 스폰하지 않고 binder 만 태운다. 동결 기준선인 BoothRuntime 은 건드리지 않고 Factory 에서 GAME_PORTAL 스킵과 같은 자리에서 거른다. 아울러 S15P21A604-899 로 넣었던 부스 상세 aiAgentId 폴백은 FE 가 게시본에 AI_AGENT 를 싣기로 해 불필요해졌으므로 되돌린다.
