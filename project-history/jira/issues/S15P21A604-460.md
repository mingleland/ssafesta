## 설명

## 작업 목적

강형순 님이 2026-09-06 FE 임베드 실측 뒤 GitLab #132 에 요청한 건이다.

Unity 쪽 조작 안내 카드(S15P21A604-451)를 FE 임베드에서 숨기도록 바꿔(S15P21A604-456, 완료) 조작 안내가 FE WorldHud 하나로 남았다. 그런데 현재 FE 카드는 3줄(WASD / F / Esc)뿐이라 사용자 테스트에서 자주 묻는 조작이 빠져 있다.

2026-09-08 사용자 테스트 전에 채우는 것이 목표다.

## 작업 내용

festa-frontend/src/features/world/ui/WorldHud.tsx 의 조작 안내 카드에 다음을 추가한다.

- Shift — 달리기
- Space — 점프
- 마우스 우클릭 드래그 — 시야 돌리기
- Alt + 클릭 — 감정 표현

그리고 H 항목이 있다면 제거한다 — FE 임베드에서는 아무 동작이 없다(Unity 쪽 카드 토글이었고 그 카드가 숨겨졌다).

안내 문구는 새로 지어내지 않고 Unity 카드(S15P21A604-451)와 같은 어휘를 쓴다 — 두 파트가 같은 조작을 다른 말로 설명하지 않게 한다.

## 완료 조건

1. Shift·Space·우클릭 드래그·Alt+클릭 4항이 조작 안내에 나온다
2. H 항목이 없다
3. 기존 WASD·F·Esc 항목·접기/펼치기 동작 회귀 없음
4. mock 월드 안내 문구 회귀 없음
5. unit test
6. tsc 0
7. vitest 전체 green
8. oxlint 신규 경고 0

실 브라우저 육안 확인은 2026-09-08 통합 acceptance 로 이월한다. 그때까지 Jira Done 으로 전환하지 않고 Closes 도 쓰지 않는다.

## 선행 작업 / Dependency

- S15P21A604-451 (Unity, 완료) — 조작 안내 카드 어휘의 출처
- S15P21A604-456 (Unity, 완료) — FE 임베드에서 Unity 카드 숨김. 이것 때문에 FE 카드가 유일한 안내가 됐다
