## 설명

S15P21A604-514 작업 중에 발견한 별건이다. HDD 트러블슈팅 T-139로 기록했다.

## 증상

셸에 `JWT_SECRET` 과 `CONNECTION_TOKEN_SECRET` 이 export 되어 있지 않으면 `OpenApiDocumentationTest` 8건이 전부 컨텍스트 로드 실패로 죽는다. 오류 메시지는 `Illegal base64 character 24` 인데, 이는 치환되지 않은 `$` 문자가 그대로 base64 디코더에 들어간 결과다. 값이 없다는 뜻이 오류 문면에 드러나지 않아 원인 파악이 느리다.

## 원인

- `backend/src/test/resources/application-local.properties` 는 R2 설정과 내부 토큰만 공급하고 JWT 키와 Connection 키는 공급하지 않는다.
- `backend/pom.xml` 에 dotenv 의존성이 없어 `backend/.env` 는 테스트 실행에서 읽히지 않는다.
- 그런데 `backend/.env.example` 5행에는 "테스트(./mvnw test)에는 이 파일이 필요 없다 — src/test/resources 가 값을 공급한다" 고 적혀 있다. 이 문장이 사실과 다르다.

기존 개발자 셸에는 값이 export 되어 있어 지금까지 드러나지 않았다. 새로 참여하는 사람의 환경과 CI 러너에서 먼저 터진다. 현재는 `ci/test` 가 테스트 전용 값을 직접 export 하는 방식으로 우회하고 있다.

## 결정이 필요한 지점

두 방향 중 하나를 골라야 한다.

1. 테스트 리소스에 두 값을 추가한다. 다른 필수값들이 이미 그 방식으로 공급되고 있어 일관적이다. `.env.example` 의 문장도 그대로 참이 된다.
2. `.env.example` 문장을 정정하고, 테스트 실행 시 두 값이 필요하다는 사실을 명시한다.

1번이 기존 방식과 일관되지만, 테스트 리소스에 들어가는 값이 커밋된다는 점(테스트 전용 더미 값이라도)에 대한 판단이 필요하다.
