## 설명

WebGL 배포가 공개 URL 검증에서 403 으로 끊긴다. 지금까지 Cloudflare 차단으로 봤는데, 응답 본문을 남기고 보니 아니었다.

근거 (build #12):
- 본문 제목이 "403 Forbidden" 이다. Cloudflare 차단 페이지가 아니라 웹 서버 기본 오류 페이지다.
- error code 줄이 없다. Cloudflare 가 막았으면 1020 같은 번호가 본문에 들어간다.
- cf-cache-status 가 DYNAMIC 이다. 엣지가 돌려보낸 응답이라는 뜻이다.

원인: 배포 스크립트가 mktemp -d 로 임시 폴더를 만든다. 그 모드가 0700 이다. 그대로 릴리스 자리로 옮기니 웹 서버 계정이 폴더에 들어가지 못해 403 을 돌려준다.

이것이 나머지도 설명한다. 검증이 실패하면 이전 배포본으로 되돌리는데, 그것은 손으로 올린 것이라 모드가 정상이다. 그래서 배포가 끝난 뒤에 열어보면 200 이었고, 출발지 IP 차이로 보였던 것은 실은 시각 차이였다.

조치: 릴리스 자리로 옮기기 전에 모드를 열어 둔다. 이미 깔린 폴더도 다시 돌릴 때 고쳐 둔다.
