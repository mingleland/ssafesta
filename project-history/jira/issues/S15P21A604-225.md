## 설명

### 작업 목적

Jenkins Controller와 빌드 Agent 구성을 코드로 재현해 파트별 Pipeline의 실행 기반을 만든다.

### 작업 내용

- Controller/Agent 컨테이너와 네트워크 구성
- JCasC로 기본 보안·플러그인·노드·Multibranch 설정
- 재기동 후 설정 유지와 Agent 재연결 검증
- Controller에서 Docker 빌드를 직접 수행하지 않도록 역할 분리

### 완료 조건

- 빈 호스트에서 문서 절차로 Controller와 Agent가 기동된다.
- JCasC 재적용이 멱등적이며 재기동 후 잡 설정이 유지된다.
- Pipeline 단계가 지정 Agent에서 실행된다.

### 선행 작업

Jenkins 호스트와 Docker 실행 권한

### 참고

- `specs/infra-001-ci-cd-pipelines`

### 테스트 방법

초기 설치→재기동→JCasC 재적용→샘플 Pipeline 실행 순으로 검증한다.
