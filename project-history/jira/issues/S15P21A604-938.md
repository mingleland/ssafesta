## 설명

GitLab front-test가 같은 SHA 재시도에서도 5000ms timeout과 DOM 탐색 실패를 반복한다.

관측
- job 585301: 11개 테스트 실패, Vitest 569.04초
- retry job 585384: 8개 테스트 실패, Vitest 561.84초
- 로컬 CI 대상 164 files / 1201 tests는 병렬·직렬 모두 통과

범위
1. CI에서만 Vitest testTimeout을 15초로 조정한다.
2. Router·Overlay의 Testing Library 명시적 5000ms 대기를 CI 환경과 정합시킨다.
3. CSS class/DOM 구조에만 결합된 brittle assertion을 사용자 관찰 behavior assertion으로 전환한다.
4. 테스트, build, GitLab pipeline을 확인한다.

제외
- Unity/Auth/STOMP/Wallet 등 계약 테스트 삭제 금지
- Game Studio 테스트 정책 변경 금지
- shard 및 runner 인프라 변경 금지.
