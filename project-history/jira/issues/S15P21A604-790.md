## 설명

월드 채팅 P0.

증상 1 — sendRealtime 은 미연결이면 throw 하는데 sendWorldChat 이 맨몸으로 부르고 WorldPage keydown 핸들러에도 try/catch 가 없다. 재연결 중이거나 5회 실패로 멈춘 상태에서 Enter 를 누르면 예외가 window 로 올라가고 화면에는 아무 표시도 남지 않는다.

증상 2 — 채팅 UI 가 realtime 연결 상태를 읽지 못한다. getRealtimeLastClose 는 과거 진단값이라 현재 상태를 반응형으로 표현할 수 없다.

완료조건: 전송 실패가 화면에 드러난다 / 입력값 보존 / 자동 재전송 없음 / CONNECTED·RECONNECTING·DISCONNECTED 반응형 상태 / 연결 불가 시 전송 비활성 / 공용 transport·allowlist 구조 보존
