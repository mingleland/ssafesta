## 설명

## 배경

FE(S15P21A604-910)가 AI 채팅의 '사람 상담 요청' 버튼을, 부스가 사람 상담 연결을 꺼 둔 경우(handoffEnabled=false) 사전 차단하려 한다. 그런데 handoffEnabled 는 현재 소유자 전용 GET /booths/{id}/agents (BOOTH_EDITOR_FORBIDDEN) 에만 있어 방문자 FE 가 값을 받을 통로가 없다.

FE 는 채팅 오버레이 마운트 시 이미 getBooth(boothId) 를 호출하므로, 방문자 공개 뷰 응답에 boolean 한 개만 추가하면 추가 왕복도 Unity/AI 파트 변경도 없다.

GitLab 이슈: https://lab.ssafy.com/s15-webmobile1-sub1/S15P21A604/-/issues/249

## 작업 내용

GET /api/v1/booths/{boothId} 응답(BoothQueryService.PublicBoothView)에 handoffEnabled: boolean 추가.

- 값 출처: ai_agents.handoff_enabled (부스당 에이전트 1개, AiAgentRepository.findByBoothId)
- AI 직원 미등록 부스: false
- 미공개(published=false) 부스: 게이트 없이 실제 값 그대로 (방문자는 진입 자체가 불가하므로 실동작 차이 없음)
- AiAgent.status 는 보지 않는다 — 소유자용 AgentView 와 동일한 값을 준다
- FE 계약 타입(festa-frontend/src/entities/booth/types.ts BoothDetail)에 handoffEnabled?: boolean 추가

## 완료 조건

- 에이전트 미등록 부스 조회 시 handoffEnabled=false
- handoffEnabled=true 로 등록된 부스 조회 시 true
- BoothApiIntegrationTest 에 위 두 케이스 통합테스트 추가
