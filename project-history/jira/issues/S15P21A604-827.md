## 설명

월드 위 입력이 레이어와 무관하게 동작하던 것을 정리한다.

- Enter 판정자에 화면 소유권을 넣는다. 오버레이·관리·메뉴가 떠 있으면 Enter 는 그 화면의 것이고 채팅을 열지 않는다. ignore 는 preventDefault 를 하지 않아 폼 제출 같은 기본 동작이 그대로 산다
- 브라우저 우클릭 메뉴를 앱 전역에서 막는다. 메뉴가 뜨면 키 입력이 페이지에 닿지 않고 ESC 가 그 메뉴를 닫는 데 먹힌다. Unity 의 오른쪽 버튼 입력은 contextmenu 와 경로가 달라 그대로 산다
- 타이밍 스톱: 결과·오류 화면에서 Space 로 즉시 재시작. 세션 발급 중 별도 화면이 번쩍이던 것 제거. 단계별로 다르던 본문 높이를 --ov-state-min-h 로 통일. 버튼 안 키캡 세로 정렬과 힌트 문장 정리
