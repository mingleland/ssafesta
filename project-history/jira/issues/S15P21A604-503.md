## 설명

작업 목적

docs/08 §17A 의 Game Studio 발행 계열 중 유일하게 구현되지 않은 endpoint 다. 편집·발행·실행·Asset·포털 중 포털(S15P21A604-158)과 이 version 목록만 남아 있다.

작업 내용

- 소유자 전용 조회. 게시 이력을 version 번호·게시 시각·상태로 내려준다.
- 캐시 정책은 docs/08 §17A 를 따른다. 현재 공개 포인터인 GET /games/{gameId}/published 는 no-cache + ETag 재검증이고, 긴 max-age·immutable 은 version 고정 URL 에만 붙인다.

완료 조건

- 타 사용자의 게임 version 조회가 거부된다.
- 목록이 게시 순서대로 나온다.
- 응답 캐시 헤더가 docs/08 §17A 규칙과 일치한다.

선행 작업 / Dependency

- 없음. POST /games/{gameId}/publish 는 이미 구현돼 있다 (GameController).

참고

- docs/08_Backend_API_명세서.md §17A (1144행, 1171행)
- backend/src/main/java/com/example/ssafesta/game/GameController.java
