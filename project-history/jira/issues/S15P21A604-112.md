## 설명

작업 목적

편집 결과를 revision 충돌 감지와 함께 저장하고 사용자의 로컬 변경을 잃지 않게 한다.

작업 내용

- Draft 조회와 expectedRevision 조건부 저장
- revision 불일치 시 currentRevision과 승인된 오류 봉투 반환
- 서버는 손상 문서를 자동 수정하지 않고 검증 결과를 위치별로 반환

완료 조건

[x] 두 세션 동시 저장에서 하나만 성공하고 다른 쪽은 명확한 충돌 응답을 받는다.

[x] Draft 부재 응답은 S15P21A604-217에서 승인한 404/204 규칙을 따른다.

[x] 비Owner 접근·검증 실패·revision 충돌이 서로 구분된다.

[ ] FE 복구 journal로 재시도해도 로컬 변경이 유실되지 않는다.

선행 작업 / Dependency

BLOCKED BY: S15P21A604-111·178·217

테스트 방법

동시 저장, stale revision, 비Owner, 손상 fixture, 재시도 시나리오를 검증한다.
