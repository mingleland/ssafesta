## 설명

사용자 지시 2026-09-10 저녁.

1) 위치 이전
- 현재: 축제장 @AdminGameBooth (-905,0,80), MinigameInteractable + Visual_ArcadeCabinet_02 (16 x 35 x 13 u).
- 이동: 11층 ssafy-11th-room 의 흰 카운터 counter-plain (bounds x -167~-158, z -314~-294, 높이 15u) 자리. counter-plain 은 비활성화(벤더 FBX 원본은 수정하지 않음), 그 자리에 기계를 두고 방 안쪽(+x)을 보게 한다.

2) 게임 화면 FE 이관
- 지금은 Unity 안의 TimerStopGameHud 가 10초 세기·정지·결과를 그린다. 이것을 FE 오버레이로 넘기고 Unity 는 F 상호작용만 한다.
- Unity: F -> InteractionFocusCamera 초점 + 새 브리지 이벤트 WORLD_MINIGAME_INTERACT { type, gameId: TIMER_STOP, machineId } 송신 (ArcadeMachineInteractable 과 같은 형태, 호스트 3초 무응답 시 초점 해제 + 토스트).
- FE: 오버레이에서 게임 진행, BE 미니게임 API(MR !570: POST /minigames/timer-stop/sessions, .../result) 직접 호출, 열 때 SetInputLocked('1') 닫을 때 SetInputLocked('0') (#132).
- Unity 의 TimerStopGameHud/TimerStopGame/HttpGameResultClient/IGameResultClient 는 FE 수신부가 develop 에 들어오면 제거. 그 전까지는 F 에 '곧 열립니다' 토스트만.
- GitLab 에 FE 통보 이슈 별도 등록(계약 제안).

확정 필요: Unity HUD 를 지금 바로 제거할지(FE 붙기 전까지 이 게임은 잠시 비활성), FE 수신부가 develop 에 들어올 때까지 남길지.

완료 기준: 11층 카운터 자리에 기계, F 로 이벤트 송신 로그 확인, 축제장에는 없음. 씬 저장·develop 병합·작업일지.
