## 설명

배경

- 관리자는 슬롯마다 부스를 하나씩 들 수 있다 (S15P21A604-905). 그런데 관리자 부스를 한 곳에서 보는 화면이 없다. FE 관리자 콘솔의 부스 목록은 GET /booth-slots 응답을 걸러 만든 것이라 관리자 부스와 회원 부스를 구분하지 못하고, 공개 여부와 설치자도 알 수 없다.
- S15P21A604-932 로 GET /booths/mine 이 관리자에게 "가장 최근 부스 하나"를 주도록 고쳤지만, 그것은 관리창이 부스 하나를 전제하기 때문에 가능한 임시 형태다. 여러 자리를 운영하는 관리자에게는 목록이 필요하다.

범위

- GET /api/v1/admin/booths 를 신설한다. admin_owned=true 인 부스 전체를 돌려준다 — 특정 관리자가 임대한 것만이 아니다. 관리자 부스는 사람이 아니라 권한을 따라가므로(FR-023) 어느 관리자든 전부 본다.
- 응답 한 행: boothId, slotId, slotCode, name, published, leaseStartedAt, installedBy(닉네임).
- 권한: AdminGuard.requireAdmin. 회원·게스트는 403.
- 정렬: slotCode 오름차순 — 화면이 자리 순서로 읽힌다.

범위 밖

- 화면은 FE 몫이다 (GitLab 이슈로 요청). 관리창(BoothManagementOverlay)의 "부스 하나" 전제는 이번에 건드리지 않는다.
- 회원 부스 목록, 페이지네이션, 방문 지표는 넣지 않는다.

테스트

- 관리자 200 + 관리자 부스만 나온다(회원 부스 미포함)
- 회원 403
- 공개한 부스의 published=true, 미공개 false
