## 설명

## 작업 목적

WebGL 자동 배포가 성공할 때마다 `/srv/festa/webgl/current.legacy.<timestamp>`가 누적되고 있다. 롤백 가능성을 유지하면서 디스크 누적을 제한하도록 static release 보존 정책과 자동 정리를 구현한다.

## 결정

- 성공 배포 후에만 정리한다.
- `current`는 삭제하지 않는다.
- 최신 `current.legacy.*` 2개는 롤백용으로 보존한다.
- 그보다 오래된 timestamp 형식 legacy 디렉터리만 삭제한다.
- 배포 검증·출처 검사 실패 시에는 정리하지 않는다.
- 정리 대상은 `/srv/festa/webgl` 하위로 한정한다.

## 주요 작업

- 배포 스크립트에 안전한 legacy retention 추가
- 보존·삭제 대상 선별 테스트 추가
- 실패 경로에서 정리가 수행되지 않는지 검증
- 작업일지 및 CI/CD 명세에 보존 정책 반영

## 완료 조건

- 성공 배포 후 최신 legacy 2개만 남는다.
- current 및 최근 롤백본은 삭제되지 않는다.
- 실패한 배포는 legacy 정리를 수행하지 않는다.
- 정리 대상 밖의 경로는 삭제하지 않는다.
