## 작업 목적

Game Studio는 지금까지 Draft/Publish/Asset을 전부 브라우저 로컬(mock/IndexedDB) 기준으로만 QA해 왔다. README(`festa-frontend/src/game-studio/README.md`)에도 "서버 소유 Asset upload/reference resolver", "Draft/Publish/Published 서버 endpoint", "Coin/Reward" 세 가지가 "아직 연결하지 않은 외부 경계"로 명시돼 있다. 배포 전이라도 백엔드는 이미 존재하고(`GameController`, `GameAssetController` 확인됨) `VITE_GAME_STUDIO_API_ENABLED=true`로 서버 어댑터를 켤 수 있으므로, 이 경계를 실제로 연동해 검증한다. 이 티켓은 하위 티켓들을 묶는 상위 티켓이며 이 자체로 구현하지 않는다.
