## 설명

h3. 배경 (GitLab #132, FE 요청)
Overlay 가 열려 있는 동안 WASD·F 가 월드로 계속 들어가고, Unity WebGL 기본값 {{WebGLInput.captureAllKeyboardInput = true}} 는 canvas 밖 입력까지 Unity 가 먹어 React 입력 필드(설문 주관식·상담 메시지)가 죽는다. 저장소에 설정 0건. 09-08 사용자 테스트의 설문·상담 시나리오가 걸린다.

h3. 할 일
# ① WebGL 일 때 {{WebGLInput.captureAllKeyboardInput = false}} (canvas 가 focus 를 가질 때만 키 입력 — canvas 는 tabIndex=-1 로 focus 가능, -421)
# ② {{InputBridge}} MonoBehaviour(DontDestroyOnLoad, 오브젝트 이름 "InputBridge"): {{SetInputLocked(string "1"|"0")}} → 정적 {{InputBridge.IsLocked}}. PlayerMovement·BoothInteractionInput·PlayerEmoteController 가 잠김 중 입력을 버린다. FE 호출: {{SendMessage('InputBridge','SetInputLocked','1')}}
# ③ cursor/pointer: Unity 는 pointer lock 을 쓰지 않는다(3인칭 고정 카메라) — 경계 없음을 명시

h3. 검증
실 WebGL 임베드에서 Overlay 열고 WASD → 월드 정지, 닫으면 다시 움직임, 오버레이 입력창에 한글 입력.
