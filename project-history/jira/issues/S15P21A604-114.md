## 설명

작업 목적

Unity Booth의 GAME_PORTAL 상호작용을 선택적 웹 게임 오버레이 진입점으로 연결한다.

제품 경계

Unity는 2D 게임을 실행하지 않는다. configId를 전달하고 오버레이 개폐·입력 상태만 주고받는다. 직접 웹 플레이는 이 작업 없이 가능해야 한다.

현재 상태

OverlayHost 자동 연결은 GitLab MR !8에서 의도적으로 제외됐다.

작업 내용

- configId → Published game resolver adapter

- feature flag 아래 OverlayHost 등록

- unavailableReason별 사용자 안내와 닫기 복구

완료 조건

[ ] Host 비활성 시 기존 Booth/앱에 변화가 없다.

[ ] 유효 포털은 Published 게임 오버레이를 연다.

[ ] 미공개·삭제·설정 오류를 게임 오류와 구분해 안내한다.

[ ] 오버레이 종료 후 Unity 입력이 복원된다.

선행 작업 / Dependency

BLOCKED BY: S15P21A604-158·204·217, GitLab #56·#104의 Host 계약 승인

후속

S15P21A604-181·186

테스트 방법

mock bridge와 실제 WebGL에서 정상·미공개·잘못된 configId·닫기 시나리오를 검증한다.
