## 설명

### 작업 목적

specs/007-ai-agent-document/plan.md가 서술하는 AI 문서 처리 Job 소유 모델(AI DB Job 테이블·SKIP LOCKED·FastAPI 내부 sweeper)이 실제 develop 구현과 어긋나 있다. 실제로는 Spring이 Job/lease/sweeper를 전부 소유하고(S15P21A604-449), FastAPI는 DocumentTaskSupervisor로 attempt를 한 번만 실행하며 heartbeat·chunk-batch·finalize/failed 콜백만 Spring에 전달한다. 문서를 실제 구현 기준으로 갱신해 향후 설계 참고·온보딩 혼선을 막는다.

### 작업 내용

- plan.md의 Job/lease/sweeper 소유 서술과 Test Strategy 중 AI DB SKIP LOCKED 관련 항목을 실제 구현 기준으로 재작성
- data-model.md의 AI DB Job 테이블 설계가 실제로 존재하는지 확인하고, 없다면 제거하거나 "미구현/폐기"로 명시
- tasks.md T033 등 AI DB Job repository 관련 task의 실제 상태(구현 여부·대체 경로) 재확인해 반영
- spec.md의 FR/SC 문구가 Spring 소유 모델 기준으로도 여전히 유효한지 확인

### 완료 조건

- [ ] plan.md/tasks.md/data-model.md가 실제 develop 코드(Spring 소유 Job/lease/sweeper, FastAPI DocumentTaskSupervisor)와 일치
