## 설명

GitLab #181 후속 중 FE 단독 가능분. BE footprint 숫자 확정(S15P21A604-698)과 분리해 이 티켓만으로 완료된다.

문제
- clampToBooth 가 중심점만 클램프해 오브젝트 크기와 회전을 보지 않는다
- 드래그로 놓을 수 있는 자리가 isAreaOutOfBounds 검증에서는 위반으로 걸린다

범위
- entities/layout/geometry.ts 의 rotateAABB 를 재사용한다. 회전 계산을 복제하지 않는다
- clampAreaToBooth(x, z, local, rotationY, bounds) 신설 — 중심 허용 범위를 회전 AABB 의 min/max 로 각 축 따로 만든다 (로컬 AABB 는 비대칭이다: PROJECT_PANEL min.x -0.78 / max.x 0.77)
- 회전 AABB 가 부스보다 크면 그 축을 0 으로 고정한다. 판정 권위는 계속 isAreaOutOfBounds 다
- clampToBooth 참조 전수 교체: PropertiesPanel / R3FBoothRenderer / TemporaryIsoRenderer / coords.test
- 로컬 AABB 를 모르는 타입은 기존 중심 클램프로 떨어뜨린다

범위 밖
- footprint 숫자 변경 (서버 카탈로그에서 오므로 BE 확정 후 fallback·mock 만 갱신)

팀 공유 정본: GitLab #181
