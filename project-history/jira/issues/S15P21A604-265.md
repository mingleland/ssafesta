## 설명

## 목적

프로젝트 EC2 지급 지연에 대응해 OCI 무료 ARM64 인스턴스에 임시 배포 환경을 구축한다.

EC2 확보 전에 Docker 기반 서비스 배포, 공개 진입점, 데이터 저장소 및 Unity 배포 가능성을 검증하여 이후 EC2 이관 시 인프라 문제와 애플리케이션 문제를 분리한다.

## 범위

- OCI 네트워크·방화벽과 VS Code Remote Tunnel 관리 경로
- Docker/Compose 실행 환경
- PostgreSQL(pgvector), Redis
- Nginx 공개 진입점
- React·Unity WebGL 정적 배포 준비
- Unity ARM64 Dedicated Server 가능성 검증
- EC2 확보 후 소스 기반 재빌드·이관
- OCI 임시 환경 정리

## 완료 조건

- OCI에서 공통 인프라와 Nginx 외부 접속 확인
- 구축 및 트러블슈팅 기록 완료
- Unity ARM64 지원 여부와 임시 검증 범위 확정
- EC2 이관 절차와 OCI 철거 기준 확정

## 운영 원칙

- 실제 Secret과 토큰은 저장소·이슈·로그에 남기지 않는다.
- PostgreSQL/Redis/Unity 7777 등 내부 포트는 공개 진입점 뒤에 둔다.
- OCI ARM에서 만든 이미지를 EC2 x86에 복사하지 않고 소스에서 재빌드한다.
- 최종 HTTPS/WSS 검증과 현재 IP 기반 HTTP/WS 임시 검증을 구분한다.
