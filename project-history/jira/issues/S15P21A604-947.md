## 설명

데모 WebGL에서 120Hz 환경이 vSync4에 고착되어 전 구역 p50 41~42ms(약 24fps), p95 50~58ms로 관측된다. 원격 플레이어 이동이 심하게 끊겨 보이며 위치와 무관하게 재현된다.

범위:
- DisplayRefreshAdapter의 vSync4 고착 및 상향 복구 조건 수정
- 120Hz 환경에서 vSync3 이하로 유지하는 긴급 안정화
- 런타임 생성 Mesh/Material/Texture/RenderTexture와 이벤트·코루틴·정적 캐시 누수 전수 점검
- 안전하게 확인된 누수 수정 및 프레임 비용 최적화
- Unity 컴파일·콘솔 오류 확인과 배포 WebGL 프레임 로그 검증

실측:
- 현재 데모 sourceCommit a8f898e8, clean develop release
- vSync3 p50 24ms 후 vSync4 전환
- vSync4에서 여러 좌표 모두 p50 41~42ms
- Front DOM 45개, 지속 애니메이션 없음, DPR 1, 캔버스 약 1MP
- World RTT 약 50ms, disconnect 없음
