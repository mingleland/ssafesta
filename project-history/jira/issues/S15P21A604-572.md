## 설명

배경: S15P21A604-496(Lease 만료 시 Job CANCELLED 전이) 구현 중 Backend가 발견. FastAPI 쪽에 실행 중인 문서 처리 attempt를 취소할 API가 없어 spec 007 FR-041을 만족 못 함. GitLab work item #162에서 계약 신설 요청, 검토 후 승인 완료.

범위:
- specs/007-ai-agent-document/contracts/document-processing-api.yaml 개정: POST /documents/cancel 추가 (jobId+attemptNo body, 204 응답, 멱등)
- festa-ai/app/api/v1/documents.py: cancel_document_processing 핸들러 추가
- festa-ai/app/workers/document_task_supervisor.py: cancel(key) 메서드 추가 (기존 _tasks dict 재사용), voluntary cancel과 shutdown cancel의 로그 레벨 분리
- 유닛 테스트: supervisor.cancel() 4케이스(실행 중+일치/불일치, job 없음, 이미 완료) + 엔드포인트 인증·멱등 테스트

참고: GitLab #162 (https://lab.ssafy.com/s15-metaverse-game-sub1/S15P21A604/-/work_items/162), S15P21A604-496, spec 007 FR-041
