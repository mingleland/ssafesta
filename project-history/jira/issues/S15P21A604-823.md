## 설명

AI 직원과의 채팅 UI 개선 4건:
1. 채팅 입력창 포커스 중 Enter 키를 채팅창이 독점하도록 수정 (다른 요소가 가로채지 않게)
2. AI 답변에서 출처 문서 표시 제거
3. 프로젝트/부스와 무관한 잡담(점심 뭐 먹지, 우울해 등) 질문은 문서에 없는 내용이므로 답변 회피
4. 답변 렌더링을 마크다운 스타일로 변경 (가독성 개선)
