## 설명

월드에서 일일 미션 패널로 바로 가는 좌상단 HUD 버튼을 추가한다.

배경: 미션 패널(DailyMissionOverlay)·조회/수령 API·ESC 메뉴 진입점은 S15P21A604-859에서 이미 완성됨. 현재는 ESC 메뉴 안에서만 열림. 월드 상시 진입점이 없어 발견성이 낮다.

작업:
- DailyMissionLauncher 컴포넌트 신설 (AdminConsoleLink 패턴 복제, openMenuPanelScreen('missions') 호출)
- WorldHud 좌상단에 배치 (기존 우상단 상담·전체화면과 대칭)
- 아이콘: checklist 메모장형
- 뱃지: 지금 보상을 받을 수 있는(CLAIMABLE) 미션 수. 0이면 숨김
- 비회원 노출 정책 확인
- canvas focus 보존(mousedown preventDefault) 회귀 검증

정책 확인 필요: WorldHud 주석/hud-decisions.md가 mission panel launcher를 금지 목록에 둔다. AdminConsoleLink·WorldGuideLauncher 선례로 완화 가능하다고 보나, 팀 확인 후 진행.

계약: 새 API 없음. 미션 조회 응답의 status 집계만 사용.
