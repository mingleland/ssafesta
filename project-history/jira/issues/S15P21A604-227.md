### 작업 목적

영구 데이터와 캐시가 dev/demo 사이에서 섞이지 않도록 저장소·계정·네트워크를 분리한다.

### 작업 내용

- 환경별 PostgreSQL DB/role/volume과 최소 권한
- 환경별 Redis namespace 또는 instance/volume
- 내부 네트워크 접근만 허용
- migration·초기화·flush가 다른 환경에 미치는 영향 검증
