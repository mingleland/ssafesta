## 설명

LaptopOverlay의 generic iframe 구조를 유지한 채 sandbox를 8토큰으로 넓히고(allow-popups-to-escape-sandbox·downloads·modals·storage-access 추가, top-navigation 계열 제외) Permissions Policy 위임(autoplay·clipboard-write·fullscreen·encrypted-media·picture-in-picture)을 신설한다. 팝업이 부모 sandbox를 상속해 깨지던 OAuth/SSO 흐름을 개선하는 것이 완료 조건이다. 함께 http 주소와 자기 오리진 주소를 iframe에 넣지 않고 새 탭 전용 안내로 분기한다(external_only). 외부 서비스 정책·third-party storage·IdP 정책으로 실패하는 경우와 X-Frame-Options/CSP 명시 차단은 해결 대상이 아니다. GitLab 후속 없음 — FE 단독.
