## 설명

front 파트 전용 세션 운영 스킬 3종(festa-boot / festa-inbox / festa-handoff)은 user scope(~/.claude/skills/)에만 존재해 사본이 원본 1벌뿐이었다. ~/.claude는 git 저장소가 아니고 ~/.claude/backups/에는 transcripts만 있어, 소실 시 복구 수단이 없는 상태가 2026-09-01까지 유지됐다.

조치: docs/LJH/skills/ 에 파일 사본을 두고, docs/LJH/26_로컬_규약_스냅샷.md 에 C-6절(백업 경로·복원 명령·드리프트 점검·유지 원칙)을 추가한다.

판정 근거:
- .claude/skills/(project scope)에 넣지 않는다 — 팀 전체 자동 로드 자리라 개인 절차 부적합. 2026-08-25 판단을 유지한다.
- docs/LJH/ 보관은 C-5와 충돌하지 않는다. C-5의 '팀 저장소 밖'은 .git/info/exclude 패턴 목록 한정이고, 26 문서는 이미 본문에 개인 도구 이름을 언급하고 있다.
- A·B절의 코드블록 방식이 아니라 파일 사본 방식을 쓴다. 드리프트를 diff -r 가 기계적으로 잡고, 3종 합계 약 19KB라 본문에 넣으면 문서가 배로 부푼다.

검증: 사본만으로 복원을 시뮬레이션해 diff -r 3종 전부 원본과 일치함을 확인했다.

범위 밖: 나머지 7개 스킬(pinlog-pr / pinlog-status / asc / asc-inbox / asc-review / orca-cli / design-taste-frontend)은 이 저장소와 무관해 사본이 없다. 각 프로젝트 저장소 또는 개인 설정 저장소가 담당할 몫이며, 개인 설정 저장소는 이 머신에 없다.
