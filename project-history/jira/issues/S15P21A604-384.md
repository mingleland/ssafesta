## 설명

# 작업 목적

- Game Studio 에디터 UI가 다크 테마 전용으로 고정돼 있어 어둡고 칙칙하다는 QA 피드백(Notion id 4)을 반영해, 에디터 화면을 라이트 테마로 전환한다.



# 작업 내용

- `GameStudioShell.css`의 하드코딩된 색상 값(240개 이상)을 라이트 톤으로 전환
- 기존 `--gss-*` 루트 토큰(13개)을 실제 전체 규칙에 일관되게 적용하는 토큰화 리팩터링 병행 — 지금은 토큰이 있어도 다수 규칙이 개별 hex를 직접 씀
- 게임 실행/미리보기 화면(`ReferenceGamePlayer.css`, `GameOverlay.css`)은 이번 범위에서 제외(다크 유지) — 게임 자체를 그리는 런타임이라 에디터 크롬과 무관



# 완료 조건

- `GameStudioShell.css`의 에디터 UI 크롬이 다크 → 라이트 테마로 전환된다
- 게임 실행/미리보기 화면은 이번 변경의 영향을 받지 않는다
- 주요 텍스트/아이콘의 대비가 라이트 배경에서도 충분히 읽힌다
- 색상 값이 가능한 한 `--gss-*` 토큰을 통해 관리된다



# 선행 작업 / Dependency

- 없음



# 테스트 방법

1. 에디터 전체 화면(사이드바·패널·버튼·모달 등)을 순회하며 다크 잔여 요소가 없는지 확인
2. 라이트 배경 위에서 텍스트/아이콘 대비가 읽기 충분한지 확인(특히 상태·경고 색상)
3. 게임 미리보기(PLAY TEST) 화면이 기존 그대로(다크) 렌더링되는지 확인
4. 반응형 브레이크포인트에서도 라이트 톤이 깨지지 않는지 확인
