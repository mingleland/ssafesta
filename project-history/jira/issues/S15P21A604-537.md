## 설명

## 작업 목적

- 플레이 화면 오브젝트가 씬 격자 크기와 무관한 고정 픽셀(34px)로 그려져,  
   에디터 캔버스(격자 칸에 비례, 88% 채움)와 시각적 크기 비율이 어긋나는  
   문제를 해결한다(S15P21A604-535와 같은 맥락).

## 작업 내용

- `ReferenceGamePlayer.css`
   
   - `.grp-object`의 고정 `height: 34px; width: 34px;`를  
      `height: calc(100% / var(--grp-rows)); width: calc(100% / var(--grp-columns));`로  
      변경한다(에디터의 `.gss-map-object`와 동일한 공식).
   - `.grp-object img`/`.grp-static-sprite`의 고정 `31px`을 `88%`로 변경한다  
      (에디터의 이미지 채움 비율과 동일).
   - 이모지 폴백 아이콘(`.grp-object > span`, `font-size: 17px`)은 고정값 그대로  
      유지한다.
   - `.grp-map`에는 이미 `--grp-columns`/`--grp-rows` CSS 변수가 씬 크기 그대로  
      설정돼 있어(타일 레이어가 이미 이 변수로 그려짐), 별도 JS/TS 변경 없이  
      CSS만으로 가능하다.
   - 플레이어(`.grp-player`), 적(`.grp-dynamic-enemy`), 투사체(`.grp-projectile`)는  
      이번 범위에서 제외한다.

## 완료 조건

- [ ] 플레이 화면 오브젝트 박스 크기가 씬 격자 칸 크기에 비례해서 커지고 작아진다
- [ ] 오브젝트 안 이미지가 칸의 88%를 채운다(에디터와 동일 비율)
- [ ] 이모지 폴백 아이콘의 글자 크기는 기존 고정값 그대로 유지된다
- [ ] 플레이어/적/투사체는 이번 변경의 영향을 받지 않는다(회귀 없음)
