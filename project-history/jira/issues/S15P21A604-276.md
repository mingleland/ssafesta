## 설명

**작업 목적**  
제작자가 기본 이미지를 자기 이미지로 교체할 때, 로컬 미리보기부터 서버 업로드 완료까지의 과정을 눈으로 보고, 실패하면 스스로 복구할 수 있게 한다.

**작업 내용**

- 이미지 교체 시 로컬 Preview 표시 + 업로드 진행/승격 상태 UI
- 업로드 성공 시 `asset://local`을 서버 발급 stable `asset://`로 명시적 교체
- 실패·재시도·삭제·"사용 중인 Asset" 경고 UI

**완료 조건**

- 사용자 이미지 교체 → 업로드 → Draft 저장 → Publish → 다른 브라우저 Published 플레이 E2E 통과
- 5MiB·허용 형식(png/jpeg/gif/webp)·권한 오류가 사용자 행동과 함께 안내된다
- retry가 중복 Asset을 만들지 않는다
- 미승격(`asset://local`) 이미지가 남아있으면 Draft 저장 시점에 걸러진다

**선행 작업 / Dependency**  
`BLOCKED BY: S15P21A604-107(BE 업로드 API), S15P21A604-116(FE GameAssetRepository 원격 어댑터), GitLab #69`

**참고**  
GitLab #69 Frontend 범위 ①~③ (④ 미승격 탐지는 S15P21A604-156/MR !8에서 이미 완료)

**테스트 방법**  
업로드→저장→새 세션→Publish→익명 플레이 왕복, 5MiB 초과/비허용 형식/네트워크 실패 재시도 시나리오 각각 검증
