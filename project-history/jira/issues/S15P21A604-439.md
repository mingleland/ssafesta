## 설명

h3. 요구(사용자 2026-09-06 01:15)

* Festival_Arcade 의 slot machine 2기에 F 상호작용을 붙인다.
* 상호작용하면 camera 가 slot machine 에 zoom-in 되고, 그 동안 플레이어 조작은 불가(InputBridge 잠금). Esc 로 나가면 camera·조작 복구.
* 10코인을 넣으면 돌고, 코인이 모자라면 팝업.
* 결과에 따라 최대 50코인 보상 — 실제 slot machine 수준의 확률(RTP ≈ 90%).

h3. 설계

* {{InteractionFocusCamera}}: 상호작용 대상 앞에 camera 를 붙이고 PlayerCameraFollow 를 잠시 비활성화. Esc 또는 외부 잠금 해제로 복구. (게임기 포털 이슈와 공유)
* {{SlotMachineInteractable}} + HUD: 잔액·베팅·결과. 릴(reel) 연출은 vendor {{PresetUVSlotMachine.SpinPresetByIndex}} 공개 API 만 사용(벤더 수정 금지).
* 결과는 Unity 가 정하지 않는다({{ISlotMachineClient.SpinAsync}} → 서버 판정, spec 014 원칙). BE 엔드포인트가 아직 없어 Mock 결과 클라이언트로 동작하며 HUD 에 "체험판 · 코인 미반영" 을 붙인다. 잔액은 회원이면 GET /api/v1/wallets/me, 게스트는 코인 없음 팝업.
* BE 계약 제안은 docs/26 에: POST /api/v1/minigames/slot-machines/{machineId}/spins {bet} → {payout, balanceAfter, outcome}, 원장 reason SLOT_BET/SLOT_PAYOUT.

h3. 완료 조건

에디터: F → zoom-in·잠금 → 베팅 → 릴 회전 → 결과·잔액 갱신 → Esc 복구. 잔액 0 에서 팝업. 월드 접속·이동에 영향 없음.
