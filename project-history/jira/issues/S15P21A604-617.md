## 설명

h3. 작업 목적

Booth Studio 외관·템플릿 모드가 *저장되지 않는 값*을 편집 가능한 것처럼 보여 준다. 사용자가 직접 플레이하며 보고한 항목(2026-09-10 감사 07)이고, 감사 08(S15P21A604-616)에서 인스펙터 쪽을 먼저 걷어냈다. 남은 것이 이 작업이다.

|| 자리 || 지금 || 실제 계약 ||
| 외관 모드 좌측 팔레트 | 벽면·바닥·그래픽 스와치 9개. 전부 {{provisional: true}} · 상시 {{disabled}} · 클릭 핸들러 없음 | {{PUT /booths/'{'id'}'/facade}} 의 4필드({{themeCode}}·{{primaryColor}}·{{signText}}·{{logoUrl}})뿐이고, 그건 오른쪽 FacadePanel 이 이미 저장한다 |
| 템플릿 인스펙터 | "포인트" 색칩({{accentHex}}) — "목업" 배지 | 저장되지 않고, 캔버스 미리보기에도 쓰이지 않는다. 표시 외 쓰임이 0 이다 |

h3. 왜 지금 할 수 있는가 — !496 결론을 기다리지 않아도 된다

MR !496 (S15P21A604-552, Draft) 이 facade 표현 방식을 조사 중이고 아직 develop 에 없다. 그 결론을 확정으로 인용하지 않는다.

인용할 필요도 없다 — *어느 결론이 오든 지금의 색 스와치 9개는 남지 않는다.* 3D 로 가든 렌더 이미지로 가든, 사용자가 고르는 것은 부스 외관 자산이지 벽면 색 이름이 아니다. 지금 스와치는 계약 밖 값을 계약 안 값처럼 보이게 하는 순수 손실이므로, 표현 방식 결정과 독립적으로 걷어낸다.

h3. 작업 내용

# {{visualAssets.ts}} 의 {{FACADE_PALETTE_SECTIONS}} 와 {{FacadeSwatch}} 제거.
# 외관 모드 좌측 팔레트는 빈 패널로 두지 않는다 — 외관 값을 어디서 저장하는지 한 줄로 안내한다.
# {{TemplateInspector}} 의 "포인트"({{accentHex}}) 행 제거. {{TemplatePreset.accentHex}} 필드도 함께 정리한다.
# {{floorHex}} 는 *남긴다* — 저장되지는 않지만 캔버스 {{decor}} 에 실제로 들어가는 미리보기 입력이다. 배지 문구를 "저장 안 됨"이 아니라 미리보기 전용임이 드러나게 고친다.

h3. 범위 밖

* *Shell 배경* ({{landing-background.png}}) — Persistent GameShell 도달 시 Unity World 로 교체된다. 감사 11 과 같은 작업이다.
* *캔버스의 파라메트릭 박스* — manifest 부재가 정상 상태다. 목업이 아니다.
* *facade 4필드의 런타임 의미* — Game 파트 확인 사항이고 코드 작업이 아니다.
* *구조 모드 잠긴 자산 3종* — 보유하면 열리는 항목이다(S15P21A604-616 코멘트).

h3. 완료 조건

# 외관 모드에 상시 {{disabled}} 컨트롤이 0 개다.
# 템플릿 인스펙터에 표시 외 쓰임이 없는 목업 값이 없다.
# 캔버스 미리보기(바닥색·대표색)는 그대로 동작한다 — 프리셋을 고르면 캔버스가 바뀐다.
