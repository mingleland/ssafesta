## 설명

### 증상

`RequireAuth` 가 그리는 공통 헤더가 회원 세션에서 `회원로 이용 중` 으로 나온다. `회원으로` 가 맞다.

게스트는 `게스트로 이용 중` 으로 정상이다 — `게스트` 가 모음(ㅡ)으로 끝나 `로` 가 맞고, `회원` 은 받침(ㄴ)이 있어 `으로` 가 필요하다.

### 원인

`festa-frontend/src/app/router/RequireAuth.tsx` 의 `AuthHeader` 가 명사만 분기하고 조사를 고정으로 붙인다.

```tsx
<span>{kind === 'member' ? '회원' : '게스트'}로 이용 중</span>
```

### 처리 방향

조사를 포함해 분기한다. 한국어 조사 처리 유틸을 새로 만들 만큼의 대상이 아니다 — 값이 두 개뿐이고 둘 다 고정 문자열이다.

### 완료 조건

- [ ] 회원 세션에서 `회원으로 이용 중`
- [ ] 게스트 세션에서 `게스트로 이용 중`
- [ ] 양쪽 문구 회귀 테스트

### 참고

`RequireAuth.test.tsx` 주석에 이미 기록돼 있던 결함이다 — *"실제 렌더는 '회원로 이용 중' — 조사 결함, 별건"*. 그때 별건으로 미룬 것을 여기서 처리한다. Auth·UI 리팩터링은 섞지 않는다.
