## 설명

P4. Project / Survey / Consultation / AI 직원 / Studio 다섯이 지금 전부 별도 route 라 관리 오버레이에서 나가면 월드가 화면에서 사라진다.

설계
- 별도 슬롯을 만들지 않는다. shared/types/overlay.ts 가 금지하고 worldScreen.ts 가 배타·입력 잠금·ESC·focus 반환을 한곳에 모아 두었다
- management 안에 상세 레이어 한 겹을 더한다. getWorldScreen 은 계속 management 를 말하고 closeTopScreen 만 상세 -> 관리 -> 월드 순으로 한 겹씩 벗긴다
- payload 는 패널별 판별 유니온. 화면 종류 + boothId 로 고정하지 않는다
- 각 페이지를 본문 컴포넌트 + route 껍데기로 가른다. route 는 지우지 않는다 (deep-link 유지)
- Studio 는 기존 lazy 경계를 유지해 three 가 월드 초기 번들에 들어가지 않게 한다
- Studio 저장 성공 뒤에만 닫고 실패·revision conflict 에서는 유지, 닫을 때 캔버스 focus 복구
- ESC 판정자 맨 앞에 열린 modal dialog 확인을 넣어 내부 dialog 가 ESC 를 먹을 때 상위 레이어가 같이 닫히지 않게 한다

완료조건
- 카드 클릭이 route 이동 없이 패널을 여는 것
- deep-link 가 여전히 PageShell 로 열리는 것
- ESC 가 한 겹씩만 닫는 것 / 열린 dialog 가 있으면 상위 레이어를 닫지 않는 것
- Studio 청크가 월드 진입 번들과 분리돼 있는 것
