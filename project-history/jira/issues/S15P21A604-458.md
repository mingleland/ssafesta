## 설명

Measured 2026-09-06 17:20 on the local integrated stack (FE localhost:5173 guest login, Unity dev build embedded).

Repro: guest enters world -> WORLD_MANAGEMENT_INTERACT reaches FE (fired with the exact Unity payload) -> overlay opens with title '내 부스 관리' and spinner '부스 정보를 불러오는 중...'.

Observed: GET /api/v1/booths/mine returns 403 MEMBER_ONLY ('회원 계정만 부스를 임대할 수 있습니다') and FE retries it forever - request ids kept climbing past 20+ seconds (17 -> 40+ requests, one CORS preflight each). The spinner never resolves and no message is shown. In the user test a guest pressing F at the ticket booth leaves a permanent request storm against Spring and a dead overlay.

Expected: on 403 MEMBER_ONLY show a login prompt ('로그인하면 부스를 빌릴 수 있어요') and stop retrying. Unity already gates guests elsewhere the same way.

Also seen in the same run: overlays stack instead of replacing (BOOTH_LAPTOP_INTERACT overlay stayed open under the management overlay).

Related: runbook note '게스트 데스크 F -> 부스 정보를 불러오지 못했습니다 (로그인 안내여야 함)' (GitLab #128) - the message is now gone entirely. Unity side is unchanged and correct.
