# 작업일지

## 2026-08-18

### 로컬 백엔드 개발 환경 초기화

- Maven 기반 Spring Boot 프로젝트를 생성했다.
- Docker Compose로 PostgreSQL 17과 Redis 7.2를 실행하도록 구성했다.
- 로컬 환경 변수 파일과 Spring `local` 프로필을 연결했다.
- Flyway와 JPA 초기화, Actuator Health Check가 정상 동작하는 것을 확인했다.
- DB 스키마는 SDD 요구사항이 확정되기 전이므로 아직 작성하지 않았다.

### 관련 파일

- `compose.yaml`
- `.env.example`
- `src/main/resources/application-local.yml`
- `src/test/java/com/example/ssafesta/TestcontainersConfiguration.java`
