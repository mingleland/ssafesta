# 작업일지

## AI 에이전트 작성 지침 (Codex · Claude Code 공통)

Codex 또는 Claude Code가 백엔드 작업을 완료하면 이 파일을 즉시 갱신한다.

- 기록은 최신 날짜가 위로 오도록 `## YYYY-MM-DD` 섹션에 작성한다. 날짜 섹션이 없으면 새로 만든다.
- 작업 항목마다 **무엇을 했는지**, **왜 했는지**, **확인 결과**를 짧게 남긴다.
- 변경한 주요 파일과 실행한 검증 명령·결과를 함께 기록한다.
- 백엔드 작업 기록은 루트 `docs/24_작업일지.md`가 아니라 이 파일에만 작성한다.
- 트러블슈팅 기록은 필요해졌을 때만 `backend/docs/트러블슈팅.md`를 별도로 만들어 관리한다. 현재는 이 파일을 만들지 않는다.

## 2026-08-18

### 로컬 백엔드 개발 환경 초기화

- 팀원이 동일한 로컬 개발 환경을 사용하도록 Maven 기반 Spring Boot 프로젝트와 Docker Compose 환경을 구성했다.
- PostgreSQL 17·Redis 7.2, 로컬 환경 변수 파일, Spring `local` 프로필을 연결했다.
- SDD 요구사항이 확정되기 전에는 DB 구조를 임의로 만들지 않기 위해 Flyway·JPA 실행 경계만 설정했다.
- `mvnw.cmd -DskipTests package`, Flyway·JPA 초기화, `/actuator/health`의 `UP` 응답으로 구성을 검증했다.
- 이후 같은 위치와 형식으로 기록하도록 이 파일 상단에 공통 작성 지침을 추가했다.
